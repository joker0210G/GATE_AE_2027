## 📌 Executive Summary & GATE Significance

> [!IMPORTANT]
> The **Pressure Altimeter** is an aneroid barometer connected exclusively to the aircraft's **Static Pressure Port**. It measures ambient static pressure ($p$) surrounding the aircraft and converts it to altitude based on the International Standard Atmosphere (ISA) hydrostatic relation:
> $$\bbox[10px,border:2px solid #2196F3,background-color:#0d1117]{ dp = -\rho g_0 dh } \implies \bbox[12px,border:3px solid #E91E63,background-color:#0d1117]{ h = \frac{T_0}{\lambda} \left[ 1 - \left(\frac{p}{p_{\text{ref}}}\right)^{\frac{\lambda R}{g_0}} \right] }$$

### Why does GATE AE care?
1. **Altimeter Error Numerical Calculations:** GATE AE frequently tests numerical corrections for **non-standard temperatures ($\Delta T_{\text{ISA}}$)** and **barometric pressure setting errors** (QNH vs. QFE vs. QNE).
2. **Pressure Gradient & Rate:** Understanding the pressure drop per unit altitude ($\approx 12 \text{ Pa/m} \approx 1 \text{ hPa} / 30 \text{ ft}$) is vital for flight level and altimeter calibration problems.
3. **Failure Diagnostics:** Determining instrument pointer movements during static port blockages or emergency alternate static port deployment.

## 开启 Core Concept 1: Internal Mechanical Anatomy & Working Principle

```
                        PRESSURE ALTIMETER ANATOMY
                        
       STATIC PORT (Ambient Pressure p)
             |
             v
       +-------------------------------------------------+
       |           ALTIMETER SEALED CASE                 |
       |                                                 |
       |       +---------------------------------+       |
       |       |  EVACUATED ANEROID CAPSULES     |       |
       |       |  Internal Pressure = 0 (Vacuum) |       |
       |       +---------------------------------+       |
       |                        |                        |
       +------------------------|------------------------+
                                v
             Mechanical Multiplier Gear Linkage
                                |
                                v
               3-Pointer Dial & Kollsman Window
```

### 1. Mechanism & Components
- **Static Pressure Case:** Sealed instrument housing connected directly to the static port. Case internal pressure equals ambient static pressure ($p$).
- **Aneroid Capsules (Bellows):** Partially evacuated thin-walled corrugated metallic chambers maintained under internal vacuum.
- **Capsule Expansion / Contraction:**
  - As aircraft **climbs** $\implies$ Ambient pressure $p$ decreases $\implies$ External force on capsules drops $\implies$ **Capsules EXPAND**.
  - As aircraft **descends** $\implies$ Ambient pressure $p$ increases $\implies$ External force on capsules rises $\implies$ **Capsules COMPRESS**.
- **Kollsman Window:** Adjustable barometric scale knob allowing the pilot to set reference sea-level pressure ($p_{\text{ref}}$).

## 🔵 Core Concept 2: Altimeter Settings & Q-Codes

```
                              Q-CODES SUMMARY
                                     |
    +--------------------------------+--------------------------------+
    |                                |                                |
   QFE                              QNH                              QNE
Surface Pressure                Sea-Level Adj.                 Standard 1013.25 hPa
Reads 0 on Runway            Reads Field Elevation             Reads Pressure Alt
(Height AGL)                   (Altitude MSL)                   (Flight Levels)
```

| Q-Code Symbol | Reference Setting | Altimeter Reading on Runway | Aviation Application |
|---|---|---|---|
| **QFE** | Local airfield surface pressure ($p_{\text{field}}$) | **ZERO ($0 \text{ m} / 0 \text{ ft}$)** | Measures Height Above Ground Level (AGL). Used for local aerobatics / circuit training. |
| **QNH** | Local airfield pressure converted to Mean Sea Level using ISA model | **Airfield Elevation above MSL** | Measures Altitude above MSL. Standard setting below Transition Altitude ($18,000 \text{ ft}$ in US, $4,000 - 10,000 \text{ ft}$ in Europe/India). |
| **QNE** | Standard ISA Sea Level Pressure (**$1013.25 \text{ hPa} / 29.92 \text{ inHg}$**) | **Pressure Altitude ($h_p$)** | Reads **Flight Levels (FL)** above Transition Level. Mandatory for en-route cruising to ensure vertical traffic separation! |

## 🔵 Core Concept 3: Altimetry Error Analysis & Calculations

An altimeter is calibrated to read true altitude ONLY in a standard ISA atmosphere with standard sea-level pressure. Real-world deviations cause **4 major types of errors**:

```
                       ALTIMETER ERROR SOURCES
                                  |
    +-----------------+-----------+-----------+-----------------+
    |                 |                       |                 |
Instrument       Position / Location     Barometric Setting    Non-Standard Temp
Error (Mechanical)   Error (Static Port)    Error (Kollsman)    Error (Cold/Hot Air)
```

### 1. Barometric Pressure Setting Error ($\Delta h_{\text{baro}}$)
If a pilot fails to update the Kollsman window when flying into a region of different sea-level pressure:
$$\Delta h_{\text{baro}} = 27.3 \text{ ft/hPa} \times (QNH_{\text{actual}} - QNH_{\text{dialed}}) \quad \text{or} \quad \Delta h_{\text{baro}} = 1000 \text{ ft/inHg} \times (QNH_{\text{actual}} - QNH_{\text{dialed}})$$

$$\bbox[10px,border:2px solid #2196F3,background-color:#0d1117]{ h_{\text{true}} = h_{\text{indicated}} + 27.3 \times (QNH_{\text{actual}} - QNH_{\text{dialed}})_{\text{hPa}} }$$

---

### 2. Non-Standard Temperature Error ($\Delta h_{\text{temp}}$)

The altimeter assumes standard ISA lapse rate ($\lambda = 6.5 \text{ K/km}$).

```
      WARM AIR (T > T_ISA)               COLD AIR (T < T_ISA)
  Isobars Spaced Farther Apart       Isobars Squeezed Together
  +--------------------------+       +--------------------------+
  |  Indicated: 10,000 ft    |       |  Indicated: 10,000 ft    |
  |  True: 10,800 ft (SAFE)  |       |  True: 9,200 ft (DANGER!)|
  +--------------------------+       +--------------------------+
```

#### A. Physical Principle:
- **Cold Air ($T_{\text{actual}} < T_{\text{ISA}}$):** Air column compresses $\implies$ vertical pressure levels squeeze closer together. The altimeter senses pressure drop and assumes standard ISA spacing $\implies$ **Indicated Altitude > True Altitude** ($h_{\text{ind}} > h_{\text{true}}$). The plane is **LOWER** than shown!
- **Warm Air ($T_{\text{actual}} > T_{\text{ISA}}$):** Air column expands $\implies$ **Indicated Altitude < True Altitude** ($h_{\text{ind}} < h_{\text{true}}$).

#### B. Exact Temperature Correction Formula:
$$\bbox[12px,border:3px solid #E91E63,background-color:#0d1117]{ h_{\text{true}} = h_{\text{station}} + (h_{\text{ind}} - h_{\text{station}}) \times \left( \frac{T_{\text{actual, K}}}{T_{\text{ISA, K}}} \right) }$$

#### C. Rule of Thumb Approximation:
True altitude changes by approximately **$4\%$ for every $10^\circ\text{C}$ deviation from ISA temperature**:
$$\bbox[10px,border:2px solid #9C27B0,background-color:#0d1117]{ \Delta h_{\text{temp}} \approx 0.004 \times h_{\text{ind}} \times (T_{\text{actual}} - T_{\text{ISA}})_{^\circ\text{C}} }$$

## 🔵 Core Concept 4: System Failure & Alternate Static Source Modes

```
               STATIC SYSTEM FAILURE MODES
                            |
    +-----------------------+-----------------------+
    |                                               |
STATIC PORT BLOCKED                             ALTERNATE STATIC OPEN
Altimeter FREEZES completely                   Cockpit Suction Effect
at altitude of blockage                         Altimeter OVERREADS slightly!
```

### 1. Static Port Blocked (Ice or Dirt)
- The static pressure inside the altimeter case becomes **trapped at the value when blockage occurred**.
- **Behavior:** The altimeter **FREEZES** at that exact altitude and stops responding to climb or descent!

### 2. Alternate Static Source Opened (Inside Cockpit)
- If external static ports freeze, pilot opens emergency alternate static valve inside the cockpit.
- **Cockpit Pressure Phenomenon:** Air flowing around fuselage creates a slight venturi suction inside the unpressurized cockpit $\implies$ Cockpit pressure is **SLIGHTLY LOWER than true ambient static pressure**.
- **Behavior:** Lower internal pressure causes aneroid capsules to expand $\implies$ **Altimeter OVERREADS** (indicates $100 - 200 \text{ ft}$ higher than actual!).

## ⚡ AIR-1 Mnemonics & Speed Tricks

### 🧠 Mnemonic 1: "HIGH TO LOW, LOOK OUT BELOW"
- Flying from **High Pressure to Low Pressure** OR **Warm Air to Cold Air** without resetting altimeter $\implies$ True altitude is **LOWER** than indicated altitude!

### 🧠 Mnemonic 2: "4% Per 10°C Temp Rule"
- For every **$10^\circ\text{C}$ colder than ISA**, subtract **$4\%$ of height above station** from indicated altitude!

### ⚡ Speed Trick 1: 1 hPa = 30 ft Quick Rule
$$\mathbf{\Delta h \approx 30 \times \Delta p \text{ (in hPa)}} \quad \text{or} \quad \mathbf{\Delta h \approx 1000 \times \Delta p \text{ (in inHg)}}$$
- Example: QNH drops by $5 \text{ hPa} \implies$ Altimeter overreads by $5 \times 30 = \mathbf{150 \text{ ft}}$.

## 📝 Solved GATE & Exam-Standard Examples

### Example 1: Temperature Error True Altitude Calculation (GATE Classic 2-Marker)
**Problem:** An aircraft is cruising at an indicated altitude $h_{\text{ind}} = 10,000 \text{ ft}$ over an airfield at sea level ($h_{\text{station}} = 0$). The altimeter is set to the correct local QNH ($29.92 \text{ inHg}$). However, the mean air temperature is $-25.0^\circ\text{C}$. 
1. Determine ISA temperature at $10,000 \text{ ft}$.
2. Calculate the True Altitude ($h_{\text{true}}$) of the aircraft.

**Solution:**
1. **ISA Temperature at $10,000 \text{ ft}$ ($3048 \text{ m}$):**
   $$T_{\text{ISA}} = 15.0^\circ\text{C} - (1.98^\circ\text{C} / 1000 \text{ ft} \times 10) = 15.0 - 19.8 = \mathbf{-4.8^\circ\text{C}} = 268.35 \text{ K}$$

2. **Actual Temperature in Kelvin:**
   $$T_{\text{actual}} = -25.0^\circ\text{C} = 248.15 \text{ K}$$

3. **Temperature Deviation ($\Delta T$):**
   $$\Delta T = -25.0 - (-4.8) = \mathbf{-20.2^\circ\text{C}} \quad (\text{Cold Air})$$

4. **Exact True Altitude Calculation:**
   $$h_{\text{true}} = h_{\text{ind}} \times \left( \frac{T_{\text{actual, K}}}{T_{\text{ISA, K}}} \right) = 10,000 \times \left( \frac{248.15}{268.35} \right) = 10,000 \times 0.92472 = \mathbf{9,247.2 \text{ ft}}$$

5. **Quick Rule-of-Thumb Check:**
   $$\Delta h_{\text{temp}} \approx 0.004 \times 10,000 \times (-20.2) = -808 \text{ ft}$$
   $$h_{\text{true}} \approx 10,000 - 808 = \mathbf{9,192 \text{ ft}} \quad (\text{Excellent agreement!})$$

**Key Insight:** In cold air, the aircraft is actually **$753 \text{ ft}$ LOWER** than indicated! This is a major terrain collision hazard!

---

### Example 2: Barometric Setting Mis-Setting Error
**Problem:** A pilot sets the Kollsman window to $1010 \text{ hPa}$ while the actual local QNH is $1018 \text{ hPa}$. If the altimeter indicates $5,000 \text{ ft}$, calculate the true altitude (assume standard temperature).

**Solution:**
Using barometric setting error formula:
$$QNH_{\text{actual}} - QNH_{\text{dialed}} = 1018 - 1010 = \mathbf{+8 \text{ hPa}}$$

$$\Delta h = 27.3 \text{ ft/hPa} \times (+8 \text{ hPa}) = \mathbf{+218.4 \text{ ft}}$$

$$h_{\text{true}} = 5,000 + 218.4 = \mathbf{5,218.4 \text{ ft}}$$

---

### Example 3: Alternate Static Port Selection Diagnostic MCQ
**Problem:** If the primary static ports freeze during flight and the pilot opens the emergency alternate static valve inside the cockpit, the pressure altimeter will:
- (A) Freeze at the altitude of selection
- (B) Read slightly LOWER than true altitude
- (C) Read slightly HIGHER than true altitude
- (D) Drop to zero immediately

**Solution:**
Due to aerodynamic airflow suction over the fuselage skin, cockpit static pressure is slightly lower than external ambient static pressure.
Lower pressure inside the altimeter case causes aneroid capsules to expand, indicating a **HIGHER altitude** (Option C).

**Correct Answer:** **(C) Read slightly HIGHER than true altitude**

## ⚠️ Common GATE Traps & Exam Pitfalls

> [!CAUTION]
> 1. **Cold Air Danger Trap:** Remember that **Cold Air $\implies h_{\text{true}} < h_{\text{ind}}$** (plane is lower than shown). Do NOT add temperature correction on a cold day; SUBTRACT it!
> 2. **Kollsman Window Direction Trap:** If local QNH is HIGH and you set a LOW value $\implies$ Altimeter reads LOWER than true altitude ($h_{\text{ind}} < h_{\text{true}}$).
> 3. **Static Blockage vs. Pitot Blockage:** A blocked static port **FREEZES** the altimeter. A blocked pitot tube makes the Airspeed Indicator act like an altimeter!
> 4. **Kelvin Temperature Conversion:** Always convert temperatures to **Absolute Kelvin** before using $h_{\text{true}} = h_{\text{ind}} (T_{\text{actual, K}} / T_{\text{ISA, K}})$.

```
====================================================================================
                     PRESSURE ALTIMETER MASTER REFERENCE CARD
====================================================================================
1. WORKING PRINCIPLE:
   - Aneroid Capsules in Static Pressure Case (Measures Static Pressure p)
   - Climb --> p drops --> Capsules EXPAND --> Pointer moves Clockwise
   - Descent --> p rises --> Capsules COMPRESS --> Pointer moves Counter-Clockwise
------------------------------------------------------------------------------------
2. Q-CODES SUMMARY:
   - QFE: Reads 0 on runway ground (Height AGL)
   - QNH: Reads Airport Elevation on runway ground (Altitude MSL)
   - QNE: Standard 1013.25 hPa / 29.92 inHg (Flight Levels / Pressure Alt)
------------------------------------------------------------------------------------
3. ERROR CORRECTIONS:
   - Barometric Error: h_true = h_ind + 27.3 * (QNH_actual - QNH_dialed)_hPa
   - Temperature Error: h_true = h_ind * (T_actual_K / T_ISA_K)
   - Cold Air (T < T_ISA) --> h_true < h_ind  ("Look Out Below!")
   - Warm Air (T > T_ISA) --> h_true > h_ind
------------------------------------------------------------------------------------
4. FAILURE MODES:
   - Blocked Static Port:  Altimeter FREEZES at blockage altitude
   - Alternate Cockpit Static: Altimeter OVERREADS (due to cockpit suction)
====================================================================================
```
