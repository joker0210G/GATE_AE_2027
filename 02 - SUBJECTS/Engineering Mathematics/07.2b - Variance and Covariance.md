> 🎯 **GATE Weightage:** 1–2 marks per paper. Variance measures the **spread or dispersion** of data around its mean. In probability theory and statistical analysis, questions testing properties of variance ($Var(aX+b)$, $Var(X \pm Y)$, $Var(\bar{X})$), covariance, and Chebyshev's inequality are among the **highest-yielding 1-mark and 2-mark questions** in GATE Aerospace!

---

## 📌 Part I: Fundamentals of Variance

### Intuitive & Physical Meaning
- **Variance** ($\sigma^2$ or $Var(X)$) measures how far numbers in a data set or outcomes of a random variable are spread out from their average value ($\mu$).
- **Analogy with Physics:** If the probability mass distribution is like mass distributed along a rod, the mean $\mu$ is the **Center of Mass**, and the variance $\sigma^2$ is the **Moment of Inertia** about the center of mass!

---

### Definitions & Formulas

#### 1. Discrete Raw Data ($n$ values)
$$\boxed{\sigma^2 = \frac{\sum_{i=1}^n (x_i - \bar{x})^2}{n} = \overline{x^2} - (\bar{x})^2}$$

#### 2. Grouped / Frequency Data
$$\boxed{\sigma^2 = \frac{\sum f_i x_i^2}{N} - \bar{x}^2 \quad \text{where } N = \sum f_i, \; \bar{x} = \frac{\sum f_i x_i}{N}}$$

#### 3. Random Variables (Probability Theory)
For a random variable $X$ with mean $\mu = E[X]$:
$$\boxed{Var(X) = \sigma^2 = E[(X - \mu)^2] = E[X^2] - (E[X])^2}$$

- **Discrete RV:** $E[X] = \sum x_i P(x_i)$, $\quad E[X^2] = \sum x_i^2 P(x_i)$
- **Continuous RV:** $E[X] = \int_{-\infty}^{\infty} x f(x) dx$, $\quad E[X^2] = \int_{-\infty}^{\infty} x^2 f(x) dx$

---

### Population vs. Sample Variance (Bessel's Correction)

| Type | Symbol | Formula | When Used in GATE |
|---|---|---|---|
| **Population Variance** | $\sigma^2$ | $\frac{\sum (x_i - \bar{x})^2}{n}$ | Default in GATE unless "sample" specified |
| **Sample Variance** | $s^2$ | $\frac{\sum (x_i - \bar{x})^2}{n-1}$ | Used when estimating population $\sigma^2$ from a small sample |

> ⚡ **GATE Rule:** $n-1$ in denominator is used ONLY when the question explicitly states *"sample variance"* or *"unbiased sample variance estimate"*. Otherwise, use $n$.

## 🧠 Part II: Master Properties of Variance (MOST TESTED IN GATE!)

### Property 1: Constant Rule
$$Var(c) = 0 \quad \text{for any constant } c$$
*(A constant has zero spread/variation)*

### Property 2: Linear Transformation Rule (CRITICAL!)
$$\boxed{Var(aX + b) = a^2 Var(X)}$$

$$\text{Standard Deviation: } \sigma_{aX+b} = |a| \sigma_X$$

> ⚡ **Key Takeaways:**
> 1. **Adding/Subtracting a constant $b$ does NOT change variance** (shifting data doesn't change spread).
> 2. **Multiplying by $a$ scales variance by $a^2$** (and SD by $|a|$).
> 3. $Var(-X) = (-1)^2 Var(X) = Var(X)$.

---

### Property 3: Sum & Difference of Two Random Variables

For ANY two random variables $X$ and $Y$:

$$\boxed{Var(X + Y) = Var(X) + Var(Y) + 2\,Cov(X, Y)}$$

$$\boxed{Var(X - Y) = Var(X) + Var(Y) - 2\,Cov(X, Y)}$$

---

### Property 4: Independent Random Variables (GATE GUARANTEED MCQ!)

If $X$ and $Y$ are **independent** (so $Cov(X, Y) = 0$):

$$\boxed{Var(X + Y) = Var(X) + Var(Y)}$$

$$\boxed{Var(X - Y) = Var(X) + Var(Y)} \quad \text{(Notice the PLUS SIGN!)}$$

> 🔴 **GOLDEN RULE:** For independent random variables, **VARIANCES ALWAYS ADD**, even when you subtract the variables!
> $$Var(X - Y) = Var(X) + Var(Y) \ne Var(X) - Var(Y)$$

---

### Property 5: General Linear Combination

For independent random variables $X_1, X_2, \ldots, X_n$ and constants $a_1, a_2, \ldots, a_n$:

$$\boxed{Var\left(\sum_{i=1}^n a_i X_i + b\right) = \sum_{i=1}^n a_i^2 Var(X_i)}$$

**If variables are NOT independent:**
$$Var(aX + bY) = a^2 Var(X) + b^2 Var(Y) + 2ab\,Cov(X, Y)$$
$$Var(aX - bY) = a^2 Var(X) + b^2 Var(Y) - 2ab\,Cov(X, Y)$$

---

### Property 6: Variance of the Sample Mean ($\bar{X}$)

If $X_1, X_2, \ldots, X_n$ are i.i.d. (independent & identically distributed) with variance $\sigma^2$:
$$\bar{X} = \frac{X_1 + X_2 + \cdots + X_n}{n}$$

$$\boxed{Var(\bar{X}) = Var\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2} \sum_{i=1}^n Var(X_i) = \frac{1}{n^2} (n\sigma^2) = \frac{\sigma^2}{n}}$$

$$\text{Standard Error (SE): } \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}$$

> ⚡ **GATE Insight:** As sample size $n \to \infty$, $Var(\bar{X}) \to 0$. This is the mathematical basis for the **Law of Large Numbers**!

---

## 🧠 Part III: Covariance & Correlation Coefficient

### Covariance Definition

$$\boxed{Cov(X, Y) = \sigma_{XY} = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - E[X]E[Y]}$$

- $Cov(X, Y) > 0$: $X$ and $Y$ tend to move in the same direction.
- $Cov(X, Y) < 0$: $X$ and $Y$ tend to move in opposite directions.
- $Cov(X, Y) = 0$: $X$ and $Y$ are uncorrelated.

### Properties of Covariance
1. $Cov(X, X) = Var(X)$
2. $Cov(X, Y) = Cov(Y, X)$ (Symmetric)
3. $Cov(aX + b, cY + d) = ac\,Cov(X, Y)$
4. If $X$ and $Y$ are **independent** $\implies E[XY] = E[X]E[Y] \implies Cov(X, Y) = 0$.

> ⚠️ **CRITICAL TRAP:** Independent $\implies Cov(X,Y) = 0$. But $Cov(X,Y) = 0$ does **NOT** necessarily imply independence (except for Bivariate Normal distributions)!

---

### Pearson Correlation Coefficient ($\rho_{XY}$)

$$\boxed{\rho_{XY} = \frac{Cov(X, Y)}{\sigma_X \sigma_Y} = \frac{E[XY] - E[X]E[Y]}{\sqrt{Var(X)}\sqrt{Var(Y)}}}$$

- Range: $\boxed{-1 \le \rho_{XY} \le 1}$
- $\rho = +1$: Perfect positive linear relationship
- $\rho = -1$: Perfect negative linear relationship
- $\rho = 0$: No linear relationship (uncorrelated)
- **Scale and Origin Invariance:** $\rho(aX + b, cY + d) = \text{sign}(ac) \cdot \rho(X, Y)$

---

## 🧠 Part IV: Variance of Standard Distributions (GATE Quick-Reference)

| Distribution | Probability Function / Density | Mean $E[X]$ | Variance $Var(X)$ |
|---|---|---|---|
| **Discrete Uniform** $\{1..n\}$ | $P(X=k) = 1/n$ | $\frac{n+1}{2}$ | $\frac{n^2 - 1}{12}$ |
| **Continuous Uniform** $[a, b]$ | $f(x) = \frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| **Bernoulli** $(p)$ | $P(X=1)=p, P(X=0)=q$ | $p$ | $pq = p(1-p)$ |
| **Binomial** $(n, p)$ | $P(X=k) = \binom{n}{k} p^k q^{n-k}$ | $np$ | $npq = np(1-p)$ |
| **Poisson** $(\lambda)$ | $P(X=k) = \frac{e^{-\lambda}\lambda^k}{k!}$ | $\lambda$ | $\lambda$ *(Mean = Variance)* |
| **Geometric** $(p)$ | $P(X=k) = q^{k-1}p$ | $\frac{1}{p}$ | $\frac{1-p}{p^2} = \frac{q}{p^2}$ |
| **Exponential** $(\lambda)$ | $f(x) = \lambda e^{-\lambda x}$ ($x \ge 0$) | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| **Normal** $(\mu, \sigma^2)$ | $f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

> ⚡ **Quick Memory:**
> - Uniform continuous on $[a,b]$: Variance = $\frac{(\text{width})^2}{12}$
> - Poisson: Mean = Variance = $\lambda$
> - Exponential: $\text{Variance} = (\text{Mean})^2 = \frac{1}{\lambda^2}$

## 🧠 Part V: Chebyshev's Inequality (Probability Bounds)

For ANY random variable $X$ with mean $\mu$ and finite variance $\sigma^2$, and for any constant $k > 1$:

$$\boxed{P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}}$$

Or in complement form:
$$\boxed{P(|X - \mu| < k\sigma) \ge 1 - \frac{1}{k^2}}$$

### Alternative Form (putting $\varepsilon = k\sigma$):
$$P(|X - \mu| \ge \varepsilon) \le \frac{\sigma^2}{\varepsilon^2}$$

> ⚡ **Why it matters:** Works for **ANY distribution** (no matter how skewed or weird), without knowing the exact PDF/PMF!

## ⚡ AIR-1 Speed Tricks & Mnemonics

### 🚀 Trick 1: "VARIANCES ALWAYS ADD FOR INDEPENDENT VARIABLES"
$$Var(X - Y) = Var(X) + Var(Y)$$
Never put a minus sign between $Var(X)$ and $Var(Y)$ when variables are independent!

---

### 🚀 Trick 2: "MSM – SM²" Formula
$$Var(X) = \underbrace{E[X^2]}_{\text{Mean of Squares (MSM)}} - \underbrace{(E[X])^2}_{\text{Square of Mean (SM²)}}$$

---

### 🚀 Trick 3: Linear Shift & Scaling Rule
- Shift ($+b$): **Zero effect** on variance.
- Scale ($\times a$): Multiplies variance by **$a^2$**.
- Example: If $Var(X) = 4$, then $Var(-3X + 7) = (-3)^2 Var(X) = 9 \times 4 = 36$.

---

### 🚀 Trick 4: Variance of Average ($\bar{X}$) vs. Sum ($\sum X_i$)
For $n$ independent variables with variance $\sigma^2$:
- Variance of SUM: $Var(X_1 + \dots + X_n) = n\sigma^2$
- Variance of AVERAGE: $Var(\bar{X}) = \frac{\sigma^2}{n}$

---

### 🧠 Mnemonic: "**VARS**" for Core Variance Rules
- **V**ariances add for independent variables: $Var(X \pm Y) = Var(X) + Var(Y)$
- **A**lways non-negative: $Var(X) \ge 0$
- **R**ule of scaling: $Var(aX+b) = a^2 Var(X)$
- **S**quare mean subtraction: $Var(X) = E[X^2] - (E[X])^2$

---

### 🧠 Mnemonic: "**COV-R**" for Covariance & Correlation
- **C**ovariance formula: $E[XY] - E[X]E[Y]$
- **O**rthogonal/Independent $\implies Cov=0$
- **V**ariance of sum: $Var(X+Y) = Var(X)+Var(Y)+2Cov(X,Y)$
- **R**ange of correlation $\rho$: $[-1, +1]$

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Variance of Independent Difference (GATE 1-Marker)
**Problem:** $X$ and $Y$ are independent random variables with $Var(X) = 5$ and $Var(Y) = 3$. Find $Var(2X - 3Y + 4)$.

**Solution:**
Since $X$ and $Y$ are independent:
$$Var(2X - 3Y + 4) = Var(2X) + Var(-3Y) + Var(4)$$
$$= 2^2 Var(X) + (-3)^2 Var(Y) + 0$$
$$= 4(5) + 9(3) = 20 + 27 = \mathbf{47}$$

$$\boxed{Var(2X - 3Y + 4) = 47}$$

---

### Example 2: Continuous RV Variance (GATE 2-Marker)
**Problem:** Let $X$ be a continuous RV with PDF $f(x) = 2x$ for $0 \le x \le 1$, and $0$ elsewhere. Find $Var(X)$.

**Solution:**
**Step 1: Compute $E[X]$:**
$$E[X] = \int_0^1 x f(x) dx = \int_0^1 x(2x) dx = \int_0^1 2x^2 dx = \left[ \frac{2x^3}{3} \right]_0^1 = \frac{2}{3}$$

**Step 2: Compute $E[X^2]$:**
$$E[X^2] = \int_0^1 x^2 f(x) dx = \int_0^1 x^2(2x) dx = \int_0^1 2x^3 dx = \left[ \frac{2x^4}{4} \right]_0^1 = \frac{2}{4} = \frac{1}{2}$$

**Step 3: Compute $Var(X) = E[X^2] - (E[X])^2$:**
$$Var(X) = \frac{1}{2} - \left(\frac{2}{3}\right)^2 = \frac{1}{2} - \frac{4}{9} = \frac{9 - 8}{18} = \frac{1}{18}$$

$$\boxed{Var(X) = \frac{1}{18} \approx 0.0556}$$

---

### Example 3: Non-Independent Linear Combination (GATE 2-Marker)
**Problem:** Given $Var(X) = 4$, $Var(Y) = 9$, and $Cov(X, Y) = 3$. Find $Var(3X - 2Y)$.

**Solution:**
Using $Var(aX + bY) = a^2 Var(X) + b^2 Var(Y) + 2ab\,Cov(X, Y)$ with $a = 3, b = -2$:

$$Var(3X - 2Y) = 3^2 Var(X) + (-2)^2 Var(Y) + 2(3)(-2) Cov(X, Y)$$
$$= 9(4) + 4(9) + (-12)(3)$$
$$= 36 + 36 - 36 = \mathbf{36}$$

$$\boxed{Var(3X - 2Y) = 36}$$

---

### Example 4: Correlation Coefficient & Covariance (GATE 2-Marker)
**Problem:** $Var(X) = 16$, $Var(Y) = 25$, and $\rho_{XY} = 0.6$. Find $Var(X + Y)$.

**Solution:**
**Step 1: Find $Cov(X, Y)$:**
$$\rho_{XY} = \frac{Cov(X, Y)}{\sigma_X \sigma_Y} \implies Cov(X, Y) = \rho_{XY} \cdot \sigma_X \cdot \sigma_Y$$
$$\sigma_X = \sqrt{16} = 4, \quad \sigma_Y = \sqrt{25} = 5$$
$$Cov(X, Y) = 0.6 \times 4 \times 5 = 12$$

**Step 2: Find $Var(X + Y)$:**
$$Var(X + Y) = Var(X) + Var(Y) + 2\,Cov(X, Y) = 16 + 25 + 2(12) = 41 + 24 = \mathbf{65}$$

$$\boxed{Var(X + Y) = 65}$$

---

### Example 5: Chebyshev's Inequality Application (GATE 2-Marker)
**Problem:** A random variable $X$ has mean $\mu = 50$ and standard deviation $\sigma = 5$. Find a lower bound for $P(40 < X < 60)$.

**Solution:**
We want $P(40 < X < 60) = P(|X - 50| < 10)$.

Here, $\mu = 50$, $\sigma = 5$, and $\varepsilon = 10$.
Set $\varepsilon = k\sigma \implies 10 = k(5) \implies k = 2$.

By Chebyshev's Inequality:
$$P(|X - \mu| < k\sigma) \ge 1 - \frac{1}{k^2}$$
$$P(40 < X < 60) \ge 1 - \frac{1}{2^2} = 1 - \frac{1}{4} = \mathbf{0.75} \quad (75\%)$$

$$\boxed{\text{Lower bound for } P(40 < X < 60) = 0.75}$$

## 📐 Master Reference Table: Variance Rules

| Operation / Property | Formula |
|---|---|
| **Definition** | $Var(X) = E[X^2] - (E[X])^2$ |
| **Constant Shift** | $Var(X + c) = Var(X)$ |
| **Constant Scaling** | $Var(c X) = c^2 Var(X)$ |
| **General Linear** | $Var(aX + b) = a^2 Var(X)$ |
| **Sum (General)** | $Var(X + Y) = Var(X) + Var(Y) + 2 Cov(X,Y)$ |
| **Diff (General)** | $Var(X - Y) = Var(X) + Var(Y) - 2 Cov(X,Y)$ |
| **Sum/Diff (Independent)** | $Var(X \pm Y) = Var(X) + Var(Y)$ |
| **Sample Mean** | $Var(\bar{X}) = \frac{\sigma^2}{n}$ |
| **Covariance** | $Cov(X,Y) = E[XY] - E[X]E[Y]$ |
| **Correlation** | $\rho_{XY} = \frac{Cov(X,Y)}{\sigma_X \sigma_Y} \in [-1, 1]$ |
| **Chebyshev Bound** | $P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}$ |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Writing $Var(X - Y) = Var(X) - Var(Y)$ for Independent Variables**  
> **THE #1 ERROR IN GATE!** Variance measures spread — subtracting two noisy signals INCREASES total uncertainty/spread, it never decreases it. $Var(X - Y) = Var(X) + Var(Y)$.

> 🔴 **Trap 2: Forgetting $a^2$ when scaling $Var(aX)$**  
> $Var(-5X) = (-5)^2 Var(X) = 25 Var(X)$, NOT $-5 Var(X)$ or $5 Var(X)$. Variance can NEVER be negative!

> 🔴 **Trap 3: Assuming $Cov(X, Y) = 0$ implies Independence**  
> Zero covariance means **no linear relationship**. It does NOT guarantee independence (e.g., $X \sim U[-1, 1]$ and $Y = X^2$ has $Cov(X, Y) = 0$ but $Y$ is completely dependent on $X$!). The only exception is Bivariate Normal distribution.

> 🔴 **Trap 4: Sample Variance vs Population Variance**  
> Standard population variance uses $\frac{1}{n}$. Sample variance uses $\frac{1}{n-1}$. Make sure to check if the question asks for "sample variance".
