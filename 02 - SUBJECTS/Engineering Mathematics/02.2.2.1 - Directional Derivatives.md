## 📌 Part I: Concept & Definition (Zero to Clear)

### 1. Intuitive Idea

While partial derivatives $\frac{\partial f}{\partial x}$ and $\frac{\partial f}{\partial y}$ give the rate of change of $f(x, y)$ strictly along the $x$ and $y$ coordinate axes, the **Directional Derivative** measures the rate of change of $f$ in **ANY arbitrary spatial direction** defined by a direction vector $\vec{d}$.

$$\text{Partial Derivative } f_x \longrightarrow \text{Rate of change along } \hat{i}$$
$$\text{Partial Derivative } f_y \longrightarrow \text{Rate of change along } \hat{j}$$
$$\mathbf{\text{Directional Derivative } D_{\hat{u}}f \longrightarrow \text{Rate of change along ANY unit vector } \hat{u}}$$

---

### 2. Formal Limit Definition & Formula

The Directional Derivative of $\phi(x, y, z)$ at point $P(x_0, y_0, z_0)$ in the direction of a **UNIT vector $\hat{u} = u_1\hat{i} + u_2\hat{j} + u_3\hat{k}$** is:

$$D_{\hat{u}}\phi = \lim_{s \to 0} \frac{\phi(x_0 + s u_1, \; y_0 + s u_2, \; z_0 + s u_3) - \phi(x_0, y_0, z_0)}{s}$$

#### 🔑 The Dot-Product Master Formula (What You Use in GATE):

$$\boxed{D_{\hat{u}}\phi = \nabla\phi \cdot \hat{u} = \frac{\partial\phi}{\partial x}u_1 + \frac{\partial\phi}{\partial y}u_2 + \frac{\partial\phi}{\partial z}u_3}$$

where $\nabla\phi = \left(\frac{\partial\phi}{\partial x}, \frac{\partial\phi}{\partial y}, \frac{\partial\phi}{\partial z}\right)$ is evaluated at point $P$.

---

## 🧠 Part II: The 4 Fundamental Extremal Properties

Using $D_{\hat{u}}\phi = \nabla\phi \cdot \hat{u} = \|\nabla\phi\| \|\hat{u}\| \cos\theta = \|\nabla\phi\| \cos\theta$ (since $\|\hat{u}\| = 1$):

```
                       ▲ ∇φ (Direction of Steepest Ascent)
                       |
                       |  θ = 0°  (D_û φ = +||∇φ||)
                       |
                       +--------------► û (Direction vector)
                      / 
                     /  θ = 90° (D_û φ = 0, along Level Surface)
                    /
                   ▼  θ = 180° (D_û φ = -||∇φ||, Steepest Descent)
```

| Direction of Unit Vector $\hat{u}$ | Angle $\theta$ with $\nabla\phi$ | Value of $D_{\hat{u}}\phi$ | Physical Meaning |
|---|---|---|---|
| Parallel to $\nabla\phi$ ($\hat{u} = \frac{\nabla\phi}{\|\nabla\phi\|}$) | $\theta = 0^\circ$ ($\cos\theta = +1$) | $\mathbf{+\|\nabla\phi\|}$ | **Maximum Rate of Increase** (Steepest Ascent) |
| Anti-parallel to $\nabla\phi$ ($\hat{u} = -\frac{\nabla\phi}{\|\nabla\phi\|}$) | $\theta = 180^\circ$ ($\cos\theta = -1$) | $\mathbf{-\|\nabla\phi\|}$ | **Maximum Rate of Decrease** (Steepest Descent) |
| Perpendicular to $\nabla\phi$ ($\hat{u} \cdot \nabla\phi = 0$) | $\theta = 90^\circ$ ($\cos\theta = 0$) | $\mathbf{0}$ | **Zero Rate of Change** (Tangent to Level Surface) |
| Arbitrary angle $\theta$ | Any $\theta$ | $\|\nabla\phi\|\cos\theta$ | Rate of change in direction $\theta$ |

## 🧠 Part III: The 5 Standard GATE Question Types

### Type 1: Compute $D_{\hat{u}}\phi$ in a Given Vector Direction $\vec{a}$

$$\mathbf{\text{Algorithm:}}$$
1. Find $\nabla\phi = \phi_x\hat{i} + \phi_y\hat{j} + \phi_z\hat{k}$ at point $P$.
2. Convert direction vector $\vec{a}$ to **unit vector**: $\hat{u} = \frac{\vec{a}}{\|\vec{a}\|}$.
3. Compute dot product: $D_{\hat{u}}\phi = \nabla\phi \cdot \hat{u}$.

---

### Type 2: Compute $D_{\hat{u}}\phi$ Toward Another Point $Q$

When the direction is given as *"from point $P(x_1, y_1, z_1)$ toward point $Q(x_2, y_2, z_2)$"*:

1. Form position vector $\vec{PQ} = (x_2 - x_1)\hat{i} + (y_2 - y_1)\hat{j} + (z_2 - z_1)\hat{k}$.
2. Convert to unit vector: $\hat{u} = \frac{\vec{PQ}}{\|\vec{PQ}\|}$.
3. Compute $D_{\hat{u}}\phi = \left.\nabla\phi\right|_P \cdot \hat{u}$.

---

### Type 3: Find Maximum/Minimum Rate of Change & Direction

- **Maximum Rate of Change:** $\|\nabla\phi\|$
- **Direction of Maximum Increase:** $\hat{u}_{\text{max}} = \frac{\nabla\phi}{\|\nabla\phi\|}$
- **Minimum Rate of Change:** $-\|\nabla\phi\|$
- **Direction of Maximum Decrease:** $\hat{u}_{\text{min}} = -\frac{\nabla\phi}{\|\nabla\phi\|}$

---

### Type 4: Find Direction in Which $D_{\hat{u}}\phi$ Equals Zero

$D_{\hat{u}}\phi = 0 \iff \nabla\phi \cdot \hat{u} = 0 \implies \hat{u}$ is **tangent to the level curve/surface** $\phi = c$.

In 2D ($xy$-plane): If $\nabla\phi = (A, B)$, then $\hat{u}$ directions for $D_{\hat{u}}\phi = 0$ are:
$$\hat{u} = \pm \frac{-B\hat{i} + A\hat{j}}{\sqrt{A^2 + B^2}}$$

---

### Type 5: Find Unknown Parameter Given $D_{\hat{u}}\phi$ Value

GATE gives $D_{\hat{u}}\phi = k$ (a known value) along $\hat{u}$ at point $P$, with an unknown constant $a$ in $\phi(x,y,z)$.

1. Set up $\nabla\phi \cdot \hat{u} = k$.
2. Solve the linear equation for $a$.

---

## ⚡ AIR-1 Topper Speed Tricks & Mnemonics

### 🚀 Trick 1: The "Unit Vector Mandatory" Rule
Always check the magnitude of the direction vector:
$$\text{If } \vec{a} = 2\hat{i} - \hat{j} + 2\hat{k} \implies \|\vec{a}\| = \sqrt{4+1+4} = 3 \implies \hat{u} = \frac{1}{3}(2\hat{i} - \hat{j} + 2\hat{k})$$
Never multiply $\nabla\phi \cdot \vec{a}$ directly without dividing by $3$!

---

### 🚀 Trick 2: 2D Perpendicular Zero-Direction Shortcut
If 2D gradient is $\nabla\phi = A\hat{i} + B\hat{j}$:
- Direction of **max change**: $(A, B)$
- Direction of **zero change**: $(-B, A)$ or $(B, -A)$ (swap components and negate one!)

---

### 🚀 Trick 3: Angle Formula for Directional Derivative
If direction $\hat{u}$ makes angle $\alpha, \beta, \gamma$ with $x, y, z$ axes:
$$\hat{u} = \cos\alpha\hat{i} + \cos\beta\hat{j} + \cos\gamma\hat{k}$$
$$D_{\hat{u}}\phi = \phi_x \cos\alpha + \phi_y \cos\beta + \phi_z \cos\gamma$$

In 2D (angle $\theta$ with positive $x$-axis):
$$D_{\hat{u}}\phi = \phi_x \cos\theta + \phi_y \sin\theta$$

---

### 🚀 Trick 4: Level Surface Tangent Vector Check
The directional derivative is **ZERO along any vector tangent to the level surface** $\phi(x,y,z) = c$.

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Type 1 — Directional Derivative Along Vector
**Problem (GATE):** Find the directional derivative of $\phi(x, y, z) = x y^2 + y z^3$ at $P(2, -1, 1)$ in the direction of vector $\vec{a} = \hat{i} + 2\hat{j} + 2\hat{k}$.

**Solution:**
1. Compute $\nabla\phi$:
   $$\phi_x = y^2 \implies \phi_x(2,-1,1) = (-1)^2 = 1$$
   $$\phi_y = 2xy + z^3 \implies \phi_y(2,-1,1) = 2(2)(-1) + (1)^3 = -4 + 1 = -3$$
   $$\phi_z = 3yz^2 \implies \phi_z(2,-1,1) = 3(-1)(1)^2 = -3$$
   $$\left.\nabla\phi\right|_P = \hat{i} - 3\hat{j} - 3\hat{k}$$

2. Unit vector $\hat{u}$:
   $$\|\vec{a}\| = \sqrt{1^2 + 2^2 + 2^2} = \sqrt{9} = 3 \implies \hat{u} = \frac{1}{3}\hat{i} + \frac{2}{3}\hat{j} + \frac{2}{3}\hat{k}$$

3. Dot product:
   $$D_{\hat{u}}\phi = (1)\left(\frac{1}{3}\right) + (-3)\left(\frac{2}{3}\right) + (-3)\left(\frac{2}{3}\right) = \frac{1}{3} - 2 - 2 = \mathbf{-\frac{11}{3}}$$

$$\boxed{D_{\hat{u}}\phi = -\frac{11}{3}}$$

---

### Example 2: Type 2 — Direction Toward Point $Q$
**Problem:** Find the directional derivative of $\phi = 2x^2 + 3y^2 + z^2$ at $P(2, 1, 3)$ toward $Q(1, 0, 2)$.

**Solution:**
1. $\nabla\phi = 4x\hat{i} + 6y\hat{j} + 2z\hat{k} \big|_P = 8\hat{i} + 6\hat{j} + 6\hat{k}$
2. Vector $\vec{PQ} = (1-2)\hat{i} + (0-1)\hat{j} + (2-3)\hat{k} = -\hat{i} - \hat{j} - \hat{k}$
3. Unit vector $\hat{u} = \frac{-\hat{i}-\hat{j}-\hat{k}}{\sqrt{1+1+1}} = \frac{-\hat{i}-\hat{j}-\hat{k}}{\sqrt{3}}$
4. $D_{\hat{u}}\phi = \frac{8(-1) + 6(-1) + 6(-1)}{\sqrt{3}} = \frac{-20}{\sqrt{3}} = \mathbf{-\frac{20\sqrt{3}}{3}}$

$$\boxed{D_{\hat{u}}\phi = -\frac{20}{\sqrt{3}}}$$

---

### Example 3: Type 3 — Max Rate & Direction
**Problem:** For $\phi = x^2 y z^3$, find the maximum directional derivative at $(1, 2, 1)$ and its direction.

**Solution:**
1. $\nabla\phi = (2xyz^3)\hat{i} + (x^2 z^3)\hat{j} + (3x^2 y z^2)\hat{k}$
2. Evaluate at $(1,2,1)$:
   $$\nabla\phi|_{(1,2,1)} = 4\hat{i} + \hat{j} + 6\hat{k}$$
3. Max Directional Derivative $= \|\nabla\phi\| = \sqrt{4^2 + 1^2 + 6^2} = \sqrt{16 + 1 + 36} = \mathbf{\sqrt{53}}$
4. Direction $= \mathbf{\frac{4\hat{i} + \hat{j} + 6\hat{k}}{\sqrt{53}}}$

$$\boxed{\text{Max Rate} = \sqrt{53}, \quad \text{Direction} = \frac{1}{\sqrt{53}}(4\hat{i} + \hat{j} + 6\hat{k})}$$

---

### Example 4: Type 4 — Direction for Zero Rate of Change
**Problem:** At point $(1, 2)$ for $\phi(x,y) = x^2 + 4y^2$, find a unit vector $\hat{u}$ along which the rate of change of $\phi$ is ZERO.

**Solution:**
1. $\nabla\phi = 2x\hat{i} + 8y\hat{j} \big|_{(1,2)} = 2\hat{i} + 16\hat{j}$
2. For $D_{\hat{u}}\phi = 0$, $\hat{u}$ must be perpendicular to $\nabla\phi = (2, 16) \parallel (1, 8)$.
3. Perpendicular vector: $\vec{d} = (-8, 1)$ or $(8, -1)$ (using Trick 2).
4. Unit vector: $\hat{u} = \mathbf{\pm \frac{-8\hat{i} + \hat{j}}{\sqrt{65}}}$

$$\boxed{\hat{u} = \pm \frac{-8\hat{i} + \hat{j}}{\sqrt{65}}}$$

---

### Example 5: Type 5 — Finding Unknown Parameter
**Problem:** The directional derivative of $\phi = a x y + b y z + c z x$ at $(1, 1, 1)$ has a maximum magnitude of $4$ along a line parallel to the $x$-axis. Find $a, b, c$.

**Solution:**
1. $\nabla\phi = (ay + cz)\hat{i} + (ax + bz)\hat{j} + (by + cx)\hat{k} \big|_{(1,1,1)} = (a+c)\hat{i} + (a+b)\hat{j} + (b+c)\hat{k}$
2. Given: Max rate occurs along $x$-axis ($\hat{i}$ direction).  
   This means $\nabla\phi$ MUST be purely in the $\hat{i}$ direction!  
   $\implies \hat{j}$ and $\hat{k}$ components of $\nabla\phi$ must be ZERO:
   $$a + b = 0 \implies b = -a$$
   $$b + c = 0 \implies c = -b = a$$
3. $\nabla\phi = (a + a)\hat{i} + 0\hat{j} + 0\hat{k} = 2a\hat{i}$
4. Max magnitude $= \|2a\hat{i}\| = |2a| = 4 \implies a = 2$ (or $-2$).
5. With $a = 2 \implies b = -2, c = 2$.

$$\boxed{a = 2, \quad b = -2, \quad c = 2}$$

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Non-Unit Direction Vector**  
> *Mistake:* Computing $D = \nabla\phi \cdot \vec{a}$ without dividing by $\|\vec{a}\|$.  
> *Correction:* **ALWAYS** convert $\vec{a} \to \hat{u} = \frac{\vec{a}}{\|\vec{a}\|}$ first!

> 🔴 **Trap 2: Wrong Direction in "Toward Point Q" Problems**  
> *Mistake:* Using $\vec{QP} = P - Q$ instead of $\vec{PQ} = Q - P$.  
> *Correction:* Direction FROM $P$ TOWARD $Q$ is $\vec{PQ} = \vec{r}_Q - \vec{r}_P$!

> 🔴 **Trap 3: Directional Derivative Sign Mistake**  
> *Mistake:* Assuming directional derivative is always positive.  
> *Correction:* Directional derivative is a scalar dot product and CAN be negative (means function is decreasing in that direction).
