## 📌 Part I: Complex Number Fundamentals

### Definition & Standard Form

A **complex number** is:
$$\boxed{z = x + iy}$$
where $x = \text{Re}(z)$ (real part), $y = \text{Im}(z)$ (imaginary part), and $i = \sqrt{-1}$ (imaginary unit).

Key: $i^2 = -1$, $i^3 = -i$, $i^4 = 1$ (cycles with period 4)

---

### Argand Plane (Complex Plane)
- $z = x + iy$ is plotted as the point $(x, y)$
- $x$-axis = Real axis; $y$-axis = Imaginary axis
- The complex plane is called the **Argand plane** (or $z$-plane)

---

## 🧠 Part II: Three Forms of a Complex Number

### 1. Rectangular (Cartesian) Form
$$z = x + iy$$

### 2. Polar Form
$$\boxed{z = r(\cos\theta + i\sin\theta) = r\angle\theta}$$

where:
- **Modulus (Absolute Value):** $r = |z| = \sqrt{x^2 + y^2} \ge 0$
- **Argument (Phase):** $\theta = \arg(z) = \arctan\!\left(\frac{y}{x}\right)$, measured from positive real axis
- **Principal Argument:** $\text{Arg}(z) \in (-\pi, \pi]$

**Converting Rectangular → Polar:**
$$r = \sqrt{x^2 + y^2}, \qquad \theta = \begin{cases} \arctan(y/x) & x > 0 \\ \arctan(y/x) + \pi & x < 0, y \ge 0 \\ \arctan(y/x) - \pi & x < 0, y < 0 \\ \pi/2 & x = 0, y > 0 \\ -\pi/2 & x = 0, y < 0 \end{cases}$$

### 3. Exponential (Euler) Form ⭐ (Most Powerful!)
$$\boxed{z = re^{i\theta}}$$

This comes from **Euler's Formula**:
$$\boxed{e^{i\theta} = \cos\theta + i\sin\theta}$$

**Special values of Euler's formula:**
| $\theta$ | $e^{i\theta}$ |
|---|---|
| $0$ | $1$ |
| $\pi/2$ | $i$ |
| $\pi$ | $-1$ ← **Euler's Identity:** $e^{i\pi} + 1 = 0$ |
| $3\pi/2$ | $-i$ |
| $2\pi$ | $1$ |

## 🧠 Part III: Algebraic Operations

### Addition/Subtraction (Use Rectangular Form)
$$(x_1 + iy_1) \pm (x_2 + iy_2) = (x_1 \pm x_2) + i(y_1 \pm y_2)$$

### Multiplication (Use Polar/Exponential Form!)
$$z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)} \implies |z_1 z_2| = r_1 r_2, \quad \arg(z_1 z_2) = \theta_1 + \theta_2$$

### Division (Use Polar/Exponential Form!)
$$\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)} \implies \left|\frac{z_1}{z_2}\right| = \frac{r_1}{r_2}, \quad \arg\!\left(\frac{z_1}{z_2}\right) = \theta_1 - \theta_2$$

### Complex Conjugate
$$\bar{z} = x - iy \implies |\bar{z}| = |z|, \quad z\bar{z} = x^2 + y^2 = |z|^2$$

**Key identities:**
$$\text{Re}(z) = \frac{z + \bar{z}}{2}, \qquad \text{Im}(z) = \frac{z - \bar{z}}{2i}$$

### Division Using Conjugate (Rectangular Form)
$$\frac{x_1 + iy_1}{x_2 + iy_2} = \frac{(x_1+iy_1)(x_2-iy_2)}{x_2^2 + y_2^2}$$

> ⚡ **Rule:** Multiply numerator AND denominator by the conjugate of the denominator to rationalize!

---

## 🧠 Part IV: De Moivre's Theorem (HIGH YIELD!)

$$\boxed{(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)}$$

Or equivalently:
$$\boxed{(e^{i\theta})^n = e^{in\theta}, \qquad (r e^{i\theta})^n = r^n e^{in\theta}}$$

### Power Shortcut
$$z^n = r^n(\cos(n\theta) + i\sin(n\theta))$$

### Roots of Complex Numbers ($n$ roots!)
The $n$-th roots of $z = re^{i\theta}$ are:
$$\boxed{z^{1/n} = r^{1/n} e^{i(\theta + 2\pi k)/n}, \quad k = 0, 1, 2, \ldots, n-1}$$

These $n$ roots are **equally spaced** on a circle of radius $r^{1/n}$ in the complex plane, separated by angle $\frac{2\pi}{n}$.

**Cube roots of unity:**
$$1, \quad \omega = e^{i2\pi/3} = -\frac{1}{2} + i\frac{\sqrt{3}}{2}, \quad \omega^2 = e^{i4\pi/3} = -\frac{1}{2} - i\frac{\sqrt{3}}{2}$$

Key property: $1 + \omega + \omega^2 = 0$ and $\omega^3 = 1$.

## 🧠 Part V: Analytic Functions & Cauchy-Riemann Equations (CORE!)

### Complex Function
A function $w = f(z) = u(x,y) + iv(x,y)$ where $u$ and $v$ are real-valued functions of real variables $x, y$.

### Differentiability of a Complex Function
$f(z)$ is differentiable at $z_0$ if $\lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$ exists and is **independent of the direction** of approach.

### Cauchy-Riemann (C-R) Equations — The Test for Analyticity

$f(z) = u + iv$ is **analytic (holomorphic)** at a point if and only if:

$$\boxed{\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} \qquad \text{and} \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}}$$

The derivative (when C-R is satisfied):
$$f'(z) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x} = \frac{\partial v}{\partial y} - i\frac{\partial u}{\partial y}$$

### Analytic Function
$f(z)$ is **analytic (holomorphic, regular)** in a domain $D$ if it is differentiable at every point of $D$.

> ⚡ **GATE Shortcut:** To check if $f(z)$ is analytic:
> 1. Write $f(z) = u(x,y) + iv(x,y)$
> 2. Check both C-R equations
> 3. If both hold AND partial derivatives are continuous → analytic ✅

---

### C-R Equations in Polar Form (Sometimes asked!)
$$\frac{\partial u}{\partial r} = \frac{1}{r}\frac{\partial v}{\partial \theta} \qquad \text{and} \qquad \frac{1}{r}\frac{\partial u}{\partial \theta} = -\frac{\partial v}{\partial r}$$

---

## 🧠 Part VI: Harmonic Functions

If $f(z) = u + iv$ is analytic, then BOTH $u$ and $v$ satisfy **Laplace's equation**:
$$\boxed{\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0} \qquad \boxed{\nabla^2 v = 0}$$

- $u$ and $v$ are called **harmonic functions**
- $v$ is called the **harmonic conjugate** of $u$ (and vice versa)
- Together $f = u + iv$ forms a **conjugate pair**

### Finding Harmonic Conjugate (Exam Procedure)
Given $u(x,y)$, find $v(x,y)$:
1. From C-R: $\frac{\partial v}{\partial y} = \frac{\partial u}{\partial x}$ → integrate w.r.t. $y$ (treat $x$ as constant) → get $v = \int \frac{\partial u}{\partial x} dy + g(x)$
2. Differentiate w.r.t. $x$ and use: $\frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y}$ → find $g'(x)$ → integrate to find $g(x)$

## 🧠 Part VII: Elementary Analytic Functions

### 1. Complex Exponential
$$e^z = e^{x+iy} = e^x(\cos y + i\sin y)$$
- $|e^z| = e^x$, $\arg(e^z) = y$
- Periodic: $e^{z+2\pi i} = e^z$ (period $2\pi i$)
- **Entire function** (analytic everywhere)

### 2. Complex Logarithm (Multi-Valued!)
$$\ln z = \ln|z| + i\arg(z) = \ln r + i\theta$$
$$\text{Log}\, z = \ln r + i\,\text{Arg}(z) \quad (\text{Principal value, } \theta \in (-\pi,\pi])$$

> ⚠️ NOT single-valued — adding $2\pi i k$ gives another branch!

### 3. Complex Trigonometric Functions
$$\cos z = \frac{e^{iz} + e^{-iz}}{2} \qquad \sin z = \frac{e^{iz} - e^{-iz}}{2i}$$

### 4. Complex Hyperbolic Functions
$$\cosh z = \frac{e^z + e^{-z}}{2} \qquad \sinh z = \frac{e^z - e^{-z}}{2}$$

**Key relationships:** $\sin(iz) = i\sinh(z)$ and $\cos(iz) = \cosh(z)$

---

## 🧠 Part VIII: Complex Integration (Contour Integration)

### Line Integral in Complex Plane
$$\int_C f(z)\, dz = \int_C (u + iv)(dx + i\,dy) = \int_C (u\,dx - v\,dy) + i\int_C (v\,dx + u\,dy)$$

### Cauchy's Theorem (Fundamental Theorem of Complex Analysis)
If $f(z)$ is **analytic** throughout a simply connected domain $D$ and $C$ is any simple closed curve in $D$:

$$\boxed{\oint_C f(z)\, dz = 0}$$

> ⚡ **Implication:** For analytic functions, contour integrals depend only on the **endpoints**, not the path (path independence).

---

### Cauchy's Integral Formula (HIGH YIELD — Guaranteed MCQ!)

If $f(z)$ is analytic inside and on a simple closed curve $C$, and $z_0$ is any point **inside** $C$:

$$\boxed{\oint_C \frac{f(z)}{z - z_0}\, dz = 2\pi i\, f(z_0)}$$

**Generalization for derivatives:**
$$\boxed{\oint_C \frac{f(z)}{(z - z_0)^{n+1}}\, dz = \frac{2\pi i}{n!}\, f^{(n)}(z_0)}$$

> ⚡ **Golden Rule:** If you see $\oint \frac{f(z)}{z-z_0}\,dz$ with $z_0$ inside $C$ and $f$ analytic → answer is $2\pi i f(z_0)$. If $z_0$ is **outside** $C$ → answer is $0$.

---

## 🧠 Part IX: Taylor & Laurent Series, Singularities

### Taylor Series (Analytic Functions)
If $f(z)$ is analytic at $z = z_0$:
$$f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!}(z - z_0)^n \quad \text{for } |z - z_0| < R$$

### Laurent Series (Near Singularities)
If $f(z)$ has a singularity at $z_0$, in the annulus $0 < |z - z_0| < R$:
$$f(z) = \sum_{n=-\infty}^{\infty} c_n (z - z_0)^n = \underbrace{\sum_{n=0}^{\infty} c_n (z-z_0)^n}_{\text{Analytic part}} + \underbrace{\sum_{n=1}^{\infty} \frac{c_{-n}}{(z-z_0)^n}}_{\text{Principal part}}$$

### Types of Singularities (Classified by Principal Part)

| Singularity Type | Principal Part | Example |
|---|---|---|
| **Removable** | No principal part ($c_{-n}=0$ for all $n\ge1$) | $\frac{\sin z}{z}$ at $z=0$ |
| **Simple pole** (order 1) | Only $\frac{c_{-1}}{z-z_0}$ term | $\frac{1}{z-1}$ at $z=1$ |
| **Pole of order $m$** | $\frac{c_{-1}}{z-z_0} + \cdots + \frac{c_{-m}}{(z-z_0)^m}$, $c_{-m}\ne 0$ | $\frac{1}{(z-1)^3}$ at $z=1$ |
| **Essential singularity** | Infinite principal part | $e^{1/z}$ at $z=0$ |

---

## 🧠 Part X: Residues & Residue Theorem (GATE's Favorite!)

### Residue Definition
The **residue** of $f(z)$ at $z = z_0$ is the coefficient $c_{-1}$ of $\frac{1}{z-z_0}$ in the Laurent series.

$$\text{Res}[f, z_0] = c_{-1}$$

### Residue Formulas

**1. Simple pole (order 1):**
$$\boxed{\text{Res}[f, z_0] = \lim_{z \to z_0}(z - z_0)\, f(z)}$$

**2. Pole of order $m$:**
$$\boxed{\text{Res}[f, z_0] = \frac{1}{(m-1)!}\lim_{z \to z_0}\frac{d^{m-1}}{dz^{m-1}}\left[(z-z_0)^m f(z)\right]}$$

**3. Quotient form $f(z) = p(z)/q(z)$ with simple pole at $q(z_0)=0$, $q'(z_0)\ne 0$:**
$$\boxed{\text{Res}[f, z_0] = \frac{p(z_0)}{q'(z_0)}}$$

### Residue Theorem (Master Formula for Contour Integration)
If $f(z)$ is analytic inside and on $C$ EXCEPT at isolated singularities $z_1, z_2, \ldots, z_n$ inside $C$:

$$\boxed{\oint_C f(z)\, dz = 2\pi i \sum_{k=1}^{n} \text{Res}[f, z_k]}$$

> ⚡ **Strategy:** To evaluate $\oint_C f(z)\, dz$:
> 1. Find all singularities of $f(z)$
> 2. Identify which ones are **inside** $C$
> 3. Compute residue at each interior singularity
> 4. Sum all residues and multiply by $2\pi i$

## ⚡ AIR-1 Speed Tricks & Mnemonics

### 🚀 Trick 1: Polar Multiplication/Division — "Multiply Magnitudes, Add Angles"
$$|z_1 z_2| = |z_1| \cdot |z_2|, \quad \arg(z_1 z_2) = \arg(z_1) + \arg(z_2)$$
$$\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}, \quad \arg\!\left(\frac{z_1}{z_2}\right) = \arg(z_1) - \arg(z_2)$$

GATE frequently asks for $|z^n|$ or $\arg(z^n)$ → apply De Moivre: $|z^n| = |z|^n$, $\arg(z^n) = n\arg(z)$.

---

### 🚀 Trick 2: C-R Check — "Cross-Partials Must Match with Sign Flip"
$$u_x = v_y \quad (\text{diagonal: same sign}) \qquad u_y = -v_x \quad (\text{off-diagonal: opposite sign})$$

Memory: Write $u,v$ in a 2×2:
$$\begin{bmatrix} u_x & u_y \\ v_x & v_y \end{bmatrix} \to \text{diagonal equal: } u_x = v_y; \text{ anti-diagonal opposite: } u_y = -v_x$$

---

### 🚀 Trick 3: Cauchy Integral Formula — "Circle Check"
Before applying Cauchy's formula to $\oint \frac{f(z)}{z-z_0}\,dz$:
1. Factor the denominator to find all singularities
2. Determine which are INSIDE vs OUTSIDE the given contour $C$
3. For each singularity inside: contribute $2\pi i \times \text{Res}$
4. Singularities outside: contribute $0$

---

### 🚀 Trick 4: "i-Power Cycle" for Quick Computations
$i^0 = 1$, $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$ (repeats!)

For $i^n$: compute $n \bmod 4$, then use the cycle.

$$i^{47} = i^{4 \times 11 + 3} = i^3 = -i$$

---

### 🧠 Mnemonic: "**CAMP**" for C-R Equations

$$\frac{\partial \mathbf{C}os}{\partial x} = \frac{\partial \mathbf{A}sin}{\partial y} \qquad \frac{\partial \mathbf{A}sin}{\partial x} = -\frac{\partial \mathbf{C}os}{\partial y}$$
- **C**osine → $u$ (real part)
- **A**sine → $v$ (imaginary part)  
Or simply: **C**auchy **R**ules → $u_x = v_y$, **A** cross → $u_y = -v_x$ (**M**inus **P**lus)

---

### 🧠 Mnemonic: "**RIPE-SE**" for Singularity Types
- **R**emovable → limits exist (e.g. $\sin z / z$)
- **P**ole (simple) → $1/(z-z_0)$ in principal part
- **P**ole (order $m$) → highest power $1/(z-z_0)^m$ 
- **E**ssential → infinite principal part, weird behavior (Picard's theorem)
- **S**ingularity outside $C$ → contributes **ZERO** to contour integral

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Check Analyticity (GATE MCQ)
**Problem:** Is $f(z) = z^2 = (x+iy)^2$ analytic?

**Solution:**
$f(z) = x^2 - y^2 + 2ixy \implies u = x^2 - y^2$, $v = 2xy$.

Check C-R:
- $u_x = 2x$, $v_y = 2x$ → $u_x = v_y$ ✅
- $u_y = -2y$, $v_x = 2y$ → $u_y = -v_x$: $-2y = -2y$ ✅

C-R satisfied everywhere → **$f(z) = z^2$ is analytic everywhere (entire).**

$$f'(z) = u_x + iv_x = 2x + i(2y) = 2(x+iy) = 2z \quad \text{(matches real calculus!)}$$

---

### Example 2: De Moivre's Theorem (GATE 1-Marker)
**Problem:** Find $(1+i)^{10}$.

**Solution:**
Convert to polar: $|1+i| = \sqrt{2}$, $\arg(1+i) = \pi/4$.

$$\boxed{(1+i)^{10} = (\sqrt{2})^{10}\left(\cos\frac{10\pi}{4} + i\sin\frac{10\pi}{4}\right) = 32\left(\cos\frac{5\pi}{2} + i\sin\frac{5\pi}{2}\right)}$$

$\cos(5\pi/2) = \cos(\pi/2) = 0$, $\sin(5\pi/2) = \sin(\pi/2) = 1$.

$$\boxed{(1+i)^{10} = 32i}$$

---

### Example 3: Cauchy's Integral Formula (GATE 4-Marker)
**Problem:** Evaluate $\displaystyle\oint_{|z|=2} \frac{e^z}{z(z-1)}\, dz$.

**Solution:**
Singularities: $z = 0$ and $z = 1$. Both are inside $|z| = 2$ (radius = 2 > both 0 and 1).

Write using **partial fractions**: $\frac{1}{z(z-1)} = \frac{-1}{z} + \frac{1}{z-1}$

$$\oint \frac{e^z}{z(z-1)}\, dz = -\oint \frac{e^z}{z}\, dz + \oint \frac{e^z}{z-1}\, dz$$

Apply Cauchy's formula ($\oint \frac{f(z)}{z-z_0}\,dz = 2\pi i f(z_0)$ for $z_0$ inside $C$):

$$= -2\pi i\, e^0 + 2\pi i\, e^1 = -2\pi i + 2\pi i e = 2\pi i(e - 1)$$

$$\boxed{\oint_{|z|=2} \frac{e^z}{z(z-1)}\, dz = 2\pi i(e-1)}$$

---

### Example 4: Residue Calculation (GATE 3-Marker)
**Problem:** Find $\text{Res}\!\left[\dfrac{z^2+1}{(z-1)^2(z+2)},\, z=1\right]$.

**Solution:** $z = 1$ is a **pole of order 2**. Use the order-2 residue formula:

$$\text{Res} = \frac{1}{1!}\lim_{z \to 1}\frac{d}{dz}\!\left[(z-1)^2 \cdot \frac{z^2+1}{(z-1)^2(z+2)}\right] = \lim_{z \to 1}\frac{d}{dz}\!\left[\frac{z^2+1}{z+2}\right]$$

$$\frac{d}{dz}\left[\frac{z^2+1}{z+2}\right] = \frac{2z(z+2) - (z^2+1)(1)}{(z+2)^2} = \frac{z^2 + 4z - 1}{(z+2)^2}$$

At $z = 1$: $\frac{1 + 4 - 1}{9} = \frac{4}{9}$

$$\boxed{\text{Res}\!\left[\frac{z^2+1}{(z-1)^2(z+2)},\, z=1\right] = \frac{4}{9}}$$

---

### Example 5: Harmonic Function / Finding $f(z)$ (GATE 3-Marker)
**Problem:** If $u = x^2 - y^2 - 2y$ is harmonic, find the harmonic conjugate $v$ and hence $f(z)$.

**Solution:**
**Verify harmonic:** $u_{xx} = 2$, $u_{yy} = -2 \implies u_{xx} + u_{yy} = 0$ ✅

**Find $v$:** From C-R: $v_y = u_x = 2x$
→ Integrate w.r.t. $y$: $v = 2xy + g(x)$

From C-R: $v_x = -u_y = -(-2y - 2) = 2y + 2$
→ $\frac{\partial}{\partial x}[2xy + g(x)] = 2y + g'(x) = 2y + 2 \implies g'(x) = 2 \implies g(x) = 2x + C$

$$v = 2xy + 2x + C$$

$$f(z) = u + iv = (x^2 - y^2 - 2y) + i(2xy + 2x + C)$$

Recognizing: $x^2 - y^2 + 2ixy = (x+iy)^2 = z^2$ and $-2y + 2ix = 2i(x+iy) = 2iz$:

$$\boxed{f(z) = z^2 + 2iz + iC}$$

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Argument Quadrant Error**  
> $\arctan(y/x)$ only gives the right angle for $x > 0$. For $x < 0$, add/subtract $\pi$ based on the quadrant. Always sketch the point $(x,y)$ to confirm the quadrant before computing $\theta$.

> 🔴 **Trap 2: Forgetting to Check if Singularity Is INSIDE the Contour**  
> The most common error in Cauchy's formula questions. ALWAYS check $|z_0|$ vs the radius of the given circular contour $|z| = R$. If $|z_0| < R$: inside (contributes $2\pi i \times \text{Res}$). If $|z_0| > R$: outside (contributes $0$).

> 🔴 **Trap 3: Treating $\ln z$ as Single-Valued**  
> $\ln z = \ln r + i\theta$ is multi-valued because $\theta$ can be $\theta + 2\pi k$ for any integer $k$. The principal logarithm $\text{Log}\,z$ restricts $\theta \in (-\pi, \pi]$, but GATE questions about $\ln(negative)$ always require the principal value.

> 🔴 **Trap 4: Non-Analytic Functions — $f(z) = \bar{z}$**  
> $f(z) = \bar{z} = x - iy$: $u = x$, $v = -y$. Check C-R: $u_x = 1 \ne v_y = -1$ ❌. So $f(z) = \bar{z}$ is **nowhere analytic** even though it's continuous everywhere. A common trick question!
