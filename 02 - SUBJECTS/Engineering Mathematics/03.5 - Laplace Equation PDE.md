> 🎯 **GATE Weightage:** 2–4 marks per year. The Laplace Equation $\nabla^2 u = 0$ is **Elliptic** ($\Delta < 0$) and models **steady-state heat conduction**, **irrotational potential flow in aerodynamics** ($\nabla^2\phi = 0$), and **electrostatics**.

---

## 📌 Part I: Statement & Classification

### 2D Laplace Equation (Standard Form)

$$\boxed{\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0}$$

In 3D Cartesian coordinates:
$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} = 0$$

- **Classification:** $A=1, B=0, C=1 \implies B^2 - 4AC = -4 < 0 \implies \mathbf{Elliptic}$
- **Nature:** Pure **Boundary Value Problem (BVP)** — No time variable $t$. Information propagates in all directions instantaneously.
- **Harmonic Functions:** Any twice-differentiable function satisfying $\nabla^2 u = 0$ is called a **Harmonic Function**.

---

### Physical Applications in Aerospace Engineering

1. **Incompressible Irrotational Potential Flow:**  
   Velocity vector $\vec{V} = \nabla\phi = \frac{\partial\phi}{\partial x}\hat{i} + \frac{\partial\phi}{\partial y}\hat{j}$.  
   Continuity equation $\nabla \cdot \vec{V} = 0 \implies \nabla \cdot (\nabla\phi) = \mathbf{\nabla^2\phi = 0}$.
2. **Steady-State Heat Conduction:**  
   When temperature does not change with time ($\frac{\partial T}{\partial t} = 0$), Fourier's heat equation $\frac{\partial T}{\partial t} = \alpha^2 \nabla^2 T$ reduces to $\mathbf{\nabla^2 T = 0}$.
3. **Stream Function $\psi$ in 2D Irrotational Flow:** $\mathbf{\nabla^2\psi = 0}$.

---

## 🧠 Part II: Boundary Value Problems (BVPs)

Since there is no time variable, Laplace's equation requires **boundary conditions on the ENTIRE enclosed boundary $\partial D$**:

| BVP Type | Boundary Condition | Physical Meaning |
|---|---|---|
| **Dirichlet Problem** | $u = f(x,y)$ on $\partial D$ | Temperature/potential fixed on boundary |
| **Neumann Problem** | $\frac{\partial u}{\partial n} = g(x,y)$ on $\partial D$ | Heat flux / velocity component fixed on boundary |
| **Robin (Mixed) Problem** | $a u + b \frac{\partial u}{\partial n} = h(x,y)$ | Convection at boundary (Newton's cooling) |

---

## 🧠 Part III: Separation of Variables in Cartesian Coordinates (Rectangular Plate)

### Problem Setup
Find steady-state temperature $u(x,y)$ in a thin rectangular plate $0 \le x \le a, \; 0 \le y \le b$:

```
                   u(x, b) = f(x) (Top boundary)
            +---------------------------------+
            |                                 |
 u(0, y) = 0|         ∇²u = 0                 |u(a, y) = 0
  (Left)    |                                 | (Right)
            +---------------------------------+
                   u(x, 0) = 0 (Bottom boundary)
```

Boundary conditions:
1. $u(0, y) = 0$
2. $u(a, y) = 0$
3. $u(x, 0) = 0$
4. $u(x, b) = f(x)$

---

### Step-by-Step Derivation

#### Step 1: Assume Product Solution
$$u(x,y) = X(x) \cdot Y(y)$$

Substitute into $\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0$:
$$X''(x) Y(y) + X(x) Y''(y) = 0 \implies \frac{X''(x)}{X(x)} = -\frac{Y''(y)}{Y(y)} = -\lambda$$

#### Step 2: Spatial ODE in $x$ (Homogeneous BCs at $x=0, x=a$)
$$X''(x) + \lambda X(x) = 0, \quad X(0) = 0, \; X(a) = 0$$

This is the standard Sturm-Liouville problem!
- **Eigenvalues:** $\lambda_n = \left(\frac{n\pi}{a}\right)^2, \quad n = 1, 2, 3, \ldots$
- **Eigenfunctions:** $X_n(x) = \sin\left(\frac{n\pi x}{a}\right)$

#### Step 3: Spatial ODE in $y$
$$Y''(y) - \lambda_n Y(y) = 0 \implies Y''(y) - \left(\frac{n\pi}{a}\right)^2 Y(y) = 0$$

General solution:
$$Y_n(y) = C_n \cosh\left(\frac{n\pi y}{a}\right) + D_n \sinh\left(\frac{n\pi y}{a}\right)$$

Apply BC $u(x,0) = 0 \implies Y(0) = 0 \implies C_n = 0$:
$$Y_n(y) = D_n \sinh\left(\frac{n\pi y}{a}\right)$$

#### Step 4: Superposition Principle
$$u(x,y) = \sum_{n=1}^\infty E_n \sin\left(\frac{n\pi x}{a}\right) \sinh\left(\frac{n\pi y}{a}\right) \quad (E_n = B_n D_n)$$

#### Step 5: Apply Top Boundary Condition $u(x,b) = f(x)$
$$u(x,b) = \sum_{n=1}^\infty \left[ E_n \sinh\left(\frac{n\pi b}{a}\right) \right] \sin\left(\frac{n\pi x}{a}\right) = f(x)$$

This is a Fourier Sine Series! By orthogonality:
$$E_n \sinh\left(\frac{n\pi b}{a}\right) = \frac{2}{a} \int_0^a f(x) \sin\left(\frac{n\pi x}{a}\right) dx$$

$$\boxed{E_n = \frac{2}{a \sinh\left(\frac{n\pi b}{a}\right)} \int_0^a f(x) \sin\left(\frac{n\pi x}{a}\right) dx}$$

## 🧠 Part IV: Polar Coordinates $(r, \theta)$ — Circular Domains (HIGH YIELD FOR GATE!)

In polar coordinates $(x = r\cos\theta, y = r\sin\theta)$, Laplace's equation becomes:

$$\boxed{\nabla^2 u = \frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{\partial r} + \frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2} = 0}$$

---

### 1. Interior Dirichlet Problem for a Disk of Radius $R$

Find $u(r, \theta)$ inside disk $r \le R$ subject to $u(R, \theta) = f(\theta)$.

```
                      (r, θ) inside disk
                          .
                       r / \ 
                        /   \  u(R, θ) = f(θ) on boundary
                       +-----+  (Radius R)
```

#### Master Interior Solution Formula:
$$\boxed{u(r, \theta) = \frac{a_0}{2} + \sum_{n=1}^\infty \left(\frac{r}{R}\right)^n \left[ a_n \cos(n\theta) + b_n \sin(n\theta) \right]}$$

where $a_n, b_n$ are standard Fourier coefficients of $f(\theta)$:
- $a_0 = \frac{1}{\pi} \int_0^{2\pi} f(\theta)\,d\theta$
- $a_n = \frac{1}{\pi} \int_0^{2\pi} f(\theta)\cos(n\theta)\,d\theta$
- $b_n = \frac{1}{\pi} \int_0^{2\pi} f(\theta)\sin(n\theta)\,d\theta$

---

### 2. Exterior Dirichlet Problem ($r \ge R$, Bounded at $\infty$)

$$\boxed{u(r, \theta) = \frac{a_0}{2} + \sum_{n=1}^\infty \left(\frac{R}{r}\right)^n \left[ a_n \cos(n\theta) + b_n \sin(n\theta) \right]}$$

> Notice: $\left(\frac{r}{R}\right)^n$ for interior vs. $\left(\frac{R}{r}\right)^n$ for exterior!

---

## 🧠 Part V: Fundamental Properties of Harmonic Functions

### 1. Mean Value Property (MVP)

If $u(x,y)$ is harmonic in a domain $D$:
- **Center Value of Disk:** The value of $u$ at the center $(0,0)$ of a disk of radius $R$ equals the **average value** of $u$ on the boundary circle:
  $$\boxed{u(0,0) = \frac{a_0}{2} = \frac{1}{2\pi} \int_0^{2\pi} u(R, \theta)\,d\theta}$$

---

### 2. Maximum / Minimum Principle (AIR-1 High-Yield Shortcut!)

Let $u(x,y)$ be continuous on a closed bounded region $D$ and harmonic inside $D$:
- $u(x,y)$ attains its **maximum** and **minimum** values **ONLY on the boundary $\partial D$** (never in the interior, unless $u$ is constant throughout $D$).

> ⚡ **GATE Exam Use:** To find $\max_{D} u(x,y)$, do NOT take partial derivatives $\nabla u = 0$ inside! Evaluate $u$ on the **boundary $\partial D$** only!

---

### 3. Uniqueness Theorem

The solution to the Dirichlet problem $\nabla^2 u = 0$ in domain $D$ with $u = f$ on boundary $\partial D$ is **UNIQUE**.

## ⚡ AIR-1 Topper Speed Tricks & Mnemonics

### 🚀 Trick 1: Disk Center Temperature = Average Boundary Temperature
To find temperature at center $r=0$ of a disk $r \le R$ with boundary $u(R,\theta) = f(\theta)$:
$$u(0,0) = \text{Average of } f(\theta) = \frac{1}{2\pi}\int_0^{2\pi} f(\theta)\,d\theta$$
No full separation of variables needed — just integrate $f(\theta)$ over $[0,2\pi]$ and divide by $2\pi$!

---

### 🚀 Trick 2: Matching Coefficients in Polar Problems
If boundary temperature $u(R, \theta) = 3 + 5\cos(2\theta) - 4\sin(3\theta)$:
Match directly with $u(r,\theta) = \frac{a_0}{2} + \sum (r/R)^n [a_n \cos n\theta + b_n \sin n\theta]$:
- $\frac{a_0}{2} = 3$
- $a_2 = 5 \implies \text{term is } 5 \left(\frac{r}{R}\right)^2 \cos(2\theta)$
- $b_3 = -4 \implies \text{term is } -4 \left(\frac{r}{R}\right)^3 \sin(3\theta)$
$$\text{Solution: } \mathbf{u(r,\theta) = 3 + 5\left(\frac{r}{R}\right)^2 \cos(2\theta) - 4\left(\frac{r}{R}\right)^3 \sin(3\theta)}$$
Done in 10 seconds without computing a single integral!

---

### 🚀 Trick 3: Maximum Principle Shortcut
If asked: *"Find maximum temperature inside square plate $[0,1] \times [0,1]$ with $u(x,y) = x^2 - y^2$"*:
Check harmonic: $u_{xx} + u_{yy} = 2 - 2 = 0$ ✓ Harmonic!  
Max occurs on boundary! Evaluate on 4 edges:
- $x=1, y \in [0,1] \implies u(1,y) = 1 - y^2 \le 1$
- Max value $= 1$ at $(1,0)$. Done!

---

### 🚀 Trick 4: Constant Boundary Value Rule
If $u(x,y) = C$ (constant) on all boundaries of a domain $D$, then:
$$u(x,y) = C \quad \text{everywhere inside } D$$

---

### 🧠 Mnemonic: "**SHIN**" for Rectangular Laplace Separation
- **S**ine in direction of homogeneous BCs ($X(x) = \sin(n\pi x/a)$)
- **H**yperbolic sine in non-homogeneous direction ($Y(y) = \sinh(n\pi y/a)$)
- **I**ntegrate Fourier sine series for coefficients
- **N**o time dependence (Elliptic, steady-state)

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Rectangular Plate (GATE PYQ Type)
**Problem:** Solve $\nabla^2 u = 0$ in $0 < x < \pi, \; 0 < y < \pi$ subject to $u(0,y) = 0$, $u(\pi,y) = 0$, $u(x,0) = 0$, and $u(x,\pi) = \sin x$.

**Solution (Using Speed Trick 2 logic):**
1. Homogeneous BCs at $x=0, \pi \implies X_n(x) = \sin(nx)$ ($a=\pi$)
2. Homogeneous BC at $y=0 \implies Y_n(y) = \sinh(ny)$
3. General form: $u(x,y) = \sum_{n=1}^\infty E_n \sin(nx) \sinh(ny)$
4. Apply top BC at $y=\pi$:
   $$u(x,\pi) = \sum_{n=1}^\infty E_n \sinh(n\pi) \sin(nx) = \sin x$$
5. Match coefficients: $n=1 \implies E_1 \sinh(\pi) = 1 \implies E_1 = \frac{1}{\sinh\pi}$. All other $E_n = 0$.

$$\boxed{u(x,y) = \frac{\sin x \sinh y}{\sinh\pi}}$$

---

### Example 2: Disk Center Temperature (GATE 2-Marker)
**Problem:** A circular plate of radius $R=2$ has boundary temperature $u(2, \theta) = 10 + 4\cos\theta + 6\sin(2\theta)$. Find the temperature at the center of the plate $(r=0)$.

**Solution (Using Speed Trick 1):**
At $r=0$, all $(r/R)^n$ terms vanish for $n \ge 1$.
$$u(0,\theta) = \frac{a_0}{2} = \text{Average boundary temperature}$$
$$\text{Average of } [10 + 4\cos\theta + 6\sin(2\theta)] \text{ over } [0, 2\pi] = 10 + 0 + 0 = 10$$

$$\boxed{u(0,0) = 10}$$

---

### Example 3: Maximum Principle (GATE MCQ)
**Problem:** Find the maximum value of $u(x,y) = x^2 - y^2 + 2xy$ in the closed disk $x^2 + y^2 \le 4$.

**Solution (Using Speed Trick 3):**
1. Check if harmonic: $u_{xx} = 2, u_{yy} = -2 \implies u_{xx} + u_{yy} = 0$ ✓ Harmonic!
2. Maximum occurs on the boundary $r=2$:
   Substitute $x = 2\cos\theta, y = 2\sin\theta$:
   $$u(2,\theta) = 4\cos^2\theta - 4\sin^2\theta + 2(2\cos\theta)(2\sin\theta)$$
   $$u(2,\theta) = 4\cos(2\theta) + 4\sin(2\theta) = 4\sqrt{2}\cos(2\theta - \pi/4)$$
3. Maximum value on boundary $= 4\sqrt{2}$.

$$\boxed{\text{Maximum value} = 4\sqrt{2}}$$

## 📐 Master Summary Table: Laplace Equation

| Domain | Solution Form | Coefficient Formula |
|---|---|---|
| **Rectangle** $0\le x\le a, 0\le y\le b$ ($u=f(x)$ at top) | $u = \sum E_n \sin\left(\frac{n\pi x}{a}\right) \sinh\left(\frac{n\pi y}{a}\right)$ | $E_n \sinh\left(\frac{n\pi b}{a}\right) = \frac{2}{a}\int_0^a f(x)\sin\left(\frac{n\pi x}{a}\right)dx$ |
| **Disk Interior** ($r \le R$) | $u = \frac{a_0}{2} + \sum \left(\frac{r}{R}\right)^n [a_n\cos n\theta + b_n\sin n\theta]$ | Standard Fourier of boundary $f(\theta)$ |
| **Disk Exterior** ($r \ge R$) | $u = \frac{a_0}{2} + \sum \left(\frac{R}{r}\right)^n [a_n\cos n\theta + b_n\sin n\theta]$ | Standard Fourier of boundary $f(\theta)$ |
| **Disk Center** ($r=0$) | $u(0,0) = \frac{a_0}{2}$ | Average of boundary function |
| **Max/Min Location** | On boundary $\partial D$ ONLY | Maximum Principle |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Confusing $\sin$ vs $\sinh$ in Rectangular Domains**  
> Direction with **two homogeneous BCs** (e.g. $x=0, x=a$) uses **trigonometric sine** $\sin\left(\frac{n\pi x}{a}\right)$.  
> Direction with **one homogeneous BC** (e.g. $y=0$) uses **hyperbolic sine** $\sinh\left(\frac{n\pi y}{a}\right)$.

> 🔴 **Trap 2: Swapping Interior vs Exterior Disk Powers**  
> - Interior ($r \le R$): power is $(r/R)^n$ so solution remains finite at $r=0$.  
> - Exterior ($r \ge R$): power is $(R/r)^n$ so solution remains finite as $r \to \infty$.

> 🔴 **Trap 3: Trying to Find Max/Min by Setting $\nabla u = 0$ Inside Domain**  
> For harmonic functions, $\nabla u = 0$ inside never gives local maxima/minima (only saddle points). The max/min ALWAYS lies on the boundary!
