## 📌 Part I: Classification of First Order ODEs

### Master Classification Tree

```
First Order ODE: dy/dx = f(x, y)
│
├── 1. Separable: f(x,y) = g(x)·h(y)
├── 2. Homogeneous: f(x,y) = f(tx,ty) i.e. f(y/x) form
├── 3. Linear: dy/dx + P(x)y = Q(x)
├── 4. Bernoulli: dy/dx + P(x)y = Q(x)·yⁿ
├── 5. Exact: M dx + N dy = 0, where ∂M/∂y = ∂N/∂x
└── 6. Integrating Factor: Non-exact made exact by μ(x) or μ(y)
```

---

## 🧠 Part II: Type 1 — Separable Equations

### Standard Form
$$\frac{dy}{dx} = g(x) \cdot h(y) \quad \Longrightarrow \quad \frac{dy}{h(y)} = g(x)\,dx$$

### Method
1. Separate variables: all $y$ terms on left, all $x$ terms on right
2. Integrate both sides
3. Apply initial condition if given

### Standard Results to Memorize

| Equation | Solution |
|---|---|
| $\frac{dy}{dx} = ky$ | $y = Ce^{kx}$ |
| $\frac{dy}{dx} = -ky$ | $y = Ce^{-kx}$ (decay) |
| $\frac{dy}{dx} = k(y - T)$ | $y = T + Ce^{kx}$ (Newton's Cooling) |
| $\frac{dy}{dx} = ky(1-y)$ | $y = \frac{1}{1+Ce^{-kx}}$ (Logistic) |

### ⚡ GATE Speed Trick: Half-Life / Time Constant
For $\frac{dy}{dt} = -ky$: solution $y = y_0 e^{-kt}$
- **Half-life:** $t_{1/2} = \frac{\ln 2}{k}$
- **Time constant:** $\tau = \frac{1}{k}$ (at $t=\tau$, $y = y_0 e^{-1} \approx 0.368\,y_0$)

## 🧠 Part III: Type 2 — Homogeneous Equations

### Test for Homogeneity
$f(x,y)$ is **homogeneous of degree $n$** if: $f(tx, ty) = t^n f(x,y)$

A first order ODE $\frac{dy}{dx} = f(x,y)$ is **homogeneous** if $f(x,y)$ can be written as $\phi\!\left(\frac{y}{x}\right)$.

### Substitution Method
$$\text{Substitute: } v = \frac{y}{x} \implies y = vx \implies \frac{dy}{dx} = v + x\frac{dv}{dx}$$

The ODE becomes:
$$v + x\frac{dv}{dx} = \phi(v) \implies x\frac{dv}{dx} = \phi(v) - v$$

This is now **separable**: $\frac{dv}{\phi(v) - v} = \frac{dx}{x}$

### ⚡ AIR-1 Recognition Shortcut
Homogeneous ODE: Every term has the **same total degree** in $x$ and $y$.  
Example: $\frac{dy}{dx} = \frac{x^2 + y^2}{xy}$ → numerator degree 2, denominator degree 2 ✓ → Homogeneous!

## 🧠 Part IV: Type 3 — Linear First Order ODE (MOST IMPORTANT FOR GATE!)

### Standard Form
$$\boxed{\frac{dy}{dx} + P(x)\,y = Q(x)}$$

where $P(x)$ and $Q(x)$ are continuous functions of $x$ only.

### The Integrating Factor (IF) Method — Master Formula

**Step 1:** Compute the Integrating Factor (IF):
$$\boxed{\mu(x) = e^{\int P(x)\,dx}}$$

**Step 2:** Multiply both sides by $\mu(x)$:
$$\mu(x)\frac{dy}{dx} + \mu(x)P(x)y = \mu(x)Q(x)$$

**Step 3:** Left side becomes an exact derivative:
$$\frac{d}{dx}[\mu(x) \cdot y] = \mu(x)Q(x)$$

**Step 4:** Integrate both sides:
$$\boxed{\mu(x) \cdot y = \int \mu(x)\,Q(x)\,dx + C}$$

**Complete Solution Formula (Direct Plug-in):**
$$\boxed{y = \frac{1}{\mu(x)}\left[\int \mu(x)\,Q(x)\,dx + C\right] = e^{-\int P\,dx}\left[\int e^{\int P\,dx} \cdot Q\,dx + C\right]}$$

---

### 🧠 Mnemonic: "IMAI" — Four Steps for Linear ODE
1. **I**dentify $P(x)$ and $Q(x)$
2. **M**ultiply by IF: $\mu = e^{\int P\,dx}$
3. **A**ccept the left side as $\frac{d}{dx}(\mu y)$
4. **I**ntegrate right side: $\mu y = \int \mu Q\,dx + C$

---

### Standard Integrating Factor Patterns (Memorize!)

| $P(x)$ | $\int P\,dx$ | IF = $e^{\int P\,dx}$ |
|---|---|---|
| $\frac{1}{x}$ | $\ln x$ | $x$ |
| $\frac{2}{x}$ | $2\ln x$ | $x^2$ |
| $\frac{n}{x}$ | $n\ln x$ | $x^n$ |
| $a$ (constant) | $ax$ | $e^{ax}$ |
| $-a$ (constant) | $-ax$ | $e^{-ax}$ |
| $\frac{1}{x+a}$ | $\ln(x+a)$ | $(x+a)$ |
| $2x$ | $x^2$ | $e^{x^2}$ |
| $\tan x$ | $-\ln\cos x$ | $\sec x$ |
| $\cot x$ | $\ln\sin x$ | $\sin x$ |

---

### Worked Example: Standard Linear ODE
**Solve:** $\frac{dy}{dx} + \frac{2y}{x} = x^2$

1. $P(x) = \frac{2}{x}$, $Q(x) = x^2$
2. IF $= e^{\int(2/x)dx} = e^{2\ln x} = x^2$
3. Multiply: $\frac{d}{dx}(x^2 y) = x^2 \cdot x^2 = x^4$
4. Integrate: $x^2 y = \frac{x^5}{5} + C$
5. **Solution:** $\boxed{y = \frac{x^3}{5} + \frac{C}{x^2}}$

---

## 🧠 Part V: Type 4 — Bernoulli's Equation (HIGH YIELD!)

### Standard Form
$$\boxed{\frac{dy}{dx} + P(x)\,y = Q(x)\,y^n}$$

where $n \ne 0, 1$ (if $n=0$: linear; if $n=1$: separable).

### Reduction Substitution
$$v = y^{1-n} \implies \frac{dv}{dx} = (1-n)y^{-n}\frac{dy}{dx}$$

Dividing the Bernoulli equation by $y^n$:
$$y^{-n}\frac{dy}{dx} + P(x)\,y^{1-n} = Q(x)$$
$$\frac{1}{1-n}\frac{dv}{dx} + P(x)\,v = Q(x)$$
$$\boxed{\frac{dv}{dx} + (1-n)P(x)\,v = (1-n)Q(x)}$$

This is now a **standard linear ODE in $v$**! Solve by IF method.

### ⚡ AIR-1 Trick: Bernoulli Recognition
Look for $y^n$ on the right side (where $n \ne 0, 1$). Common in GATE:
- $\frac{dy}{dx} - \frac{y}{x} = xy^2$ → Bernoulli with $n=2$
- $\frac{dy}{dx} + y = y^3 e^x$ → Bernoulli with $n=3$

---

## 🧠 Part VI: Type 5 — Exact Differential Equations (HIGH YIELD!)

### Standard Form
$$M(x,y)\,dx + N(x,y)\,dy = 0$$

### Exactness Test
$$\boxed{\text{Exact} \iff \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}}$$

### Solution Method for Exact ODE
If exact, solution $F(x,y) = C$ where:
$$\frac{\partial F}{\partial x} = M \quad \text{and} \quad \frac{\partial F}{\partial y} = N$$

**Step 1:** Integrate $M$ w.r.t $x$ (treating $y$ as constant):
$$F = \int M\,dx + g(y)$$

**Step 2:** Differentiate $F$ w.r.t $y$ and equate to $N$:
$$\frac{\partial F}{\partial y} = N \implies \text{find } g'(y) \implies \text{integrate to get } g(y)$$

**Step 3:** Write solution $F(x,y) = C$.

---

### 🧠 Mnemonic: "M-partial-y = N-partial-x" → EXACT
**"My = Nx"** (sounds like "My ex!") — $M_y = N_x$ means the ODE is Exact ✅

---

### Worked Example: Exact ODE
**Solve:** $(2xy + y^2)\,dx + (x^2 + 2xy)\,dy = 0$

**Check:** $M = 2xy+y^2$, $M_y = 2x+2y$  
$N = x^2+2xy$, $N_x = 2x+2y$ ✓ Exact!

**Solve:**
$F = \int(2xy+y^2)\,dx = x^2 y + xy^2 + g(y)$  
$F_y = x^2 + 2xy + g'(y) = N = x^2 + 2xy \implies g'(y) = 0 \implies g(y) = C_1$

**Solution:** $\boxed{x^2 y + xy^2 = C}$

---

## 🧠 Part VII: Integrating Factor for Non-Exact ODEs

If $M_y \ne N_x$, the ODE is **not exact** but can be made exact by multiplying by an **Integrating Factor (IF)**.

### Finding the IF

**Case 1:** IF is a function of $x$ only (most common in GATE):
$$\text{If } \frac{M_y - N_x}{N} = f(x) \text{ (function of $x$ only)} \implies \mu(x) = e^{\int f(x)\,dx}$$

**Case 2:** IF is a function of $y$ only:
$$\text{If } \frac{N_x - M_y}{M} = g(y) \text{ (function of $y$ only)} \implies \mu(y) = e^{\int g(y)\,dy}$$

---

## ⚡ Master Algorithm for Any First Order ODE

```
Receive ODE: dy/dx = f(x,y)  or  M dx + N dy = 0

Step 1: Is it SEPARABLE? (RHS splits as g(x)·h(y))
        → YES: Separate and integrate directly.

Step 2: Is it LINEAR? (dy/dx + P(x)y = Q(x) form)
        → YES: IF = e^∫P dx → Solution: μy = ∫μQ dx + C

Step 3: Is it BERNOULLI? (dy/dx + P(x)y = Q(x)yⁿ)
        → YES: Substitute v = y^(1-n) → Reduces to linear ODE.

Step 4: Write as M dx + N dy = 0. Check My = Nx?
        → YES: EXACT → Integrate to find F(x,y) = C.
        → NO:  Compute (My - Nx)/N = f(x) or (Nx - My)/M = g(y)
               → IF = e^∫f(x)dx  or  e^∫g(y)dy → Multiply → Now EXACT.

Step 5: Is it HOMOGENEOUS? (f(tx,ty) = f(x,y))
        → YES: Substitute v = y/x → Separable ODE.
```

## 📝 Solved GATE-Standard Examples

### Example 1: Separable ODE (2 marks)
**Problem:** Solve $\frac{dy}{dx} = \frac{x(1+y^2)}{y(1+x^2)}$ with $y(0) = 1$.

**Solution:**
Separate: $\frac{y\,dy}{1+y^2} = \frac{x\,dx}{1+x^2}$

Integrate: $\frac{1}{2}\ln(1+y^2) = \frac{1}{2}\ln(1+x^2) + C_1$  
$\ln(1+y^2) = \ln(1+x^2) + \ln C$ (absorbing the 2)  
$1+y^2 = C(1+x^2)$

Apply $y(0)=1$: $1+1 = C(1+0) \implies C = 2$

$$\boxed{1+y^2 = 2(1+x^2)}$$

---

### Example 2: Linear ODE (GATE 2019 Type)
**Problem:** Solve $\frac{dy}{dx} - \frac{y}{x} = x\cos x$ with $y(\pi) = 0$.

**Solution:**
$P = -\frac{1}{x}$, $Q = x\cos x$

IF $= e^{\int(-1/x)dx} = e^{-\ln x} = \frac{1}{x}$

$\frac{d}{dx}\left(\frac{y}{x}\right) = \frac{1}{x} \cdot x\cos x = \cos x$

Integrate: $\frac{y}{x} = \sin x + C$

Apply $y(\pi)=0$: $\frac{0}{\pi} = \sin\pi + C \implies C = 0$

$$\boxed{y = x\sin x}$$

---

### Example 3: Bernoulli's Equation (GATE Type)
**Problem:** Solve $\frac{dy}{dx} + \frac{y}{x} = x^2 y^3$.

**Solution:**
Bernoulli with $n=3$. Substitute $v = y^{1-3} = y^{-2}$:  
$\frac{dv}{dx} = -2y^{-3}\frac{dy}{dx}$

Divide equation by $y^3$:  
$y^{-3}\frac{dy}{dx} + \frac{y^{-2}}{x} = x^2$

$-\frac{1}{2}\frac{dv}{dx} + \frac{v}{x} = x^2$

$\frac{dv}{dx} - \frac{2v}{x} = -2x^2$ ← Linear ODE in $v$!

IF $= e^{\int(-2/x)dx} = x^{-2}$

$\frac{d}{dx}(x^{-2}v) = -2x^2 \cdot x^{-2} = -2$

$x^{-2}v = -2x + C \implies v = x^{-2}(-2x+C) \cdot x^2$

Wait, let me redo: $x^{-2}v = -2x + C \implies v = x^2(-2x + C) = -2x^3 + Cx^2$

Since $v = y^{-2}$:  
$$\boxed{\frac{1}{y^2} = Cx^2 - 2x^3}$$

---

### Example 4: Exact ODE (GATE PYQ)
**Problem:** Solve $(e^y + 1)\cos x\,dx + e^y \sin x\,dy = 0$.

**Check Exactness:**  
$M = (e^y+1)\cos x$, $M_y = e^y\cos x$  
$N = e^y\sin x$, $N_x = e^y\cos x$ ✓ Exact!

**Solve:**  
$F = \int(e^y+1)\cos x\,dx = (e^y+1)\sin x + g(y)$  
$F_y = e^y\sin x + g'(y) = e^y\sin x \implies g'(y) = 0 \implies g(y) = C_1$

$$\boxed{(e^y + 1)\sin x = C}$$

## 📐 Master Comparison Table: All 5 First-Order ODE Types

| Type | Standard Form | Method | Key Formula |
|---|---|---|---|
| **Separable** | $\frac{dy}{dx} = g(x)h(y)$ | Separate & Integrate | $\int\frac{dy}{h(y)} = \int g(x)dx$ |
| **Linear** | $y' + P(x)y = Q(x)$ | IF = $e^{\int P\,dx}$ | $\mu y = \int\mu Q\,dx + C$ |
| **Bernoulli** | $y' + Py = Qy^n$ | $v = y^{1-n}$ | Reduces to Linear |
| **Exact** | $M\,dx + N\,dy = 0$ | Check $M_y = N_x$ | $F(x,y) = C$ |
| **Homogeneous** | $y' = \phi(y/x)$ | $v = y/x$ | Reduces to Separable |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Not rewriting in Standard Linear Form First**  
> The ODE must be in the form $y' + P(x)y = Q(x)$ with **coefficient of $y'$ equal to 1** before identifying $P(x)$. If given $xy' + 2y = x^3$, divide by $x$ first to get $y' + \frac{2}{x}y = x^2$.

> 🔴 **Trap 2: Forgetting the Constant of Integration in IF**  
> When computing IF $= e^{\int P\,dx}$, always choose the **simplest antiderivative** (set $C = 0$). The constant reappears in the final solution naturally.

> 🔴 **Trap 3: Bernoulli Substitution — Wrong Exponent**  
> For $y' + Py = Qy^n$, the substitution is $v = y^{\mathbf{1-n}}$ (NOT $y^n$ or $y^{-n}$). Common error causes the linear ODE step to fail.

> 🔴 **Trap 4: Exactness Test — Partial Derivative Direction**  
> $M$ is the coefficient of $dx$ → differentiate $M$ w.r.t. $\mathbf{y}$ → get $M_y$.  
> $N$ is the coefficient of $dy$ → differentiate $N$ w.r.t. $\mathbf{x}$ → get $N_x$.  
> Mixing directions gives wrong test result!

## 📐 Quick-Fire Formula Sheet (For Last-Minute Revision)

$$\text{Linear: } \mu = e^{\int P\,dx}, \quad y = \frac{1}{\mu}\!\left(\int\mu Q\,dx + C\right)$$

$$\text{Bernoulli: } v = y^{1-n}, \quad v' + (1-n)Pv = (1-n)Q$$

$$\text{Exact Test: } M_y = N_x$$

$$\text{Homogeneous: } v = y/x, \quad xv' = \phi(v) - v$$

$$\text{IF for non-exact: } \mu(x) = e^{\int\frac{M_y-N_x}{N}dx} \quad \text{or} \quad \mu(y) = e^{\int\frac{N_x-M_y}{M}dy}$$
