> 🎯 **GATE Weightage:** 2–4 marks per year. Trapezoidal rule is the **most fundamental Newton-Cotes quadrature formula**. It approximates the area under $f(x)$ by dividing it into trapezoids with linear interpolating segments.

---

## 📌 Part I: Geometric Concept & Single-Segment Formula

### Geometric Idea
To evaluate $I = \int_a^b f(x)\,dx$, connect $(a, f(a))$ and $(b, f(b))$ with a straight line. The integral is approximated by the area of the trapezoid formed under this straight line.

```
          y ^          Linear Interpolant (straight line)
            |             + (b, f(b))
            |            /|
            |   (a, f(a)/ |  Trapezoid Area
            |         +   |  = (h/2) [f(a) + f(b)]
     -------+---------+---+--------► x
            |         a   b
            |<--- h ---->|
```

### Single-Segment Formula ($n=1$, $h = b - a$)

$$\boxed{\int_a^b f(x)\,dx \approx \frac{b - a}{2} \left[ f(a) + f(b) \right] = \frac{h}{2} (y_0 + y_1)}$$

---

## 🧠 Part II: Composite Trapezoidal Rule (MASTER FORMULA FOR GATE!)

To increase accuracy, divide $[a, b]$ into $n$ equal sub-intervals of width:

$$\boxed{h = \frac{b - a}{n}}$$

Mesh points: $x_0 = a, \; x_1 = a+h, \; x_2 = a+2h, \; \ldots, \; x_n = b$.  
Ordinates: $y_0 = f(x_0), \; y_1 = f(x_1), \; \ldots, \; y_n = f(x_n)$.

### Master Composite Formula

$$\boxed{\int_a^b f(x)\,dx \approx \frac{h}{2} \left[ (y_0 + y_n) + 2(y_1 + y_2 + y_3 + \cdots + y_{n-1}) \right]}$$

In words:

$$\boxed{\text{Integral} = \frac{h}{2} \left[ (\text{First} + \text{Last}) + 2 \times (\text{Sum of all intermediate ordinates}) \right]}$$

---

### Weight Pattern / Stencil

The weights $w_i$ applied to ordinates $[y_0, y_1, y_2, \ldots, y_{n-1}, y_n]$ follow the pattern:

$$\frac{h}{2} \times \begin{bmatrix} 1 & 2 & 2 & \cdots & 2 & 1 \end{bmatrix}$$

---

## 🧠 Part III: Error Analysis & Accuracy (HIGH YIELD!)

### 1. Degree of Precision (Order of Exactness)
- **Degree of Precision = 1**
- Trapezoidal rule is **EXACT** for polynomials of degree $\le 1$ ($f(x) = Ax + B$, i.e. linear functions and constants).

---

### 2. Truncation Error Formulas

#### Single Segment Error ($n=1$):
$$E = -\frac{(b - a)^3}{12} f''(\xi) = -\frac{h^3}{12} f''(\xi) = \mathbf{O(h^3)}$$

#### Composite Rule Error ($n$ sub-intervals):
$$\boxed{E_n = -\frac{(b - a) h^2}{12} f''(\xi) = -\frac{(b - a)^3}{12 n^2} f''(\xi) = \mathbf{O(h^2)}}$$

where $\xi$ is some unknown point in $(a, b)$.

- **Order of Accuracy:** $\mathbf{O(h^2)}$ (Halving step size $h \implies$ error becomes $\frac{1}{4}$th!).

---

### 3. Maximum Error Bound & Minimum Sub-intervals Formula

$$\boxed{|E_n| \le \frac{(b - a) h^2}{12} M_2 = \frac{(b - a)^3}{12 n^2} M_2}$$

where $M_2 = \max_{x \in [a, b]} |f''(x)|$.

To guarantee error $|E_n| < \epsilon$, set $\frac{(b - a)^3}{12 n^2} M_2 < \epsilon$:

$$\boxed{n_{min} \ge \sqrt{\frac{(b - a)^3 M_2}{12 \epsilon}}}$$

---

## 🧠 Part IV: Overestimation vs Underestimation (Convexity Test)

The sign of the truncation error depends on the second derivative $f''(x)$:

| Second Derivative | Curve Shape | Trapezoidal Rule Result | Error $E_n$ Sign |
|---|---|---|---|
| $f''(x) > 0$ | **Concave Up (Convex)** | **OVERESTIMATES** (Approx > Exact) | $E_n < 0$ |
| $f''(x) < 0$ | **Concave Down (Concave)** | **UNDERESTIMATES** (Approx < Exact) | $E_n > 0$ |
| $f''(x) = 0$ | **Straight Line** | **EXACT** (Approx = Exact) | $E_n = 0$ |

```
    f''(x) > 0 (Concave Up)                 f''(x) < 0 (Concave Down)
       Straight line is ABOVE curve             Straight line is BELOW curve
           --> OVERESTIMATE                         --> UNDERESTIMATE
```

## ⚡ AIR-1 Speed Tricks & Mnemonics

### 🚀 Trick 1: "1-2-2-2-1" Fast Stencil Calculator Method
For tabular data, enter sum in calculator:  
$$\text{Sum} = y_0 + 2y_1 + 2y_2 + \cdots + 2y_{n-1} + y_n$$
Then multiply by $h/2$. Done in 15 seconds!

---

### 🚀 Trick 2: Number of Ordinates vs Sub-intervals ($N = n+1$)
- $n$ = number of **sub-intervals**
- $N = n+1$ = number of **data points / ordinates**
- *Example:* Data table with 6 points $\implies n = 5$ sub-intervals ($h = \frac{b-a}{5}$).

---

### 🚀 Trick 3: Over/Under-Estimation 3-Second Test
Quickly compute $f''(x)$:
- $f''(x) > 0 \implies$ Trapezoidal area > True integral
- $f''(x) < 0 \implies$ Trapezoidal area < True integral

---

### 🚀 Trick 4: Minimum Sub-intervals 10-Second Calculation
To guarantee error $< 10^{-4}$ for $\int_a^b f(x)dx$:
1. Compute $M_2 = \max |f''(x)|$ on $[a,b]$.
2. Compute $n = \sqrt{\frac{(b-a)^3 M_2}{12 \times 10^{-4}}}$. Round UP to next integer!

---

### 🧠 Mnemonic: "**HALF**" for Trapezoidal Rule
- **H**alves the boundary sum and multiplies by $h$: $\frac{h}{2}[y_0 + 2\sum y_{mid} + y_n]$
- **A**curacy order $O(h^2)$
- **L**inear interpolant (exact for degree 1 polynomials)
- **F**ourth-power denominator in min-n formula: $\sqrt{\frac{(b-a)^3 M_2}{12\epsilon}}$

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Standard Composite Integration (GATE 2-Marker)
**Problem:** Evaluate $I = \int_0^1 \frac{dx}{1 + x}$ using the Trapezoidal Rule with $n = 4$ sub-intervals.

**Solution:**
1. Step size $h = \frac{b - a}{n} = \frac{1 - 0}{4} = 0.25$.
2. Mesh points & ordinates ($y_i = \frac{1}{1 + x_i}$):

| $i$ | $x_i$ | $y_i = \frac{1}{1 + x_i}$ | Weight $w_i$ | $w_i \cdot y_i$ |
|---|---|---|---|---|
| $0$ | $0.00$ | $1.0000$ | $1$ | $1.0000$ |
| $1$ | $0.25$ | $0.8000$ | $2$ | $1.6000$ |
| $2$ | $0.50$ | $0.6667$ | $2$ | $1.3333$ |
| $3$ | $0.75$ | $0.5714$ | $2$ | $1.1429$ |
| $4$ | $1.00$ | $0.5000$ | $1$ | $0.5000$ |

3. Sum of weighted ordinates $= 1.0000 + 1.6000 + 1.3333 + 1.1429 + 0.5000 = 5.5762$
4. Multiply by $\frac{h}{2} = \frac{0.25}{2} = 0.125$:
   $$I \approx 0.125 \times 5.5762 = \mathbf{0.6970}$$

*(Exact value $= \ln 2 \approx 0.6931$. Error $= 0.6970 - 0.6931 = +0.0039$, an overestimate because $f''(x) = \frac{2}{(1+x)^3} > 0$!)*

$$\boxed{I \approx 0.6970}$$

---

### Example 2: Minimum Sub-intervals Calculation (GATE PYQ Type)
**Problem:** Find the minimum number of sub-intervals $n$ required to integrate $\int_0^2 e^x\,dx$ using the Trapezoidal Rule with an error less than $10^{-3}$.

**Solution (Using Speed Trick 4):**
1. $f(x) = e^x \implies f'(x) = e^x \implies f''(x) = e^x$.
2. Max of $|f''(x)|$ on $[0, 2]$ occurs at $x=2$: $M_2 = e^2 \approx 7.389$.
3. $b - a = 2 - 0 = 2$. Tolerance $\epsilon = 10^{-3}$.
4. Apply formula:
   $$n \ge \sqrt{\frac{(b - a)^3 M_2}{12 \epsilon}} = \sqrt{\frac{2^3 \times 7.389}{12 \times 10^{-3}}} = \sqrt{\frac{8 \times 7.389}{0.012}} = \sqrt{\frac{59.112}{0.012}} = \sqrt{4926} \approx 70.18$$
5. Round UP: $n_{min} = 71$.

$$\boxed{n_{min} = 71}$$

---

### Example 3: Tabular Flight Test Integration (GATE Aerospace Type)
**Problem:** The lift force per unit span is given by $L' = \int_0^c p(x)\,dx$. Given pressure measurements across chord $c = 2\text{ m}$:

| $x$ (m) | $0.0$ | $0.5$ | $1.0$ | $1.5$ | $2.0$ |
|---|---|---|---|---|---|
| $p(x)$ (kPa) | $10$ | $14$ | $18$ | $12$ | $6$ |

Estimate $L'$ using the Trapezoidal Rule.

**Solution:**
1. Step size $h = 0.5\text{ m}$. Number of sub-intervals $n = 4$.
2. Apply formula:
   $$L' \approx \frac{0.5}{2} \left[ (10 + 6) + 2(14 + 18 + 12) \right] = 0.25 \left[ 16 + 2(44) \right] = 0.25 \left[ 16 + 88 \right] = 0.25 \times 104 = \mathbf{26\text{ kN/m}}$$

$$\boxed{L' = 26\text{ kN/m}}$$

---

### Example 4: Over/Under Estimation MCQ (GATE 1-Marker)
**Problem:** The Trapezoidal Rule applied to $I = \int_0^1 x^3\,dx$ with $n=2$ sub-intervals will:  
(a) Overestimate $I$  
(b) Underestimate $I$  
(c) Give exact value  
(d) Cannot be determined

**Solution (Using Speed Trick 3):**
$f(x) = x^3 \implies f'(x) = 3x^2 \implies f''(x) = 6x$.  
On $(0, 1)$, $f''(x) = 6x > 0$ (Concave Up).  
$f''(x) > 0 \implies$ Trapezoidal rule **OVERESTIMATES** the true integral.

$$\boxed{\text{Correct Answer: (a) Overestimate } I}$$

## 📐 Master Summary Table: Trapezoidal Rule

| Property | Formula / Value |
|---|---|
| **Single Segment ($n=1$)** | $\frac{b-a}{2}[f(a) + f(b)]$ |
| **Composite Rule ($n$ intervals)** | $\frac{h}{2}\left[(y_0 + y_n) + 2\sum_{i=1}^{n-1} y_i\right]$ |
| **Step Size $h$** | $h = \frac{b-a}{n}$ |
| **Weights Pattern** | $\frac{h}{2}[1, 2, 2, \ldots, 2, 1]$ |
| **Degree of Precision** | $1$ (Exact for linear $Ax + B$) |
| **Composite Truncation Error** | $E_n = -\frac{(b-a)h^2}{12}f''(\xi) = \mathbf{O(h^2)}$ |
| **Min. Sub-intervals Formula** | $n_{min} \ge \sqrt{\frac{(b-a)^3 M_2}{12\epsilon}}$ |
| **Overestimates when** | $f''(x) > 0$ (Concave Up) |
| **Underestimates when** | $f''(x) < 0$ (Concave Down) |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Confusing Number of Points ($N$) with Sub-intervals ($n$)**  
> A table with $N = 5$ points has $n = 4$ sub-intervals. Step size is $h = \frac{b-a}{4}$ (NOT $\frac{b-a}{5}$).

> 🔴 **Trap 2: Forgetting Factor of 2 for Intermediate Ordinates**  
> The first and last ordinates have weight $1$, but ALL middle ordinates have weight **$2$**. Forgetting to multiply middle terms by 2 is a common calculation error.

> 🔴 **Trap 3: Denominator in Composite Formula is $2$, not $n$ or $3$**  
> Trapezoidal multiplier is $\frac{h}{\mathbf{2}}$. (Do not confuse with Simpson's $\frac{h}{\mathbf{3}}$!).

> 🔴 **Trap 4: Overestimate vs Underestimate Sign Reversal**  
> Error formula has a negative sign $E_n = -\frac{h^2(b-a)}{12}f''(\xi)$.  
> $f'' > 0 \implies E_n < 0 \implies \text{Approx} - \text{Exact} > 0 \implies \mathbf{Overestimate}$.
