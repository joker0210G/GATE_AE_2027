## 📌 Part I: The Two Types of Integrals (Zero to Clear)

### 1. Indefinite Integral (Anti-Derivative)

$$\int f(x)\,dx = F(x) + C \quad \text{where } F'(x) = f(x), \; C = \text{constant}$$

- Represents a **family of functions** differing only in the constant $C$.
- The "+C" is **mandatory** — losing it costs marks in GATE!

### 2. Definite Integral (Area / Net Change)

$$\int_a^b f(x)\,dx = F(b) - F(a) \quad (\text{Fundamental Theorem of Calculus})$$

- Represents the **net signed area** between $f(x)$ and the $x$-axis from $a$ to $b$.
- Result is a **number** (no $+C$).

### Fundamental Theorem of Calculus (FTC):
$$\boxed{\frac{d}{dx}\left[\int_a^x f(t)\,dt\right] = f(x)}$$

## 🧠 Part II: Standard Integral Formulas (Must Memorize ALL)

### Group A: Power & Algebraic

| $\int f(x)\,dx$ | $= F(x) + C$ |
|---|---|
| $\int x^n\,dx$ | $\dfrac{x^{n+1}}{n+1} + C \quad (n \neq -1)$ |
| $\int \dfrac{1}{x}\,dx$ | $\ln|x| + C$ |
| $\int \dfrac{1}{\sqrt{x}}\,dx$ | $2\sqrt{x} + C$ |
| $\int \sqrt{x}\,dx$ | $\dfrac{2}{3}x^{3/2} + C$ |
| $\int k\,dx$ | $kx + C$ |

### Group B: Exponential & Logarithmic

| $\int f(x)\,dx$ | $= F(x) + C$ |
|---|---|
| $\int e^x\,dx$ | $e^x + C$ |
| $\int e^{ax}\,dx$ | $\dfrac{e^{ax}}{a} + C$ |
| $\int a^x\,dx$ | $\dfrac{a^x}{\ln a} + C$ |
| $\int \ln x\,dx$ | $x\ln x - x + C$ |
| $\int \log_a x\,dx$ | $\dfrac{x\ln x - x}{\ln a} + C$ |

### Group C: Trigonometric

| $\int f(x)\,dx$ | $= F(x) + C$ |
|---|---|
| $\int \sin x\,dx$ | $-\cos x + C$ |
| $\int \cos x\,dx$ | $\sin x + C$ |
| $\int \tan x\,dx$ | $-\ln|\cos x| + C = \ln|\sec x| + C$ |
| $\int \cot x\,dx$ | $\ln|\sin x| + C$ |
| $\int \sec x\,dx$ | $\ln|\sec x + \tan x| + C$ |
| $\int \csc x\,dx$ | $\ln|\csc x - \cot x| + C$ |
| $\int \sec^2 x\,dx$ | $\tan x + C$ |
| $\int \csc^2 x\,dx$ | $-\cot x + C$ |
| $\int \sec x \tan x\,dx$ | $\sec x + C$ |
| $\int \csc x \cot x\,dx$ | $-\csc x + C$ |

| $\int f(x)\,dx$ | $= F(x) + C$ |
|---|---|

## 🧠 Part III: Integration Techniques (The 7 Power Tools)

### Technique 1: U-Substitution (Reverse Chain Rule)

**When to use:** Integrand contains $f(g(x)) \cdot g'(x)$ — composite function with its derivative present.

**Method:**
1. Spot the "inner function" $u = g(x)$
2. Compute $du = g'(x)\,dx$
3. Rewrite integral entirely in terms of $u$
4. Integrate in $u$
5. Back-substitute $u = g(x)$

$$\int f(g(x))\cdot g'(x)\,dx = \int f(u)\,du \quad (u = g(x))$$

**GATE Recognition Pattern:**
- Power over derivative: $\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$ ← **Instant formula!**
- Exponential: $\int f'(x) e^{f(x)}\,dx = e^{f(x)} + C$ ← **Instant formula!**

**Examples:**
$$\int 2x e^{x^2}\,dx \xrightarrow{u=x^2} \int e^u\,du = e^{x^2} + C$$
$$\int \frac{2x}{x^2+1}\,dx = \ln(x^2+1) + C \quad [\text{numerator} = \text{derivative of denominator}]$$

---

### Technique 2: Integration by Parts (IBP)

**Formula:**
$$\boxed{\int u\,dv = uv - \int v\,du}$$

**When to use:** Product of two different "types" of functions.

> 🎯 **ILATE Rule** — choose $u$ from the first applicable category:
> **I** — Inverse trig ($\sin^{-1}x$, $\tan^{-1}x$, ...)  
> **L** — Logarithmic ($\ln x$, $\log_a x$)  
> **A** — Algebraic/Polynomial ($x^n$, $x^2$, ...)  
> **T** — Trigonometric ($\sin x$, $\cos x$, ...)  
> **E** — Exponential ($e^x$, $a^x$)  
>
> Choose $u$ = function appearing **earlier** in ILATE, $dv$ = **later** function $\times dx$

**Examples:**
$$\int x e^x\,dx: \quad u=x,\; dv=e^x dx \implies xe^x - e^x + C = e^x(x-1)+C$$
$$\int \ln x\,dx: \quad u=\ln x,\; dv=dx \implies x\ln x - x + C$$
$$\int x^2 \sin x\,dx: \quad \text{Apply IBP twice (tabular method for speed)}$$

#### ⚡ Tabular Method for Repeated IBP (GATE Speed Tool)

For $\int x^n \cdot (\sin x \text{ or } \cos x \text{ or } e^{ax})\,dx$:

| Sign | $u$ (differentiate ↓) | $dv/dx$ (integrate ↓) |
|---|---|---|
| $+$ | $x^2$ | $\sin x$ |
| $-$ | $2x$ | $-\cos x$ |
| $+$ | $2$ | $-\sin x$ |
| $-$ | $0$ | $\cos x$ |

Answer: $+x^2(-\cos x) - 2x(-\sin x) + 2(\cos x) = -x^2\cos x + 2x\sin x + 2\cos x + C$

---

### Technique 3: Partial Fractions (For Rational Functions)

**When to use:** $\int \frac{P(x)}{Q(x)}\,dx$ where degree$(P) <$ degree$(Q)$ and $Q(x)$ factors.

#### Decomposition Forms:

| Factor in $Q(x)$ | Partial Fraction Form |
|---|---|
| $(x - a)$ (distinct linear) | $\dfrac{A}{x-a}$ |
| $(x - a)^n$ (repeated linear) | $\dfrac{A_1}{x-a} + \dfrac{A_2}{(x-a)^2} + \cdots + \dfrac{A_n}{(x-a)^n}$ |
| $(x^2 + bx + c)$ (irreducible quadratic) | $\dfrac{Ax + B}{x^2+bx+c}$ |
| $(x^2 + bx + c)^n$ (repeated quadratic) | $\dfrac{A_1x+B_1}{x^2+bx+c} + \cdots + \dfrac{A_nx+B_n}{(x^2+bx+c)^n}$ |

> ⚠️ If degree$(P) \ge$ degree$(Q)$: **Perform polynomial long division first!**

#### ⚡ Cover-Up Method (Fastest for Distinct Linear Factors):
For $\frac{P(x)}{(x-a)(x-b)\cdots}$: To find coefficient $A$ of $\frac{A}{x-a}$:
$$A = \left.\frac{P(x)}{(x-b)(x-c)\cdots}\right|_{x=a} \quad \text{(Cover the factor } (x-a)\text{ and substitute)}$$

---

### Technique 4: Trigonometric Substitution

**When to use:** Integrals containing $\sqrt{a^2-x^2}$, $\sqrt{a^2+x^2}$, or $\sqrt{x^2-a^2}$.

| Expression | Substitution | Simplification |
|---|---|---|
| $\sqrt{a^2-x^2}$ | $x = a\sin\theta$, $dx = a\cos\theta\,d\theta$ | $\sqrt{a^2-x^2} = a\cos\theta$ |
| $\sqrt{a^2+x^2}$ | $x = a\tan\theta$, $dx = a\sec^2\theta\,d\theta$ | $\sqrt{a^2+x^2} = a\sec\theta$ |
| $\sqrt{x^2-a^2}$ | $x = a\sec\theta$, $dx = a\sec\theta\tan\theta\,d\theta$ | $\sqrt{x^2-a^2} = a\tan\theta$ |

---

### Technique 5: Trigonometric Integrals ($\sin^m x \cos^n x$)

| Case | Strategy |
|---|---|
| $m$ odd | Save one $\sin x$, convert rest with $\sin^2 x = 1-\cos^2 x$, sub $u=\cos x$ |
| $n$ odd | Save one $\cos x$, convert rest with $\cos^2 x = 1-\sin^2 x$, sub $u=\sin x$ |
| Both even | Use half-angle formulas: $\sin^2 x = \frac{1-\cos 2x}{2}$, $\cos^2 x = \frac{1+\cos 2x}{2}$ |

**Standard Results:**
$$\int \sin^2 x\,dx = \frac{x}{2} - \frac{\sin 2x}{4} + C \qquad \int \cos^2 x\,dx = \frac{x}{2} + \frac{\sin 2x}{4} + C$$

---

### Technique 6: Integration by Completing the Square

For integrands with $ax^2 + bx + c$ in denominator/under root:
1. Complete the square: $ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \left(c - \frac{b^2}{4a}\right)$
2. Substitute $t = x + \frac{b}{2a}$
3. Apply standard inverse-trig formulas

---

### Technique 7: Weierstrass / Half-Angle Substitution (for rational trig)

For integrands like $\frac{1}{a + b\sin x}$ or $\frac{1}{a + b\cos x}$:

$$t = \tan\!\frac{x}{2} \implies \sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}$$

## 🧠 Part IV: Properties of Definite Integrals

### Master Property Table (GATE Exam Essentials):

| # | Property | Formula |
|---|---|---|
| 1 | **Reversal** | $\int_a^b f(x)\,dx = -\int_b^a f(x)\,dx$ |
| 2 | **Same Limits** | $\int_a^a f(x)\,dx = 0$ |
| 3 | **Splitting** | $\int_a^b f = \int_a^c f + \int_c^b f \quad (c \in [a,b])$ |
| 4 | **King's Property** | $\int_a^b f(x)\,dx = \int_a^b f(a+b-x)\,dx$ |
| 5 | **King's (0 to a)** | $\int_0^a f(x)\,dx = \int_0^a f(a-x)\,dx$ |
| 6 | **Even Function** | $\int_{-a}^{a} f(x)\,dx = 2\int_0^a f(x)\,dx$ if $f(-x) = f(x)$ |
| 7 | **Odd Function** | $\int_{-a}^{a} f(x)\,dx = 0$ if $f(-x) = -f(x)$ |
| 8 | **Periodicity** | $\int_0^{nT} f(x)\,dx = n\int_0^T f(x)\,dx$ if $f(x+T)=f(x)$ |
| 9 | **Scaling** | $\int_0^a f(x)\,dx = \int_0^a f(a-x)\,dx$ |

> 🎯 **GATE's Most Used:** King's Property + Even/Odd symmetry eliminate 70% of complex definite integrals instantly!

## 🧠 Part V: Leibniz Rule (Differentiation Under Integral Sign)

### Standard Form (Variable Limits):
$$\frac{d}{dx}\left[\int_{u(x)}^{v(x)} f(t)\,dt\right] = f(v(x))\cdot v'(x) - f(u(x))\cdot u'(x)$$

### General Form (Integrand Also Depends on $x$):
$$\frac{d}{dx}\left[\int_{u(x)}^{v(x)} f(t,x)\,dt\right] = f(v,x)\cdot v'(x) - f(u,x)\cdot u'(x) + \int_{u(x)}^{v(x)} \frac{\partial f}{\partial x}\,dt$$

### Classic Applications:

**Type 1:** $\frac{d}{dx}\int_0^{x^2} \sin(t)\,dt = \sin(x^2)\cdot 2x$

**Type 2:** $\frac{d}{dx}\int_x^{x^3} e^{t^2}\,dt = e^{x^6}\cdot 3x^2 - e^{x^2}\cdot 1$

**Type 3 (Evaluate via Leibniz):** $I(\alpha) = \int_0^1 \frac{x^\alpha - 1}{\ln x}\,dx$  
Differentiate: $I'(\alpha) = \int_0^1 x^\alpha\,dx = \frac{1}{\alpha+1}$  
Integrate: $I(\alpha) = \ln(\alpha+1) + C$  
At $\alpha = 0$: $I(0) = 0 \implies C = 0 \implies I(\alpha) = \ln(\alpha+1)$

## 🧠 Part VI: Special Functions — Gamma, Beta & Wallis

### 1. Gamma Function $\Gamma(n)$

$$\Gamma(n) = \int_0^\infty x^{n-1} e^{-x}\,dx \quad (n > 0)$$

#### Key Properties:
| Property | Formula |
|---|---|
| Recurrence | $\Gamma(n+1) = n\,\Gamma(n)$ |
| Integer values | $\Gamma(n+1) = n!$ for $n \in \mathbb{Z}^+$ |
| Half-integer | $\Gamma\!\left(\dfrac{1}{2}\right) = \sqrt{\pi}$ |
| Derived halves | $\Gamma\!\left(\dfrac{3}{2}\right) = \dfrac{\sqrt{\pi}}{2}$, $\Gamma\!\left(\dfrac{5}{2}\right) = \dfrac{3\sqrt{\pi}}{4}$ |
| Reflection formula | $\Gamma(n)\,\Gamma(1-n) = \dfrac{\pi}{\sin(n\pi)} \quad (0 < n < 1)$ |

**Alternative forms:**
$$\Gamma(n) = 2\int_0^\infty t^{2n-1}e^{-t^2}\,dt \qquad \int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2} = \frac{\Gamma(1/2)}{2}$$

---

### 2. Beta Function $B(m, n)$

$$B(m,n) = \int_0^1 x^{m-1}(1-x)^{n-1}\,dx = \frac{\Gamma(m)\,\Gamma(n)}{\Gamma(m+n)}$$

#### Key Properties:
| Property | Formula |
|---|---|
| Symmetry | $B(m,n) = B(n,m)$ |
| Gamma relation | $B(m,n) = \dfrac{\Gamma(m)\Gamma(n)}{\Gamma(m+n)}$ |
| Trig form | $B(m,n) = 2\displaystyle\int_0^{\pi/2} \sin^{2m-1}\theta \cos^{2n-1}\theta\,d\theta$ |

---

### 3. Wallis' Formula (GATE Direct Questions!)

$$\int_0^{\pi/2} \sin^m x \cos^n x\,dx = \frac{\Gamma\!\left(\frac{m+1}{2}\right)\,\Gamma\!\left(\frac{n+1}{2}\right)}{2\,\Gamma\!\left(\frac{m+n+2}{2}\right)} = \frac{B\!\left(\frac{m+1}{2}, \frac{n+1}{2}\right)}{2}$$

#### ⚡ Wallis' Formula for Pure Powers (Quick Version):

$$\int_0^{\pi/2} \sin^n x\,dx = \int_0^{\pi/2} \cos^n x\,dx = W_n$$

| $n$ | $W_n$ |
|---|---|
| 0 | $\pi/2$ |
| 1 | $1$ |
| 2 | $\pi/4$ |
| 3 | $2/3$ |
| 4 | $3\pi/16$ |
| 5 | $8/15$ |
| 6 | $5\pi/32$ |

**Recurrence:** $W_n = \frac{n-1}{n} W_{n-2}$ where $W_0 = \pi/2$, $W_1 = 1$

## ⚡ AIR-1 Topper Speed Tricks & Mnemonics

### 🚀 Trick 1: Numerator = Derivative of Denominator → Instant $\ln$
$$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C \quad \text{← Recognize this INSTANTLY}$$

*Examples (2 seconds each):*
- $\int \frac{\cos x}{\sin x}\,dx = \ln|\sin x| + C = \ln|\text{denominator}| + C$
- $\int \frac{2x}{x^2+5}\,dx = \ln(x^2+5) + C$
- $\int \frac{e^x}{e^x + 3}\,dx = \ln(e^x+3) + C$

---

### 🚀 Trick 2: King's Property — Symmetric Integral Killer
For definite integrals on $[0, \pi]$ or $[-a, a]$ with trig functions:

**Pattern 1:** $\int_0^\pi x \cdot f(\sin x)\,dx = \frac{\pi}{2} \int_0^\pi f(\sin x)\,dx$

*Example:* $\int_0^\pi \frac{x \sin x}{1 + \cos^2 x}\,dx$  
By King's: $= \frac{\pi}{2}\int_0^\pi \frac{\sin x}{1+\cos^2 x}\,dx$  
Sub $t = \cos x$: $= \frac{\pi}{2}\int_{-1}^{1} \frac{dt}{1+t^2} = \frac{\pi}{2} \cdot \frac{\pi}{2} = \frac{\pi^2}{4}$ ← Done in 30 seconds!

**Pattern 2:** Odd function over symmetric interval → **Answer = 0 INSTANTLY**
$\int_{-2}^{2} x^3 \cos x\,dx = 0$ (odd function), no computation needed!

---

### 🚀 Trick 3: IBP for $\int e^{ax}[f(x) + f'(x)]\,dx$ — The Magic Shortcut
$$\int e^{ax}[f(x) + f'(x)]\,dx = e^{ax} f(x) + C \quad \text{(No integration needed!)}$$

More generally:
$$\int e^x[f(x) + f'(x)]\,dx = e^x f(x) + C$$

*Example:* $\int e^x(\sin x + \cos x)\,dx = e^x \sin x + C$ ← Instant! (because $(\sin x)' = \cos x$)

---

### 🚀 Trick 4: Definite Integral Shortcut — Gamma/Beta Pattern Recognition
Whenever you see:
- $\int_0^\infty x^n e^{-x}\,dx$ → Answer is $\Gamma(n+1) = n!$
- $\int_0^1 x^m(1-x)^n\,dx$ → Answer is $B(m+1, n+1) = \frac{m!\,n!}{(m+n+1)!}$ (for integers)
- $\int_0^{\pi/2} \sin^m x \cos^n x\,dx$ → Use Wallis' formula directly

---

### 🚀 Trick 5: Add-and-Subtract Numerator (For Difficult Rational Integrals)
For $\int \frac{x+5}{x^2+4x+8}\,dx$:  
Write numerator as $\frac{1}{2}(2x+4) + 3$:
$$= \frac{1}{2}\int \frac{2x+4}{x^2+4x+8}\,dx + 3\int \frac{dx}{(x+2)^2+4}$$
$$= \frac{1}{2}\ln(x^2+4x+8) + \frac{3}{2}\tan^{-1}\!\left(\frac{x+2}{2}\right) + C$$

---

### 🚀 Trick 6: ILATE Table (IBP Choice) — 5-Word Mantra
**"I Love All The Elephants"** = **I**nverse trig → **L**ogarithm → **A**lgebraic → **T**rig → **E**xponential  
Always pick $u$ from the **EARLIER** (left) category!

## 📝 Step-by-Step Solved GATE Examples

### Example 1: U-Substitution
**Problem:** $\int \frac{\ln x}{x}\,dx$

**Solution:** $u = \ln x$, $du = \frac{1}{x}dx$:
$$= \int u\,du = \frac{u^2}{2} + C = \boxed{\frac{(\ln x)^2}{2} + C}$$

---

### Example 2: IBP with ILATE
**Problem:** $\int x^2 e^x\,dx$

**Solution (Tabular):**

| Sign | $u$ (diff) | $dv$ (integrate) |
|---|---|---|
| $+$ | $x^2$ | $e^x$ |
| $-$ | $2x$ | $e^x$ |
| $+$ | $2$ | $e^x$ |
| $-$ | $0$ | $e^x$ |

$$= x^2 e^x - 2xe^x + 2e^x + C = \boxed{e^x(x^2 - 2x + 2) + C}$$

---

### Example 3: Partial Fractions (Cover-Up)
**Problem:** $\int \frac{x+1}{(x-1)(x-2)}\,dx$

**Solution:** $\frac{x+1}{(x-1)(x-2)} = \frac{A}{x-1} + \frac{B}{x-2}$

Cover-up: $A = \frac{1+1}{1-2} = -2$; $B = \frac{2+1}{2-1} = 3$

$$\int \left(\frac{-2}{x-1} + \frac{3}{x-2}\right)dx = \boxed{-2\ln|x-1| + 3\ln|x-2| + C}$$

---

### Example 4: King's Property (GATE PYQ type)
**Problem:** $\int_0^{\pi/2} \frac{\sin^{3/2} x}{\sin^{3/2} x + \cos^{3/2} x}\,dx$

**Solution:** Let $I = \int_0^{\pi/2} \frac{\sin^{3/2} x}{\sin^{3/2} x + \cos^{3/2} x}\,dx$

By King's ($x \to \pi/2 - x$): $I = \int_0^{\pi/2} \frac{\cos^{3/2} x}{\cos^{3/2} x + \sin^{3/2} x}\,dx$

Adding: $2I = \int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$

$$\boxed{I = \frac{\pi}{4}}$$

---

### Example 5: Leibniz Rule
**Problem:** Find $\frac{d}{dx}\int_{\sin x}^{\cos x} e^{t^2}\,dt$

**Solution:**
$$= e^{\cos^2 x} \cdot (-\sin x) - e^{\sin^2 x} \cdot \cos x = \boxed{-\sin x\,e^{\cos^2 x} - \cos x\,e^{\sin^2 x}}$$

---

### Example 6: Wallis' Formula
**Problem:** $\int_0^{\pi/2} \sin^4 x \cos^2 x\,dx$ ($m=4$, $n=2$)

**Solution:**
$$= \frac{\Gamma(5/2)\,\Gamma(3/2)}{2\,\Gamma(4)} = \frac{\frac{3\sqrt{\pi}}{4} \cdot \frac{\sqrt{\pi}}{2}}{2 \cdot 6} = \frac{\frac{3\pi}{8}}{12} = \boxed{\frac{\pi}{32}}$$

---

### Example 7: $\int e^x[f(x)+f'(x)]$ Trick
**Problem:** $\int e^x\!\left(\tan x + \sec^2 x\right)\!dx$

**Solution:** Recognize $f(x) = \tan x$, $f'(x) = \sec^2 x$:
$$= \boxed{e^x \tan x + C} \quad \text{← Done in 3 seconds!}$$

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Forgetting $+C$ in Indefinite Integrals**  
> Never omit the constant! GATE deducts marks for missing $+C$.

> 🔴 **Trap 2: Wrong IBP Choice (Not Following ILATE)**  
> *Mistake:* $\int x \ln x\,dx$ — choosing $u = x$, $dv = \ln x\,dx$ ❌  
> *Correction:* $u = \ln x$ (L before A in ILATE), $dv = x\,dx$ ✅

> 🔴 **Trap 3: Partial Fractions — Degree Not Reduced First**  
> *Mistake:* Decomposing $\frac{x^3}{x^2-1}$ directly.  
> *Correction:* Long divide first! $\frac{x^3}{x^2-1} = x + \frac{x}{x^2-1}$, then decompose $\frac{x}{x^2-1}$.

> 🔴 **Trap 4: Missing $\,dx$ Factor After U-Substitution**  
> Always check that $du = g'(x)\,dx$ completely replaces the $dx$ term.

> 🔴 **Trap 5: Even/Odd Classification Error**  
> Check BOTH the numerator AND denominator when classifying a rational function as even/odd before using symmetry property.
