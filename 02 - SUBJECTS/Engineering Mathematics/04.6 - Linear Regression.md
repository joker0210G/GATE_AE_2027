> 🎯 **GATE Weightage:** 2–3 marks per year. Linear Regression finds the **best-fit straight line** through scattered experimental data using the **Least Squares Criterion** — minimizing total squared error. Used extensively in aerodynamic data analysis, engine performance curves, and experimental flight testing.

---

## 📌 Part I: Problem Statement & Core Concept

### What Is Linear Regression?
Given $n$ experimental data pairs $(x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)$, find the **best-fit line**:

$$\hat{y} = a_0 + a_1 x$$

that best represents the trend in the data.

---

### The Least Squares Criterion

"Best-fit" means **minimizing the sum of squared residuals (errors)**:

$$S = \sum_{i=1}^n e_i^2 = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \sum_{i=1}^n (y_i - a_0 - a_1 x_i)^2$$

$$\boxed{\text{Minimize } S = \sum_{i=1}^n (y_i - a_0 - a_1 x_i)^2}$$

---

## 🧠 Part II: Normal Equations — Derivation

To minimize $S$, take partial derivatives and set to zero:

$$\frac{\partial S}{\partial a_0} = 0 \implies -2\sum_{i=1}^n (y_i - a_0 - a_1 x_i) = 0$$

$$\frac{\partial S}{\partial a_1} = 0 \implies -2\sum_{i=1}^n x_i(y_i - a_0 - a_1 x_i) = 0$$

This gives the **Normal Equations** (a 2×2 linear system in $a_0, a_1$):

$$\boxed{\sum y_i = n \, a_0 + a_1 \sum x_i}$$

$$\boxed{\sum x_i y_i = a_0 \sum x_i + a_1 \sum x_i^2}$$

---

## 🧠 Part III: Master Formulas for Slope & Intercept

Solving the 2×2 normal equations simultaneously gives the explicit formulas:

$$\boxed{a_1 = \frac{n \sum x_i y_i - \sum x_i \sum y_i}{n \sum x_i^2 - \left(\sum x_i\right)^2}}$$

$$\boxed{a_0 = \bar{y} - a_1 \bar{x}}$$

where $\bar{x} = \frac{\sum x_i}{n}$ (mean of $x$) and $\bar{y} = \frac{\sum y_i}{n}$ (mean of $y$).

---

## 🧠 Part IV: Summary Table Method (GATE Standard Approach)

The standard GATE approach uses a 5-column summation table:

| $i$ | $x_i$ | $y_i$ | $x_i^2$ | $x_i y_i$ |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| $\vdots$ | | | | |
| $n$ | | | | |
| **Σ** | $\sum x_i$ | $\sum y_i$ | $\sum x_i^2$ | $\sum x_i y_i$ |

Then substitute row totals directly into the normal equations.

---

## 🧠 Part V: Correlation Coefficient $r$ (Goodness of Fit)

The **Pearson Correlation Coefficient** $r$ measures the strength and direction of the linear relationship between $x$ and $y$:

$$\boxed{r = \frac{n \sum x_i y_i - \sum x_i \sum y_i}{\sqrt{\left[n \sum x_i^2 - (\sum x_i)^2\right]\left[n \sum y_i^2 - (\sum y_i)^2\right]}}}$$

| Value of $r$ | Interpretation |
|---|---|
| $r = +1$ | Perfect positive linear correlation |
| $0 < r < 1$ | Positive linear correlation (stronger as $r \to 1$) |
| $r = 0$ | No linear correlation (uncorrelated) |
| $-1 < r < 0$ | Negative linear correlation |
| $r = -1$ | Perfect negative linear correlation |
| $|r| > 0.9$ | Strong correlation (good fit) |
| $|r| < 0.5$ | Weak correlation (poor fit) |

---

## 🧠 Part VI: Non-Linear Regression via Linearization

Many physical relationships are **not linear**, but can be **transformed** into a linear form for regression.

### 1. Power Law: $y = a x^b$
Take $\ln$ both sides:
$$\ln y = \ln a + b \ln x$$
Let $Y = \ln y$, $X = \ln x$, $A = \ln a$:
$$\boxed{Y = A + bX} \quad \text{(Linear!)}$$

---

### 2. Exponential: $y = a e^{bx}$
Take $\ln$ both sides:
$$\ln y = \ln a + bx$$
Let $Y = \ln y$, $A = \ln a$:
$$\boxed{Y = A + bx} \quad \text{(Linear in } x!)}$$

---

### 3. Reciprocal: $y = \frac{1}{a + bx}$
Take reciprocal both sides:
$$\frac{1}{y} = a + bx$$
Let $Y = \frac{1}{y}$:
$$\boxed{Y = a + bx} \quad \text{(Linear!)}$$

---

### Aerospace Application: Drag Polar Curve Fitting
In aerodynamics, the drag polar is $C_D = C_{D0} + k C_L^2$ — a quadratic relationship.  
By treating $X = C_L^2$ and $Y = C_D$:
$$C_D = C_{D0} + k \cdot X \quad \text{(Linear in } C_L^2!)$$
Use linear regression on pairs $(C_L^2, C_D)$ to find $C_{D0}$ and $k$.

## ⚡ AIR-1 Topper Speed Tricks & Mnemonics

### 🚀 Trick 1: The Best-Fit Line Always Passes Through $(\bar{x}, \bar{y})$
The regression line $\hat{y} = a_0 + a_1 x$ **always passes through the point** $(\bar{x}, \bar{y})$ (centroid of data).
- **Verification check:** Substitute $(\bar{x}, \bar{y})$ into your line equation — it must satisfy it! If not, you made an arithmetic error.
- **Quick intercept:** Once you have $a_1$, find $a_0 = \bar{y} - a_1 \bar{x}$ in one step.

---

### 🚀 Trick 2: The Numerator of $a_1$ = Numerator of $r$
The numerator of slope $a_1$ and correlation coefficient $r$ are **identical**:
$$\text{Numerator} = n\sum x_i y_i - \sum x_i \sum y_i$$
Compute it once, use it for both $a_1$ and $r$!

---

### 🚀 Trick 3: Short-Cut Formulas Using Mean-Centered Data
Define mean-centered values: $u_i = x_i - \bar{x}$, $v_i = y_i - \bar{y}$. Then:
$$a_1 = \frac{\sum u_i v_i}{\sum u_i^2} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}$$

For symmetric $x$-data (evenly spaced around $\bar{x}$), many terms cancel — halving computation!

---

### 🚀 Trick 4: Sign of $r$ = Sign of $a_1$
The correlation coefficient $r$ and slope $a_1$ **always have the same sign** (both positive, both negative, or both zero). Use this as an instant sanity check on your calculation.

---

### 🧠 Mnemonic: "**SNOV**" for Building the Summary Table
- **S**um all $x_i$ — compute $\sum x_i$
- **N**oted: compute $\sum y_i$
- **O**btain $\sum x_i^2$
- **V**erify $\sum x_i y_i$
Then plug all four sums into the slope formula!

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Standard Linear Regression (GATE 2-Marker)
**Problem:** Fit a straight line $y = a_0 + a_1 x$ to the following data using the method of least squares:

| $x$ | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|
| $y$ | $2$ | $3$ | $5$ | $4$ | $6$ |

**Solution:**

**Step 1:** Build the 5-column table ($n = 5$):

| $i$ | $x_i$ | $y_i$ | $x_i^2$ | $x_i y_i$ |
|---|---|---|---|---|
| 1 | 1 | 2 | 1 | 2 |
| 2 | 2 | 3 | 4 | 6 |
| 3 | 3 | 5 | 9 | 15 |
| 4 | 4 | 4 | 16 | 16 |
| 5 | 5 | 6 | 25 | 30 |
| **Σ** | **15** | **20** | **55** | **69** |

**Step 2:** Compute means: $\bar{x} = \frac{15}{5} = 3$, $\bar{y} = \frac{20}{5} = 4$.

**Step 3:** Compute slope $a_1$:
$$a_1 = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - (\sum x_i)^2} = \frac{5(69) - (15)(20)}{5(55) - (15)^2} = \frac{345 - 300}{275 - 225} = \frac{45}{50} = \mathbf{0.9}$$

**Step 4:** Compute intercept $a_0$:
$$a_0 = \bar{y} - a_1 \bar{x} = 4 - 0.9 \times 3 = 4 - 2.7 = \mathbf{1.3}$$

**Verification (Speed Trick 1):** Does line pass through $(\bar{x}, \bar{y}) = (3, 4)$?  
$\hat{y}(3) = 1.3 + 0.9(3) = 1.3 + 2.7 = 4$ ✅

$$\boxed{\hat{y} = 1.3 + 0.9x}$$

---

### Example 2: Predict Value with Fitted Line (GATE 1-Marker Type)
**Problem** (continuing Example 1): Using the fitted line $\hat{y} = 1.3 + 0.9x$, predict $y$ at $x = 6$.

**Solution:**
$$\hat{y}(6) = 1.3 + 0.9(6) = 1.3 + 5.4 = \mathbf{6.7}$$

$$\boxed{\hat{y}(6) = 6.7}$$

---

### Example 3: Power Law Linearization (GATE PYQ Type)
**Problem:** The following data follows a power law $y = ax^b$. Linearize and find the relation.

| $x$ | $1$ | $2$ | $4$ | $8$ |
|---|---|---|---|---|
| $y$ | $2$ | $5.66$ | $16$ | $45.25$ |

**Solution (using Speed Trick & linearization):**
Transform: $X = \ln x$, $Y = \ln y$. Then $Y = \ln a + b X$.

| $x_i$ | $y_i$ | $X_i = \ln x_i$ | $Y_i = \ln y_i$ |
|---|---|---|---|
| 1 | 2.00 | 0 | 0.693 |
| 2 | 5.66 | 0.693 | 1.733 |
| 4 | 16.00 | 1.386 | 2.773 |
| 8 | 45.25 | 2.079 | 3.812 |

Notice $Y_i / X_i \approx \frac{1.733}{0.693} \approx \frac{2.773}{1.386} \approx \frac{3.812}{2.079} \approx 2.5$ for all non-zero rows!  
This means $b \approx 1.5 = \frac{3}{2}$.

And $\ln a = Y - bX$: At $x=1$, $X=0 \implies Y = \ln a \implies \ln a = 0.693 \implies a = e^{0.693} = 2$.

$$\boxed{y = 2 x^{1.5} = 2 x^{3/2}}$$

## 📐 Master Summary: Linear Regression Formulas

| Formula | Expression |
|---|---|
| **Best-fit line** | $\hat{y} = a_0 + a_1 x$ |
| **Slope** | $a_1 = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - (\sum x_i)^2}$ |
| **Intercept** | $a_0 = \bar{y} - a_1 \bar{x}$ |
| **Key identity** | Line passes through $(\bar{x}, \bar{y})$ |
| **Correlation coeff.** | $r = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{\sqrt{[n\sum x_i^2 - (\sum x_i)^2][n\sum y_i^2 - (\sum y_i)^2]}}$ |
| **Power law** $y = ax^b$ | Linearize: $\ln y = \ln a + b \ln x$ |
| **Exponential** $y = ae^{bx}$ | Linearize: $\ln y = \ln a + bx$ |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Using Formulas Without Building the Table**  
> The most common error is arithmetic mistakes when computing $\sum x_i y_i$ and $\sum x_i^2$ in your head. Always build the 5-column table systematically — it takes 1 extra minute but prevents wrong answers.

> 🔴 **Trap 2: Forgetting to Verify with $(\bar{x}, \bar{y})$**  
> After computing $a_0$ and $a_1$, substitute $x = \bar{x}$ into the line. You should get $\hat{y} = \bar{y}$. This is a 5-second check that catches almost all arithmetic errors!

> 🔴 **Trap 3: Confusing $r$ with $r^2$ (Coefficient of Determination)**  
> $r$ = correlation coefficient (range $[-1, 1]$).  
> $r^2$ = coefficient of determination (range $[0, 1]$) = fraction of variance explained.  
> If a question asks for "goodness of fit", they may mean $r^2$, not $r$!
