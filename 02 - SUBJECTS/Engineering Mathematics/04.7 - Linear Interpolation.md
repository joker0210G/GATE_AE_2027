> 🎯 **GATE Weightage:** 2–4 marks per year. Interpolation is used to **estimate unknown values between known data points** without needing an analytical formula. Critical in aerodynamics (look-up tables for $C_L$, $C_D$), propulsion (turbine blade temperature), and structural analysis (material property tables). This note covers **all major interpolation methods tested in GATE**.

---

## 📌 Part I: The Interpolation Problem — Core Concept

### What Is Interpolation?
Given a **table of known values** $(x_0, y_0), (x_1, y_1), \ldots, (x_n, y_n)$, find the value of $y$ at some point $x = x^*$ that lies **between** the known $x$-values.

| Feature | Interpolation | Regression (Curve Fitting) |
|---|---|---|
| **Curve passes through points?** | ✅ YES — exactly | ❌ NO — best fit |
| **Used when data has errors?** | No (exact data) | Yes (noisy/experimental data) |
| **Purpose** | Estimate intermediate value | Find underlying trend |
| **GATE context** | Table look-up, ODE step methods | Performance data analysis |

---

## 🧠 Part II: Linear Interpolation — The Foundation

### 1. Two-Point Linear Interpolation

Given two known points $(x_0, y_0)$ and $(x_1, y_1)$, estimate $y$ at $x = x^*$:

$$\boxed{y^* = y_0 + \frac{(x^* - x_0)}{(x_1 - x_0)} \cdot (y_1 - y_0)}$$

**Geometric meaning:** This is simply the equation of the straight line through $(x_0, y_0)$ and $(x_1, y_1)$, evaluated at $x^*$.

---

### 2. Alternate Form: Slope-Point Form (Fastest for GATE)

$$\boxed{y^* = y_0 + \left(\frac{y_1 - y_0}{x_1 - x_0}\right)(x^* - x_0)}$$

where $m = \frac{y_1 - y_0}{x_1 - x_0}$ is the finite difference slope.

---

### 3. Error in Linear Interpolation

The truncation error is bounded by:
$$\boxed{|E| \leq \frac{(x_1 - x_0)^2}{8} \max|f''(x)|}$$

> ⚡ **GATE Insight:** Error is $O(h^2)$ where $h = x_1 - x_0$. Halving the step size reduces the error by a factor of **4** (2nd-order method).

---

## 🧠 Part III: Newton's Forward Difference Interpolation (Equally Spaced Data)

### When to Use
- Data is **equally spaced**: $x_0, x_0+h, x_0+2h, \ldots$
- You want to interpolate **near the beginning** of the table

### Finite Difference Notation

Define forward differences $\Delta$:

| Order | Formula | Notation |
|---|---|---|
| 1st forward diff. | $\Delta y_i = y_{i+1} - y_i$ | $\Delta y_0, \Delta y_1, \ldots$ |
| 2nd forward diff. | $\Delta^2 y_i = \Delta y_{i+1} - \Delta y_i$ | $\Delta^2 y_0, \ldots$ |
| $k$-th forward diff. | $\Delta^k y_i = \Delta^{k-1}y_{i+1} - \Delta^{k-1}y_i$ | $\Delta^k y_0$ |

### Forward Difference Table (Build this First!)

| $x$ | $y$ | $\Delta y$ | $\Delta^2 y$ | $\Delta^3 y$ | $\Delta^4 y$ |
|---|---|---|---|---|---|
| $x_0$ | $y_0$ | | | | |
| $x_1$ | $y_1$ | $\Delta y_0 = y_1 - y_0$ | | | |
| $x_2$ | $y_2$ | $\Delta y_1 = y_2 - y_1$ | $\Delta^2 y_0 = \Delta y_1 - \Delta y_0$ | | |
| $x_3$ | $y_3$ | $\Delta y_2 = y_3 - y_2$ | $\Delta^2 y_1 = \Delta y_2 - \Delta y_1$ | $\Delta^3 y_0 = \Delta^2 y_1 - \Delta^2 y_0$ | |
| $x_4$ | $y_4$ | $\Delta y_3 = y_4 - y_3$ | $\Delta^2 y_2 = \Delta y_3 - \Delta y_2$ | $\Delta^3 y_1 = \Delta^2 y_2 - \Delta^2 y_1$ | $\Delta^4 y_0 = \Delta^3 y_1 - \Delta^3 y_0$ |

---

### Newton's Forward Interpolation Formula (Gregory-Newton)

Define **substitution parameter** (dimensionless):
$$\boxed{s = \frac{x - x_0}{h}}$$

Then:
$$\boxed{y(x) = y_0 + s\,\Delta y_0 + \frac{s(s-1)}{2!}\Delta^2 y_0 + \frac{s(s-1)(s-2)}{3!}\Delta^3 y_0 + \cdots}$$

Or in compact form:
$$y(x) = \sum_{k=0}^{n} \binom{s}{k} \Delta^k y_0$$

where $\binom{s}{k} = \frac{s(s-1)(s-2)\cdots(s-k+1)}{k!}$.

---

## 🧠 Part IV: Newton's Backward Difference Interpolation (Equally Spaced Data)

### When to Use
- Data is **equally spaced**
- You want to interpolate **near the END** of the table

### Backward Difference Operator $\nabla$

$$\nabla y_i = y_i - y_{i-1} \qquad \nabla^2 y_i = \nabla y_i - \nabla y_{i-1} \qquad \text{etc.}$$

### Newton's Backward Interpolation Formula

Define substitution parameter from the END:
$$\boxed{s = \frac{x - x_n}{h}}$$

(Note: $s \le 0$ for values inside the table, $s = 0$ at $x_n$, $s = -1$ at $x_{n-1}$, etc.)

$$\boxed{y(x) = y_n + s\,\nabla y_n + \frac{s(s+1)}{2!}\nabla^2 y_n + \frac{s(s+1)(s+2)}{3!}\nabla^3 y_n + \cdots}$$

---

## 🧠 Part V: Lagrange Interpolation (Unequally Spaced Data — HIGH YIELD!)

### When to Use
- Data is **unevenly spaced** (non-uniform $x$-values)
- GATE's most commonly tested interpolation formula

### Lagrange Interpolating Polynomial

Given $n+1$ distinct data points $(x_0, y_0), (x_1, y_1), \ldots, (x_n, y_n)$:

$$\boxed{P(x) = \sum_{i=0}^{n} y_i \, L_i(x)}$$

where $L_i(x)$ is the **Lagrange Basis Polynomial**:

$$\boxed{L_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j}}$$

---

### Linear Lagrange (2 points, degree 1)

$$\boxed{P(x) = y_0 \cdot \frac{x - x_1}{x_0 - x_1} + y_1 \cdot \frac{x - x_0}{x_1 - x_0}}$$

This is exactly the **2-point linear interpolation formula** in disguise!

---

### Quadratic Lagrange (3 points, degree 2)

$$P(x) = y_0 \frac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)} + y_1 \frac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)} + y_2 \frac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)}$$

---

### Key Properties of Lagrange Basis Functions

| Property | Formula |
|---|---|
| **Cardinal property** | $L_i(x_j) = \delta_{ij} = \begin{cases} 1 & i=j \\ 0 & i\ne j \end{cases}$ |
| **Partition of unity** | $\sum_{i=0}^n L_i(x) = 1$ (for ALL $x$) |
| **Polynomial passes through all points** | $P(x_i) = y_i$ ✅ |

> ⚡ **Trick — "Partition of Unity":** $\sum L_i(x) = 1$ is a fast verification. If your computed $L_i$ values don't sum to 1, you made an arithmetic error!

---

### Error in Lagrange Interpolation

$$\boxed{|E_n(x)| = \frac{|f^{(n+1)}(\xi)|}{(n+1)!} \cdot |(x-x_0)(x-x_1)\cdots(x-x_n)|}$$

for some $\xi$ in $[x_0, x_n]$. Error is $O(h^{n+1})$ for degree-$n$ polynomial on equally spaced nodes.

---

## 🧠 Part VI: Newton's Divided Difference Interpolation (General — Unequal Spacing)

### Divided Differences Table

| Order | Notation | Formula |
|---|---|---|
| 0th | $f[x_i]$ | $= y_i$ |
| 1st | $f[x_i, x_{i+1}]$ | $= \frac{f[x_{i+1}] - f[x_i]}{x_{i+1} - x_i}$ |
| 2nd | $f[x_i, x_{i+1}, x_{i+2}]$ | $= \frac{f[x_{i+1},x_{i+2}] - f[x_i,x_{i+1}]}{x_{i+2} - x_i}$ |
| $k$-th | $f[x_0, \ldots, x_k]$ | $= \frac{f[x_1,\ldots,x_k] - f[x_0,\ldots,x_{k-1}]}{x_k - x_0}$ |

### Newton's Divided Difference Formula

$$\boxed{P(x) = f[x_0] + f[x_0,x_1](x-x_0) + f[x_0,x_1,x_2](x-x_0)(x-x_1) + \cdots}$$

$$= \sum_{k=0}^{n} f[x_0,x_1,\ldots,x_k] \prod_{j=0}^{k-1}(x - x_j)$$

> ⚡ **Relationship:** Newton's Divided Differences with **equal spacing** reduce exactly to Newton's Forward Differences (where $f[x_0,x_1,\ldots,x_k] = \frac{\Delta^k y_0}{k!\, h^k}$).

## ⚡ AIR-1 Speed Tricks & Mnemonics

### 🚀 Trick 1: Two-Point Linear — The "Proportion" Trick

The linear interpolation fraction $p = \frac{x^* - x_0}{x_1 - x_0}$ is just a proportion!

$$y^* = y_0 + p \cdot (y_1 - y_0) = (1-p)\, y_0 + p\, y_1$$

- If $x^*$ is **exactly midway** between $x_0$ and $x_1$: $p = 0.5 \implies y^* = \frac{y_0 + y_1}{2}$ (simple average!)
- In GATE, many linear interpolation problems reduce to "find the weighted average"

---

### 🚀 Trick 2: Lagrange MCQ Short-Cut — "Numerator-Denominator Pattern"

For 3-point Lagrange at $x = x^*$:
1. Write $(x^* - x_0)(x^* - x_1)(x^* - x_2)$ — call this $\omega$
2. Each $L_i = \frac{\omega / (x^* - x_i)}{(x_i - x_0)\cdots (x_i - x_{k\ne i})}$

This avoids expanding each bracket separately.

---

### 🚀 Trick 3: Newton's Forward — Terminate Early When Differences Become Zero
If all $k$th-order differences are zero (or negligibly small), stop at degree $k-1$. For example:
- A linear dataset has $\Delta^2 y = 0$ for all entries → Stop at $k=1$.
- A quadratic dataset has $\Delta^3 y = 0$ for all entries → Stop at $k=2$.
- This is how GATE asks "what degree polynomial fits this data?"

---

### 🚀 Trick 4: Interpolation vs. Extrapolation — AIR-1 Trap Awareness
- $x^*$ **inside** $[x_0, x_n]$: **Interpolation** ✅ (reliable)
- $x^*$ **outside** $[x_0, x_n]$: **Extrapolation** ⚠️ (Newton's Backward/Forward, not Lagrange — errors grow rapidly)

---

### 🧠 Mnemonic: "**FEB BEN LAG**" — Three Interpolation Methods

| Method | When | Mnemonic |
|---|---|---|
| **F**orward Differences | **E**qually spaced, near **B**eginning | **F-E-B** |
| **B**ackward Differences | **E**qually spaced, near **En**d | **B-E-N** |
| **Lag**range | **U**nequal spacing / any position | **LAG** |

---

### 🧠 Mnemonic: Newton's Forward Formula — "**SOME SQUARE CUBE**"

$$y = y_0 + s\Delta y_0 + \frac{s(s-1)}{2!}\Delta^2 y_0 + \frac{s(s-1)(s-2)}{3!}\Delta^3 y_0 + \cdots$$

- **S**ome: $+s\,\Delta y_0$ (1st order)
- **Sq**uare: $+\frac{s(s-1)}{2!}\Delta^2 y_0$ (2nd order — 2 falling factors)
- **Cu**be: $+\frac{s(s-1)(s-2)}{3!}\Delta^3 y_0$ (3rd order — 3 falling factors)

The numerator of the $k$th term always has $k$ **falling factorial** factors: $s(s-1)\cdots(s-k+1)$.

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Two-Point Linear Interpolation (GATE 1-Marker)
**Problem:** The speed of sound at altitude $h = 5$ km is found by interpolation:

| $h$ (km) | $a$ (m/s) |
|---|---|
| $4$ | $334.8$ |
| $6$ | $318.0$ |

Find $a$ at $h = 5$ km.

**Solution:**
$$a(5) = 334.8 + \frac{(5-4)}{(6-4)} \times (318.0 - 334.8) = 334.8 + \frac{1}{2} \times (-16.8)$$
$$= 334.8 - 8.4 = \mathbf{326.4 \text{ m/s}}$$

> Speed Trick: $h = 5$ is exactly midway → simple average: $\frac{334.8 + 318.0}{2} = 326.4$ ✅

$$\boxed{a(5) = 326.4 \text{ m/s}}$$

---

### Example 2: Newton's Forward Difference Interpolation (GATE 4-Marker)
**Problem:** Using Newton's Forward Interpolation, find $f(1.5)$ from:

| $x$ | $1.0$ | $2.0$ | $3.0$ | $4.0$ |
|---|---|---|---|---|
| $f(x)$ | $1$ | $8$ | $27$ | $64$ |

(This is $f(x) = x^3$; step size $h = 1$.)

**Solution:**
**Step 1:** Build Forward Difference Table:

| $x$ | $y$ | $\Delta y$ | $\Delta^2 y$ | $\Delta^3 y$ |
|---|---|---|---|---|
| 1.0 | 1 | | | |
| 2.0 | 8 | $8-1=7$ | | |
| 3.0 | 27 | $27-8=19$ | $19-7=12$ | |
| 4.0 | 64 | $64-27=37$ | $37-19=18$ | $18-12=6$ |

Top row values: $y_0=1$, $\Delta y_0 = 7$, $\Delta^2 y_0 = 12$, $\Delta^3 y_0 = 6$.

**Step 2:** Compute $s$: $x^* = 1.5$, $x_0 = 1.0$, $h = 1 \implies s = \frac{1.5 - 1.0}{1} = 0.5$.

**Step 3:** Apply Newton's Forward formula:
$$f(1.5) = 1 + (0.5)(7) + \frac{(0.5)(0.5-1)}{2}(12) + \frac{(0.5)(0.5-1)(0.5-2)}{6}(6)$$

$$= 1 + 3.5 + \frac{(0.5)(-0.5)}{2}(12) + \frac{(0.5)(-0.5)(-1.5)}{6}(6)$$

$$= 1 + 3.5 + \frac{-0.25}{2}(12) + \frac{0.375}{6}(6)$$

$$= 1 + 3.5 - 1.5 + 0.375 = \mathbf{3.375}$$

**Verification:** $f(1.5) = (1.5)^3 = 3.375$ ✅ (exact, since cubic → $\Delta^4 y = 0$)

$$\boxed{f(1.5) = 3.375}$$

---

### Example 3: Lagrange Interpolation (GATE 4-Marker, HIGH YIELD)
**Problem:** Using Lagrange interpolation, find $f(2)$ from unequally spaced data:

| $x$ | $0$ | $1$ | $3$ |
|---|---|---|---|
| $f(x)$ | $2$ | $3$ | $7$ |

**Solution:** $x_0=0, x_1=1, x_2=3$; $y_0=2, y_1=3, y_2=7$; $x^*=2$.

**Lagrange basis functions at $x=2$:**

$$L_0(2) = \frac{(2-1)(2-3)}{(0-1)(0-3)} = \frac{(1)(-1)}{(-1)(-3)} = \frac{-1}{3}$$

$$L_1(2) = \frac{(2-0)(2-3)}{(1-0)(1-3)} = \frac{(2)(-1)}{(1)(-2)} = \frac{-2}{-2} = 1$$

$$L_2(2) = \frac{(2-0)(2-1)}{(3-0)(3-1)} = \frac{(2)(1)}{(3)(2)} = \frac{2}{6} = \frac{1}{3}$$

**Verification (Partition of Unity):** $L_0 + L_1 + L_2 = -\frac{1}{3} + 1 + \frac{1}{3} = 1$ ✅

**Interpolated value:**
$$P(2) = 2\left(-\frac{1}{3}\right) + 3(1) + 7\left(\frac{1}{3}\right) = -\frac{2}{3} + 3 + \frac{7}{3} = -\frac{2}{3} + \frac{7}{3} + 3 = \frac{5}{3} + 3 = \frac{14}{3}$$

$$\boxed{f(2) \approx 4.667}$$

---

### Example 4: Newton's Divided Difference (GATE 3-Marker)
**Problem:** Build the divided difference table and find $P(1.5)$ for data:

| $x$ | $0$ | $1$ | $2$ | $4$ |
|---|---|---|---|---|
| $f(x)$ | $1$ | $3$ | $7$ | $21$ |

**Solution:**
**Divided Difference Table:**

| $x$ | $f[x]$ | 1st DD | 2nd DD | 3rd DD |
|---|---|---|---|---|
| 0 | 1 | | | |
| 1 | 3 | $\frac{3-1}{1-0}=2$ | | |
| 2 | 7 | $\frac{7-3}{2-1}=4$ | $\frac{4-2}{2-0}=1$ | |
| 4 | 21 | $\frac{21-7}{4-2}=7$ | $\frac{7-4}{4-1}=1$ | $\frac{1-1}{4-0}=0$ |

Newton's DD formula with $x^* = 1.5$:
$$P(1.5) = 1 + 2(1.5-0) + 1(1.5-0)(1.5-1) + 0(\cdots)$$
$$= 1 + 3 + 1(1.5)(0.5) = 1 + 3 + 0.75 = \mathbf{4.75}$$

$$\boxed{P(1.5) = 4.75}$$

> **Pattern Note:** 3rd divided difference = 0 → data fits a **quadratic** exactly.

## 📐 Master Comparison: All Interpolation Methods

| Method | Spacing | Best For | Formula Complexity |
|---|---|---|---|
| **2-Point Linear** | Any | Quick estimates between 2 points | ⭐ Easiest |
| **Newton's Forward** | Equal $h$ | Near beginning of table | ⭐⭐ Medium |
| **Newton's Backward** | Equal $h$ | Near end of table | ⭐⭐ Medium |
| **Lagrange** | Any | Unequal spacing, any position | ⭐⭐⭐ Higher |
| **Newton's Divided Diff.** | Any | Unequal spacing, adding new points | ⭐⭐⭐ Higher |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Wrong Sign on $s$ in Backward Formula**  
> In Newton's Backward formula, $s = (x - x_n)/h$ where $x_n$ is the **LAST** point. So if $x < x_n$, then $s < 0$. Students forget this and use $s = (x - x_0)/h$ (forward formula's $s$) for both. The sign flip in $s$ is critical for getting the right answer!

> 🔴 **Trap 2: Lagrange — Wrong Denominator Order**  
> The denominator of $L_i$ uses $(x_i - x_j)$ NOT $(x_j - x_i)$. One sign error in the denominator changes the entire answer. Write it systematically: numerator = "all $(x - x_j)$ for $j \ne i$", denominator = "all $(x_i - x_j)$ for $j \ne i$."

> 🔴 **Trap 3: Using Forward Formula for End-of-Table Values**  
> Newton's Forward formula gives large errors when $x^*$ is near the end of the table (large $s$). Always use **Backward** formula for end-of-table values and **Forward** for beginning. Using the wrong formula won't give a wrong ANSWER (both give the same polynomial!) but requires more terms for the same accuracy.

> 🔴 **Trap 4: Forgetting the Partition of Unity Check**  
> After computing all $L_i(x^*)$, verify $\sum L_i = 1$ before multiplying by $y_i$. This is a free 5-second sanity check that catches most arithmetic errors.
