> 🎯 **GATE Weightage:** 1–2 marks per paper. These are the core **descriptive statistics** — they summarize a data set with a single number. GATE tests both raw data and frequency-table calculations, as well as the relationship between mean/median/mode in skewed distributions. Often combined with variance questions.

---

## 📌 Part I: Measures of Central Tendency

### Three Measures — At a Glance

| Measure | What It Represents | Best For |
|---|---|---|
| **Mean** | Arithmetic average (balancing point) | Symmetric, no outliers |
| **Median** | Middle value | Skewed data or outliers present |
| **Mode** | Most frequent value | Categorical data, peaks |

---

## 🧠 Part II: Arithmetic Mean (AM)

### Raw (Ungrouped) Data — $n$ values $x_1, x_2, \ldots, x_n$

$$\boxed{\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n} = \frac{x_1 + x_2 + \cdots + x_n}{n}}$$

### Weighted Mean
When each $x_i$ has a weight $w_i$:
$$\boxed{\bar{x}_w = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}}$$

### Grouped (Frequency Table) Data
For data grouped with class midpoints $x_i$ and frequencies $f_i$:
$$\boxed{\bar{x} = \frac{\sum f_i x_i}{\sum f_i} = \frac{\sum f_i x_i}{N}}$$
where $N = \sum f_i$ = total number of observations.

### Key Properties of AM
1. $\sum (x_i - \bar{x}) = 0$ (deviations from mean sum to zero)
2. $\sum (x_i - \bar{x})^2$ is **minimized** (mean minimizes sum of squared deviations)
3. If all values increase by constant $c$: new mean = $\bar{x} + c$
4. If all values multiply by constant $c$: new mean = $c\bar{x}$
5. Combined mean of two groups: $\bar{x}_{combined} = \frac{n_1\bar{x}_1 + n_2\bar{x}_2}{n_1 + n_2}$

---

### Geometric Mean (GM) & Harmonic Mean (HM) — GATE Extras

$$\boxed{GM = \left(\prod_{i=1}^n x_i\right)^{1/n} = \sqrt[n]{x_1 \cdot x_2 \cdots x_n}}$$

$$\boxed{HM = \frac{n}{\sum_{i=1}^n \frac{1}{x_i}}}$$

**The AM-GM-HM Inequality (Always!):**
$$\boxed{HM \le GM \le AM}$$

Equality holds ONLY when all values are equal.

**When to use each:**
| Mean Type | Use Case |
|---|---|
| AM | Simple average, balanced data |
| GM | Growth rates, ratios, multiplicative quantities |
| HM | Speed, rate problems (average speed for equal distances) |

> ⚡ **Speed Trick for Average Speed:** If you travel equal distances at speeds $v_1$ and $v_2$:
> $$v_{avg} = HM(v_1, v_2) = \frac{2v_1 v_2}{v_1 + v_2}$$
> NOT the arithmetic mean!

---

## 🧠 Part III: Median

### Raw Ungrouped Data — Sort First!

Arrange values in ascending (or descending) order.

$$\text{Median} = \begin{cases} x_{(n+1)/2} & \text{if } n \text{ is odd} \\ \dfrac{x_{n/2} + x_{n/2+1}}{2} & \text{if } n \text{ is even} \end{cases}$$

### Grouped Data — Median Formula (GATE High Yield!)

$$\boxed{M = L + \frac{\left(\frac{N}{2} - F\right)}{f} \times h}$$

where:
- $L$ = Lower boundary of the **median class** (class containing the $N/2$-th value)
- $N = \sum f_i$ = total frequency
- $F$ = cumulative frequency of all classes BEFORE the median class
- $f$ = frequency of the median class
- $h$ = class width

**Step-by-step to find median class:**
1. Compute $N/2$
2. Build cumulative frequency column
3. Median class = first class where cumulative frequency $\ge N/2$

### Key Properties of Median
1. **Robust to outliers** — one extreme value doesn't shift the median much
2. $\sum |x_i - M|$ is **minimized** by the median (mean minimizes squared deviations; median minimizes absolute deviations)
3. For symmetric data: Median = Mean

---

## 🧠 Part IV: Mode

### Raw Data
Mode = the value that appears **most frequently**.
- **Unimodal:** one mode
- **Bimodal:** two modes
- **Multimodal:** more than two modes
- **No mode:** all values appear equally often

### Grouped Data — Modal Class Formula

$$\boxed{Z = L + \frac{f_1 - f_0}{2f_1 - f_0 - f_2} \times h}$$

where:
- $L$ = Lower boundary of the **modal class** (class with highest frequency)
- $f_1$ = frequency of modal class
- $f_0$ = frequency of class BEFORE modal class
- $f_2$ = frequency of class AFTER modal class
- $h$ = class width

### Key Properties of Mode
1. Mode need not be unique
2. Not affected by extreme values
3. Can be used for qualitative (categorical) data
4. In a symmetrical distribution: Mode = Median = Mean

---

## 🧠 Part V: Relationship Between Mean, Median, Mode (HIGH YIELD!)

### Empirical Relationship (Karl Pearson's Approximate Formula)

$$\boxed{\text{Mean} - \text{Mode} = 3(\text{Mean} - \text{Median})}$$

Rearranging:
$$\text{Mode} \approx 3\,\text{Median} - 2\,\text{Mean}$$

$$\text{Median} \approx \frac{2\,\text{Mean} + \text{Mode}}{3}$$

### Skewness and the Order of Mean, Median, Mode

| Distribution Type | Order | Tail Direction |
|---|---|---|
| **Symmetric** | Mode = Median = Mean | No tail (both equal) |
| **Positively skewed** (right-skewed) | Mode < Median < **Mean** | Long right tail |
| **Negatively skewed** (left-skewed) | **Mean** < Median < Mode | Long left tail |

> 🧠 **Mnemonic for Skew: "MOMED"**
> - **Mo**de, **Med**ian, **M**ean (in this order from left to right for positive skew)
> - Mean is pulled toward the tail (outliers drag the mean!)
> - **Mo**de stays at the peak; **Median** is middle; **M**ean follows the tail

## 🧠 Part VI: Measures of Dispersion

### 1. Range
$$\boxed{\text{Range} = x_{\max} - x_{\min}}$$

Simple, but highly sensitive to outliers.

---

### 2. Mean Deviation (MD) — About Mean or Median

$$\boxed{MD_{mean} = \frac{\sum |x_i - \bar{x}|}{n}} \qquad \boxed{MD_{median} = \frac{\sum |x_i - M|}{n}}$$

For grouped data: replace $\sum$ with $\sum f_i \cdot |\ldots|$ and $n$ with $N$.

> ⚡ **Key Fact:** $MD_{median} \le MD_{mean}$ (median minimizes mean absolute deviation)

---

### 3. Variance & Standard Deviation (MOST IMPORTANT!)

**Population Variance:**
$$\boxed{\sigma^2 = \frac{\sum_{i=1}^n (x_i - \bar{x})^2}{n} = \frac{\sum x_i^2}{n} - \bar{x}^2}$$

**Population Standard Deviation:**
$$\boxed{\sigma = \sqrt{\sigma^2}}$$

**Sample Variance (Bessel's Correction — $n-1$ denominator):**
$$\boxed{s^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}}$$

> ⚡ **GATE rule:** Unless stated "sample variance" or "unbiased estimate," use $n$ in denominator (population variance). GATE AE typically deals with population statistics.

### Computational Shortcut for Variance:

$$\boxed{\sigma^2 = \frac{\sum x_i^2}{n} - \left(\frac{\sum x_i}{n}\right)^2 = \overline{x^2} - (\bar{x})^2}$$

**In words:** "Mean of squares minus square of mean" — **MSM – SM²**

### For Grouped Data:
$$\sigma^2 = \frac{\sum f_i x_i^2}{N} - \bar{x}^2$$

---

### 4. Coefficient of Variation (CV) — Relative Dispersion

$$\boxed{CV = \frac{\sigma}{\bar{x}} \times 100\%}$$

Use CV to compare variability of two different datasets with different units or scales.

---

### 5. Quartiles & Percentiles

$$Q_1 = \text{25th percentile}, \quad Q_2 = Q_{50} = \text{Median}, \quad Q_3 = \text{75th percentile}$$

**Interquartile Range (IQR):**
$$\boxed{IQR = Q_3 - Q_1}$$

**For grouped data (Quartile formula):**
$$Q_k = L + \frac{\left(\frac{kN}{4} - F\right)}{f} \times h \quad (k = 1, 2, 3)$$

---

## ⚡ AIR-1 Speed Tricks & Mnemonics

### 🚀 Trick 1: "MSM – SM²" for Variance (Zero Computation Wasted)
$$\sigma^2 = \underbrace{\frac{\sum x_i^2}{n}}_{\text{Mean of Squares}} - \underbrace{\left(\bar{x}\right)^2}_{\text{Square of Mean}}$$

Build one table with columns $x_i$, $x_i^2$ and sum both. Never expand $(x_i - \bar{x})^2$!

---

### 🚀 Trick 2: Combined Mean Shortcut
Two groups: $n_1 = 10$, $\bar{x}_1 = 20$; $n_2 = 15$, $\bar{x}_2 = 30$.
$$\bar{x}_{combined} = \frac{10(20) + 15(30)}{10+15} = \frac{200+450}{25} = \frac{650}{25} = 26$$
No need to list all 25 values!

---

### 🚀 Trick 3: "Mode from Median and Mean" (Karl Pearson's Formula)
If you know Mean and Median:
$$\text{Mode} = 3\,\text{Median} - 2\,\text{Mean}$$
This is a guaranteed 1-marker if mean and median are given and mode is asked!

---

### 🚀 Trick 4: Variance Under Linear Transformation
If $y = ax + b$, then:
$$\bar{y} = a\bar{x} + b \qquad \sigma_y^2 = a^2 \sigma_x^2 \qquad \sigma_y = |a|\sigma_x$$

Note: **Adding a constant $b$ does NOT change variance or SD** (it shifts but doesn't spread/compress). Only multiplication by $a$ affects variance.

---

### 🚀 Trick 5: Finding Missing Values from Mean/Variance
If mean of $n$ values is $\bar{x}$, and one value $x_k$ is unknown:
$$x_k = n\bar{x} - \sum_{\text{other}} x_i$$

If variance is given too, set up $\overline{x^2} - \bar{x}^2 = \sigma^2$ and solve for $x_k^2$ → find $x_k$.

---

### 🧠 Mnemonic: "**MOMED**" — Skewness Order

| Distribution | Order (left → right) |
|---|---|
| Positive skew | **Mo**de, **Med**ian, **M**ean (🡒 tail pulls mean right) |
| Negative skew | **M**ean, **Med**ian, **Mo**de (🡐 tail pulls mean left) |
| Symmetric | All Three Equal |

> Remember: **Mean follows the tail** (extreme values drag the mean). Mode stays at the peak.

---

### 🧠 Mnemonic: "**VAMP**" for Dispersion Measures
- **V**ariance: $\sigma^2 = \overline{x^2} - \bar{x}^2$
- **A**verage deviation: MD = $\frac{\sum|x_i - \bar{x}|}{n}$
- **M**ode minimizes nothing special; **M**edian minimizes $\sum|x-M|$; **M**ean minimizes $\sum(x-\bar{x})^2$
- **P**earson's rule: Mode = 3 Median − 2 Mean

---

## 📝 Step-by-Step Solved GATE Examples

### Example 1: Mean, Median, Mode from Raw Data (GATE 1-Marker)
**Problem:** Find mean, median, and mode of: $3, 5, 7, 5, 8, 2, 5, 9, 4, 1$

**Solution:**
Sorted: $1, 2, 3, 4, 5, 5, 5, 7, 8, 9$ ($n = 10$)

**Mean:** $\bar{x} = \frac{1+2+3+4+5+5+5+7+8+9}{10} = \frac{49}{10} = \mathbf{4.9}$

**Median:** $n=10$ (even): $M = \frac{x_5 + x_6}{2} = \frac{5+5}{2} = \mathbf{5}$

**Mode:** Most frequent value = $5$ (appears 3 times) = $\mathbf{5}$

Since Mean (4.9) < Median (5) = Mode (5): **Slightly negatively skewed** (mean pulled left by values 1, 2, 3).

$$\boxed{\bar{x} = 4.9, \quad M = 5, \quad Z = 5}$$

---

### Example 2: Variance Using Shortcut Formula (GATE 2-Marker)
**Problem:** Find variance of: $2, 4, 6, 8, 10$

**Solution (using MSM – SM² trick):**

$\sum x_i = 30$, $n = 5$, $\bar{x} = 6$

$\sum x_i^2 = 4 + 16 + 36 + 64 + 100 = 220$

$$\sigma^2 = \frac{220}{5} - 6^2 = 44 - 36 = \mathbf{8}$$

Standard deviation: $\sigma = \sqrt{8} = 2\sqrt{2} \approx 2.83$

$$\boxed{\sigma^2 = 8, \quad \sigma = 2\sqrt{2}}$$

---

### Example 3: Mode from Mean and Median (GATE 1-Marker)
**Problem:** For a dataset, mean = 35 and median = 33. Find the mode.

**Solution (Pearson's empirical formula):**
$$\text{Mode} = 3\,\text{Median} - 2\,\text{Mean} = 3(33) - 2(35) = 99 - 70 = \mathbf{29}$$

Check skewness: Mean (35) > Median (33) > Mode (29) → **Positively skewed** ✅

$$\boxed{\text{Mode} = 29}$$

---

### Example 4: Grouped Data Mean & Variance (GATE 3-Marker)
**Problem:** Find mean and variance for the following:

| Class | Frequency $f_i$ |
|---|---|
| 0–10 | 4 |
| 10–20 | 8 |
| 20–30 | 12 |
| 30–40 | 10 |
| 40–50 | 6 |

**Solution:**
Midpoints: 5, 15, 25, 35, 45. $N = 40$.

| Class | $x_i$ | $f_i$ | $f_i x_i$ | $f_i x_i^2$ |
|---|---|---|---|---|
| 0–10 | 5 | 4 | 20 | 100 |
| 10–20 | 15 | 8 | 120 | 1800 |
| 20–30 | 25 | 12 | 300 | 7500 |
| 30–40 | 35 | 10 | 350 | 12250 |
| 40–50 | 45 | 6 | 270 | 12150 |
| **Σ** | — | **40** | **1060** | **33800** |

$$\bar{x} = \frac{1060}{40} = \mathbf{26.5}$$

$$\sigma^2 = \frac{33800}{40} - (26.5)^2 = 845 - 702.25 = \mathbf{142.75}$$

$$\sigma = \sqrt{142.75} \approx \mathbf{11.95}$$

$$\boxed{\bar{x} = 26.5, \quad \sigma^2 = 142.75, \quad \sigma \approx 11.95}$$

---

### Example 5: Combined Mean & Variance (GATE 3-Marker)
**Problem:** Group A: $n_1=50$, $\bar{x}_1=63$, $\sigma_1=9$. Group B: $n_2=100$, $\bar{x}_2=57$, $\sigma_2=6$. Find the combined mean and standard deviation.

**Solution:**
**Combined Mean:**
$$\bar{x}_{12} = \frac{50(63)+100(57)}{150} = \frac{3150+5700}{150} = \frac{8850}{150} = \mathbf{59}$$

**Combined Variance (requires $d_i = \bar{x}_i - \bar{x}_{12}$):**
$$d_1 = 63 - 59 = 4, \qquad d_2 = 57 - 59 = -2$$

$$\sigma_{12}^2 = \frac{n_1(\sigma_1^2 + d_1^2) + n_2(\sigma_2^2 + d_2^2)}{n_1 + n_2}$$

$$= \frac{50(81+16) + 100(36+4)}{150} = \frac{50(97) + 100(40)}{150} = \frac{4850 + 4000}{150} = \frac{8850}{150} = \mathbf{59}$$

$$\sigma_{12} = \sqrt{59} \approx \mathbf{7.68}$$

$$\boxed{\bar{x}_{12} = 59, \quad \sigma_{12} \approx 7.68}$$

## 📐 Master Formula Reference Card

| Measure | Formula (Ungrouped) | Formula (Grouped) |
|---|---|---|
| **AM** | $\frac{\sum x_i}{n}$ | $\frac{\sum f_i x_i}{N}$ |
| **GM** | $(\prod x_i)^{1/n}$ | — |
| **HM** | $\frac{n}{\sum 1/x_i}$ | — |
| **Median** | Middle value after sorting | $L + \frac{N/2 - F}{f} \times h$ |
| **Mode** | Most frequent | $L + \frac{f_1-f_0}{2f_1-f_0-f_2} \times h$ |
| **Variance** | $\overline{x^2} - \bar{x}^2$ | $\frac{\sum f_i x_i^2}{N} - \bar{x}^2$ |
| **SD** | $\sqrt{\sigma^2}$ | $\sqrt{\sigma^2}$ |
| **CV** | $\frac{\sigma}{\bar{x}} \times 100\%$ | Same |
| **Pearson's** | Mode ≈ $3M - 2\bar{x}$ | Same |
| **Skew positive** | $\bar{x} > M > Z$ | Mean > Median > Mode |
| **Skew negative** | $\bar{x} < M < Z$ | Mean < Median < Mode |

## ⚠️ Common Exam Traps & Pitfalls

> 🔴 **Trap 1: Using $n$ vs $(n-1)$ in Variance**  
> Population variance uses $n$; sample variance (unbiased estimate) uses $n-1$. GATE almost always expects $n$ (population). If the problem says "sample variance" or "estimate of population variance," use $n-1$. Default to $n$.

> 🔴 **Trap 2: Average Speed ≠ Arithmetic Mean of Speeds**  
> For equal distances at different speeds $v_1, v_2$: use $v_{avg} = HM = \frac{2v_1v_2}{v_1+v_2}$, NOT $\frac{v_1+v_2}{2}$. This is a classic 1-marker trap!

> 🔴 **Trap 3: Adding Constant Doesn't Change Variance**  
> If every data point increases by 5: the mean increases by 5, but variance stays the SAME. Students often multiply the variance by 5 (confusing with multiplication transformation). Only multiplication by $a$ scales variance by $a^2$.

> 🔴 **Trap 4: Median Class vs. Modal Class**  
> Median class: where cumulative frequency first reaches $N/2$.  
> Modal class: class with the HIGHEST frequency $f_1$.  
> They are different! Use the correct formula for each (the two formulas are similar but use different quantities).
