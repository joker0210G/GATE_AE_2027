## 🧠 Part I: Reynolds Transport Theorem — The Master Bridge

### 1.1 The Core Equation

For any **extensive** fluid property $N$ with corresponding **intensive** property $\eta = N/m$ (property per unit mass):

$$\mathbf{\frac{dN_{\text{sys}}}{dt} = \frac{\partial}{\partial t}\iiint_{\text{CV}} \eta\,\rho\,d\mathcal{V} + \iint_{\text{CS}} \eta\,\rho\,(\vec{V}\cdot\hat{n})\,dA}$$

| Term | Physical Meaning |
|---|---|
| $\frac{dN_{\text{sys}}}{dt}$ | Rate of change of property $N$ for the closed system (Lagrangian) |
| $\frac{\partial}{\partial t}\iiint_{\text{CV}} \eta\,\rho\,d\mathcal{V}$ | Rate of **accumulation** of $N$ inside the fixed CV |
| $\iint_{\text{CS}} \eta\,\rho\,(\vec{V}\cdot\hat{n})\,dA$ | Net **outflow** of $N$ through the control surface |
| $\hat{n}$ | **Outward** unit normal to the CS (always outward!) |

### 1.2 The Three Laws from RTT

| Conservation Law | $N$ (Extensive) | $\eta$ (Intensive) | System Rate | Result |
|---|---|---|---|---|
| **Mass (Continuity)** | $m$ | $1$ | $= 0$ (mass conserved) | Integral continuity |
| **Linear Momentum** | $m\vec{V}$ | $\vec{V}$ | $= \sum\vec{F}_{\text{ext}}$ | Integral momentum |
| **Energy** | $E$ | $u + \frac{V^2}{2} + gz$ | $= \dot{Q} - \dot{W}_s$ | Energy/Bernoulli |

### 1.3 The Critical CV Discipline Checklist

Run this every time before writing any equation:

```
CV CHECKLIST — 30-Second Discipline Protocol
┌─────────────────────────────────────────────────────────────┐
│ 1. DRAW the CV. Cut surfaces ⊥ to flow. Include the body    │
│    whose reaction force you want inside the CV boundary.    │
│ 2. LABEL: every inlet (V̂·n̂ < 0) and outlet (V̂·n̂ > 0).   │
│ 3. PRESSURES: use GAUGE everywhere when any opening is at   │
│    atmosphere (atmospheric forces cancel on closed surface). │
│ 4. STEADY? → Delete ∂/∂t accumulation term.                 │
│ 5. HORIZONTAL? → Delete ρgz gravity terms.                  │
│ 6. WRITE component-by-component, never as one grand vector. │
└─────────────────────────────────────────────────────────────┘
```

> ⚠️ **Atmospheric Pressure Cancellation Law:** For any CV with at least one opening to atmosphere, using **gauge pressures** at ALL cuts automatically cancels the atmospheric contribution on all closed surfaces. This is the #1 rule violated in momentum problems.

## 🧠 Part II: Integral Continuity Equation

### 2.1 General (Unsteady) Form

Setting $\eta = 1$, $\frac{dm_{\text{sys}}}{dt} = 0$:

$$\mathbf{\frac{\partial}{\partial t}\iiint_{\text{CV}} \rho\,d\mathcal{V} + \iint_{\text{CS}} \rho\,(\vec{V}\cdot\hat{n})\,dA = 0}$$

$$\underbrace{\frac{\partial}{\partial t}\iiint_{\text{CV}} \rho\,d\mathcal{V}}_{\text{Mass accumulation rate in CV}} + \underbrace{\sum \dot{m}_{\text{out}} - \sum \dot{m}_{\text{in}}}_{\text{Net mass outflow rate}} = 0$$

### 2.2 Engineering Specializations

```
┌──────────────────────┬───────────────────────────────────────────┐
│ Flow Condition       │ Simplified Form                           │
├──────────────────────┼───────────────────────────────────────────┤
│ Steady any fluid     │ Σṁ_out = Σṁ_in                          │
│                      │ ρ₁A₁V₁ = ρ₂A₂V₂ = ṁ                   │
├──────────────────────┼───────────────────────────────────────────┤
│ Steady incompressible│ A₁V₁ = A₂V₂ = Q (volume flow)           │
│ (ρ = const)          │ ṁ = ρQ                                   │
├──────────────────────┼───────────────────────────────────────────┤
│ Unsteady (tank fill) │ dM_CV/dt = ṁ_in - ṁ_out                │
│                      │ ρA(dh/dt) = ṁ_in - ρA_e·V_e             │
├──────────────────────┼───────────────────────────────────────────┤
│ Multi-port junction  │ Σᵢ ρᵢAᵢVᵢ (in) = Σⱼ ρⱼAⱼVⱼ (out)     │
└──────────────────────┴───────────────────────────────────────────┘
```

### 2.3 Logarithmic Quasi-1D Nozzle Form

For steady compressible flow through a duct: $\rho A V = \dot{m} = \text{const}$

Taking $\ln$ and differentiating:

$$\frac{d\rho}{\rho} + \frac{dA}{A} + \frac{dV}{V} = 0$$

Combined with Euler's equation and $a^2 = dp/d\rho$:

$$\mathbf{\frac{dA}{A} = (M^2 - 1)\frac{dV}{V}}$$

| Mach | $M^2-1$ | Behavior |
|---|---|---|
| $M < 1$ subsonic | $< 0$ | Converging → accelerates; Diverging → decelerates |
| $M = 1$ sonic | $= 0$ | $dA = 0$ → **throat is area minimum** |
| $M > 1$ supersonic | $> 0$ | Diverging → accelerates; Converging → decelerates |

> ⚠️ **AIR-1 Trap:** The supersonic area-velocity relationship is the **OPPOSITE** of subsonic intuition. A diverging channel decelerates subsonic flow but **accelerates** supersonic flow. This is the planted conceptual MCQ every year.

## 🧠 Part III: Integral Momentum Equation

### 3.1 The Governing Equation

Setting $\eta = \vec{V}$, $\frac{dP_{\text{sys}}}{dt} = \sum\vec{F}_{\text{ext}}$:

$$\mathbf{\sum\vec{F}_{\text{ext}} = \frac{\partial}{\partial t}\iiint_{\text{CV}} \rho\vec{V}\,d\mathcal{V} + \iint_{\text{CS}} \rho\vec{V}\,(\vec{V}\cdot\hat{n})\,dA}$$

For **steady flow, 1D ports**, per Cartesian component:

$$\sum F_x = \sum_{\text{out}} \dot{m}\,u_{\text{out}} - \sum_{\text{in}} \dot{m}\,u_{\text{in}} = \dot{m}(u_{\text{out}} - u_{\text{in}})$$

### 3.2 Forces Breakdown

$$\sum\vec{F}_{\text{ext}} = \underbrace{\iint_{\text{CS}} (-p\hat{n})\,dA}_{\text{Pressure forces}} + \underbrace{\vec{R}}_{\text{Reaction/anchor}} + \underbrace{\iiint_{\text{CV}} \rho\vec{g}\,d\mathcal{V}}_{\text{Body forces}}$$

### 3.3 Momentum Correction Factor $\beta$

For non-uniform velocity profiles (e.g., laminar pipe flow):

$$\beta = \frac{1}{A\bar{V}^2}\iint_A u^2\,dA$$

| Profile | $\beta$ | Consequence of ignoring |
|---|---|---|
| Uniform | $1.000$ | None |
| Turbulent pipe (1/7 law) | $\approx 1.020$ | ~2% error |
| Laminar 2D channel | $\frac{6}{5} = 1.200$ | 20% error |
| Laminar circular pipe (parabolic) | $\frac{4}{3} = 1.333$ | **33% error** |

> 🔴 **Non-Negotiable:** For laminar pipe flow problems, $\beta = 4/3$. Using $\beta = 1$ in these problems causes a 33% error in the momentum flux — a guaranteed wrong answer.

### 3.4 Jet Engine / Rocket Thrust

$$\mathbf{T = \dot{m}_e V_e - \dot{m}_a V_0 + (p_e - p_a)A_e}$$

| Term | Name | When non-zero |
|---|---|---|
| $\dot{m}_e V_e$ | Momentum thrust | Always |
| $-\dot{m}_a V_0$ | Intake momentum drag | In flight (not on test stand with still air) |
| $(p_e - p_a)A_e$ | Pressure thrust | When nozzle not ideally expanded |

> 🎯 **Key Memory:** Ideally expanded nozzle: $p_e = p_a$ → pressure thrust = 0. Under-expanded ($p_e > p_a$): positive pressure thrust bonus. Over-expanded: negative penalty.

## 🧠 Part IV: Bernoulli Equation — Derivation, Forms & Validity Fence

### 4.1 Derivation from Euler's Equation (Exam-Standard Proof)

Apply Newton's second law to a fluid sliver of cross-section $dA$, length $ds$ along a streamline, rising by $dz$. For **steady, inviscid** flow:

$$p\,dA - (p+dp)\,dA - \rho g\,dA\,dz = \rho\,dA\,ds\cdot V\frac{dV}{ds}$$

Dividing by $\rho\,dA\,ds$:

$$\frac{dp}{\rho} + V\,dV + g\,dz = 0 \quad \text{(Euler along streamline)}$$

Integrating with $\rho = \text{const}$ (incompressible):

$$\mathbf{p + \frac{1}{2}\rho V^2 + \rho g z = H = \text{constant along a streamline}}$$

### 4.2 Three Forms of Bernoulli

$$p + \frac{1}{2}\rho V^2 + \rho g z = H \qquad \text{[Pressure form, Pa]}$$

$$\frac{p}{\rho g} + \frac{V^2}{2g} + z = H_h \qquad \text{[Head form, m]}$$

$$\frac{p}{\rho} + \frac{V^2}{2} + gz = h_0 \qquad \text{[Energy form, J/kg]}$$

### 4.3 Pressure Vocabulary (GATE Essential)

| Pressure Type | Symbol | Formula | Physical Meaning |
|---|---|---|---|
| **Static pressure** | $p$ | measured by wall tap / static port | Molecular bombardment; "what the gas feels at rest" |
| **Dynamic pressure** | $q$ | $\frac{1}{2}\rho V^2$ | Kinetic energy per unit volume |
| **Stagnation (total) pressure** | $p_0$ | $p + q$ | Energy if flow brought isentropically to rest |
| **Pressure coefficient** | $C_p$ | $\frac{p - p_\infty}{q_\infty}$ | Normalized pressure; stagnation point: $C_p = 1$ |
| **Piezometric head** | — | $p/(\rho g) + z$ | Constant across cross-sections in hydrostatic limit |

### 4.4 The Validity Fence — 5 Non-Negotiable Assumptions

```
┌──────────────────────────────────────────────────────────────────┐
│                  BERNOULLI VALIDITY FENCE                         │
├───────────────────┬──────────────────────────────────────────────┤
│ ASSUMPTION        │ CONSEQUENCE OF VIOLATION                     │
├───────────────────┼──────────────────────────────────────────────┤
│ 1. Steady flow    │ Add ρ∂φ/∂t term (unsteady Bernoulli)        │
│    ∂/∂t = 0       │ Needed for: water hammer, piston flows       │
├───────────────────┼──────────────────────────────────────────────┤
│ 2. Incompressible │ Use isentropic stagnation relations          │
│    ρ = const      │ Required when: M > 0.3 (>1% density change) │
├───────────────────┼──────────────────────────────────────────────┤
│ 3. Inviscid       │ Add head loss h_L (energy equation)         │
│    μ = 0          │ Needed for: pipe friction, sudden expansion  │
├───────────────────┼──────────────────────────────────────────────┤
│ 4. Along a        │ Same H only if flow is IRROTATIONAL globally │
│    streamline     │ Rotational flows: H differs per streamline   │
├───────────────────┼──────────────────────────────────────────────┤
│ 5. No shaft work  │ Add pump head h_P or turbine head h_T       │
│    between points │ Full energy equation required                │
└───────────────────┴──────────────────────────────────────────────┘
```

### 4.5 Extended Energy Equation (When Bernoulli Fails)

For real pipe systems with pump head $h_P$, turbine head $h_T$, friction loss $h_L$, and kinetic energy correction factor $\alpha$ (laminar pipe: $\alpha = 2$; turbulent: $\alpha \approx 1.05$):

$$\frac{p_1}{\rho g} + \alpha_1\frac{V_1^2}{2g} + z_1 + h_P = \frac{p_2}{\rho g} + \alpha_2\frac{V_2^2}{2g} + z_2 + h_T + h_L$$

### Quick-Reference Summary

**Incompressible Bernoulli ($M < 0.3$):**

$$V_\infty = \sqrt{\frac{2(p_0 - p_\infty)}{\rho_\infty}} = \sqrt{\frac{2\Delta p}{\rho_\infty}}$$

**With manometer (gauge fluid $\rho_m$, stream fluid $\rho_f$, deflection $h$):**

$$\Delta p = (\rho_m - \rho_f)gh \qquad V_\infty = \sqrt{\frac{2(\rho_m - \rho_f)gh}{\rho_f}}$$

**Validity check (always run this):**

$$a = \sqrt{\gamma RT}, \qquad M = \frac{V_\infty}{a} \stackrel{?}{<} 0.3$$

**Altitude speed ratio shortcut (GATE 2023 Q34):**

$$\frac{V_A}{V_B} = \sqrt{\frac{\rho_B}{\rho_A}} \quad \text{(same } \Delta p \text{ at both altitudes)}$$

Exit: $A_2 = 0.1\text{ m}^2$, $p_2 = 150\text{ kPa}$, $T_2 = 50°C$. $R = 287\text{ J/(kg·K)}$. Find: (a) mass flow rate $\dot{m}$, (b) exit velocity $V_2$, (c) what incompressible $A_1V_1 = A_2V_2$ wrongly predicts.

>

>
> $$T_1 = 303\text{ K}, \quad T_2 = 323\text{ K}$$
>
> **Step 2 — Inlet density (ideal gas):**

>
> **Step 3 — Mass flow:**
>
> $$\dot{m} = \rho_1 A_1 V_1 = 2.300 \times 0.2 \times 100 = \mathbf{46.0\text{ kg/s}}$$
>
> **Step 4 — Exit density:**
>
> $$\rho_2 = \frac{150000}{287 \times 323} = 1.618\text{ kg/m}^3$$
>

>
> $$V_2 = \frac{\dot{m}}{\rho_2 A_2} = \frac{46.0}{1.618 \times 0.1} = \mathbf{284.3\text{ m/s}}$$
>
> **Step 6 — Incompressible illusion:**
>
> $$V_2^{\text{wrong}} = \frac{A_1}{A_2}V_1 = \frac{0.2}{0.1}\times 100 = 200\text{ m/s} \quad (\mathbf{30\%\text{ error}!})$$
>
> **GATE Bands:** (a) $[45.5, 46.5]$ kg/s · (b) $[282, 286]$ m/s

> **TCS Keystrokes:**

### PYQ-D1-02: Nozzle Anchoring Force (NAT) ⭐⭐⭐

### PYQ-D1-04: 90° Pipe Bend Force (NAT) ⭐⭐
**Problem:** Water at 5 m/s through a horizontal 90° bend of uniform diameter 100 mm. Gauge pressure throughout = 100 kPa. Find the resultant force required to hold the bend (N).

> [!faq]- 🔍 View Full Solution
>
> $A = \pi(0.05)^2 = 0.007854\text{ m}^2$; $\dot{m} = 1000 \times 0.007854 \times 5 = 39.27\text{ kg/s}$
>
> Flow enters in $+x$ direction, exits in $+y$ direction:
>
> $x$-component: $\sum F_x = \dot{m}(u_{\text{out}} - u_{\text{in}}) = \dot{m}(0 - V) = -39.27 \times 5 = -196.3\text{ N}$
>
> Pressure force in $x$: $+pA = +100000 \times 0.007854 = +785.4\text{ N}$ (inlet pushes water in +x)
>
> Outlet pressure in $-y$: $-pA = -785.4\text{ N}$ (outlet acts in $-y$ on CS)
>
> Force of **bend on water**: $R_x = \dot{m}(0-V) - pA_{\text{in}} = -196.3 - 785.4 = -981.7\text{ N}$
>
> $R_y = \dot{m}(V - 0) + pA_{\text{out}} = +196.3 + 785.4 = +981.7\text{ N}$
>
> Force of **water on bend** (Newton III): $(-R_x, -R_y) = (+981.7, -981.7)\text{ N}$
>
> Magnitude: $F = \sqrt{981.7^2 + 981.7^2} = 981.7\sqrt{2} = \mathbf{1388\text{ N}}$
>
> **GATE Band:** $[1380, 1395]$ N

### PYQ-D1-05: Torricelli Drain + Orifice Coefficient (NAT) ⭐
**Problem:** Tank with water 5 m deep, small orifice at base, $C_d = 0.62$. Find actual exit velocity (m/s) and volume flow rate if orifice diameter is 30 mm.

> [!faq]- 🔍 View Full Solution
>
> Ideal Torricelli velocity: $V_{\text{ideal}} = \sqrt{2gh} = \sqrt{2 \times 9.81 \times 5} = 9.905\text{ m/s}$
>
> Actual velocity: $V_{\text{actual}} = C_v \times V_{\text{ideal}}$. For $C_d = C_v \times C_c$, if $C_c = 1$ (sharp-edged): $V = 0.62 \times 9.905 = \mathbf{6.14\text{ m/s}}$
>
> Area: $A = \pi(0.015)^2 = 7.069\times10^{-4}\text{ m}^2$
>
> $Q = C_d \times A \times V_{\text{ideal}} = 0.62 \times 7.069\times10^{-4} \times 9.905 = \mathbf{4.34\times10^{-3}\text{ m}^3\text{/s}}$
>
> **GATE Band:** $V: [6.10, 6.18]$ m/s · $Q: [4.30, 4.38]\times10^{-3}$ m³/s

## ⚠️ Part VIII: Master Trap Catalog

> 🔴 **Trap 1: Celsius in Ideal Gas Law**
> $T_1 = 30°C$ → MUST use $303\text{ K}$. Using $30\text{ K}$ gives density 100× too large. Sanity check: air density ≈ $1.0$–$2.5\text{ kg/m}^3$ at typical conditions — anything outside this range means you used Celsius.

> 🔴 **Trap 2: Absolute vs Gauge Pressure in CV Momentum**
> Using absolute pressure at the exit jet opening (gauge = 0) adds $p_{atm} \times A_e \approx 800\text{ N}$ for a 100 mm nozzle. Use gauge EVERYWHERE when any port opens to atmosphere.

> 🔴 **Trap 3: Missing the Fluid Column Subtraction in Manometers**
> Mercury pitot in a water tunnel: $\Delta p = (13600 - 1000) \times 9.81 \times h = 12600\text{ ...}$, NOT $13600\text{ ...}$. For air tunnels the error is tiny (1.225 vs 0), but for water: 8% error. Subtract always.

> 🔴 **Trap 4: Area-Velocity Intuition Flip at $M > 1$**
> Diverging section → decelerates subsonic flow → **accelerates** supersonic flow. This is the $M^2 - 1$ sign change. Drawing a converging-diverging nozzle and forgetting which regime you're in is the most common compressible flow MCQ error.

> 🔴 **Trap 5: Momentum Correction Factor $\beta = 4/3$ for Laminar Pipe**
> Using $\beta = 1$ (uniform profile assumption) in a laminar pipe flow problem underestimates momentum flux by 33%. GATE explicitly tests this. Recognize the trigger word: "fully developed laminar flow in a circular pipe."

> 🔴 **Trap 6: Bernoulli Constant Across Streamlines**
> $p + \frac{1}{2}\rho V^2 = \text{const}$ applies globally (across streamlines) ONLY when the flow is irrotational ($\nabla\times\vec{V} = 0$). For rotational flows, the Bernoulli constant is per-streamline. This is the most tested conceptual MCQ on Bernoulli.

> 🔴 **Trap 7: $\rho$ in Pitot Formula is STREAM Density, not Manometer Density**
> $V = \sqrt{2\Delta p / \rho_{\text{stream}}}$. Never divide by $\rho_m$ (manometer fluid). After calculating $\Delta p$ from the manometer, plug in the stream density ($\rho_{\text{air}}$, $\rho_{\text{water}}$) for the velocity formula.

## 🃏 Part X: Flashcard Battery (Foldable)

> [!question]- 🃏 Flashcard: RTT — Say It From Memory
> **Question:** Write the RTT equation, naming every symbol. What does $\hat{n}$ convention produce at outflow vs inflow?
> > [!success]- **Answer & AIR-1 Traps:**
> > $$\frac{dN_{\text{sys}}}{dt} = \frac{\partial}{\partial t}\iiint_{\text{CV}} \eta\rho\,d\mathcal{V} + \iint_{\text{CS}} \eta\rho(\vec{V}\cdot\hat{n})\,dA$$
> > $\hat{n}$ = **outward** unit normal. Outflow: $\vec{V}\cdot\hat{n} > 0$ (positive flux). Inflow: $\vec{V}\cdot\hat{n} < 0$ (negative flux).
> > ⚠️ Trap: If $\hat{n}$ is defined inward (rare), all signs flip — the standard is always outward.

> [!question]- 🃏 Flashcard: Bernoulli — 5 Assumptions (Speed Round)
> **Question:** Name the 5 validity assumptions of Bernoulli's equation in ≤5 words each.
> > [!success]- **Answer & AIR-1 Traps:**
> > 1. **Steady** ($\partial/\partial t = 0$)
> > 2. **Incompressible** ($\rho = \text{const}$, requires $M < 0.3$)
> > 3. **Inviscid** ($\mu = 0$, no friction losses)
> > 4. **Along a streamline** (or irrotational for global constant)
> > 5. **No shaft work/heat** between the two points
> > ⚠️ AIR-1 Trap: The "irrotational for global constant" clause is tested every year as a True/False.

> [!question]- 🃏 Flashcard: Area-Velocity Paradox
> **Question:** In a supersonic nozzle, a larger exit area produces what effect on velocity? Derive the sign.
> > [!success]- **Answer & AIR-1 Traps:**
> > $dA/A = (M^2-1)dV/V$. At $M > 1$: $(M^2-1) > 0$. So $dA > 0 \implies dV > 0$ → **velocity increases** with area.
> > ⚠️ Trap: Subsonic intuition says "bigger area → slower flow." At supersonic speeds it is the OPPOSITE. This is the planted MCQ trap in every GATE nozzle question.

> [!question]- 🃏 Flashcard: Pitot + Manometer Chain
> **Question:** Write the full chain from manometer reading $h$ to airspeed $V_\infty$ (two-step formula).
> > [!success]- **Answer & AIR-1 Traps:**
> > Step 1: $\Delta p = (\rho_m - \rho_f)gh$
> > Step 2: $V_\infty = \sqrt{2\Delta p / \rho_f}$
> > ⚠️ Trap 1: Using $\rho_m$ instead of $\rho_f$ in Step 2 gives 0.89 m/s for an aircraft — absurd sanity fail.
> > ⚠️ Trap 2: For air tubes, $\rho_f \ll \rho_m$ so $(\rho_m - \rho_f) \approx \rho_m$ — but for water/mercury it matters: $(13600 - 1000) = 12600$, NOT 13600.

> [!question]- 🃏 Flashcard: Momentum Correction Factor
> **Question:** What is $\beta$ for (a) uniform profile, (b) laminar circular pipe, (c) laminar 2D channel?
> > [!success]- **Answer & AIR-1 Traps:**
> > (a) Uniform: $\beta = 1.000$
> > (b) Laminar circular pipe (parabolic): $\beta = \mathbf{4/3 = 1.333}$
> > (c) Laminar 2D channel (parabolic): $\beta = \mathbf{6/5 = 1.200}$
> > ⚠️ Trap: "Laminar flow" + "circular pipe" → $\beta = 4/3$ is automatic. Turbulent → $\beta \approx 1.0$ (usually neglected). Using $\beta = 1$ for laminar pipe = 33% momentum flux error.
