# PYQ Analyzer Skill

Use this skill whenever analyzing a GATE AE Previous Year Question (PYQ).

## Workflow

1. **Create PYQ Note:**
   - File path: `04 - PYQs/<Section>/GATE-AE-YYYY-QNN.md`
   - Use template: `07 - TEMPLATES/PYQ Analysis Template.md`

2. **Categorize Question:**
   - Section: 1 (Math), 2 (FM & Space Dyn), 3 (Aero), 4 (Structures), 5 (Propulsion), GA.
   - Type: **Core Topic** (≥90%) vs. **Special Topic** (≤10%).

3. **Analysis Components:**
   - **Problem Statement:** Clear text & figures if applicable.
   - **Step-by-Step Solution:** Mathematical working using LaTeX `$...$` and `$$...$$`.
   - **Key Formula:** Link to corresponding formula in `06 - FORMULA SHEETS/`.
   - **Concept Note Link:** Link to concept note in `02 - SUBJECTS/`.
   - **Mistake Analysis:** Why candidates get this wrong (trap options, unit conversions, formula misapplication).

4. **Update Index:**
   - Update `04 - PYQs/_PYQ Master Index.md` attempt count and performance table.
