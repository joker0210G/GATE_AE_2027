### Question 01 `[MCQ — 1 Mark]`
A real-valued function $f(x)$ is defined to be **Continuous at $x = a$** if and only if:
- (A) $\lim_{x \to a} f(x) = f(a)$
- (B) $f'(a) = 0$
- (C) $f(a) > 0$
- (D) $\lim_{x \to a} f(x) = \infty$

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(A) $\lim_{x \to a} f(x) = f(a)$**
> 
> **The Three-Condition Continuity Test:**
> Continuity at $x = a$ strictly requires:
> 1. $f(a)$ is defined and finite.
> 2. $\lim_{x \to a} f(x)$ exists ($\text{LHL} = \text{RHL} = L$).
> 3. The limit equals the actual functional value: $L = f(a)$.

### Question 02 `[NAT — 1 Mark]`
The function:
$$f(x) = \begin{cases} \frac{x^2 - 16}{x - 4}, & x \neq 4 \\ k, & x = 4 \end{cases}$$
is continuous at $x = 4$. The value of $k$ is ________ (Answer in integer).

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **$8$** (Acceptable range: `8` to `8`)
> 
> **Removable Discontinuity Resolution:**
> $$k = f(4) = \lim_{x \to 4} \frac{x^2 - 16}{x - 4} = \lim_{x \to 4} \frac{(x-4)(x+4)}{x-4} = \lim_{x \to 4} (x+4) = 8$$

### Question 08 `[NAT — 1 Mark]`
The function $f(x) = \frac{x^2 - 4}{(x-2)(x-5)}$ has vertical asymptotes (infinite discontinuities). The number of infinite discontinuities on $\mathbb{R}$ is ________ (Answer in integer).

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **$1$** (Acceptable range: `1` to `1`)
> 
> **Hole vs Vertical Asymptote:**
> 1. Factor numerator: $x^2 - 4 = (x-2)(x+2)$.
> 2. $f(x) = \frac{(x-2)(x+2)}{(x-2)(x-5)} = \frac{x+2}{x-5}$ for $x \neq 2$.
> 3. At $x = 2$: $(x-2)$ cancels $\implies$ **Removable Discontinuity (Hole)**.
> 4. At $x = 5$: Denominator vanishes while numerator $= 7 \neq 0 \implies$ **Infinite Discontinuity (Vertical Asymptote)**.
> 5. Total number of infinite discontinuities $= 1$.

If $f(x)$ is continuous on the closed interval $[a, b]$, which of the following is **ALWAYS TRUE**?

- (B) $f(x)$ attains its absolute maximum and absolute minimum on $[a, b]$ (Extreme Value Theorem).
- (C) $f'(x) = 0$ at least once in $(a, b)$.

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(B) $f(x)$ attains its absolute maximum and absolute minimum on $[a, b]$ (Extreme Value Theorem).**
> 
> **The Extreme Value Theorem (EVT):**
> Any function continuous on a compact (closed and bounded) set is guaranteed to achieve its global supremum (maximum) and global infimum (minimum).

### Question 13 `[MCQ — 1 Mark]`
The function $f(x) = \frac{1}{1 + e^{1/x}}$ for $x \neq 0$ and $f(0) = 0$ has at $x = 0$:
- (A) A Jump Discontinuity
- (B) A Removable Discontinuity
- (C) No Discontinuity (Continuous)
- (D) An Infinite Discontinuity

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(A) A Jump Discontinuity**
> 
> **One-Sided Exponential Limits:**
> 1. Right limit ($x \to 0^+$): $1/x \to +\infty \implies e^{1/x} \to \infty \implies \text{RHL} = \frac{1}{1 + \infty} = 0$.
> 2. Left limit ($x \to 0^-$): $1/x \to -\infty \implies e^{1/x} \to 0 \implies \text{LHL} = \frac{1}{1 + 0} = 1$.
> 3. Since $\text{LHL} = 1 \neq \text{RHL} = 0$ (both finite), it is a **Jump Discontinuity** of jump size $1$.

For what value of $a$ is the function:

### Question 21 `[MCQ — 2 Marks]`
Let $f(x) = \begin{cases} x^2 \sin(1/x), & x \neq 0 \\ 0, & x = 0 \end{cases}$. At $x = 0$, the function $f(x)$ is:
- (A) Both Continuous and Differentiable
- (B) Continuous but NOT Differentiable
- (C) Differentiable but NOT Continuous
- (D) Neither Continuous nor Differentiable

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(A) Both Continuous and Differentiable**
> 
> **Squeeze Theorem Analysis:**
> 1. Continuity: $-x^2 \le x^2 \sin(1/x) \le x^2 \implies \lim_{x \to 0} f(x) = 0 = f(0)$ (Continuous!).
> 2. Differentiability: $f'(0) = \lim_{h \to 0} \frac{f(h) - f(0)}{h} = \lim_{h \to 0} \frac{h^2 \sin(1/h)}{h} = \lim_{h \to 0} h \sin(1/h) = 0$.
> 3. Since $f'(0) = 0$ exists and is finite, $f(x)$ is **Both Continuous and Differentiable at $x = 0$**.

### Question 23 `[MCQ — 2 Marks]`
According to the **Intermediate Value Theorem (IVT)**, if a continuous function $f(x)$ on $[0, 1]$ satisfies $0 \le f(x) \le 1$ for all $x \in [0, 1]$, then:
- (A) There exists at least one **Fixed Point** $c \in [0, 1]$ such that $f(c) = c$.
- (B) $f'(x) = 1$ everywhere.
- (C) $f(x)$ must be linear.
- (D) $f(0)$ must equal $0$.

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(A) There exists at least one Fixed Point $c \in [0, 1]$ such that $f(c) = c$.**
> 
> **Brouwer's Fixed Point Theorem (1D Case):**
> 1. Define $g(x) = f(x) - x$.
> 2. $g(0) = f(0) - 0 = f(0) \ge 0$.
> 3. $g(1) = f(1) - 1 \le 0$ (since $f(1) \le 1$).
> 4. By IVT, $\exists c \in [0, 1]$ such that $g(c) = 0 \implies f(c) = c$.

### Question 24 `[NAT — 2 Marks]`
Let $f(x) = \begin{cases} a x^2 + b, & x \le 1 \\ 4x - 1, & x > 1 \end{cases}$. If $f(x)$ is **Differentiable at $x = 1$** (which implies it is continuous), the value of $a \cdot b$ is ________ (Answer in integer).

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **$2$** (Acceptable range: `2` to `2`)
> 
> **Differentiability and Continuity Matching:**
> 1. Differentiability matching: $f'(1^-) = 2a(1) = 2a$. $f'(1^+) = 4$.
>    $$2a = 4 \implies a = 2$$
> 2. Continuity matching: $f(1^-) = a(1)^2 + b = a + b$. $f(1^+) = 4(1) - 1 = 3$.
>    $$a + b = 3 \implies 2 + b = 3 \implies b = 1$$
> 3. Product: $a \cdot b = 2 \cdot 1 = 2$.

Let $f(x) = \begin{cases} \frac{\ln(1+2x)}{x}, & x \neq 0 \\ k, & x = 0 \end{cases}$. For $f(x)$ to be continuous at $x = 0$, the value of $k$ must be:

> [!faq]- 🔍 View Solution & Detailed Explanation

> 
> **Logarithmic Limit:**

### Question 31 `[MCQ — 2 Marks]`
Let $f(x) = \begin{cases} x^p \sin(1/x^q), & x \neq 0 \\ 0, & x = 0 \end{cases}$ where $p, q > 0$. The function $f(x)$ is:
1. **Continuous at $x = 0$** if and only if $p > 0$.
2. **Differentiable at $x = 0$** if and only if $p > 1$.
3. **$f'(x)$ is Continuous at $x = 0$** if and only if $p > 1 + q$.

Which of the statements are **CORRECT**?
- (A) 1, 2, and 3 are all correct.
- (B) Only 1 and 2 are correct.
- (C) Only 1 is correct.
- (D) None are correct.

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(A) 1, 2, and 3 are all correct.**
> 
> **Oscillatory Function Exponent Hierarchy:**
> - $\lim_{x\to 0} x^p \sin(1/x^q) = 0 \iff p > 0$ (Continuity).
> - $f'(0) = \lim \frac{h^p \sin(1/h^q)}{h} = \lim h^{p-1} \sin(1/h^q) = 0 \iff p - 1 > 0 \iff p > 1$ (Differentiability).
> - $f'(x) = p x^{p-1} \sin(1/x^q) - q x^{p-1-q} \cos(1/x^q) \to 0 \iff p - 1 - q > 0 \iff p > 1 + q$ (Continuity of Derivative).

### Question 35 `[MCQ — 2 Marks]`
Let $f(x)$ and $g(x)$ be continuous functions on $[a, b]$ such that $f(a) < g(a)$ and $f(b) > g(b)$. Then:
- (A) There exists at least one $c \in (a, b)$ where $f(c) = g(c)$ (their graphs MUST intersect).
- (B) $f(x) = g(x)$ for all $x \in [a, b]$.
- (C) The curves never cross.
- (D) $f'(c) = g'(c) = 0$.

> [!faq]- 🔍 View Solution & Detailed Explanation
> **Correct Answer:** **(A) There exists at least one $c \in (a, b)$ where $f(c) = g(c)$ (their graphs MUST intersect).**
> 
> **IVT Intersection Theorem:**
> Define $h(x) = f(x) - g(x)$.
> $h(a) = f(a) - g(a) < 0$ and $h(b) = f(b) - g(b) > 0$.
> By IVT, $\exists c \in (a, b)$ such that $h(c) = 0 \implies f(c) = g(c)$.

Consider the **Dirichlet Function**:

The function $D(x)$ is:

Let $f: [a, b] \to [a, b]$ be a continuous function. If $f$ is strictly decreasing on $[a, b]$, the number of fixed points $c \in [a, b]$ where $f(c) = c$ is:

- (B) At least 2
- (C) 0
