## 1. Quantitative Aptitude — Key Formulas

### Number Theory
| Formula | Description |
|---|---|
| $n! = n \times (n-1)!$ | Factorial |
| HCF × LCM = Product of two numbers | HCF-LCM relation |
| Sum of first $n$ naturals = $n(n+1)/2$ | Arithmetic series |
| Sum of first $n$ squares = $n(n+1)(2n+1)/6$ | |
| Sum of first $n$ cubes = $[n(n+1)/2]^2$ | |

### Percentages & Profit-Loss
| Formula | Description |
|---|---|
| $\% \text{ change} = \frac{\text{change}}{\text{original}} \times 100$ | Percentage change |
| Profit % = (Profit/CP) × 100 | Profit percentage |
| SP = CP × (1 + Profit%/100) | Selling price |
| Discount = MP × Discount%/100 | Discount amount |

### Time, Speed, Distance
| Formula | Description |
|---|---|
| $D = S \times T$ | Distance formula |
| Avg speed (equal distance) = $2v_1 v_2/(v_1+v_2)$ | Harmonic mean |
| Relative speed (opposite) = $v_1 + v_2$ | |
| Relative speed (same dir) = $|v_1 - v_2|$ | |

### Permutations & Combinations
| Formula | Description |
|---|---|
| $^nP_r = n!/(n-r)!$ | Permutations |
| $^nC_r = n!/[r!(n-r)!]$ | Combinations |
| $^nC_r = ^nC_{n-r}$ | Symmetry |
| Circular permutations = $(n-1)!$ | Arrangements in a circle |

## 2. Verbal Ability — Key Concepts

### English Grammar Checklist
- Subject-Verb agreement rules
- Tense consistency
- Active/Passive voice
- Direct/Indirect speech
- Prepositions (at, in, on, by, with...)
- Articles (a, an, the) — count/uncountable nouns

### Vocabulary Strategy
- Root words (bene-, mal-, extra-, intra-)
- Synonyms/Antonyms (GRE word lists work well)
- Para jumbles — find the opening sentence first (has no pronoun without antecedent)
