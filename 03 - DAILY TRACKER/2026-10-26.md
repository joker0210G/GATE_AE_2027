#### 📌 BLOCK 11 — Directional Static Stability & Rudder Control
```
THE N-N-P RULE:
  Pitch: C_mα < 0 (Negative)
  Roll : C_lβ < 0 (Negative)
  Yaw  : C_nβ > 0 (POSITIVE!)

DIRECTIONAL STABILITY:
  C_nβ ≡ ∂C_n / ∂β > 0 (Weathercock effect)
  Fuselage Contribution: C_{nβ,fuse} < 0 (Destabilizing!)
  Vertical Tail Ratio  : V_v = (l_v S_v) / (b S)  [uses SPAN b!]
  Tail Contribution    : C_{nβ,v} = V_v η_v a_v (1 − dσ/dβ) > 0
  Total Aircraft       : C_nβ = C_{nβ,fuse} + V_v η_v a_v (1 − dσ/dβ) > 0

RUDDER POWER & OEI TRIM:
  C_{n\delta_r} = −V_v η_v a_v τ_r < 0
  OEI Trim: δ_{r,trim} = −(T_live · y_E) / (q_inf S b C_{n\delta_r})
```

#### 📌 BLOCK 12 — Lateral Static Stability & Dihedral Effect
```
LATERAL STABILITY (DIHEDRAL EFFECT):
  C_lβ ≡ ∂C_l / ∂β < 0 (Restores wings level upon sideslip)

CONTRIBUTIONS:
  1. Geometric Dihedral (Γ) : C_{lβ,dihedral} ≈ −(a/6) Γ < 0
  2. Wing Sweepback (Λ)      : C_{lβ,sweep} ≈ −(1/2) C_L sin(2Λ) < 0 (∝ C_L!)
  3. High Wing Position     : ΔC_lβ < 0 (Equivalent to +2° to +3° dihedral)
  4. Low Wing Position      : ΔC_lβ > 0 (Destabilizing ⟹ requires geometric Γ > 0)
  5. Vertical Tail Offset   : C_{lβ,v} = −V_v (z_v / l_v) η_v a_v < 0

AILERONS & ADVERSE YAW:
  Aileron Power: C_{l\delta_a}
  Adverse Yaw  : Down-aileron has higher C_L ⟹ higher induced drag ⟹ yaws opposite!
```

#### 📌 BLOCK 13 — 6-DOF Dynamics & Subsystem Decoupling
```
BODY AXES:
  x_b: Forward (u, p, L) | y_b: Starboard (v, q, M) | z_b: Downward (w, r, N)

ROTATIONAL EULER EQUATIONS:
  L = I_xx ṗ − I_xz ṙ + q r (I_zz − I_yy) − p q I_xz
  M = I_yy q̇ + p r (I_xx − I_zz) + (p² − r²) I_xz
  N = I_zz ṙ − I_xz ṗ + p q (I_yy − I_xx) + q r I_xz

DECOUPLING:
  Longitudinal (Symmetric) : [Δu, Δw, Δq, Δθ]ᵀ | Controls: δ_e, Thrust
  Lateral-Directional (Asym): [Δv, Δp, Δr, Δφ]ᵀ | Controls: δ_a, δ_r
```

#### 📌 BLOCK 14 — Longitudinal Dynamic Modes
```
SHORT PERIOD MODE:
  High frequency (1–10 rad/s), Heavy damping (0.3–0.8)
  Pitch θ and AoA α oscillate at CONSTANT AIRSPEED (u ≈ 0)
  ω_n,sp ≈ √(-M_α) | ζ_sp ≈ −(M_q + M_α̇ + Z_α/U₀) / (2 ω_n,sp)

PHUGOID (LONG PERIOD) MODE:
  Very low frequency (0.05–0.2 rad/s), Light damping (0.04–0.10)
  Airspeed u and Altitude h exchange at CONSTANT AoA (α ≈ 0)
  LANCHESTER FORMULAS:
    ω_n,ph = (√2 g) / V_inf ⟹ T_ph ≈ 0.45 V_inf (seconds)
    ζ_ph = 1 / [√2 (L/D)] ≈ 0.707 / (L/D) (Higher L/D ⟹ LOWER damping!)
```

#### 📌 BLOCK 15 — Lateral-Directional Dynamic Modes
```
1. ROLL SUBSIDENCE:
  Single large negative real root | Heavily damped pure roll
  Time Constant: τ_roll = −I_xx / L_p < 0.5 s (L_p < 0)

2. SPIRAL MODE:
  Single real root near origin (s ≈ 0) | Slow coupled yaw-roll dive
  STABILITY CRITERION: C_lβ C_nr > C_nβ C_lr ⟹ STABLE

3. DUTCH ROLL MODE:
  Complex conjugate pair | Coupled yaw-roll-sideslip oscillation (ω_n ≈ 1–3 rad/s)

DESIGN TRADE-OFF:
  Higher |C_lβ| (Dihedral)  ⟹ Spiral MORE stable, Dutch Roll WORSE
  Higher C_nβ (Vertical Tail) ⟹ Dutch Roll BETTER, Spiral LESS stable
```

### Step 2 — Week 4 (Space Dynamics & Grand Subject Test) Preview (20 min)
Week 4 begins tomorrow (Oct 27, 2026):
1. **Central Force Motion & Keplerian Conic Orbits (D1):** Two-body gravitational equation $\ddot{\vec{r}} = -\frac{\mu}{r^3}\vec{r}$, Specific mechanical energy $\mathcal{E} = \frac{v^2}{2} - \frac{\mu}{r} = -\frac{\mu}{2a}$, Specific angular momentum $\vec{h} = \vec{r}\times\vec{v} = \text{const}$, Orbit equation $r(\theta) = \frac{p}{1 + e\cos\theta}$, Conic classifications (Circle $e = 0, \mathcal{E} < 0$; Ellipse $0 < e < 1, \mathcal{E} < 0$; Parabola $e = 1, \mathcal{E} = 0$; Hyperbola $e > 1, \mathcal{E} > 0$).
2. **Kepler's Laws, Vis-Viva Equation & Escape Velocity (D2):**
   - Kepler's 1st Law (Elliptical orbits), 2nd Law (Constant areal velocity $\frac{dA}{dt} = \frac{h}{2}$), 3rd Law ($T^2 = \frac{4\pi^2}{\mu} a^3$).
   - **The Vis-Viva Equation:** $\mathbf{v^2 = \mu\left(\frac{2}{r} - \frac{1}{a}\right)}$.
   - Circular velocity: $v_{\text{circ}} = \sqrt{\frac{\mu}{r}}$, Escape velocity: $\mathbf{v_{\text{esc}} = \sqrt{\frac{2\mu}{r}} = \sqrt{2} v_{\text{circ}}}$.
   - Perigee and Apogee speeds: $v_p = \sqrt{\frac{\mu}{a}\frac{1+e}{1-e}}$, $v_a = \sqrt{\frac{\mu}{a}\frac{1-e}{1+e}}$, $r_p v_p = r_a v_a = h$.
3. **Orbital Maneuvers & Transfers (D3):**
   - Coplanar Hohmann Transfer between circular orbits ($r_1 \to r_2$): Semi-major axis $a_{tx} = \frac{r_1 + r_2}{2}$, Transfer time $t_{tx} = \pi\sqrt{\frac{a_{tx}^3}{\mu}}$, Velocity impulses $\Delta v_1 = \sqrt{\frac{\mu}{r_1}}\left(\sqrt{\frac{2r_2}{r_1+r_2}} - 1\right)$, $\Delta v_2 = \sqrt{\frac{\mu}{r_2}}\left(1 - \sqrt{\frac{2r_1}{r_1+r_2}}\right)$, Total $\Delta v_{\text{total}} = \Delta v_1 + \Delta v_2$.
   - Orbital plane change: $\Delta v = 2 v \sin(\theta/2)$ (Best executed at apogee where velocity $v$ is lowest!).
