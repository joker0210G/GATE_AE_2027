#### 📌 BLOCK 1 — Standard Atmosphere & Airspeeds
```
ISA CONSTANTS:
  T₀ = 288.15 K | p₀ = 101325 Pa | ρ₀ = 1.225 kg/m³ | g₀ = 9.80665 m/s² | R = 287 J/(kg·K)

TROPOSPHERE (0 ≤ h ≤ 11 km):
  Lapse Rate: L = 6.5 K/km = 0.0065 K/m
  T(h) = T₀ − L·h | p/p₀ = (T/T₀)^(5.2561) | ρ/ρ₀ = (T/T₀)^(4.2561)

STRATOSPHERE (11 ≤ h ≤ 20 km):
  T = 216.65 K = const | p/p₁₁ = ρ/ρ₁₁ = exp[−g₀(h − 11000)/(RT₁₁)]

AIRSPEED HIERARCHY:
  IAS ──► CAS ──► EAS ──► TAS
  Dynamic Pressure: q = (1/2) ρ₀ V_eas² = (1/2) ρ V_tas²
  TAS: V_tas = V_eas / √σ = V_eas / √(ρ/ρ₀)
  Stall Speed in EAS (V_stall,eas) is CONSTANT at all altitudes!
```

#### 📌 BLOCK 2 — Drag Polar & Level Flight Performance
```
PARABOLIC DRAG POLAR:
  C_D = C_D0 + K C_L² = C_D0 + C_L² / (π e AR)
  Total Drag: D = (1/2) ρ V² S C_D0 + (2 K W²) / (ρ V² S)

MINIMUM THRUST REQUIRED (T_R,min = D_min):
  Condition  : C_D0 = C_Di = K C_L² (Parasite = Induced)
  Optimal C_L: C_{L,md} = √(C_D0 / K)
  Max Metric : (L/D)_max = 1 / [2 √(K C_D0)]
  Min T_R    : T_{R,min} = W / (L/D)_max = 2 W √(K C_D0) (INDEPENDENT of altitude!)
  Speed      : V_md = √[(2W) / (ρ S C_{L,md})] ∝ 1/√ρ

MINIMUM POWER REQUIRED (P_R,min):
  Condition  : C_Di = 3 C_D0 (Induced = 3 × Parasite)
  Optimal C_L: C_{L,mp} = √(3 C_D0 / K) = √3 · C_{L,md} ≈ 1.732 C_{L,md}
  Max Metric : (C_L^(3/2) / C_D)_max = 3^(3/4) / [4 K^(3/4) C_D0^(1/4)]
  Speed      : V_mp = V_md / 3^(1/4) ≈ 0.7598 V_md
  Min P_R    : P_{R,min} ∝ 1/√ρ (INCREASES with altitude!)
```

#### 📌 BLOCK 3 — Climb Performance & Ceilings
```
EQUATIONS OF CLIMB:
  Climb Angle  : sin γ = (T − D) / W = Excess Thrust / W
  Rate of Climb: R/C = V sin γ = (T V − D V) / W = (P_A − P_R) / W = Excess Power / W

PROPULSION OPTIMUMS:
  Jet Aircraft (T ≈ const) : Max Climb Angle γ_max at V_md ((L/D)_max) ⟹ sin γ_max = T/W − 1/(L/D)_max
                             Max Rate of Climb R/C_max at V > V_md
  Prop Aircraft (P_A ≈ const): Max Rate of Climb R/C_max at V_mp ((C_L^(3/2)/C_D)_max)
                             ⟹ R/C_max = (P_A − P_R,min) / W

CEILINGS:
  Absolute Ceiling (h_abs)  : R/C_max = 0
  Service Ceiling (h_service): R/C_max = 100 ft/min (0.508 m/s) (Prop) | 500 ft/min (2.54 m/s) (Jet)
  Time to Climb: t = [h_abs / (R/C)₀] · ln[h_abs / (h_abs − h)]
```

#### 📌 BLOCK 4 — Gliding Flight & Descent Performance
```
UNPOWERED GLIDE (T = 0):
  tan θ = D / L = 1 / (L/D)
  Glide Range: R = h / tan θ = h · (L/D)
  Sink Rate  : V_sink = V sin θ = (D V) / W = P_R / W

MAXIMUM GLIDE RANGE (R_max):
  Condition  : (L/D)_max ⟹ C_D0 = K C_L² ⟹ C_L,md = √(C_D0 / K)
  Range      : R_max = h · (L/D)_max = h / [2 √(K C_D0)]
  Invariants : INDEPENDENT of aircraft weight W and air density ρ!
  Speed      : V_md ∝ √W ∝ 1/√ρ

MINIMUM SINK RATE (V_sink,min):
  Condition  : (C_L^(3/2)/C_D)_max ⟹ C_Di = 3 C_D0 ⟹ V = V_mp = 0.76 V_md
  Sink Speed : V_sink,min = √[(2W)/(ρS)] · [1 / (C_L^(3/2)/C_D)_max] ∝ √W
```

#### 📌 BLOCK 5 — Range & Endurance (Breguet Matrix)
```
PROPELLER AIRCRAFT:
  Range    : R = (η_p / c_p) (C_L / C_D) ln(W₀ / W₁) ⟹ Max at (L/D)_max (V = V_md)
  Endurance: E = (η_p / c_p) √(ρS/2) (C_L^(3/2) / C_D) [1/√W₁ − 1/√W₀] ⟹ Max at (C_L^(3/2)/C_D)_max (V = V_mp = 0.76 V_md)

JET AIRCRAFT:
  Range    : R = (2 / c_t) √(2/(ρS)) (C_L^(1/2) / C_D) [√W₀ − √W₁] ⟹ Max at (C_L^(1/2)/C_D)_max (V = 1.32 V_md)
  Endurance: E = (1 / c_t) (C_L / C_D) ln(W₀ / W₁) ⟹ Max at (L/D)_max (V = V_md)
```

### Step 2 — Week 2 (Maneuvering Flight, Turning Flight, $V$-$n$ Diagram & Longitudinal Static Stability) Preview (20 min)
Week 2 begins tomorrow (Oct 13, 2026):
1. **Accelerated Flight & Load Factor (D1):** Load factor $n = L/W$, Accelerated stall speed $V_{\text{stall,acc}} = V_{\text{stall}}\sqrt{n}$, Pull-up ($n = 1 + \frac{V^2}{g R}$) and Pull-down ($n = \frac{V^2}{g R} - 1$) maneuvers.
2. **Turning Flight Performance (D2):** Coordinated level turn (Bank angle $\phi$, Load factor $n = \frac{1}{\cos\phi}$, Turn radius $R = \frac{V^2}{g\tan\phi} = \frac{V^2}{g\sqrt{n^2-1}}$, Turn rate $\omega = \dot{\psi} = \frac{g\tan\phi}{V} = \frac{g\sqrt{n^2-1}}{V}$, Maximum turn rate and minimum turn radius at corner speed $V^*$).
3. **Flight Envelope & $V$-$n$ Diagram (D3):** Aerodynamic limit boundary ($n \propto V^2$), Positive & negative structural limit load factors ($n_{\max}, n_{\min}$), Maneuvering corner speed $V^*$, Gust load factor and FAA/military gust envelope ($K_g$ gust alleviation factor).
4. **Longitudinal Static Stability — Stick-Fixed (D4):** Pitching moment equation $C_m = C_{m0} + C_{m\alpha}\alpha$, Criterion for longitudinal static stability ($\mathbf{C_{m\alpha} < 0}$ and $\mathbf{C_{m0} > 0}$), Wing-body and horizontal tail contributions ($V_H = \frac{l_t S_t}{\bar{c} S}$), Neutral Point ($x_{np} = x_{ac,wb} + V_H \frac{a_t}{a}(1 - \frac{d\epsilon}{d\alpha})$), Static Margin ($\mathbf{SM = \frac{x_{np} - x_{cg}}{\bar{c}}}$).
5. **Stick-Free Stability, Elevator Controls & Trim Analysis (D5):** Elevator control power ($C_{m\delta_e} < 0$), Trim angle of attack and elevator trim deflection ($\delta_{e,\text{trim}}$), Elevator hinge moments ($C_h = C_{h0} + C_{h\alpha}\alpha_t + C_{h\delta_e}\delta_e + C_{h\delta_t}\delta_t$), Floating angle $\delta_{e,\text{float}}$, Stick-free neutral point ($x'_{np}$), Stick force gradient ($dF_s/dV$).
