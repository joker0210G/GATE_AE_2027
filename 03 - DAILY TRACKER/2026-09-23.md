### Step 2 — 1D Isentropic Compressible Flow Relations (20 min)
Open `05.1 - 1D Compressible Flow`.

1. **Speed of Sound & Mach Angle:**
   $$a = \sqrt{\gamma R T} = \sqrt{\gamma \frac{p}{\rho}} \quad (\text{For air: } \gamma = 1.4, R = 287\text{ J/(kg}\cdot\text{K)})$$
   $$\sin\mu = \frac{1}{M} \iff \mu = \arcsin\left(\frac{1}{M}\right) \quad (\text{Mach Cone Angle for } M \ge 1)$$
2. **Isentropic Stagnation Relations (Calorically Perfect Gas, $\gamma = 1.4$):**
   $$\boxed{\frac{T_0}{T} = 1 + \frac{\gamma - 1}{2}M^2 = 1 + 0.2 M^2}$$
   $$\boxed{\frac{p_0}{p} = \left(1 + \frac{\gamma - 1}{2}M^2\right)^{\frac{\gamma}{\gamma - 1}} = (1 + 0.2 M^2)^{3.5}}$$
   $$\boxed{\frac{\rho_0}{\rho} = \left(1 + \frac{\gamma - 1}{2}M^2\right)^{\frac{1}{\gamma - 1}} = (1 + 0.2 M^2)^{2.5}}$$
3. **Critical Sonic Reference Properties ($M = 1$):**
   - $\frac{T^*}{T_0} = \frac{2}{\gamma + 1} = \frac{2}{2.4} \approx \mathbf{0.8333}$
   - $\frac{p^*}{p_0} = \left(\frac{2}{\gamma + 1}\right)^{\frac{\gamma}{\gamma - 1}} = (0.8333)^{3.5} \approx \mathbf{0.5283}$
   - $\frac{\rho^*}{\rho_0} = \left(\frac{2}{\gamma + 1}\right)^{\frac{1}{\gamma - 1}} \approx \mathbf{0.6339}$
4. **Critical Area Ratio ($A/A^*$ for 1D Isentropic Nozzle):**
   $$\boxed{\left(\frac{A}{A^*}\right)^2 = \frac{1}{M^2}\left[\frac{2}{\gamma + 1}\left(1 + \frac{\gamma - 1}{2}M^2\right)\right]^{\frac{\gamma + 1}{\gamma - 1}} = \frac{1}{M^2}\left[\frac{1 + 0.2 M^2}{1.2}\right]^6}$$

### Step 3 — Normal Shock Waves (Rankine-Hugoniot Relations) (25 min)
Open `05.2 - Normal and Oblique Shock Waves`.

Across a stationary normal shock wave separating upstream supersonic state $(1)$ from downstream subsonic state $(2)$:

```
                     NORMAL SHOCK DISCONTINUITY
            Upstream (1)                  Downstream (2)
         ───────────────────┐        ┌───────────────────
         Supersonic M_1 > 1 │  SHOCK │  Subsonic M_2 < 1
         p_1, T_1, ρ_1      │   WAVE │  p_2 > p_1, T_2 > T_1, ρ_2 > ρ_1
         p_01, T_01, s_1    │   │││  │  p_02 < p_01 (Total pressure drop!)
                            │        │  T_02 = T_01 (Adiabatic!)
         ───────────────────┘        └───────────────────
```

#### 🔑 The 6 Fundamental Normal Shock Jump Relations ($\gamma = 1.4$):

1. **Downstream Mach Number ($M_2 < 1$):**
   $$\boxed{M_2^2 = \frac{2 + (\gamma - 1)M_1^2}{2\gamma M_1^2 - (\gamma - 1)} = \frac{2 + 0.4 M_1^2}{2.8 M_1^2 - 0.4}}$$
2. **Static Pressure Ratio ($p_2/p_1 > 1$):**
   $$\boxed{\frac{p_2}{p_1} = 1 + \frac{2\gamma}{\gamma + 1}(M_1^2 - 1) = 1 + \frac{7}{6}(M_1^2 - 1) = \frac{7 M_1^2 - 1}{6}}$$
3. **Static Density & Velocity Ratio ($\rho_2/\rho_1 = u_1/u_2 > 1$):**
   $$\boxed{\frac{\rho_2}{\rho_1} = \frac{u_1}{u_2} = \frac{(\gamma + 1)M_1^2}{2 + (\gamma - 1)M_1^2} = \frac{2.4 M_1^2}{2 + 0.4 M_1^2}}$$
   - **Asymptotic Density Limit ($M_1 \to \infty$):** $\lim_{M_1\to\infty} \frac{\rho_2}{\rho_1} = \frac{\gamma + 1}{\gamma - 1} = \frac{2.4}{0.4} = \mathbf{6.0}$.
4. **Static Temperature Ratio ($T_2/T_1 > 1$):**
   $$\boxed{\frac{T_2}{T_1} = \left(\frac{p_2}{p_1}\right)\left(\frac{\rho_1}{\rho_2}\right)}$$
5. **Stagnation Temperature is CONSTANT ($T_{02} = T_{01}$):**
   - Because no heat is added to or removed from the system ($q = 0$), $h_0 = \text{const} \implies \mathbf{T_{02} = T_{01}}$.
6. **Stagnation Pressure DROPS ($p_{02} < p_{01}$) & Entropy INCREASES ($\Delta s > 0$):**
   $$\boxed{\Delta s = s_2 - s_1 = -R \ln\left(\frac{p_{02}}{p_{01}}\right) > 0 \implies \frac{p_{02}}{p_{01}} < 1}$$

### Step 4 — Rayleigh Supersonic Pitot Tube Formula (10 min)

When a Pitot tube measures total pressure in a supersonic flow $M_1 > 1$, a detached normal shock forms directly in front of the probe nose. The probe measures **$p_{02}$ (downstream stagnation pressure)**, NOT $p_{01}$:

$$\boxed{\frac{p_{02}}{p_1} = \left(\frac{\gamma + 1}{2}M_1^2\right)^{\frac{\gamma}{\gamma - 1}} \left(\frac{\gamma + 1}{2\gamma M_1^2 - (\gamma - 1)}\right)^{\frac{1}{\gamma - 1}} = \left(\frac{6 M_1^2}{5}\right)^{3.5} \left(\frac{6}{7 M_1^2 - 1}\right)^{2.5}}$$

---

### Step 5 — Traps & Self-Check (5 min)
> 🔴 **Trap 1: Supersonic Pitot Tube Reading**
> A Pitot tube in supersonic flow reads $p_{02}$ (post-shock total pressure), NOT $p_{01}$ (free-stream total pressure). Using standard incompressible Bernoulli or subsonic isentropic $p_0/p = (1+0.2M^2)^{3.5}$ gives massive errors!
> 🔴 **Trap 2: Normal Shock Asymptotic Density**
> As $M_1 \to \infty$, $p_2/p_1 \to \infty$ and $T_2/T_1 \to \infty$, BUT density ratio $\rho_2/\rho_1$ is capped at $\frac{\gamma+1}{\gamma-1} = 6.0$ for diatomic gas.

> **(A)** $103.3\text{ kPa}$ **(B)** $206.7\text{ kPa}$ **(C)** $180.0\text{ kPa}$ **(D)** $240.0\text{ kPa}$

> **Q4 (1 mark):** As the upstream Mach number $M_1 \to \infty$, the density ratio $\rho_2/\rho_1$ across a normal shock wave in air ($\gamma = 1.4$) approaches a maximum limiting value of:
> **(A)** $\infty$ **(B)** $4.0$ **(C)** $6.0$ **(D)** $1.4$

> **Q5 (2 marks NAT):** An aircraft flies at Mach $M = 1.5$ in standard air at an altitude where static temperature is $T = 250\text{ K}$. The stagnation temperature $T_0$ measured by the on-board temperature sensor is ___ $\text{K}$ (round off to 1 decimal place).

> [!faq]- 🔍 View D2 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (B) Stagnation temperature (T₀)**
> In an adiabatic flow without shaft work, the stagnation enthalpy $h_0 = c_p T_0$ is strictly conserved across shock waves ($T_{02} = T_{01}$).
>
> **Q2: (B) 0.577**
> $M_2^2 = \frac{2 + 0.4(2.0^2)}{2.8(2.0^2) - 0.4} = \frac{2 + 1.6}{11.2 - 0.4} = \frac{3.6}{10.8} = \frac{1}{3} \implies M_2 = \frac{1}{\sqrt{3}} \approx \mathbf{0.577}$.
>
> **Q3: (B) 206.7 kPa**
> $\frac{p_2}{p_1} = 1 + \frac{7}{6}(M_1^2 - 1) = 1 + \frac{7}{6}(3^2 - 1) = 1 + \frac{7}{6}(8) = 1 + \frac{56}{6} = 1 + 9.333 = 10.333$.
> $p_2 = 20\text{ kPa} \times 10.333 = \mathbf{206.67\text{ kPa} \approx 206.7\text{ kPa}}$.
>
> **Q4: (C) 6.0**
> $\lim_{M_1\to\infty} \frac{\rho_2}{\rho_1} = \frac{\gamma + 1}{\gamma - 1} = \frac{1.4 + 1}{1.4 - 1} = \frac{2.4}{0.4} = \mathbf{6.0}$.
>
> **Q5: 362.5**
> $T_0 = T[1 + 0.2 M^2] = 250[1 + 0.2(1.5^2)] = 250[1 + 0.2(2.25)] = 250[1 + 0.45] = 250(1.45) = \mathbf{362.5\text{ K}}$.
