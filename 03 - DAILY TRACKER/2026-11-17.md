### Step 2 — Axial Compressor Stage Architecture (15 min)
Open `04 - Axial Compressors`.

An axial compressor stage consists of a **Rotor** (rotating blade row) followed by a **Stator** (stationary blade row):

```
                    AXIAL COMPRESSOR STAGE (ROTOR + STATOR)
             Station 1               Station 2               Station 3
           Rotor Inlet             Rotor Exit /            Stator Exit
                                   Stator Inlet
           ┌──────────┐            ┌──────────┐            ┌──────────┐
      ────►│  ROTOR   ├───────────►│  STATOR  ├───────────►│ (Next    │
           │ (Moving) │            │ (Fixed)  │            │  Stage)  │
           └──────────┘            └──────────┘            └──────────┘
           Energy & Static         Diffuses Kinetic
           Pressure Added          Energy into Pressure
```

1. **Rotor:** Work is done on the fluid ($w > 0$). Blade speed is $U = \omega r$. Increases both static pressure ($p_2 > p_1$) and absolute kinetic energy ($V_2 > V_1$).
2. **Stator:** Stationary ($U = 0$, $w = 0$). Converts high kinetic energy into additional static pressure ($p_3 > p_2, V_3 < V_2$) and realigns the flow for the next stage.
3. **Axial Velocity ($C_a$):** Assumed constant across the stage ($C_{a1} = C_{a2} = C_{a3} = C_a$).

### Step 3 — Velocity Triangles & Angle Conventions (25 min)

```
                    AXIAL COMPRESSOR VELOCITY TRIANGLES
             ROTOR INLET (Station 1)              ROTOR EXIT (Station 2)
                 ▲ C_a                                ▲ C_a
                 │ \                                  │   \
                 │  \ W_1 (Relative)                  │    \ W_2
                 │   \                                │     \
                 │ α₁ \ β₁                            │  α₂  \ β₂
                 ┼─────┼────────────►                 ┼───────┼────────►
                 │ V_1 │     U (Blade)                │  V_2  │   U
                 ▼     ▼                              ▼       ▼
              V_θ1    W_θ1                         V_θ2      W_θ2
```

#### 🔑 Velocity Vector Relations:
$$\vec{V} = \vec{U} + \vec{W}$$
- Absolute velocity: $V$, Swirl angle $\alpha$ (measured from axial direction).
- Relative velocity: $W$, Relative angle $\beta$ (measured from axial direction).
- Tangential components: $V_\theta = C_a \tan\alpha, \quad W_\theta = C_a \tan\beta$.

#### 🔑 The Fundamental Geometric Identity:
$$\boxed{U = V_\theta + W_\theta = C_a(\tan\alpha + \tan\beta)}$$
- At Rotor Inlet (1): $\boxed{\tan\beta_1 = \frac{U}{C_a} - \tan\alpha_1}$
- At Rotor Exit (2): $\boxed{\tan\alpha_2 = \frac{U}{C_a} - \tan\beta_2}$

---

### Step 4 — The Euler Work Equation & Stage Loading Factor (15 min)

1. **Euler Turbine/Compressor Work Equation:**
   Applying angular momentum balance across the rotor:
   $$w = U(V_{\theta 2} - V_{\theta 1}) = U C_a(\tan\alpha_2 - \tan\alpha_1)$$
   Using $\tan\alpha_2 - \tan\alpha_1 = (\frac{U}{C_a} - \tan\beta_2) - (\frac{U}{C_a} - \tan\beta_1) = \tan\beta_1 - \tan\beta_2$:
   $$\boxed{w = U C_a(\tan\beta_1 - \tan\beta_2) = c_p \Delta T_{0,\text{stage}}}$$

2. **Stage Loading Factor ($\psi$) & Flow Coefficient ($\phi$):**
   - **Flow Coefficient:** $\boxed{\phi \equiv \frac{C_a}{U}}$.
   - **Stage Loading Factor (Work Coefficient):**
     $$\boxed{\psi \equiv \frac{\Delta h_0}{U^2} = \frac{c_p \Delta T_{0,\text{stage}}}{U^2} = \frac{C_a}{U}(\tan\beta_1 - \tan\beta_2) = \phi(\tan\beta_1 - \tan\beta_2)}$$

---

### Step 5 — Traps & Self-Check (5 min)
> 🔴 **Trap 1: Angle Reference Datum**
> In British/GATE aerospace convention, flow angles $\alpha$ and $\beta$ are measured from the **AXIAL DIRECTION** ($V_a = V\cos\alpha, V_\theta = V\sin\alpha \implies V_\theta = C_a\tan\alpha$). If a problem gives angles from the *tangential direction*, convert via $\alpha_{\text{axial}} = 90^\circ - \alpha_{\text{tangential}}$!
> 🔴 **Trap 2: Flow Diffusion in Rotor**
> The rotor blade passages are **converging in relative space** ($W_2 < W_1 \implies \beta_2 < \beta_1$) to act as a relative diffuser, causing static pressure rise: $\Delta h_{\text{rotor}} = \frac{W_1^2 - W_2^2}{2}$.

### Step 3 — D1 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** In an axial flow compressor stage, work is transferred from the blades to the fluid across the:
> **(A)** Stator only **(B)** Rotor only **(C)** Both rotor and stator equally **(D)** Inlet guide vanes

> **Q2 (1 mark):** If air enters an axial compressor rotor purely in the axial direction ($\alpha_1 = 0^\circ$), the relative flow angle $\beta_1$ at rotor inlet is given by:
> **(A)** $\tan\beta_1 = \frac{C_a}{U}$ **(B)** $\tan\beta_1 = \frac{U}{C_a}$ **(C)** $\tan\beta_1 = \frac{U^2}{C_a}$ **(D)** $\beta_1 = 0^\circ$

> **Q3 (2 marks):** An axial compressor stage has blade speed $U = 240\text{ m/s}$ and constant axial velocity $C_a = 160\text{ m/s}$. Air enters with zero pre-whirl ($\alpha_1 = 0^\circ$) and leaves the rotor with relative flow angle $\beta_2 = 30^\circ$. Given $c_p = 1005\text{ J/(kg}\cdot\text{K)}$, the stage total temperature rise $\Delta T_{0,\text{stage}}$ (in $\text{K}$) is:
> **(A)** $22.4\text{ K}$ **(B)** $35.3\text{ K}$ **(C)** $42.5\text{ K}$ **(D)** $57.6\text{ K}$

> **Q4 (2 marks):** An axial compressor operates with flow coefficient $\phi = 0.50$, rotor inlet relative angle $\beta_1 = 55^\circ$, and rotor exit relative angle $\beta_2 = 35^\circ$. The stage loading factor $\psi$ is:
> **(A)** $0.285$ **(B)** $0.364$ **(C)** $0.450$ **(D)** $0.562$

> **Q5 (2 marks NAT):** An axial compressor rotor has $U = 280\text{ m/s}, C_a = 140\text{ m/s}$. The air leaves the rotor with absolute swirl angle $\alpha_2 = 45^\circ$ and enters with $\alpha_1 = 15^\circ$. The specific work input $w$ (in $\text{kJ/kg}$) is ___ (round off to 2 decimal places).

> [!faq]- 🔍 View D1 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (B) Rotor only**
> Stators are stationary ($U = 0 \implies w = 0$). Work is done solely by moving rotor blades.
>
> **Q2: (B) tan β₁ = U / C_a**
> $\tan\beta_1 = \frac{U}{C_a} - \tan\alpha_1 = \frac{U}{C_a} - 0 = \frac{U}{C_a}$.
>
> **Q3: (B) 35.3 K**
> $\tan\beta_1 = \frac{240}{160} = 1.50$. $\tan\beta_2 = \tan(30^\circ) = 0.57735$.
> $w = U C_a(\tan\beta_1 - \tan\beta_2) = (240)(160)(1.50 - 0.57735) = 38400(0.92265) = 35,429.8\text{ J/kg}$.
> $\Delta T_{0,\text{stage}} = \frac{35429.8}{1005} \approx \mathbf{35.25\text{ K} \approx 35.3\text{ K}}$.
>
> **Q4: (B) 0.364**
> $\psi = \phi(\tan 55^\circ - \tan 35^\circ) = 0.50(1.4281 - 0.7002) = 0.50(0.7279) \approx \mathbf{0.36395 \approx 0.364}$.
>
> **Q5: 28.70**
> $w = U C_a(\tan\alpha_2 - \tan\alpha_1) = (280)(140)(\tan 45^\circ - \tan 15^\circ) = 39,200(1.0 - 0.26795) = 39,200(0.73205) = 28,696.4\text{ J/kg} = \mathbf{28.70\text{ kJ/kg}}$.
