#### 📌 BLOCK 1 — Fluid Kinematics & Flow Fields
```
MATERIAL DERIVATIVE: D/Dt = ∂/∂t + (V·∇)
  Acceleration: a = ∂V/∂t (local) + (V·∇)V (convective)

FLOW FORMULATIONS:
  Velocity Potential ϕ: Valid ONLY if ∇×V = 0 (Irrotational)
    u = ∂ϕ/∂x,  v = ∂ϕ/∂y | ∇²ϕ = 0 (Incompressible)
  Stream Function ψ: Valid ONLY if ∇·V = 0 (Incompressible)
    u = ∂ψ/∂y,  v = −∂ψ/∂x | Flow rate: Q' = ψ₂ − ψ₁
  Orthogonal Flow Net: (dy/dx)_ϕ · (dy/dx)_ψ = −1

VORTICITY & CIRCULATION:
  Vorticity: ω = ∇×V ⟹ ω_z = ∂v/∂x − ∂u/∂y
  Angular Velocity: Ω = (1/2) ω
  Circulation: Γ = ∮ V·dr = ∬ ω_z dA
  Forced Vortex (Rotational): v_θ = Ω r ⟹ ω_z = 2Ω
  Free Vortex (Irrotational): v_θ = Γ / (2πr) ⟹ ω_z = 0 (r ≠ 0)
```

#### 📌 BLOCK 2 — Flow Lines, Curvature & Optical Visualization
```
FLOW LINES:
  Streamline : dx/u = dy/v = dz/w (Frozen instant t)
  Pathline   : dx/dt = u, dy/dt = v (Particle trajectory)
  Streakline : Locus of particles from injector (x₀,y₀) at past times τ ≤ t
  Equivalence: In STEADY flow, Streamline ≡ Pathline ≡ Streakline

STREAMLINE CURVATURE:
  ∂p/∂n = ρ V² / R (p increases outward away from center of curvature)
  Airfoil Lift: Convex upper surface ⟹ Center of curvature inside ⟹ Suction (p < p_inf)

OPTICAL FLOW VISUALIZATION (Gladstone-Dale: n − 1 = Kρ):
  Interferometry : Senses Density (ρ) directly
  Schlieren      : Senses First Derivative of Density (∇ρ) via Knife Edge
  Shadowgraph    : Senses Second Derivative of Density (∇²ρ)
```

#### 📌 BLOCK 3 — Conservation of Mass (Continuity Equation)
```
INTEGRAL RTT FORM:
  ∂/∂t ∭_CV ρ dV + ∬_CS ρ(V·n̂) dA = 0
  Steady 1D: ρ₁ A₁ V̄₁ = ρ₂ A₂ V̄₂ | V̄ = (1/A) ∬ u dA

DIFFERENTIAL CONTINUITY:
  Conservative : ∂ρ/∂t + ∇·(ρV) = 0
  Incompressible: ∇·V = 0 (Cartesian: ∂u/∂x + ∂v/∂y + ∂w/∂z = 0)
  Cylindrical  : (1/r) ∂(r v_r)/∂r + (1/r) ∂v_θ/∂θ + ∂v_z/∂z = 0

QUASI-1D COMPRESSIBLE NOZZLE:
  dA/A = (M² − 1) (dV/V)
  M < 1 (Subsonic)  : dA < 0 (converging) ⟹ dV > 0 (accelerates)
  M > 1 (Supersonic): dA > 0 (diverging)  ⟹ dV > 0 (accelerates)
  M = 1 (Sonic)     : dA = 0 (Throat)
```

#### 📌 BLOCK 4 — Conservation of Linear Momentum & Wake Drag
```
INTEGRAL MOMENTUM:
  Σ F = ∂/∂t ∭_CV ρV dV + ∬_CS ρV(V·n̂) dA
  Steady 1D: Σ F_x = ṁ (V_out − V_in)

MOMENTUM CORRECTION FACTOR (β = (1/A V̄²) ∬ u² dA):
  Uniform: β = 1.0 | Laminar Pipe: β = 4/3 ≈ 1.33 | 2D Channel: β = 6/5 = 1.20

WAKE PROFILE DRAG:
  D' = ∫ ρ u(y) [U_inf − u(y)] dy = ρ_inf U_inf² θ
  Momentum Thickness: θ = ∫ (u/U_inf) [1 − u/U_inf] dy
  Section Drag Coeff : c_d = 2 θ / c

PROPULSION THRUST:
  T = ṁ_e V_e − ṁ_a V₀ + (p_e − p_a) A_e
  Rocket (ṁ_a = 0): T = ṁ V_e + (p_e − p_a) A_e
```

#### 📌 BLOCK 5 — Energy Conservation & Dimensional Analysis
```
STAGNATION TEMPERATURE (Adiabatic flow):
  T₀ = T [1 + ((γ−1)/2) M²] = const (γ=1.4 ⟹ T₀ = T [1 + 0.2 M²])
  Recovery Temp: T_aw = T_e [1 + r ((γ−1)/2) M_e²]
  Recovery factors: r_lam = √Pr ≈ 0.84 | r_turb = ∛Pr ≈ 0.89

BUCKINGHAM PI THEOREM:
  N_Π = n − k  (n = variables, k = primary dimensions M, L, T, θ)

DIMENSIONLESS NUMBERS:
  Re = ρVL / μ  (Inertia / Viscous)
  M  = V / a    (Inertia / Compressibility)
  Fr = V / √(gL) (Inertia / Gravity)
  Pr = μ c_p / k = ν / α (Momentum diff / Thermal diff)
  Kn = λ / L ≈ 1.25 M / Re  (Continuum if Kn < 0.01)

DYNAMIC SIMILARITY:
  Re_m = Re_p  AND  M_m = M_p
  Pressurized Tunnel: p_m = p_p · (L_p / L_m)
```
