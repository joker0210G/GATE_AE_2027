### Step 3 — Integration Techniques (20 min)

**Technique 1 — Substitution ($u$-sub):**
When you see $f(g(x))\cdot g'(x)$ → let $u=g(x)$, $du=g'(x)dx$
> *Pattern:* Derivative of inside is present (or proportional) outside

**Technique 2 — Integration by Parts:**
$$\int u\,dv = uv - \int v\,du$$
**ILATE rule** (choose $u$ in this priority order):
**I**nverse trig, **L**ogarithm, **A**lgebraic, **T**rigonometric, **E**xponential

*Classic examples:*
- $\int x e^x\,dx$: $u=x$ ($A$), $dv=e^x dx$
- $\int x\sin x\,dx$: $u=x$ ($A$), $dv=\sin x\,dx$
- $\int \ln x\,dx$: $u=\ln x$ ($L$), $dv=dx$

**Technique 3 — Partial Fractions:**
For $\frac{P(x)}{Q(x)}$ where $\deg P < \deg Q$. Factor $Q(x)$ and decompose:
- Linear factor $(x-a)$: $\frac{A}{x-a}$
- Repeated linear $(x-a)^2$: $\frac{A}{x-a}+\frac{B}{(x-a)^2}$
- Irreducible quadratic $(x^2+bx+c)$: $\frac{Ax+B}{x^2+bx+c}$

**Technique 4 — Trig Substitutions:**
| Integrand form | Substitution | Result |
|---|---|---|
| $\sqrt{a^2-x^2}$ | $x=a\sin\theta$ | $\sqrt{a^2-x^2}=a\cos\theta$ |
| $\sqrt{a^2+x^2}$ | $x=a\tan\theta$ | $\sqrt{a^2+x^2}=a\sec\theta$ |
| $\sqrt{x^2-a^2}$ | $x=a\sec\theta$ | $\sqrt{x^2-a^2}=a\tan\theta$ |

**Technique 5 — Reduction Formulas (GATE shortcut):**
$$\int\sin^n x\,dx = -\frac{\sin^{n-1}x\cos x}{n}+\frac{n-1}{n}\int\sin^{n-2}x\,dx$$
$$\int\cos^n x\,dx = \frac{\cos^{n-1}x\sin x}{n}+\frac{n-1}{n}\int\cos^{n-2}x\,dx$$

### Step 4 — Definite Integrals & Key Properties (10 min)

**Fundamental Theorem of Calculus:**
$$\int_a^b f(x)\,dx = F(b)-F(a) \quad \text{where }F'(x)=f(x)$$

**Leibniz Rule (GATE Favourite):**
$$\frac{d}{dx}\int_{g(x)}^{h(x)}f(t)\,dt = f(h(x))\cdot h'(x) - f(g(x))\cdot g'(x)$$

**Properties of Definite Integrals — Burn these 8 in:**

| Property | Formula | Recall? |
|---|---|---|
| Reversal | $\int_a^b f\,dx = -\int_b^a f\,dx$ | ☐ |
| Splitting | $\int_a^b f\,dx = \int_a^c f\,dx+\int_c^b f\,dx$ | ☐ |
| Zero | $\int_a^a f\,dx=0$ | ☐ |
| Constant scale | $\int_a^b kf\,dx = k\int_a^b f\,dx$ | ☐ |
| Shift: $a+b-x$ | $\int_a^b f(x)\,dx=\int_a^b f(a+b-x)\,dx$ | ☐ |
| King's property | $\int_0^a f(x)\,dx=\int_0^a f(a-x)\,dx$ | ☐ |
| Even function | $\int_{-a}^a f\,dx=2\int_0^a f\,dx$ if $f(-x)=f(x)$ | ☐ |
| Odd function | $\int_{-a}^a f\,dx=0$ if $f(-x)=-f(x)$ | ☐ |

**Wallis' Formula (definite integral shortcut):**
$$\int_0^{\pi/2}\sin^n x\,dx=\int_0^{\pi/2}\cos^n x\,dx = \begin{cases}\frac{(n-1)!!}{n!!}\cdot\frac{\pi}{2}&n\text{ even}\\\frac{(n-1)!!}{n!!}&n\text{ odd}\end{cases}$$

### Step 5 — 4 Traps (5 min)
> 🔴 **Trap 1:** $\int\frac{1}{x}\,dx=\ln x+C$ — write $\ln|x|+C$ (valid for $x<0$ too)
> 🔴 **Trap 2:** Leibniz rule — don't forget to multiply by derivative of the limits
> 🔴 **Trap 3:** ILATE rule — $\ln x$ is always chosen as $u$ over algebraic/trig functions
> 🔴 **Trap 4:** Odd function on $[-a,a]$: integral is ZERO — saves huge computation time

### D4 Mini Quiz (3:45–4:00)

> **Q1 (1 mark):** $\int\dfrac{x}{1+x^2}\,dx=$
> **(A)** $\ln(1+x^2)+C$ **(B)** $\frac{1}{2}\ln(1+x^2)+C$ **(C)** $\tan^{-1}x+C$ **(D)** $\frac{1}{2}\tan^{-1}x+C$

> **Q3 (1 mark NAT):** $\int_0^{\pi/2}\dfrac{\sin x}{\sin x+\cos x}\,dx=$ ___

> **Q4 (2 marks):** $\int xe^x\,dx=$
> **(A)** $xe^x-e^x+C$ **(B)** $xe^x+e^x+C$ **(C)** $e^x(x-1)+C$ **(D)** $xe^x+C$

> **Q5 (1 mark):** $\dfrac{d}{dx}\int_0^{x^2}e^{-t^2}\,dt=$
> **(A)** $e^{-x^4}$ **(B)** $2xe^{-x^4}$ **(C)** $e^{-x^2}$ **(D)** $2xe^{-x^2}$

> [!faq]- 🔍 View D4 Mini Quiz Answers
>
> **Q1: (B) $\frac{1}{2}\ln(1+x^2)+C$**
> Let $u=1+x^2$, $du=2x\,dx$. So $\int\frac{x}{1+x^2}dx=\frac{1}{2}\int\frac{du}{u}=\frac{1}{2}\ln|u|=\frac{1}{2}\ln(1+x^2)+C$
>
> **Q2: (C) 0**
> $f(x)=x^3\sin^2x$. Check: $f(-x)=(-x)^3\sin^2(-x)=-x^3\sin^2x=-f(x)$. Odd function!
> $\int_{-\pi}^{\pi}(\text{odd})=0$
>
> **Q3: $\pi/4$**
> Use King's property: $I=\int_0^{\pi/2}\frac{\sin x}{\sin x+\cos x}dx$
> King's: $I=\int_0^{\pi/2}\frac{\cos x}{\cos x+\sin x}dx$
> Add: $2I=\int_0^{\pi/2}1\,dx=\frac{\pi}{2} \Rightarrow I=\frac{\pi}{4}$
>
> **Q4: (C) $e^x(x-1)+C$** (same as (A) since $xe^x-e^x=e^x(x-1)$)
> By parts: $u=x$, $dv=e^xdx \Rightarrow v=e^x$
> $\int xe^x\,dx = xe^x - \int e^x\,dx = xe^x-e^x+C = e^x(x-1)+C$
>
> **Q5: (B) $2xe^{-x^4}$**
> Leibniz rule: $\frac{d}{dx}\int_0^{x^2}e^{-t^2}dt = e^{-(x^2)^2}\cdot\frac{d}{dx}(x^2) = e^{-x^4}\cdot2x$
