### Step 2 — Bisection Method Master Facts (15 min)
Open `04.1 - Bisection Method`.

1. **Intermediate Value Theorem (IVT):** If $f(x)$ is continuous on $[a, b]$ and $f(a) \cdot f(b) < 0$, $\exists \alpha \in (a, b)$ such that $f(\alpha) = 0$.
2. **Iteration Formula:** $c_k = \frac{a_k + b_k}{2}$.
3. **Interval Halving Law:** After $n$ iterations, interval length $L_n = \frac{b_0 - a_0}{2^n}$.
4. **Error Bound:** $|c_n - \alpha| \le \frac{b_0 - a_0}{2^{n+1}}$.
5. **Minimum Iterations for Tolerance $\epsilon$:**
   $$\boxed{n > \frac{\ln\left(\frac{b_0 - a_0}{\epsilon}\right)}{\ln 2} = \log_2\left(\frac{b_0 - a_0}{\epsilon}\right)}$$
6. **Convergence:** Linear Convergence ($p = 1$, rate $= 0.5$). Guaranteed to converge, but slow.

---

### Step 3 — Newton-Raphson Method (The #1 GATE Root Method) (20 min)
Open `04.2 - Newton Raphson Method`.

1. **Master Iteration Formula:**
   $$\boxed{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}}$$
2. **Order of Convergence:**
   - **Quadratic Convergence ($p = 2$):** Error $e_{n+1} \approx C \cdot e_n^2$ where $C = \left|\frac{f''(\alpha)}{2f'(\alpha)}\right|$.
   - Number of correct decimal places **doubles** with each iteration!
3. **Sufficient Condition for Convergence:** $\left|\frac{f(x) \cdot f''(x)}{[f'(x)]^2}\right| < 1$.
4. **Special Reciprocal & Root Iteration Formulas (Memorize for GATE!):**
   - **Square Root of $N$ ($x = \sqrt{N} \implies f(x) = x^2 - N = 0$):**
     $$\boxed{x_{n+1} = \frac{1}{2}\left(x_n + \frac{N}{x_n}\right)}$$
   - **Reciprocal / Inverse of $N$ ($x = 1/N \implies f(x) = \frac{1}{x} - N = 0$):**
     $$\boxed{x_{n+1} = x_n(2 - N x_n)}$$ *(Division-free calculation!)*
   - **$k$-th Root of $N$ ($x = N^{1/k}$):**
     $$x_{n+1} = \frac{1}{k}\left[(k-1)x_n + \frac{N}{x_n^{k-1}}\right]$$
5. **Failure Cases:** $f'(x_n) = 0$ (horizontal tangent / division by zero), inflection point oscillations, root with multiplicity $m > 1$ (convergence drops to linear $p=1$ unless modified to $x_{n+1} = x_n - m \frac{f(x_n)}{f'(x_n)}$).

### Step 4 — Numerical Differentiation (Finite Differences) (15 min)
Open `04.3 - Numerical Differentiation`.

| Scheme | Formula for $f'(x_0)$ | Truncation Error Order |
|---|---|---|
| **Forward Difference** | $\dfrac{f(x_0 + h) - f(x_0)}{h}$ | $\mathcal{O}(h)$ (1st order accurate) |
| **Backward Difference** | $\dfrac{f(x_0) - f(x_0 - h)}{h}$ | $\mathcal{O}(h)$ (1st order accurate) |
| **Central Difference** | $\dfrac{f(x_0 + h) - f(x_0 - h)}{2h}$ | $\mathcal{O}(h^2)$ (**2nd order accurate!**) |
| **Second Derivative (Central)** | $\dfrac{f(x_0 + h) - 2f(x_0) + f(x_0 - h)}{h^2}$ | $\mathcal{O}(h^2)$ |

> ⚡ **GATE Insight:** Central difference is ALWAYS preferred over forward/backward because it cancels the 1st-order error terms, giving $\mathcal{O}(h^2)$ accuracy with the same grid step $h$!

---

### Step 5 — Traps & Self-Check (5 min)
> 🔴 **Trap 1:** Forgetting to check $f'(x_0)$ before running Newton-Raphson. If $f'(x_0) = 0$, the algorithm blows up.
> 🔴 **Trap 2:** For Central difference, denominator is $2h$, NOT $h$. For Second derivative central difference, denominator is $h^2$.

> **Q4 (1 mark):** The minimum number of iterations required in the Bisection method to achieve an accuracy of $10^{-3}$ on the initial interval $[0, 1]$ is:

> **Q5 (1 mark):** The central difference approximation for the first derivative of a function $f(x)$ with step size $h$ has a truncation error of order:
> **(A)** $\mathcal{O}(h)$ **(B)** $\mathcal{O}(h^2)$ **(C)** $\mathcal{O}(h^3)$ **(D)** $\mathcal{O}(1/h)$

> [!faq]- 🔍 View D1 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (C) 2**
> Newton-Raphson has quadratic convergence ($p = 2$) for simple roots ($f'(\alpha) \neq 0$).
>
> **Q2: (A) 2.1**
> $f(x) = x^3 - 2x - 5 \implies f(2) = 2^3 - 2(2) - 5 = 8 - 4 - 5 = -1$.
> $f'(x) = 3x^2 - 2 \implies f'(2) = 3(2^2) - 2 = 12 - 2 = 10$.
> $x_1 = x_0 - \frac{f(x_0)}{f'(x_0)} = 2 - \frac{-1}{10} = 2 + 0.1 = \mathbf{2.1}$.
>
> **Q3: (A) 2.25**
> Using square root formula $x_{n+1} = \frac{1}{2}\left(x_n + \frac{N}{x_n}\right)$ with $N = 5, x_0 = 2$:
> $x_1 = \frac{1}{2}\left(2 + \frac{5}{2}\right) = \frac{1}{2}(2 + 2.5) = \frac{4.5}{2} = \mathbf{2.25}$.
>
> **Q4: (B) 10**
> $n > \frac{\ln[(1 - 0)/10^{-3}]}{\ln 2} = \frac{\ln(1000)}{\ln 2} = \frac{6.9077}{0.6931} \approx 9.96$.
> Smallest integer $n = \mathbf{10}$.
>
> **Q5: (B) O(h²)**
> Central difference cancels the first-order Taylor expansion terms $\implies \mathcal{O}(h^2)$ (second-order accurate).
