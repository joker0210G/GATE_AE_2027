### Step 2 — Plane Stress State Fundamentals (20 min)
Open `01 - Stress Strain and Elasticity`.

```
                    PLANE STRESS STATE (THIN STRUCTURES t ≪ L, W)
                           Free Surfaces Top & Bottom
                         ┌───────────────────────────┐
                    σ_x ◄┤     Thickness t ≪ L       ├► σ_x
                         │   σ_z = 0, τ_xz = τ_yz = 0│
                         └───────────────────────────┘
                         ▲ Out-of-plane strain ε_z ≠ 0 (Free Poisson contraction!)
```

1. **Assumptions & Conditions:**
   - Stress field: $\mathbf{\sigma_z = 0, \quad \tau_{xz} = 0, \quad \tau_{yz} = 0}$.
   - Non-zero components: $\sigma_x, \sigma_y, \tau_{xy}$.
   - **Out-of-Plane Normal Strain ($\epsilon_z$):**
     $$\boxed{\epsilon_z = -\frac{\nu}{E}(\sigma_x + \sigma_y) = -\frac{\nu}{1-\nu}(\epsilon_x + \epsilon_y) \ne 0}$$

2. **Direct Hooke's Law (Strains in terms of Stresses):**
   $$\epsilon_x = \frac{1}{E}(\sigma_x - \nu \sigma_y), \quad \epsilon_y = \frac{1}{E}(\sigma_y - \nu \sigma_x), \quad \gamma_{xy} = \frac{\tau_{xy}}{G}$$

3. **Inverted Constitutive Equations (Stresses in terms of Strains):**
   $$\boxed{\sigma_x = \frac{E}{1 - \nu^2}(\epsilon_x + \nu \epsilon_y)}$$
   $$\boxed{\sigma_y = \frac{E}{1 - \nu^2}(\epsilon_y + \nu \epsilon_x)}$$
   $$\boxed{\tau_{xy} = G \gamma_{xy} = \frac{E}{2(1+\nu)}\gamma_{xy}}$$

### Step 3 — Plane Strain State Fundamentals (20 min)

```
                    PLANE STRAIN STATE (THICK / LONG STRUCTURES L ≫ t)
                         Rigidly Constrained in Z-direction
                         ┌───────────────────────────┐
                    σ_x ◄┤       Long / Thick Body   ├► σ_x
                         │ ε_z = 0, γ_xz = 0, γ_yz = 0│
                         └───────────────────────────┘
                         ▲ Out-of-plane stress σ_z ≠ 0 (Reaction against constraint!)
```

1. **Assumptions & Conditions:**
   - Strain field: $\mathbf{\epsilon_z = 0, \quad \gamma_{xz} = 0, \quad \gamma_{yz} = 0}$.
   - Non-zero components: $\epsilon_x, \epsilon_y, \gamma_{xy}$.
   - **Out-of-Plane Normal Stress ($\sigma_z$):**
     $$\epsilon_z = \frac{1}{E}[\sigma_z - \nu(\sigma_x + \sigma_y)] = 0 \implies \boxed{\sigma_z = \nu(\sigma_x + \sigma_y) \ne 0}$$

2. **Inverted Constitutive Equations (Stresses in terms of Strains):**
   $$\boxed{\sigma_x = \frac{E}{(1+\nu)(1-2\nu)}\left[(1-\nu)\epsilon_x + \nu \epsilon_y\right]}$$
   $$\boxed{\sigma_y = \frac{E}{(1+\nu)(1-2\nu)}\left[(1-\nu)\epsilon_y + \nu \epsilon_x\right]}$$
   $$\boxed{\tau_{xy} = G \gamma_{xy}}$$

---

### Step 4 — Master Equivalence Transformation Rule (15 min)

Any equation valid for **Plane Stress** can be instantly converted to **Plane Strain** by replacing material constants:

$$\boxed{E \longrightarrow \frac{E}{1 - \nu^2} \qquad \text{and} \qquad \nu \longrightarrow \frac{\nu}{1 - \nu}}$$

```
                    PLANE STRESS vs. PLANE STRAIN COMPARISON
  Feature                  Plane Stress State                 Plane Strain State
  ─────────────────────────────────────────────────────────────────────────────
  Physical Regime          Thin plates / Aircraft skin (t ≪ L) Thick bulkheads / Dams (L ≫ t)
  Stress Field             σ_z = 0, τ_xz = 0, τ_yz = 0        σ_z = ν(σ_x + σ_y) ≠ 0
  Strain Field             ε_z = −(ν/E)(σ_x + σ_y) ≠ 0        ε_z = 0, γ_xz = 0, γ_yz = 0
  Constitutive Factor      E / (1 − ν²)                       E / [(1+ν)(1−2ν)]
```

---

### Step 5 — Traps & Self-Check (5 min)
> 🔴 **Trap 1: Out-of-Plane Quantities**
> In Plane Stress, $\sigma_z = 0$ but $\mathbf{\epsilon_z \ne 0}$ (unless $\sigma_x = -\sigma_y$). In Plane Strain, $\epsilon_z = 0$ but $\mathbf{\sigma_z \ne 0}$ (unless $\sigma_x = -\sigma_y$).
> 🔴 **Trap 2: 3D Mohr's Circle in Plane Stress**
> Because $\sigma_z = 0$, the third principal stress is $\mathbf{\sigma_3 = 0}$. If both in-plane principal stresses $\sigma_1, \sigma_2$ are tensile ($>0$), the absolute maximum shear stress is $\mathbf{\tau_{\max,\text{abs}} = \frac{\sigma_1 - 0}{2} = \frac{\sigma_1}{2}}$, NOT $\frac{\sigma_1 - \sigma_2}{2}$!

### Step 3 — D2 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** In a state of plane stress ($\sigma_z = \tau_{xz} = \tau_{yz} = 0$), the out-of-plane normal strain $\epsilon_z$ is zero ONLY when:
> **(A)** $\sigma_x = \sigma_y$ **(B)** $\sigma_x = -\sigma_y$ **(C)** $\tau_{xy} = 0$ **(D)** $\nu = 0.5$

> **Q2 (1 mark):** A body is in a state of plane strain in the $x\text{--}y$ plane ($\epsilon_z = 0$). If $\sigma_x = 100\text{ MPa}, \sigma_y = 50\text{ MPa}$, and $\nu = 0.30$, the normal stress $\sigma_z$ is:
> **(A)** $0\text{ MPa}$ **(B)** $15\text{ MPa}$ **(C)** $30\text{ MPa}$ **(D)** $45\text{ MPa}$

> **Q3 (2 marks):** A thin aluminum plate ($E = 70\text{ GPa}, \nu = 0.33$) in plane stress experiences strains $\epsilon_x = 1.0\times 10^{-3}$ and $\epsilon_y = 0.40\times 10^{-3}$. The normal stress $\sigma_x$ (in $\text{MPa}$) is:
> **(A)** $65.2\text{ MPa}$ **(B)** $78.4\text{ MPa}$ **(C)** $88.9\text{ MPa}$ **(D)** $98.0\text{ MPa}$

> **Q4 (2 marks):** A structure in plane strain ($E = 200\text{ GPa}, \nu = 0.25$) has strains $\epsilon_x = 6.0\times 10^{-4}$ and $\epsilon_y = 2.0\times 10^{-4}$. The normal stress $\sigma_x$ (in $\text{MPa}$) is:
> **(A)** $120.0\text{ MPa}$ **(B)** $140.0\text{ MPa}$ **(C)** $160.0\text{ MPa}$ **(D)** $180.0\text{ MPa}$

> **Q5 (2 marks NAT):** A thin steel sheet ($E = 200\text{ GPa}, \nu = 0.30$) in plane stress is subjected to $\sigma_x = 240\text{ MPa}$ and $\sigma_y = 160\text{ MPa}$. The out-of-plane normal strain $\epsilon_z$ (in microstrains, $\mu\epsilon \equiv \epsilon \times 10^6$) is ___ $\mu\epsilon$.

> [!faq]- 🔍 View D2 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (B) σ_x = −σ_y**
> $\epsilon_z = -\frac{\nu}{E}(\sigma_x + \sigma_y) = 0 \implies \sigma_x + \sigma_y = 0 \implies \mathbf{\sigma_x = -\sigma_y}$.
>
> **Q2: (D) 45 MPa**
> $\sigma_z = \nu(\sigma_x + \sigma_y) = 0.30(100 + 50) = 0.30(150) = \mathbf{45.0\text{ MPa}}$.
>
> **Q3: (C) 88.9 MPa**
> $\sigma_x = \frac{E}{1 - \nu^2}(\epsilon_x + \nu \epsilon_y) = \frac{70\times 10^3}{1 - (0.33)^2}[1.0\times 10^{-3} + 0.33(0.40\times 10^{-3})] = \frac{70000}{0.8911}[1.132\times 10^{-3}] = \frac{79.24}{0.8911} \approx \mathbf{88.92\text{ MPa} \approx 88.9\text{ MPa}}$.
>
> **Q4: (C) 160.0 MPa**
> Factor $= \frac{E}{(1+\nu)(1-2\nu)} = \frac{200\times 10^3}{(1.25)(0.50)} = \frac{200000}{0.625} = 320,000\text{ MPa}$.
> $\sigma_x = 320000[(1 - 0.25)(6.0\times 10^{-4}) + 0.25(2.0\times 10^{-4})] = 320000[4.5\times 10^{-4} + 0.5\times 10^{-4}] = 320000[5.0\times 10^{-4}] = \mathbf{160.0\text{ MPa}}$.
>
> **Q5: −600**
> $\epsilon_z = -\frac{\nu}{E}(\sigma_x + \sigma_y) = -\frac{0.30}{200\times 10^3}(240 + 160) = -\frac{0.30}{200000}(400) = -0.000600 = \mathbf{-600\times 10^{-6} = -600\ \mu\epsilon}$.
