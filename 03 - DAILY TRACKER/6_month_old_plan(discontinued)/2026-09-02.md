### Step 2 — Master Numerical Integration Comparison Table (25 min)
Open `04.4 - Trapezoidal Rule` and `04.5 - Simpsons Rules`.

Let step size $h = \frac{b - a}{n}$, where $x_i = a + i h$ and $y_i = f(x_i)$.

| Rule | Formula | Interval Constraint ($n$) | Exact for Polynomial of Degree | Truncation Error |
|---|---|---|---|---|
| **Trapezoidal Rule** | $\displaystyle I \approx \frac{h}{2}\left[(y_0 + y_n) + 2\sum_{i=1}^{n-1}y_i\right]$ | Any integer $n \ge 1$ | $\le 1$ (Linear) | $E_T = -\frac{(b-a)h^2}{12} f''(\xi) = \mathbf{\mathcal{O}(h^2)}$ |
| **Simpson's 1/3 Rule** | $\displaystyle I \approx \frac{h}{3}\left[(y_0 + y_n) + 4\sum y_{\text{odd}} + 2\sum y_{\text{even}}\right]$ | $n$ **MUST be EVEN** (Odd number of points) | $\le 3$ (**Cubic polynomials!**) | $E_S = -\frac{(b-a)h^4}{180} f^{(4)}(\xi) = \mathbf{\mathcal{O}(h^4)}$ |
| **Simpson's 3/8 Rule** | $\displaystyle I \approx \frac{3h}{8}\left[(y_0 + y_n) + 3\sum y_{\text{not mult of 3}} + 2\sum y_{\text{mult of 3}}\right]$ | $n$ **MUST be MULTIPLE of 3** | $\le 3$ (Cubic) | $E = -\frac{3(b-a)h^4}{80} f^{(4)}(\xi) = \mathbf{\mathcal{O}(h^4)}$ |

#### 🔑 The 3 Super Facts for GATE MCQs:
1. **Simpson's 1/3 integrates cubics $f(x) = ax^3 + bx^2 + cx + d$ EXACTLY** (Zero Error!), even though it fits quadratic parabolas over pairs of intervals.
2. If the function is linear ($f(x) = ax + b$), **Trapezoidal Rule gives the EXACT analytical answer**.
3. Halving the step size ($h \to h/2$):
   - Trapezoidal error reduces by a factor of $2^2 = \mathbf{4}$.
   - Simpson's 1/3 error reduces by a factor of $2^4 = \mathbf{16}$!

### Step 3 — Linear Regression & Method of Least Squares (15 min)
Open `04.6 - Linear Regression` and `04.6b - Least Squares Method`.

To fit a straight line $y = a + b x$ to $n$ data points $(x_1, y_1), \dots, (x_n, y_n)$:

**The 2 Normal Equations:**
$$\boxed{\begin{cases} \sum y = n a + b \sum x \\ \sum xy = a \sum x + b \sum x^2 \end{cases}}$$

- **Slope ($b$):** $\displaystyle b = \frac{n \sum xy - (\sum x)(\sum y)}{n \sum x^2 - (\sum x)^2}$
- **Intercept ($a$):** $\displaystyle a = \bar{y} - b \bar{x} = \frac{\sum y - b \sum x}{n}$

> 💡 **Centered Data Shortcut:** If $\sum x = 0$ (e.g. symmetrical points $x = -2, -1, 0, 1, 2$), the normal equations uncouple instantly:
> $$a = \frac{\sum y}{n} = \bar{y}, \qquad b = \frac{\sum xy}{\sum x^2}$$

### Step 4 — Linear Interpolation (5 min)
For a point $x$ between $(x_0, y_0)$ and $(x_1, y_1)$:
$$y = y_0 + \frac{y_1 - y_0}{x_1 - x_0}(x - x_0)$$

### Step 5 — Traps & Self-Check (10 min)
> 🔴 **Trap 1: Simpson's 1/3 Rule Subinterval Count**
> You CANNOT apply Simpson's 1/3 rule if $n$ is odd (e.g. 3 subintervals). $n$ must be 2, 4, 6, 8...
> 🔴 **Trap 2: Simpson's 1/3 Odd vs. Even Multipliers**
> In Simpson's 1/3: Multiplier 4 is for ODD subscripts ($y_1, y_3, y_5$), and Multiplier 2 is for EVEN subscripts ($y_2, y_4, y_6$).

**Self-Check:**
1. Error order of Simpson's 1/3 rule is: ___ *(Ans: $\mathcal{O}(h^4)$)*
2. Exact value of $\int_0^2 (x^3 + 2)dx$ using Simpson's 1/3 with $h=1$ vs Analytical: ___ *(Ans: Identical! Zero error because degree $\le 3$)*

### Step 3 — D2 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** Simpson's 1/3 rule evaluates the integral $\int_a^b P(x)dx$ EXACTLY (zero truncation error) for any polynomial $P(x)$ of degree up to:
> **(A)** $1$ **(B)** $2$ **(C)** $3$ **(D)** $4$

> **Q2 (2 marks):** Using the Trapezoidal rule with $2$ equal subintervals ($h = 1$), the estimated value of $\int_0^2 x^3 dx$ is:
> **(A)** $4$ **(B)** $5$ **(C)** $4.5$ **(D)** $6$

> **Q3 (2 marks):** For the integral $\int_0^6 f(x)dx$, the minimum number of subintervals required to apply Simpson's 3/8 rule is:
> **(A)** $2$ **(B)** $3$ **(C)** $4$ **(D)** $6$

> **Q4 (1 mark):** If the step size $h$ in Simpson's 1/3 rule is halved, the global truncation error decreases by a factor of:
> **(A)** $2$ **(B)** $4$ **(C)** $8$ **(D)** $16$

> **Q5 (2 marks NAT):** Using the method of least squares to fit a line $y = a + bx$ to the points $(-1, 0), (0, 2), (1, 4)$, the value of the slope $b$ is ___.

> [!faq]- 🔍 View D2 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (C) 3**
> Even though Simpson's 1/3 rule uses quadratic parabolas, the odd-symmetry of the error term causes the 3rd derivative term to vanish, making it **exact for cubic polynomials (degree $\le 3$)**.
>
> **Q2: (B) 5**
> $a = 0, b = 2, n = 2 \implies h = 1$. Points: $x_0 = 0, x_1 = 1, x_2 = 2$.
> $y_0 = 0^3 = 0, y_1 = 1^3 = 1, y_2 = 2^3 = 8$.
> $I \approx \frac{h}{2}[y_0 + y_2 + 2y_1] = \frac{1}{2}[0 + 8 + 2(1)] = \frac{10}{2} = \mathbf{5}$.
> *(Analytical value is $\int_0^2 x^3 dx = [x^4/4]_0^2 = 4$. Trapezoidal overestimates convex functions).*
>
> **Q3: (B) 3**
> Simpson's 3/8 rule requires the number of subintervals $n$ to be a multiple of 3 $\implies$ minimum $n = \mathbf{3}$.
>
> **Q4: (D) 16**
> Error of Simpson's 1/3 is $\mathcal{O}(h^4)$. When $h \to h/2$, error $\to (h/2)^4 = \frac{1}{16} h^4 \implies$ decreases by factor of **16**.
>
> **Q5: 2**
> Symmetrical $x$-values: $\sum x = -1 + 0 + 1 = 0$.
> $\sum xy = (-1)(0) + (0)(2) + (1)(4) = 4$.
> $\sum x^2 = (-1)^2 + 0^2 + 1^2 = 2$.
> Slope $b = \frac{\sum xy}{\sum x^2} = \frac{4}{2} = \mathbf{2}$.
