#### 📌 BLOCK 1 — Elementary Potential Flows
```
GOVERNING EQ: ∇²ϕ = 0  AND  ∇²ψ = 0 (Linear ⟹ Superposition valid)

ELEMENTARY FLOWS:
  1. Uniform Flow: ϕ = V_inf r cos(θ − α) | ψ = V_inf r sin(θ − α)
  2. Source (+Λ) / Sink (−Λ): ϕ = (Λ/2π) ln r | ψ = (Λ/2π) θ | v_r = Λ/(2πr)
  3. Doublet (κ = 2π R² V_inf): ϕ = (κ/2π) (cos θ / r) | ψ = −(κ/2π) (sin θ / r)
  4. Point Vortex (Clockwise Γ): ϕ = −(Γ/2π) θ | ψ = (Γ/2π) ln r | v_θ = −Γ/(2πr)

PRESSURE COEFFICIENT:
  C_p = 1 − (V / V_inf)² | Stagnation point (V = 0) ⟹ C_p = +1.0
```

#### 📌 BLOCK 2 — Flow Past Cylinders & Kutta-Joukowski Theorem
```
NON-LIFTING CYLINDER (Uniform + Doublet):
  ψ = V_inf r sin θ [1 − R²/r²]
  Surface Velocity: v_θ = −2 V_inf sin θ | v_r = 0
  Surface C_p: C_p(θ) = 1 − 4 sin² θ (Min at top/bottom = −3.0; Max at stagnation = +1.0)
  D'Alembert's Paradox: L' = 0, D' = 0

LIFTING CYLINDER (Uniform + Doublet + Vortex):
  Surface Velocity: v_θ = −2 V_inf sin θ − Γ / (2πR)
  Stagnation Points: sin θ_s = −Γ / (4π V_inf R)
  Regimes:
    Γ = 0            ⟹ 2 points at θ = 0°, 180°
    Γ < 4π V_inf R   ⟹ 2 points in lower half
    Γ = 4π V_inf R   ⟹ 1 point at bottom (θ = 270°)
    Γ > 4π V_inf R   ⟹ 0 points on surface (floats below)

KUTTA-JOUKOWSKI THEOREM:
  L' = ρ_inf V_inf Γ  (Lift per unit span, perpendicular to V_inf)
  D' = 0              (Inviscid potential flow)
```

#### 📌 BLOCK 3 — Thin Airfoil Theory
```
GLAUERT TRANSFORMATION: x = (c/2) (1 − cos θ)

FOURIER COEFFICIENTS:
  A₀ = α − (1/π) ∫₀^π (dz/dx) dθ
  A_n = (2/π) ∫₀^π (dz/dx) cos(nθ) dθ

AERODYNAMIC PROPERTIES:
  Lift Coefficient: C_L = 2π (A₀ + A₁/2) = 2π (α − α_{L=0})
  Lift Curve Slope: dC_L/dα = 2π rad⁻¹ ≈ 0.1097 deg⁻¹ (Universal!)
  Zero-Lift Angle : α_{L=0} = −(1/π) ∫₀^π (dz/dx) (cos θ − 1) dθ = (1/π) ∫₀^π (dz/dx) dθ − A₁/2
  Pitching Moment : C_{m,c/4} = (π/4) (A₂ − A₁) = const (indep of α)
  Aerodynamic Ctr : x_ac = c/4 = 0.25c (always for 2D thin subsonic!)
  Center of Press : x_cp = (c/4) [1 + (π/C_L)(A₁ − A₂)]

PARABOLIC CAMBER SHORTCUT (z = 4h (x/c)(1 − x/c)):
  A₁ = 4h/c, A₂ = 0 ⟹ α_{L=0} = −2h/c rad ⟹ C_{m,c/4} = −πh/c
```

#### 📌 BLOCK 4 — Kutta Condition & NACA Nomenclature
```
KUTTA CONDITION:
  Flow leaves sharp TE smoothly ⟹ γ(c) = 0
  Cusp TE: V_upper = V_lower at TE | Finite angle TE: Stagnation point at TE

KELVIN'S THEOREM & STARTING VORTEX:
  DΓ/Dt = 0 ⟹ Γ_bound + Γ_start = 0 ⟹ Γ_bound = −Γ_start

NACA 4-DIGIT AIRFOILS (NACA MPXX):
  M  = Max camber in % chord (e.g. 4 = 4% = 0.04c)
  P  = Location of max camber in tenths of chord (e.g. 4 = 40% = 0.4c)
  XX = Max thickness in % chord (e.g. 12 = 12% = 0.12c)

HIGH-SPEED THRESHOLDS:
  Critical Mach (M_cr): Free stream M where local M_max reaches 1.0
  Prandtl-Glauert: C_p = C_{p,0} / √(1 − M_inf²) | C_L = C_{L,0} / √(1 − M_inf²)
  Drag Divergence (M_dd): M where dC_D/dM reaches 0.1
```

#### 📌 BLOCK 5 — 3D Finite Wing Theory (Prandtl Lifting-Line)
```
ASPECT RATIO: AR = b² / S = b / c̄
EFFECTIVE ANGLE: α_eff = α − α_i | α_i = w / V_inf (rad)
INDUCED DRAG: D_i = L · α_i ⟹ C_Di = C_L · α_i

ELLIPTIC LIFT DISTRIBUTION (Minimum Induced Drag):
  Circulation : Γ(y) = Γ₀ √(1 − (2y/b)²)
  Downwash    : w = Γ₀ / (2b) = CONSTANT across span
  Induced AoA : α_i = C_L / (π AR) rad = (57.3 C_L) / (π AR) deg
  Induced Drag: C_Di = C_L² / (π AR)
  3D Lift Slope: a = a₀ / [1 + a₀ / (π AR)] = 2π / [1 + 2/AR]

GENERAL (NON-ELLIPTIC) WINGS:
  C_L  = π AR A₁
  C_Di = C_L² / (π e AR) = (C_L² / π AR) (1 + δ)
  Span Efficiency Factor: e = 1 / (1 + δ) ≤ 1.0
  3D Lift Slope: a = a₀ / [1 + a₀ / (π e₁ AR)]
```
