1. **Definition:** $\frac{\partial f}{\partial x} = f_x = \lim_{h\to0} \frac{f(x+h, y) - f(x, y)}{h}$ (treat all other variables as constants).
2. **Clairaut's / Schwarz's Theorem:** $f_{xy} = f_{yx}$ for all smooth continuous functions.
3. **Total Differential:**
   $$dz = \frac{\partial f}{\partial x}dx + \frac{\partial f}{\partial y}dy$$
   For 3 variables: $dw = f_x dx + f_y dy + f_z dz$.
4. **Multivariable Chain Rule (Tree Method):**
   - Single parameter $t$: $\frac{dz}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}$
   - Two parameters $s, t$: $\frac{\partial z}{\partial s} = \frac{\partial f}{\partial x}\frac{\partial x}{\partial s} + \frac{\partial f}{\partial y}\frac{\partial y}{\partial s}$

### Step 3 — Euler's Theorem for Homogeneous Functions (GATE Goldmine!) (15 min)

A function $u = f(x, y)$ is **homogeneous of degree $n$** if $f(tx, ty) = t^n f(x, y)$.

**Master Theorems:**

| Theorem | Formula | Notes |
|---|---|---|
| **First-Order Euler's** | $x \frac{\partial u}{\partial x} + y \frac{\partial u}{\partial y} = n u$ | For 3 variables: $x u_x + y u_y + z u_z = n u$ |
| **Second-Order Euler's** | $x^2 \frac{\partial^2 u}{\partial x^2} + 2xy \frac{\partial^2 u}{\partial x \partial y} + y^2 \frac{\partial^2 u}{\partial y^2} = n(n-1)u$ | Instant 2-mark evaluation |
| **Composite Euler's Rule** | If $z = f(u)$ where $u(x,y)$ is homogeneous of degree $n$:<br>$x \frac{\partial z}{\partial x} + y \frac{\partial z}{\partial y} = n \cdot \frac{F(z)}{F'(z)}$ where $F(z) = u$ | e.g., $z = \sin^{-1}\left(\frac{x+y}{\sqrt{x}+\sqrt{y}}\right) \implies \sin z = u$ (deg $1/2$) |

> ⚡ **Composite Shortcut Example:** If $u = \tan^{-1}\left(\frac{x^3 + y^3}{x - y}\right)$, degree of inside $n = 3 - 1 = 2$.
> Then $\tan u = \frac{x^3+y^3}{x-y}$ is homogeneous of degree 2.
> $$x \frac{\partial u}{\partial x} + y \frac{\partial u}{\partial y} = n \frac{F(u)}{F'(u)} = 2 \frac{\tan u}{\sec^2 u} = 2 \sin u \cos u = \mathbf{\sin(2u)}$$

### Step 4 — Gradient ($\nabla \phi$) & Directional Derivatives (15 min)
Open `02.2.2 - Gradient` and `02.2.2.1 - Directional Derivatives`.

1. **Gradient Operator ($\nabla$):**
   $$\nabla \phi = \text{grad}\,\phi = \frac{\partial \phi}{\partial x}\hat{i} + \frac{\partial \phi}{\partial y}\hat{j} + \frac{\partial \phi}{\partial z}\hat{k}$$
   - **Geometric Meaning:** $\nabla \phi$ is a vector **perpendicular (normal)** to the level surface $\phi(x, y, z) = C$ at any point.
   - **Unit Normal Vector to a surface:** $\hat{n} = \frac{\nabla \phi}{|\nabla \phi|}$
   - **Angle $\theta$ between two surfaces $\phi_1 = C_1$ and $\phi_2 = C_2$:**
     $$\cos \theta = \frac{\nabla \phi_1 \cdot \nabla \phi_2}{|\nabla \phi_1| |\nabla \phi_2|}$$

2. **Directional Derivative ($D_{\hat{u}} \phi$):**
   Rate of change of scalar field $\phi$ in the direction of unit vector $\hat{u}$:
   $$\boxed{D_{\hat{u}} \phi = \nabla \phi \cdot \hat{u} = |\nabla \phi| \cos \theta}$$
   - **Maximum Directional Derivative:** Occurs when $\cos \theta = 1$ (in the direction of $\nabla \phi$).
     $$\text{Max Value} = |\nabla \phi|$$
   - **Minimum Directional Derivative:** Occurs in direction opposite to $\nabla \phi$ ($-\nabla \phi$).
     $$\text{Min Value} = -|\nabla \phi|$$
   - **Zero Directional Derivative:** Occurs along the tangent to the level curve/surface ($\nabla \phi \cdot \hat{u} = 0$).

> ⚠️ **CRITICAL TRAP:** The vector $\vec{a}$ giving the direction must ALWAYS be converted to a **unit vector** $\hat{u} = \frac{\vec{a}}{|\vec{a}|}$ before dotting with $\nabla \phi$!

### Step 5 — Traps & Self-Check (10 min)
> 🔴 **Trap 1:** Forgetting to normalize the direction vector $\hat{u}$ in directional derivative calculations.
> 🔴 **Trap 2:** Applying basic Euler's theorem $x u_x + y u_y = n u$ directly to non-algebraic functions like $\tan^{-1}(...)$ without applying Composite Euler's $n \frac{F}{F'}$.
> 🔴 **Trap 3:** Confusing normal to a surface with tangent plane. Normal vector is $\vec{N} = \nabla \phi$; Tangent plane equation at $(x_0, y_0, z_0)$ is $\nabla \phi \cdot (\vec{r} - \vec{r}_0) = 0 \implies \phi_x(x-x_0) + \phi_y(y-y_0) + \phi_z(z-z_0) = 0$.

### Step 3 — D1 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** If $u = \ln\left(\dfrac{x^4 + y^4}{x + y}\right)$, then $x \dfrac{\partial u}{\partial x} + y \dfrac{\partial u}{\partial y}$ is equal to:

> **Q3 (1 mark):** The unit normal vector to the surface $x^2 + y^2 - z = 1$ at the point $(1, 1, 1)$ is:
> **(A)** $\frac{2\hat{i} + 2\hat{j} - \hat{k}}{3}$ **(B)** $\frac{2\hat{i} + 2\hat{j} + \hat{k}}{3}$ **(C)** $\frac{\hat{i} + \hat{j} - \hat{k}}{\sqrt{3}}$ **(D)** $\frac{2\hat{i} - 2\hat{j} - \hat{k}}{3}$

> **Q4 (2 marks NAT):** The maximum value of the directional derivative of $\phi = 2x^2 + 3y^2 + 5z^2$ at the point $(1, 1, -1)$ is ___ (round off to 2 decimal places).

> **Q5 (1 mark):** If $f(x, y) = x^3 y + e^{x y^2}$, then $\dfrac{\partial^2 f}{\partial x \partial y} - \dfrac{\partial^2 f}{\partial y \partial x} =$
> **(A)** $3x^2$ **(B)** $2xy e^{xy^2}$ **(C)** $0$ **(D)** $1$

> [!faq]- 🔍 View D1 Mini Quiz Answers & Detailed Steps
>
> **Q1: (B) 3**
> Let $e^u = \frac{x^4+y^4}{x+y} = F(x,y)$.
> $F(x,y)$ is homogeneous of degree $n = 4 - 1 = 3$.
> Using composite Euler's theorem:
> $x \frac{\partial u}{\partial x} + y \frac{\partial u}{\partial y} = n \frac{F(u)}{F'(u)} = 3 \frac{e^u}{e^u} = \mathbf{3}$.
>
> **Q2: (A) $\frac{11}{3}$**
> $\nabla \phi = \frac{\partial \phi}{\partial x}\hat{i} + \frac{\partial \phi}{\partial y}\hat{j} + \frac{\partial \phi}{\partial z}\hat{k} = (y^2)\hat{i} + (2xy + z^3)\hat{j} + (3yz^2)\hat{k}$.
> At $(2, -1, 1)$:
> $\nabla \phi = ((-1)^2)\hat{i} + (2(2)(-1) + 1^3)\hat{j} + (3(-1)(1)^2)\hat{k} = \hat{i} - 3\hat{j} - 3\hat{k}$.
> Unit direction vector: $\hat{u} = \frac{2\hat{i} - \hat{j} - 2\hat{k}}{\sqrt{2^2 + (-1)^2 + (-2)^2}} = \frac{2\hat{i} - \hat{j} - 2\hat{k}}{3}$.
> Directional derivative:
> $D_{\hat{u}}\phi = \nabla \phi \cdot \hat{u} = \frac{(1)(2) + (-3)(-1) + (-3)(-2)}{3} = \frac{2 + 3 + 6}{3} = \mathbf{\frac{11}{3}}$.
>
> **Q3: (A) $\frac{2\hat{i} + 2\hat{j} - \hat{k}}{3}$**
> Let $f(x,y,z) = x^2 + y^2 - z - 1 = 0$.
> $\nabla f = 2x\hat{i} + 2y\hat{j} - \hat{k}$.
> At $(1, 1, 1)$: $\nabla f = 2\hat{i} + 2\hat{j} - \hat{k}$.
> Magnitude $|\nabla f| = \sqrt{2^2 + 2^2 + (-1)^2} = \sqrt{9} = 3$.
> Unit normal: $\hat{n} = \frac{\nabla f}{|\nabla f|} = \mathbf{\frac{2\hat{i} + 2\hat{j} - \hat{k}}{3}}$.
>
> **Q4: 11.49**
> $\nabla \phi = 4x\hat{i} + 6y\hat{j} + 10z\hat{k}$.
> At $(1, 1, -1)$: $\nabla \phi = 4\hat{i} + 6\hat{j} - 10\hat{k}$.
> Max directional derivative $= |\nabla \phi| = \sqrt{4^2 + 6^2 + (-10)^2} = \sqrt{16 + 36 + 100} = \sqrt{152} \approx \mathbf{11.49}$.
>
> **Q5: (C) 0**
> By Clairaut's / Schwarz's Theorem, mixed partial derivatives are equal for smooth continuous functions ($f_{xy} = f_{yx} \implies f_{xy} - f_{yx} = \mathbf{0}$).
