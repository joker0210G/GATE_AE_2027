### Step 2 — Eigenvectors: Core Concept (15 min)

**Definition:** $\vec{x}\neq\vec{0}$ is an eigenvector of $A$ for eigenvalue $\lambda$ if $A\vec{x}=\lambda\vec{x}$

**How to find eigenvector for given $\lambda$:**
1. Form matrix $(A-\lambda I)$
2. Solve $(A-\lambda I)\vec{x} = \vec{0}$ (always consistent since $\det(A-\lambda I)=0$)
3. Express solution with free variables → basis of eigenspace

**Eigenspace:** $E_\lambda = \text{Null}(A-\lambda I) = \{\vec{x}: (A-\lambda I)\vec{x}=\vec{0}\}$

**Algebraic Multiplicity (AM):** Multiplicity of $\lambda$ as root of char. poly
**Geometric Multiplicity (GM):** $\dim(E_\lambda) = n - \text{rank}(A-\lambda I)$

> ⚡ **Critical Inequality:** $1 \leq GM(\lambda) \leq AM(\lambda)$ always
> - $GM = AM$ for all eigenvalues → **diagonalizable**
> - $GM < AM$ for some eigenvalue → **NOT diagonalizable** (defective)

### Step 3 — Properties of Eigenvectors (10 min)

| Property | Rule | Recall? |
|---|---|---|
| Eigenvectors for distinct eigenvalues | Always linearly independent | ☐ |
| Scalar multiples of eigenvectors | Also eigenvectors (for same $\lambda$) | ☐ |
| Sum of eigenvectors for different $\lambda$ | Generally NOT an eigenvector | ☐ |
| $A\vec{x}=\lambda\vec{x}$ | $A^k\vec{x}=\lambda^k\vec{x}$, $A^{-1}\vec{x}=(1/\lambda)\vec{x}$ | ☐ |
| Symmetric matrix | Eigenvectors for different eigenvalues are **orthogonal** | ☐ |
| Orthogonal diagonalization | Symmetric $A = QDQ^T$ where $Q$ is orthogonal | ☐ |

### Step 4 — Cayley-Hamilton Deep Dive (15 min)

**Statement:** Every $n\times n$ matrix $A$ satisfies $P(A) = O$ where $P(\lambda)$ is its characteristic polynomial.

**How to use in GATE (3 patterns):**

**Pattern 1 — Find $A^{-1}$ for 2×2:**
Given $A = \begin{pmatrix}2&1\\1&3\end{pmatrix}$:
- Char poly: $\lambda^2 - 5\lambda + 5 = 0$
- By Cayley-Hamilton: $A^2 - 5A + 5I = O$
- Rearrange: $5I = 5A - A^2 = A(5I - A)$
- So $A^{-1} = \frac{1}{5}(5I - A) = I - \frac{A}{5}$

**Pattern 2 — Find $A^{-1}$ for 3×3:**
If char poly is $\lambda^3 - p\lambda^2 + q\lambda - r = O$, then:
$A^3 - pA^2 + qA - rI = O$
$\Rightarrow A^{-1} = \frac{1}{r}(A^2 - pA + qI)$ (divide both sides by $-rA^{-1}$... wait: multiply by $A^{-1}$ and rearrange)
$$A^{-1} = \frac{1}{r}(-A^2+pA-qI+\frac{\det A}{\det A}I)$$
Simpler: $rA^{-1} = A^2 - pA + qI$ → $A^{-1} = \frac{A^2-pA+qI}{r}$

**Pattern 3 — Express high powers:**
If $A^2 = 5A - 6I$ (from char poly), then:
$A^3 = A\cdot A^2 = A(5A-6I) = 5A^2-6A = 5(5A-6I)-6A = 19A-30I$
$A^4 = A\cdot A^3 = A(19A-30I) = 19A^2-30A = 19(5A-6I)-30A = 65A-114I$

### Step 5 — Traps (5 min)
> 🔴 **Trap 1:** GM ≤ AM always — if problem states GM > AM it's impossible
> 🔴 **Trap 2:** Zero vector is NEVER an eigenvector — definition requires $\vec{x}\neq\vec{0}$
> 🔴 **Trap 3:** Eigenvectors of $A$ and $A^{-1}$ for eigenvalue $\lambda$ are THE SAME vectors
> 🔴 **Trap 4:** When using Cayley-Hamilton to find $A^{-1}$: the constant term of char poly must be $\det(A) \neq 0$
