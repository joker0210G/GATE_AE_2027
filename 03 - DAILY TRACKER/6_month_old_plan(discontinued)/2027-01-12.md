## ⏰ HOUR 1 (0:00 – 1:00): 34-MARK CORE THEORY & INVARIANT SCAN

### Step 1 — Aerodynamics Master Invariants (30 min)
1. **Thin Airfoil Theory:**
   - Symmetric: $C_l = 2\pi\alpha, \ C_{m,c/4} = 0, \ x_{\text{ac}} = c/4, \ x_{\text{cp}} = c/4$.
   - Cambered: $C_l = 2\pi(\alpha - \alpha_{L=0}), \ C_{m,c/4} = \frac{\pi}{4}(A_2 - A_1), \ x_{\text{cp}} = \frac{c}{4}\left[1 + \frac{\pi}{C_l}(A_1 - A_2)\right]$.
2. **Finite Wing Theory (Prandtl Lifting Line):**
   - Drag Polar: $C_D = C_{D0} + C_{Di} = C_{D0} + \frac{C_L^2}{\pi e \text{AR}}$.
   - Downwash: $w = \frac{V_\infty C_L}{\pi \text{AR}}$ (for elliptical lift distribution $e = 1.0$).
   - General Wing Lift: $C_L = \pi \text{AR} A_1, \ C_{Di} = \frac{C_L^2}{\pi \text{AR}}(1 + \delta)$ with $\delta = \sum_{n=2}^\infty n \left(\frac{A_n}{A_1}\right)^2$.
3. **Compressible Gas Dynamics:**
   - Isentropic Stagnation: $\frac{T_0}{T} = 1 + \frac{\gamma-1}{2}M^2, \ \frac{p_0}{p} = (1 + \frac{\gamma-1}{2}M^2)^{\frac{\gamma}{\gamma-1}}$.
   - Normal Shock Wave: $M_2^2 = \frac{2 + (\gamma-1)M_1^2}{2\gamma M_1^2 - (\gamma-1)}, \ \frac{p_2}{p_1} = 1 + \frac{2\gamma}{\gamma+1}(M_1^2 - 1)$.
   - Oblique Shock Wave: $M_{n1} = M_1 \sin\beta, \ \tan\theta = 2\cot\beta \left[\frac{M_1^2\sin^2\beta - 1}{M_1^2(\gamma + \cos 2\beta) + 2}\right]$.
   - Prandtl-Meyer Expansion: $\nu(M) = \sqrt{\frac{\gamma+1}{\gamma-1}}\tan^{-1}\sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)} - \tan^{-1}\sqrt{M^2-1}, \ \nu(M_2) = \nu(M_1) + \theta$.
   - Supersonic Flat Plate: $c_l = \frac{4\alpha}{\sqrt{M_\infty^2 - 1}}, \ c_{d,w} = \frac{4\alpha^2}{\sqrt{M_\infty^2 - 1}}$.
4. **Boundary Layer Theory:**
   - Laminar ($dp/dx = 0$): $\frac{\delta}{x} = \frac{5.0}{\sqrt{\text{Re}_x}}, \ C_{f,x} = \frac{0.664}{\sqrt{\text{Re}_x}}, \ C_D = \frac{1.328}{\sqrt{\text{Re}_L}}$.
   - Turbulent ($dp/dx = 0$): $\frac{\delta}{x} = \frac{0.37}{\text{Re}_x^{1/5}}, \ C_{f,x} = \frac{0.0592}{\text{Re}_x^{1/5}}, \ C_D = \frac{0.074}{\text{Re}_L^{1/5}}$.

### Step 2 — Aerospace Structures Master Invariants (30 min)
1. **Constitutive Relations & 3D Elasticity:**
   - Plane Stress: $\sigma_z = 0, \ \epsilon_z = -\frac{\nu}{E}(\sigma_x + \sigma_y), \ \sigma_x = \frac{E}{1-\nu^2}(\epsilon_x + \nu\epsilon_y)$.
   - Plane Strain: $\epsilon_z = 0, \ \sigma_z = \nu(\sigma_x + \sigma_y), \ \sigma_x = \frac{E}{(1+\nu)(1-2\nu)}[(1-\nu)\epsilon_x + \nu\epsilon_y]$.
   - Elastic Constants: $E = 2G(1+\nu) = 3K(1-2\nu) = \frac{9KG}{3K+G}$.
2. **Mohr's Circle & Failure Theories:**
   - Center $C = (\frac{\sigma_x+\sigma_y}{2}, 0)$, Radius $R = \sqrt{(\frac{\sigma_x-\sigma_y}{2})^2 + \tau_{xy}^2}$, $\sigma_{1,2} = \sigma_{\text{avg}} \pm R$.
   - Absolute Max Shear: $\tau_{\max,\text{abs}} = \frac{\sigma_1 - \sigma_3}{2}$ (If $\sigma_1, \sigma_2 > 0 \implies \tau_{\max,\text{abs}} = \frac{\sigma_1}{2}$).
   - Yield Criteria: Tresca ($\tau_{\max} \le 0.50\sigma_y$), von Mises ($\sigma_{\text{vm}} \le \sigma_y, \ \tau_y = \frac{\sigma_y}{\sqrt{3}} \approx 0.577\sigma_y$).
3. **Bending & Unsymmetrical Bending:**
   - Pure Bending: $\frac{M}{I} = \frac{\sigma}{y} = \frac{E}{R}$.
   - Product of Inertia: $I_{xy} = \iint xy \, dA$ (Thin equal Z-section: $I_{xy} = \frac{b^2 h t}{2}$).
   - Unsymmetrical Bending: $\sigma_z = \left(\frac{M_x I_y - M_y I_{xy}}{I_x I_y - I_{xy}^2}\right)y + \left(\frac{M_y I_x - M_x I_{xy}}{I_x I_y - I_{xy}^2}\right)x, \ \tan\alpha_{\text{NA}} = \frac{I_{xy}}{I_y}$ (for pure $M_x$).
4. **Thin-Walled Aircraft Sections, Torsion & Buckling:**
   - Jourawski Shear & Flow: $\tau = \frac{VQ}{Ib}, \ q = \tau t = \frac{VQ}{I}, \ q(s) = q_0 - \frac{V_y}{I_x}\int y t \, ds$.
   - Shear Center: C-channel $e = \frac{3b}{6+h/b}$, Semicircular slit tube $e = \frac{4r}{\pi}$, Angle/T-sections at corner vertex.
   - Bredt-Batho Torsion: $q = \frac{T}{2 A_m} = \text{const}, \ \tau_{\max} = \frac{T}{2 A_m t_{\min}}, \ \theta = \frac{T}{4 A_m^2 G}\oint \frac{ds}{t}$.
   - Euler Column Buckling: $P_{\text{cr}} = \frac{\pi^2 E I_{\min}}{L_e^2}$ ($L_e = L, 2L, 0.5L, 0.707L$).
5. **Energy Methods & Structural Dynamics:**
   - Total Strain Energy: $U_{\text{bending}} = \int \frac{M^2}{2EI}dx, \ U_{\text{axial}} = \frac{P^2 L}{2EA}, \ U_{\text{torsion}} = \frac{T^2 L}{2GJ}$.
   - Castigliano 2nd: $\Delta_i = \frac{\partial U}{\partial P_i} = \int \frac{M}{EI}\frac{\partial M}{\partial P_i}dx, \ \Delta_{\text{truss}} = \sum \frac{nNL}{EA}$.
   - Vibrations: $\omega_n = \sqrt{\frac{k}{m}}, \ \zeta = \frac{c}{2\sqrt{km}}, \ \omega_d = \omega_n\sqrt{1-\zeta^2}, \ \text{DMF}_{\text{res}} = \frac{1}{2\zeta}, \ \det([K]-\omega^2[M]) = 0$.

### Step 3 — D1 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** In thin airfoil theory, the theoretical aerodynamic center location of any 2D thin airfoil is:
> **(A)** Leading edge **(B)** $c/4$ **(C)** $c/2$ **(D)** $3c/4$

> **Q2 (1 mark):** In a state of plane stress, if $\sigma_1 = 160\text{ MPa}$ and $\sigma_2 = 60\text{ MPa}$ (both tensile), the absolute maximum shear stress $\tau_{\max,\text{abs}}$ is:
> **(A)** $50.0\text{ MPa}$ **(B)** $80.0\text{ MPa}$ **(C)** $100.0\text{ MPa}$ **(D)** $160.0\text{ MPa}$

> **Q3 (2 marks):** An elliptical wing of aspect ratio $\text{AR} = 8.0$ operates at lift coefficient $C_L = 0.60$. The induced drag coefficient $C_{Di}$ is:
> **(A)** $0.0095$ **(B)** $0.0143$ **(C)** $0.0286$ **(D)** $0.0450$

> **Q4 (2 marks):** A thin-walled square closed box has side length $a = 50\text{ mm}$ and wall thickness $t = 2.0\text{ mm}$. Under twisting torque $T = 600\text{ N}\cdot\text{m}$, the shear stress developed in the wall (in $\text{MPa}$) is:
> **(A)** $30.0\text{ MPa}$ **(B)** $60.0\text{ MPa}$ **(C)** $90.0\text{ MPa}$ **(D)** $120.0\text{ MPa}$

> **Q5 (2 marks NAT):** An undamped SDOF mass-spring system has mass $m = 4.0\text{ kg}$ and spring stiffness $k = 3600\text{ N/m}$. The natural circular frequency $\omega_n$ (in $\text{rad/s}$) is ___ $\text{rad/s}$.

> [!faq]- 🔍 View D1 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (B) c/4**
> Quarter-chord invariant of thin airfoil theory.
>
> **Q2: (B) 80.0 MPa**
> Ordered 3D stresses: $160 \ge 60 \ge 0 \implies \tau_{\max,\text{abs}} = \frac{160 - 0}{2} = \mathbf{80.0\text{ MPa}}$.
>
> **Q3: (B) 0.0143**
> $C_{Di} = \frac{C_L^2}{\pi \text{AR}} = \frac{0.60^2}{8\pi} = \frac{0.36}{25.1327} \approx \mathbf{0.01432 \approx 0.0143}$.
>
> **Q4: (B) 60.0 MPa**
> $A_m = 50^2 = 2500\text{ mm}^2$.
> $q = \frac{600\times 10^3\text{ N}\cdot\text{mm}}{2(2500\text{ mm}^2)} = \frac{600,000}{5000} = 120\text{ N/mm}$.
> $\tau = \frac{q}{t} = \frac{120\text{ N/mm}}{2.0\text{ mm}} = \mathbf{60.0\text{ MPa}}$.
>
> **Q5: 30.0**
> $\omega_n = \sqrt{\frac{k}{m}} = \sqrt{\frac{3600}{4.0}} = \sqrt{900} = \mathbf{30.0\text{ rad/s}}$.
