#### 📌 BLOCK 1 — Multivariable Differential Calculus
```
TOTAL DIFFERENTIAL: dz = f_x dx + f_y dy | dw = f_x dx + f_y dy + f_z dz
MULTIVARIABLE CHAIN: dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)
IMPLICIT DERIVATIVE: dy/dx = −F_x / F_y | dz/dx = −F_x / F_z

EULER'S THEOREM (Homogeneous f of degree n):
  x·u_x + y·u_y = n·u
  x²·u_xx + 2xy·u_xy + y²·u_yy = n(n−1)·u
  Composite: If f(u) is homogeneous of deg n ⟹ x·u_x + y·u_y = n·[f(u)/f'(u)]
```

#### 📌 BLOCK 2 — Vector Differential Calculus
```
GRADIENT: ∇ϕ = (∂ϕ/∂x)î + (∂ϕ/∂y)ĵ + (∂ϕ/∂z)k̂ (Normal to surface ϕ=C)
  Unit Normal: n̂ = ∇ϕ / |∇ϕ|
  Directional Derivative: D_u ϕ = ∇ϕ · (a / |a|) = |∇ϕ| cos θ
  Max rate of change = |∇ϕ| (in direction of ∇ϕ)

DIVERGENCE: div F = ∇·F = ∂F₁/∂x + ∂F₂/∂y + ∂F₃/∂z
  Solenoidal Vector Field: ∇·F = 0 (Incompressible flow)

CURL: curl F = ∇×F = det[î ĵ k̂; ∂_x ∂_y ∂_z; F₁ F₂ F₃]
  Irrotational Vector Field: ∇×F = 0 (Potential flow F = ∇ϕ)

VECTOR IDENTITIES:
  ∇·(∇×F) = 0 (Div of Curl is ALWAYS 0)
  ∇×(∇ϕ) = 0  (Curl of Grad is ALWAYS 0)
  ∇²ϕ = ∂²ϕ/∂x² + ∂²ϕ/∂y² + ∂²ϕ/∂z² (Laplacian)
```

#### 📌 BLOCK 3 — Vector Integral Calculus & The Big 3 Theorems
```
LINE INTEGRAL: W = ∫_C F·dr = ∫_C (F₁dx + F₂dy + F₃dz)
  Conservative: ∇×F = 0 ⟺ F = ∇ϕ ⟺ ∫_A^B F·dr = ϕ(B) − ϕ(A) ⟺ ∮_C F·dr = 0

GREEN'S THEOREM (2D Plane):
  ∮_C (P dx + Q dy) = ∬_R (∂Q/∂x − ∂P/∂y) dx dy
  Area = (1/2) ∮_C (x dy − y dx)

STOKES' THEOREM (3D Open Surface to Perimeter Loop):
  ∮_C F·dr = ∬_S (∇×F)·n̂ dS

GAUSS DIVERGENCE THEOREM (3D Closed Surface to Solid Volume):
  ∯_S F·n̂ dS = ∭_V (∇·F) dV
  Position Vector Flux: ∯_S r·n̂ dS = 3·Volume(V)
  Solenoidal Vector (∇·F = 0) ⟹ Outward Flux = 0
```

#### 📌 BLOCK 4 — Ordinary Differential Equations (ODEs)
```
1ST ORDER ODEs:
  Exact: M dx + N dy = 0 ⟺ M_y = N_x ⟹ ∫ M dx (y=const) + ∫ N_(free from x) dy = C
  Integrating Factor: IF = exp[∫ (M_y − N_x)/N dx] OR exp[∫ (N_x − M_y)/M dy]
  Linear: y' + P(x)y = Q(x) ⟹ IF = exp[∫ P dx] ⟹ y·IF = ∫ Q·IF dx + C
  Bernoulli: y' + Py = Q·yⁿ ⟹ divide by yⁿ, let v = y¹⁻ⁿ

HIGHER ORDER LINEAR (am² + bm + c = 0):
  Distinct: y_cf = c₁ e^(m₁x) + c₂ e^(m₂x)
  Repeated: y_cf = (c₁ + c₂x) e^(mx)
  Complex (α ± iβ): y_cf = e^(αx) [c₁ cos βx + c₂ sin βx]

PARTICULAR INTEGRAL (PI = [1/f(D)] X):
  X = e^(ax) ⟹ [1/f(a)] e^(ax) (if f(a)=0 ⟹ x·[1/f'(a)] e^(ax))
  X = sin(ax)/cos(ax) ⟹ replace D² → −a² (if zero ⟹ x·[1/f'(D)] sin(ax))
  X = e^(ax) V(x) ⟹ e^(ax) [1/f(D+a)] V(x)

CAUCHY-EULER EQUATION (x² y'' + p x y' + q y = 0):
  Let x = eᶻ, z = ln x, x D = θ, x² D² = θ(θ−1) ⟹ θ(θ−1) + pθ + q = 0
```

#### 📌 BLOCK 5 — Partial Differential Equations (PDEs)
```
CLASSIFICATION (A u_xx + B u_xy + C u_yy + ... = 0):
  Discriminant: Δ = B² − 4AC
    Δ > 0 ⟹ Hyperbolic (Wave Eq, Supersonic flow)
    Δ = 0 ⟹ Parabolic  (Heat Eq, Boundary layers)
    Δ < 0 ⟹ Elliptic   (Laplace Eq, Subsonic potential flow)

CANONICAL EQUATIONS:
  1. Wave Eq (u_tt = c² u_xx): u(x,t) = f(x − ct) + g(x + ct)
  2. Heat Eq (u_t = α u_xx): u(x,t) = (A cos px + B sin px) exp(−α p² t)
  3. Laplace Eq (∇²u = 0): Harmonic function, extrema strictly on boundary
```
