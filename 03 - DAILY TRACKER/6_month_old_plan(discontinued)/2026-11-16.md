#### 🔑 Key Formulas & Invariants for Week 3:
1. **Axial Compressor Velocity Triangles & Euler Work:**
   - Absolute velocities ($V$), Relative velocities ($W$), Blade speed ($U = \omega r$), Axial velocity ($C_a$).
   - **Euler Work Equation:** $\mathbf{w = U(V_{\theta 2} - V_{\theta 1}) = U C_a(\tan\beta_1 - \tan\beta_2) = c_p \Delta T_{0,\text{stage}}}$.
   - Stage Loading Factor: $\mathbf{\psi \equiv \frac{\Delta h_0}{U^2} = \frac{C_a}{U}(\tan\beta_1 - \tan\beta_2)}$.
   - Flow Coefficient: $\mathbf{\phi \equiv \frac{C_a}{U}}$.
2. **Degree of Reaction ($R$):**
   $$\boxed{R \equiv \frac{\Delta h_{\text{rotor}}}{\Delta h_{\text{stage}}} = \frac{W_1^2 - W_2^2}{2 w} = 1 - \frac{V_{\theta 1} + V_{\theta 2}}{2U} = \frac{C_a}{2U}(\tan\beta_1 + \tan\beta_2)}$$
   - **$50\%$ Reaction ($R = 0.5$ — Symmetrical Triangles):** $V_1 = W_2, \ V_2 = W_1, \ \alpha_1 = \beta_2, \ \alpha_2 = \beta_1$ (Maximum pressure rise efficiency!).
3. **Centrifugal Compressors:**
   - Impeller tip speed $U_2$, Slip factor $\mathbf{\sigma \equiv \frac{V_{\theta 2}}{V_{\theta 2\infty}} < 1.0}$ (typically $\approx 0.85\text{--}0.90$).
   - Pressure ratio per stage: $\mathbf{\pi_c = \left[1 + \frac{\eta_c \sigma U_2^2}{c_p T_{01}}\right]^{\frac{\gamma}{\gamma-1}}}$.
4. **Axial Turbines:**
   - Impulse Stage ($R = 0$): All enthalpy drop occurs in nozzle/stator; rotor has constant relative velocity ($W_1 = W_2$).
   - $50\%$ Reaction Stage ($R = 0.5$): Equal enthalpy drop in stator and rotor.
   - Turbine blade cooling: Convection, Impingement, Film, and Transpiration cooling.
