### Step 3 — 11 Gold Rules of Determinants (15 min)
Read Part III. Cover the formula and recall each rule:

| Rule | Statement | Recall? |
|---|---|---|
| 1. Transpose Invariance | $\det(A)=\det(A^T)=1/\det(A^{-1})$ | ☐ |
| 2. Product Rule | $\det(AB)=\det(A)\det(B)$ | ☐ |
| 3. Scalar Factor Law ⭐ | $\det(kA_{n\times n})=k^n\det(A)$ | ☐ |
| 4. Inverse Det | $\det(A^{-1})=1/\det(A)$ | ☐ |
| 5. Power Rule | $\det(A^k)=(\det A)^k$ | ☐ |
| 6. Row/Col Swap | Single swap → $-\Delta$; cyclic 3-shift → $+\Delta$ | ☐ |
| 7. Single Row Scaling | Factor $K$ from ONE row → $K\Delta$ | ☐ |
| 8. ERO invariance ⚠️ | $R_i \to R_i + kR_j$ → unchanged; $R_i \to cR_i + kR_j$ → multiplied by $c$ | ☐ |
| 9. Zero det conditions | Identical/proportional rows/cols, or all-zero row/col → $\Delta=0$ | ☐ |
| 10. Triangular det | $\det = \prod$ diagonal elements | ☐ |
| 11. Sum Split | Split det when row/col elements are sums | ☐ |

|---|---|---|

| Det of adj(adj) | $\det(\text{adj}(\text{adj}(A))) = (\det A)^{(n-1)^2}$ | ☐ |

| adj transpose | $\text{adj}(A^T) = (\text{adj}(A))^T$ | ☐ |
| adj of inverse | $\text{adj}(A^{-1}) = A/\det(A)$ | ☐ |
| Scalar adj | $\text{adj}(kA) = k^{n-1}\text{adj}(A)$ | ☐ |

### Step 5 — 9 Shortcuts Speed-Run (10 min)
Read the shortcuts section. Know each by name:
- **SC1:** 2×2 inverse — Swap diagonal, flip off-diagonal signs, divide by det
- **SC2:** Adjoint determinant ladder — $(\det A)^{n-1}$, $(\det A)^{(n-1)^2}$, ...
- **SC3:** Odd skew-symmetric → $\det = 0$ instantly
- **SC4:** Orthogonal matrix → $A^{-1} = A^T$ instantly
- **SC5:** Sarrus' Rule for 3×3 (only works for 3×3!)
- **SC6:** Anti-diagonal block: $\det = (1-\alpha^2)^n$
- **SC7:** Equal off-diagonal: $\det = [x+(n-1)a](x-a)^{n-1}$
- **SC8:** Column-structured diagonal shift: $\det = x^{n-1}(x+\sum c_j)$
- **SC9:** Vandermonde: $\det = (a-b)(b-c)(c-a)$

### Step 6 — 4 Traps Burned In (5 min)
> 🔴 **Trap 1:** $\det(kA_{3\times3}) = k^3\det(A)$ NOT $k\det(A)$
> 🔴 **Trap 2:** $AB=O \not\Rightarrow A=O$ or $B=O$ (zero product fallacy)
> 🔴 **Trap 3:** $\text{tr}(ABC) = \text{tr}(BCA) = \text{tr}(CAB)$ — ONLY cyclic shifts; NOT $\text{tr}(ACB)$
> 🔴 **Trap 4:** Skew-symmetric diagonal entries MUST be zero; trace MUST be zero

### D2 Mini Quiz (3:45–4:00) — 5 Questions, 10 min timed

> **Q1 (1 mark):** If $A$ is a $4\times4$ matrix and $\det(A) = 3$, then $\det(2A)$ = ?
> **(A)** 6 **(B)** 12 **(C)** 48 **(D)** 16

> **Q2 (2 marks):** If $A$ is $3\times3$ with $\det(A) = 5$, then $\det(\text{adj}(\text{adj}(A)))$ = ?
> **(A)** 25 **(B)** 125 **(C)** 625 **(D)** 3125

> **Q3 (1 mark):** For a $5\times5$ real skew-symmetric matrix $A$, $\det(A)$ is always:
> **(A)** Positive **(B)** Negative **(C)** Zero **(D)** Cannot be determined

> **Q4 (2 marks):** If $A = \begin{pmatrix}3&1\\5&2\end{pmatrix}$, find $A^{-1}$.

> **Q5 (1 mark NAT):** If $A$ is $3\times3$ and $A^2 = A$, then $\text{tr}(A) - \text{rank}(A)$ = ___

> [!faq]- 🔍 View D2 Mini Quiz Answers
>
> **Q1: (C) 48**
> $\det(2A_{4\times4}) = 2^4 \det(A) = 16 \times 3 = 48$
> Trap: $2\times3=6$ is WRONG. You must raise 2 to the power of the matrix size (n=4).
>
> **Q2: (C) 625**
> $\det(\text{adj}(\text{adj}(A))) = (\det A)^{(n-1)^2} = 5^{(3-1)^2} = 5^4 = 625$
>
> **Q3: (C) Zero**
> Odd-order ($n=5$) skew-symmetric matrix ALWAYS has $\det = 0$.
> Proof: $\det(A^T) = \det(-A) = (-1)^5\det(A) = -\det(A)$. Also $\det(A^T) = \det(A)$.
> So $\det(A) = -\det(A) \Rightarrow 2\det(A)=0 \Rightarrow \det(A)=0$.
>
> **Q4:**
> $\det(A) = 3(2)-1(5) = 6-5 = 1$
> $A^{-1} = \frac{1}{1}\begin{pmatrix}2&-1\\-5&3\end{pmatrix} = \begin{pmatrix}2&-1\\-5&3\end{pmatrix}$
>
> **Q5: 0**
> For idempotent matrix $A^2=A$: $\text{tr}(A) = \text{rank}(A)$ always.
> So $\text{tr}(A) - \text{rank}(A) = 0$.
