### Step 2 — Oblique Shock Geometry & Velocity Decomposition (20 min)
Open `05.2 - Normal and Oblique Shock Waves`.

When a supersonic flow ($M_1 > 1$) encounters a 2D wedge of semi-vertex angle $\theta$, an oblique shock forms at shock angle $\beta$ relative to the upstream flow direction:

```
                      OBLIQUE SHOCK WAVE GEOMETRY
                                  ▲ Shock Wave (Angle β)
                                 /
       V_1 (Mach M_1)           /  Downstream V_2 (Mach M_2)
       ───────────────────────►/ ──► (Deflection Angle θ)
                              / ─────── Wedge Surface
                             /  θ
       ─────────────────────/────────────────────────►
```

#### 🔑 Velocity Component Invariance Principle:
- **Tangential Component is CONTINUOUS (Unchanged across shock):**
  $$\boxed{V_{t1} = V_{t2} = V_1\cos\beta = V_2\cos(\beta - \theta)}$$
- **Normal Component UNDERGOES A NORMAL SHOCK:**
  $$\boxed{V_{n1} = V_1\sin\beta \implies M_{n1} = M_1\sin\beta}$$
  $$\boxed{V_{n2} = V_2\sin(\beta - \theta) \implies M_{n2} = M_2\sin(\beta - \theta)}$$

---

### Step 3 — Oblique Shock Jump Formulas ($\gamma = 1.4$) (20 min)

Replace $M_1$ with the **Normal Mach Number $M_{n1} = M_1\sin\beta$** in all normal shock relations:

1. **Downstream Normal Mach Number ($M_{n2} < 1$):**
   $$\boxed{M_{n2}^2 = \frac{2 + (\gamma - 1)M_{n1}^2}{2\gamma M_{n1}^2 - (\gamma - 1)} = \frac{2 + 0.4 M_1^2\sin^2\beta}{2.8 M_1^2\sin^2\beta - 0.4}}$$
2. **Total Downstream Mach Number ($M_2$):**
   $$\boxed{M_2 = \frac{M_{n2}}{\sin(\beta - \theta)}}$$
3. **Static Pressure Ratio ($p_2/p_1 > 1$):**
   $$\boxed{\frac{p_2}{p_1} = 1 + \frac{2\gamma}{\gamma + 1}(M_{n1}^2 - 1) = \frac{7 M_1^2\sin^2\beta - 1}{6}}$$
4. **Density Ratio ($\rho_2/\rho_1 = V_{n1}/V_{n2}$):**
   $$\boxed{\frac{\rho_2}{\rho_1} = \frac{(\gamma + 1)M_{n1}^2}{2 + (\gamma - 1)M_{n1}^2} = \frac{2.4 M_1^2\sin^2\beta}{2 + 0.4 M_1^2\sin^2\beta}}$$
5. **Stagnation Properties:**
   - $\mathbf{T_{02} = T_{01}}$ (Stagnation temperature is constant!).
   - $\mathbf{p_{02} < p_{01}}$ (Total pressure drops: $\frac{p_{02}}{p_{01}} = f(M_{n1}) < 1$).

---

### Step 4 — The $\theta$-$\beta$-$M$ Relation & Shock Polars (15 min)

$$\boxed{\tan\theta = 2\cot\beta \left[\frac{M_1^2\sin^2\beta - 1}{M_1^2(\gamma + \cos(2\beta)) + 2}\right]}$$

```
                       THE θ-β-M SHOCK POLAR REGIMES
          Shock Angle β
          90° ┌───────────────────────────┐ Normal Shock (θ = 0)
              │       Strong Shock        │ (Subsonic M_2 < 1)
              │       (Higher β)          │
              │                 θ_max     │
              │                   ▲       │
              │        Weak Shock │       │ (Supersonic M_2 > 1)
              │        (Lower β)  │       │
          μ   └───────────────────┴───────┘ Mach Wave (θ = 0, β = μ)
              0°                 θ_max
                          Deflection Angle θ
```

#### 🔑 Key Physical Takeaways:
1. **Weak vs. Strong Shock Solutions:**
   - **Weak Shock (Smaller $\beta$):** $M_2 > 1$ (Supersonic downstream). *Naturally occurs on sharp aerodynamic wedges in unconfined supersonic flows.*
   - **Strong Shock (Larger $\beta \approx 90^\circ$):** $M_2 < 1$ (Subsonic downstream). *Occurs when high back-pressure exists downstream.*
2. **Maximum Deflection Angle ($\theta_{\max}$):**
   - For any given $M_1$, there is a maximum wedge angle $\theta_{\max}$ for which an attached straight oblique shock can exist.
   - If $\theta > \theta_{\max}$, the shock wave **detaches** from the wedge tip and stands off as a **Detached Bow Shock**.
3. **Limiting Cases ($\theta \to 0$):**
   - Weak shock limit: $\beta \to \mu = \arcsin(1/M_1)$ (Infinitely weak Mach wave).
   - Strong shock limit: $\beta \to 90^\circ$ (Normal shock wave).

---

### Step 5 — Traps & Self-Check (5 min)
> 🔴 **Trap 1: Downstream Mach Angle Relation**
> $M_2 = \frac{M_{n2}}{\sin(\beta - \theta)}$. Do not write $\sin\beta$ in the denominator — it MUST be $\sin(\beta - \theta)$!
> 🔴 **Trap 2: Tangential Velocity Conservation**
> Only the normal velocity component changes across an oblique shock. The tangential component $V_t = V\cos\beta$ is completely continuous ($V_{t1} = V_{t2}$).

### Step 3 — D3 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** Across an oblique shock wave, which velocity component remains strictly continuous (invariant)?
> **(A)** Normal component ($V_n$) **(B)** Tangential component ($V_t$) **(C)** Total velocity magnitude ($V$) **(D)** Sonic velocity ($a$)

> **Q2 (2 marks):** A uniform supersonic stream at Mach $M_1 = 2.0$ passes over a 2D wedge generating an attached oblique shock at an angle $\beta = 30^\circ$. The normal Mach number $M_{n1}$ upstream of the shock is:
> **(A)** $1.0$ **(B)** $1.414$ **(C)** $1.732$ **(D)** $0.5$

> **Q3 (2 marks):** For the same shock ($M_1 = 2.0, \beta = 30^\circ, M_{n1} = 1.0$), the static pressure ratio $p_2/p_1$ across the shock is:
> **(A)** $1.0$ **(B)** $2.17$ **(C)** $4.50$ **(D)** $0.528$

> **Q4 (1 mark):** In an attached oblique shock wave on a wedge in an unconfined supersonic flow, the downstream flow Mach number $M_2$ for the weak shock solution is typically:
> **(A)** Subsonic ($M_2 < 1$) **(B)** Supersonic ($M_2 > 1$) **(C)** Sonic ($M_2 = 1$) **(D)** Zero

> **Q5 (2 marks NAT):** A supersonic flow at $M_1 = 3.0$ undergoes an oblique shock with shock angle $\beta = 40^\circ$. If the flow deflection angle is $\theta = 20^\circ$ and downstream normal Mach is $M_{n2} = 0.60$, the total downstream Mach number $M_2$ is ___ (round off to 2 decimal places).

> [!faq]- 🔍 View D3 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (B) Tangential component (V_t)**
> No pressure gradient acts along the tangential direction of the shock discontinuity, so momentum conservation requires $V_{t1} = V_{t2}$.
>
> **Q2: (A) 1.0**
> $M_{n1} = M_1\sin\beta = 2.0\sin(30^\circ) = 2.0(0.5) = \mathbf{1.0}$.
>
> **Q3: (A) 1.0**
> Because $M_{n1} = 1.0$, the shock is an infinitely weak Mach wave ($M_1\sin\beta = 1$).
> $\frac{p_2}{p_1} = \frac{7(1.0^2) - 1}{6} = \frac{6}{6} = \mathbf{1.0}$.
>
> **Q4: (B) Supersonic (M₂ > 1)**
> The weak shock solution maintains supersonic downstream flow ($M_2 > 1$) for almost all deflection angles except for a very narrow range adjacent to $\theta_{\max}$.
>
> **Q5: 1.75**
> $M_2 = \frac{M_{n2}}{\sin(\beta - \theta)} = \frac{0.60}{\sin(40^\circ - 20^\circ)} = \frac{0.60}{\sin(20^\circ)} = \frac{0.60}{0.34202} \approx \mathbf{1.75}$.
