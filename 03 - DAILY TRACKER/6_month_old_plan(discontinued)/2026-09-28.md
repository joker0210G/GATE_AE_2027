#### 📌 BLOCK 1 — Viscous Boundary Layer Theory
```
THICKNESS DEFINITIONS:
  Displacement: δ* = ∫₀^δ (1 − u/U_inf) dy
  Momentum    : θ = ∫₀^δ (u/U_inf) [1 − u/U_inf] dy
  Shape Factor: H = δ* / θ

BLASIUS LAMINAR SOLUTION:
  δ / x = 5.0 / √Re_x | δ* / x = 1.72 / √Re_x | θ / x = 0.664 / √Re_x
  H_lam = 2.59 | C_f = 0.664 / √Re_x | C_F = 1.328 / √Re_L = 2 C_f(L)

TURBULENT BL (1/7-th Power Law):
  δ / x = 0.37 / Re_x^(1/5) | δ* = (1/8) δ | θ = (7/72) δ | H_turb = 9/7 ≈ 1.29
  C_f = 0.0592 / Re_x^(1/5) | C_F = 0.074 / Re_L^(1/5)

SEPARATION & MOMENTUM INTEGRAL:
  von Kármán: dθ/dx + (θ/U_inf)(2+H) (dU_inf/dx) = C_f / 2 = τ_w / (ρ U_inf²)
  Separation condition: (∂u/∂y)_{y=0} = 0 ⟺ τ_w = 0 in adverse gradient (dp/dx > 0)
```

#### 📌 BLOCK 2 — 1D Isentropic Compressible Flow & Normal Shocks
```
ISENTROPIC STAGNATION (γ = 1.4):
  T₀ / T = 1 + 0.2 M² | p₀ / p = (1 + 0.2 M²)^(3.5) | ρ₀ / ρ = (1 + 0.2 M²)^(2.5)
  Sonic Throat: p* / p₀ = 0.5283 | T* / T₀ = 0.8333

NORMAL SHOCKS (M₁ > 1 ⟹ M₂ < 1):
  Downstream Mach : M₂² = (2 + 0.4 M₁²) / (2.8 M₁² − 0.4)
  Pressure Ratio  : p₂ / p₁ = (7 M₁² − 1) / 6
  Density Ratio   : ρ₂ / ρ₁ = (2.4 M₁²) / (2 + 0.4 M₁²) ⟹ lim_{M₁→∞} = 6.0
  Stagnation Invariants: T₀₂ = T₀₁ | p₀₂ < p₀₁ (DROPS, Δs > 0)

RAYLEIGH PITOT TUBE:
  p₀₂ / p₁ = [1.2 M₁²]^(3.5) · [6 / (7 M₁² − 1)]^(2.5)
```

#### 📌 BLOCK 3 — Oblique Shock Waves
```
KINEMATICS:
  V_t1 = V_t2 = V_1 cos β = V_2 cos(β − θ) (Tangential is CONTINUOUS)
  M_n1 = M_1 sin β | M_n2 = M_2 sin(β − θ)

JUMP RELATIONS:
  M_n2² = (2 + 0.4 M_n1²) / (2.8 M_n1² − 0.4) | M_2 = M_n2 / sin(β − θ)
  p₂ / p₁ = (7 M_n1² − 1) / 6 | T₀₂ = T₀₁ | p₀₂ < p₀₁

θ-β-M & POLARS:
  tan θ = 2 cot β [(M₁² sin² β − 1) / (M₁² (γ + cos(2β)) + 2)]
  Weak Shock  : Smaller β ⟹ M₂ > 1 (Standard open flow)
  Strong Shock: Larger β  ⟹ M₂ < 1 (High back-pressure)
  Detachment  : If θ > θ_max ⟹ Detached Bow Shock forms
```

#### 📌 BLOCK 4 — Prandtl-Meyer Expansion & Supersonic Airfoils
```
PRANDTL-MEYER EXPANSION:
  Isentropic Flow: Δs = 0 ⟹ p₀₂ = p₀₁ AND T₀₂ = T₀₁
  Expansion Angle: ν(M₂) = ν(M₁) + θ
  Mach Lines     : Forward μ₁ = arcsin(1/M₁) | Rear μ₂ = arcsin(1/M₂)

ACKERET LINEARIZED SUPERSONIC AIRFOILS:
  C_p = ± 2θ / √(M_inf² − 1)
  Flat Plate Lift: C_L = 4α / √(M_inf² − 1)
  Flat Plate Drag: C_{D,wave} = C_L · α = 4α² / √(M_inf² − 1)
  Aerodynamic Ctr: x_ac = 0.50c (Mid-chord!)
  Diamond Wedge  : C_{D,wave} = [4α² + 4(t/c)²] / √(M_inf² − 1)
```
