### Step 2 — Elastic Constants & Hooke's Law Relations (15 min)
Open `01 - Stress Strain and Elasticity`.

For an isotropic, homogeneous linear elastic material:
- Young's Modulus ($E$), Shear Modulus ($G$), Bulk Modulus ($K$), Poisson's Ratio ($\nu$).
- Theoretical limits for isotropic materials: $-1.0 \le \nu \le 0.5$ (For metals: $\nu \approx 0.30\text{--}0.33$).

$$\boxed{E = 2G(1 + \nu) = 3K(1 - 2\nu) = \frac{9KG}{3K + G}}$$
$$\boxed{\nu = \frac{3K - 2G}{6K + 2G}}$$

- **Generalized 3D Hooke's Law:**
  $$\epsilon_x = \frac{1}{E}\left[\sigma_x - \nu(\sigma_y + \sigma_z)\right], \quad \gamma_{xy} = \frac{\tau_{xy}}{G}$$
  $$\text{Volumetric Strain: } \epsilon_v = \epsilon_x + \epsilon_y + \epsilon_z = \frac{1 - 2\nu}{E}(\sigma_x + \sigma_y + \sigma_z) = \frac{\sigma_m}{K}$$

### Step 3 — Plane Stress vs. Plane Strain (The #1 Confusion Killer) (15 min)

| State | Definition | Non-Zero Stress Components | Non-Zero Strain Components | Out-of-Plane Value | Physical Example |
|---|---|---|---|---|---|
| **Plane Stress** | Thin plates loaded in their plane ($\sigma_z = 0$) | $\sigma_x, \sigma_y, \tau_{xy}$ | $\epsilon_x, \epsilon_y, \gamma_{xy}, \mathbf{\epsilon_z \neq 0}$ | $\mathbf{\epsilon_z = -\frac{\nu}{E}(\sigma_x + \sigma_y)}$ | Thin aircraft skin, web of spar |
| **Plane Strain** | Thick/long bodies constrained along $z$ ($\epsilon_z = 0$) | $\sigma_x, \sigma_y, \tau_{xy}, \mathbf{\sigma_z \neq 0}$ | $\epsilon_x, \epsilon_y, \gamma_{xy}$ | $\mathbf{\sigma_z = \nu(\sigma_x + \sigma_y)}$ | Long dam, pressurized fuselage cylinder length |

### Step 4 — 2D Stress Transformation & Mohr's Circle (15 min)
Open `03 - Stress Transformations and Failure Criteria`.

For an element subjected to stresses $(\sigma_x, \sigma_y, \tau_{xy})$:

```
                      2D MOHR'S CIRCLE OF STRESS
               τ ^                 Top: (σ_avg, +R = τ_max)
                 │                       ▲
                 │                   ┌───┼───┐
                 │           (σ_y, -τ)───┼───(σ_x, +τ)
                 │                   └───┼───┘
                 │                       ▼
         ────────┼───────────────┬───────┼───────┬──────► σ
                 0             σ_2     σ_avg    σ_1
                 │          Bottom: (σ_avg, -R = -τ_max)
```

1. **Mohr's Circle Parameters:**
   - **Center:** $\mathbf{C = (\sigma_{\text{avg}}, 0) = \left(\frac{\sigma_x + \sigma_y}{2}, 0\right)}$
   - **Radius ($R = \tau_{\max,\text{in-plane}}$):**
     $$\boxed{R = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}}$$
2. **Principal Stresses ($\sigma_1, \sigma_2$ where shear stress is ZERO):**
   $$\boxed{\sigma_{1,2} = \sigma_{\text{avg}} \pm R = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}}$$
3. **Principal Plane Orientation ($\theta_p$):**
   $$\boxed{\tan(2\theta_p) = \frac{2\tau_{xy}}{\sigma_x - \sigma_y}}$$
4. **Maximum Shear Stress:**
   - **In-Plane Maximum Shear:** $\tau_{\max,\text{in-plane}} = R = \frac{\sigma_1 - \sigma_2}{2}$.
   - **Absolute Maximum Shear (3D):**
     $$\boxed{\tau_{\text{abs,\max}} = \max\left(\frac{|\sigma_1 - \sigma_2|}{2}, \frac{|\sigma_2 - \sigma_3|}{2}, \frac{|\sigma_3 - \sigma_1|}{2}\right)}$$
     *(In Plane Stress, $\sigma_3 = 0$. If $\sigma_1 > 0$ and $\sigma_2 > 0$ (both tensile), then $\tau_{\text{abs,\max}} = \frac{\sigma_1 - 0}{2} = \mathbf{\sigma_1 / 2}$!).*

### Step 5 — Yield & Failure Theories for Ductile Metals (10 min)

1. **Maximum Shear Stress Theory (Tresca Criterion):**
   $$\boxed{\tau_{\text{abs,\max}} \le \frac{\sigma_y}{2} \iff \max(|\sigma_1 - \sigma_2|, |\sigma_2 - \sigma_3|, |\sigma_3 - \sigma_1|) \le \sigma_y}$$
2. **Distortion Energy Theory (von Mises Criterion):**
   $$\boxed{\sigma_{\text{vm}} = \sqrt{\frac{1}{2}\left[(\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2\right]} \le \sigma_y}$$
   - For 2D Plane Stress ($\sigma_3 = 0$):
     $$\boxed{\sigma_{\text{vm}} = \sqrt{\sigma_1^2 - \sigma_1\sigma_2 + \sigma_2^2} = \sqrt{\sigma_x^2 - \sigma_x\sigma_y + \sigma_y^2 + 3\tau_{xy}^2} \le \sigma_y}$$
   - **Pure Shear Case ($\tau_{xy} = \tau$):**
     - Tresca predicts yield at: $\tau_y = 0.50 \sigma_y$.
     - von Mises predicts yield at: $\tau_y = \frac{\sigma_y}{\sqrt{3}} \approx \mathbf{0.577 \sigma_y}$ (15% higher shear capacity!).

### Step 3 — D1 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** In a state of 2D plane stress ($\sigma_z = 0$), the out-of-plane normal strain $\epsilon_z$ is:
> **(A)** Zero **(B)** $-\frac{\nu}{E}(\sigma_x + \sigma_y)$ **(C)** $\frac{\nu}{E}(\sigma_x + \sigma_y)$ **(D)** Infinite

> **Q2 (2 marks):** A point in a structural component is subjected to a state of plane stress: $\sigma_x = 100\text{ MPa}, \sigma_y = 40\text{ MPa}, \tau_{xy} = 40\text{ MPa}$. The major principal stress $\sigma_1$ is:
> **(A)** $120\text{ MPa}$ **(B)** $140\text{ MPa}$ **(C)** $150\text{ MPa}$ **(D)** $110\text{ MPa}$

> **Q3 (2 marks):** For the same stress state ($\sigma_1 = 120\text{ MPa}, \sigma_2 = 20\text{ MPa}, \sigma_3 = 0$), the absolute maximum shear stress $\tau_{\text{abs,\max}}$ is:
> **(A)** $50\text{ MPa}$ **(B)** $60\text{ MPa}$ **(C)** $70\text{ MPa}$ **(D)** $100\text{ MPa}$

> **Q4 (1 mark):** Under pure shear loading ($\tau_{xy} = \tau$), the yield strength predicted by the von Mises failure criterion $\tau_y$ in terms of uniaxial tensile yield strength $\sigma_y$ is:
> **(A)** $0.50 \sigma_y$ **(B)** $0.577 \sigma_y$ **(C)** $1.00 \sigma_y$ **(D)** $0.707 \sigma_y$

> **Q5 (2 marks NAT):** An isotropic material has Young's modulus $E = 210\text{ GPa}$ and shear modulus $G = 84\text{ GPa}$. The bulk modulus $K$ (in $\text{GPa}$) of the material is ___.

> [!faq]- 🔍 View D1 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (B) -(ν/E)(σ_x + σ_y)**
> From 3D Hooke's Law: $\epsilon_z = \frac{1}{E}[\sigma_z - \nu(\sigma_x + \sigma_y)]$. With $\sigma_z = 0 \implies \epsilon_z = -\frac{\nu}{E}(\sigma_x + \sigma_y)$.
>
> **Q2: (A) 120 MPa**
> $\sigma_{\text{avg}} = \frac{100 + 40}{2} = 70\text{ MPa}$.
> $R = \sqrt{\left(\frac{100 - 40}{2}\right)^2 + 40^2} = \sqrt{30^2 + 40^2} = \sqrt{900 + 1600} = 50\text{ MPa}$.
> $\sigma_1 = \sigma_{\text{avg}} + R = 70 + 50 = \mathbf{120\text{ MPa}}$.
>
> **Q3: (B) 60 MPa**
> The three principal stresses are $\sigma_1 = 120\text{ MPa}, \sigma_2 = 20\text{ MPa}, \sigma_3 = 0$.
> $\tau_1 = \frac{|120 - 20|}{2} = 50\text{ MPa}$.
> $\tau_2 = \frac{|20 - 0|}{2} = 10\text{ MPa}$.
> $\tau_3 = \frac{|120 - 0|}{2} = \mathbf{60\text{ MPa}}$.
> $\tau_{\text{abs,\max}} = \max(50, 10, 60) = \mathbf{60\text{ MPa}}$.
>
> **Q4: (B) 0.577 σ_y**
> von Mises: $\sigma_{\text{vm}} = \sqrt{3\tau^2} = \sqrt{3}\tau \le \sigma_y \implies \tau_y = \frac{\sigma_y}{\sqrt{3}} \approx \mathbf{0.577\sigma_y}$.
>
> **Q5: 140**
> $E = 2G(1+\nu) \implies 210 = 2(84)(1+\nu) = 168(1+\nu) \implies 1+\nu = \frac{210}{168} = 1.25 \implies \nu = 0.25$.
> $K = \frac{E}{3(1-2\nu)} = \frac{210}{3(1 - 2(0.25))} = \frac{210}{3(0.5)} = \frac{210}{1.5} = \mathbf{140\text{ GPa}}$.
