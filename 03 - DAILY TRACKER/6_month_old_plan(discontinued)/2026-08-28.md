### Step 2 — First Order ODEs Taxonomy (15 min)
Open `03.1 - First Order Linear ODEs`.

#### 1. Exact Differential Equations ($M dx + N dy = 0$)
- **Condition for Exactness:** $\boxed{\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}}$
- **Solution Rule:**
  $$\boxed{\int M\,dx \quad (\text{treating } y \text{ as a constant}) + \int (\text{terms of } N \text{ free from } x)\,dy = C}$$

#### 2. Integrating Factor (IF) Rules
If $\frac{\partial M}{\partial y} \neq \frac{\partial N}{\partial x}$:
- If $\frac{M_y - N_x}{N} = f(x)$ alone $\implies \boxed{IF = e^{\int f(x)\,dx}}$
- If $\frac{N_x - M_y}{M} = g(y)$ alone $\implies \boxed{IF = e^{\int g(y)\,dy}}$

#### 3. First-Order Linear Differential Equation
Standard Form: $\frac{dy}{dx} + P(x)y = Q(x)$
- **Integrating Factor:** $\boxed{IF = e^{\int P(x)\,dx}}$
- **General Solution:** $\boxed{y \cdot (IF) = \int Q(x) \cdot (IF)\,dx + C}$

#### 4. Bernoulli's Equation
Standard Form: $\frac{dy}{dx} + P(x)y = Q(x)y^n$
- **Resolution:** Divide by $y^n$, substitute $v = y^{1-n} \implies \frac{1}{1-n}\frac{dv}{dx} + P(x)v = Q(x)$ (reduces to Linear ODE).

### Step 3 — Higher-Order Linear ODEs with Constant Coefficients (20 min)
Open `03.2 - Higher Order Linear ODEs`.

General Form: $a \frac{d^2y}{dx^2} + b \frac{dy}{dx} + c y = f(x)$
$$\boxed{y(x) = y_{\text{CF}} + y_{\text{PI}}}$$

#### 1. Complementary Function (CF) via Auxiliary Equation $am^2 + bm + c = 0$:

| Roots of Auxiliary Equation | Complementary Function ($y_{\text{CF}}$) |
|---|---|
| Real & Distinct ($m_1 \neq m_2$) | $C_1 e^{m_1 x} + C_2 e^{m_2 x}$ |
| Real & Repeated ($m_1 = m_2 = m$) | $(C_1 + C_2 x) e^{m x}$ |
| Real & Tripled ($m_1 = m_2 = m_3 = m$) | $(C_1 + C_2 x + C_3 x^2) e^{m x}$ |
| Complex Conjugates ($m = \alpha \pm i\beta$) | $e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$ |

#### 2. Particular Integral (PI) Speed Rules ($y_{\text{PI}} = \frac{1}{f(D)} X(x)$):

| RHS Function $X(x)$ | Particular Integral Formula | Failure Rule (if denominator $= 0$) |
|---|---|---|
| **$e^{ax}$** | $\dfrac{1}{f(a)} e^{ax}$ | If $f(a) = 0 \implies x \cdot \dfrac{1}{f'(a)} e^{ax}$ |
| **$\sin(ax)$ or $\cos(ax)$** | Replace $D^2 \to -a^2$ in $f(D^2)$ | If denominator $= 0 \implies x \cdot \dfrac{1}{f'(D)} \sin(ax)$ |
| **$x^m$ (Polynomial)** | Expand $[f(D)]^{-1}$ via Binomial theorem in ascending powers of $D$ | — |
| **$e^{ax} V(x)$** | $e^{ax} \cdot \dfrac{1}{f(D+a)} V(x)$ (Exponential Shift) | — |

### Step 4 — Cauchy-Euler Differential Equations (10 min)

Standard Form: $\boxed{x^2 \frac{d^2y}{dx^2} + p x \frac{dy}{dx} + q y = f(x)}$
- **Transformation:** Substitute $x = e^z \iff z = \ln x$.
- **Derivative Operators:**
  $$x \frac{d}{dx} = \theta, \qquad x^2 \frac{d^2}{dx^2} = \theta(\theta - 1) \quad \text{where } \theta = \frac{d}{dz}$$
- Converts Cauchy-Euler equation into a standard **constant coefficient ODE** in variable $z$!

---

### Step 5 — Traps & Self-Check (10 min)
> 🔴 **Trap 1: Trigonometric PI Substitution Error**
> In $\frac{1}{D^2 + a^2}\sin(ax)$, replace $D^2$ with $-a^2$ (NOT $(-a)^2$). For example, if $a = 3$, $D^2 \to -(3^2) = -9$.
> 🔴 **Trap 2: Cauchy-Euler Solution Variable**
> When solving Cauchy-Euler equations, the roots give solutions in $z$ (e.g. $e^{m z}$). You MUST substitute back $z = \ln x \implies e^{m \ln x} = x^m$.

**Self-Check:**
1. Integrating factor of $\frac{dy}{dx} + \frac{2}{x}y = x^3$ is: ___ *(Ans: $e^{\int (2/x)dx} = e^{2\ln x} = x^2$)*
2. General solution of $\frac{d^2y}{dx^2} + 4y = 0$ is: ___ *(Ans: $C_1 \cos 2x + C_2 \sin 2x$)*
3. Roots of auxiliary equation for $x^2 y'' + 3x y' + y = 0$ are: ___ *(Ans: $\theta(\theta-1) + 3\theta + 1 = \theta^2 + 2\theta + 1 = 0 \implies (\theta+1)^2 = 0 \implies m = -1, -1$)*

### Step 3 — D4 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q1 (1 mark):** The integrating factor for the differential equation $\dfrac{dy}{dx} + \dfrac{3}{x}y = \dfrac{\sin x}{x^2}$ is:
> **(A)** $x^3$ **(B)** $x^2$ **(C)** $\frac{1}{x^3}$ **(D)** $3\ln x$

> **Q2 (2 marks):** The particular integral of the differential equation $\dfrac{d^2y}{dx^2} - 4y = e^{2x}$ is:
> **(A)** $\frac{1}{4} e^{2x}$ **(B)** $\frac{x}{4} e^{2x}$ **(C)** $\frac{x}{2} e^{2x}$ **(D)** $x e^{2x}$

> **Q3 (2 marks):** The general solution of the Cauchy-Euler differential equation $x^2 \dfrac{d^2y}{dx^2} - 3x \dfrac{dy}{dx} + 4y = 0$ for $x > 0$ is:
> **(A)** $y = (C_1 + C_2 x) x^2$ **(B)** $y = (C_1 + C_2 \ln x) x^2$ **(C)** $y = C_1 x^2 + C_2 x^4$ **(D)** $y = C_1 x + C_2 x^3$

> **Q4 (1 mark):** The differential equation $(2xy + 3)dx + (x^2 + 4y)dy = 0$ is:
> **(A)** Exact **(B)** Non-exact **(C)** Homogeneous **(D)** Non-linear

> **Q5 (2 marks NAT):** For the initial value problem $\dfrac{dy}{dx} = -2xy$ with $y(0) = 3$, the value of $y(1)$ is ___ (round off to 3 decimal places).

> [!faq]- 🔍 View D4 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (A) x³**
> $P(x) = \frac{3}{x} \implies IF = e^{\int (3/x)dx} = e^{3\ln x} = e^{\ln(x^3)} = \mathbf{x^3}$.
>
> **Q2: (B) (x/4) e^(2x)**
> $f(D) = D^2 - 4$.
> When substituting $D = 2$: $f(2) = 2^2 - 4 = 0$ (Case of failure!).
> Using derivative rule: $y_{\text{PI}} = x \cdot \frac{1}{f'(2)} e^{2x} = x \cdot \frac{1}{2(2)} e^{2x} = \mathbf{\frac{x}{4} e^{2x}}$.
>
> **Q3: (B) y = (C₁ + C₂ ln x) x²**
> Substitute $x = e^z, z = \ln x$:
> $\theta(\theta-1) - 3\theta + 4 = 0 \implies \theta^2 - 4\theta + 4 = 0 \implies (\theta-2)^2 = 0 \implies m = 2, 2$.
> In variable $z$: $y(z) = (C_1 + C_2 z) e^{2z}$.
> Substitute back $z = \ln x, e^{2z} = x^2$:
> $y(x) = \mathbf{(C_1 + C_2 \ln x) x^2}$.
>
> **Q4: (A) Exact**
> $M = 2xy + 3 \implies \frac{\partial M}{\partial y} = 2x$.
> $N = x^2 + 4y \implies \frac{\partial N}{\partial x} = 2x$.
> Since $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} = 2x$, the equation is **Exact**.
>
> **Q5: 1.104**
> Variable separable: $\frac{dy}{y} = -2x dx \implies \ln y = -x^2 + C \implies y = A e^{-x^2}$.
> Using $y(0) = 3 \implies A = 3 \implies y(x) = 3 e^{-x^2}$.
> At $x = 1$: $y(1) = 3 e^{-1} = \frac{3}{2.71828} \approx \mathbf{1.104}$.
