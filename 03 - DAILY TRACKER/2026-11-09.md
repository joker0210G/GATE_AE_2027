#### 📌 BLOCK 1 — Thermodynamics & Stagnation Properties
```
SFEE: q − w_s = h_02 − h_01
  Diffuser  : T_02 = T_01 = T_0
  Compressor: −w_s = c_p (T_02 − T_01)
  Burner    : q_in = c_p (T_04 − T_03)
  Turbine   : w_s = c_p (T_04 − T_05)
  Nozzle    : V_e = √[2 c_p (T_05 − T_e)]

IDEAL GAS & STAGNATION LAWS:
  c_p − c_v = R | γ = c_p / c_v | c_p = γ R / (γ − 1)
  T_0 / T = 1 + [(γ−1)/2] M²  (Adiabatic invariant!)
  p_0 / p = (1 + [(γ−1)/2] M²)^(γ/(γ−1))  (Isentropic invariant!)
  ρ_0 / ρ = (1 + [(γ−1)/2] M²)^(1/(γ−1))
```

#### 📌 BLOCK 2 — 1D Compressible Flow & Choking
```
HUGONIOT EQUATION: dA/A = (M² − 1) dV/V
  M < 1 : Converging accelerates (dV > 0)
  M = 1 : Occurs ONLY at minimum area (Throat A = A*)
  M > 1 : Diverging accelerates (dV > 0)

CRITICAL STATE (γ = 1.4):
  T*/T_0 = 2 / (γ+1) ≈ 0.8333
  p*/p_0 = [2 / (γ+1)]^(γ/(γ−1)) ≈ 0.52828 ≈ 0.528 (Choking threshold!)

CHOKED MASS FLOW FORMULA:
  ṁ_max = (p_0 A* / √T_0) √[ (γ/R) (2/(γ+1))^((γ+1)/(γ−1)) ]
  Air (γ = 1.4, R = 287): ṁ_max ≈ 0.04042 (p_0 A* / √T_0)
  (ṁ ∝ p_0, ṁ ∝ A*, ṁ ∝ 1/√T_0, ṁ independent of p_back once choked!)
```

#### 📌 BLOCK 3 — CD Nozzles & Expansion Regimes
```
CD NOZZLE REGIMES:
  p_b > p_b1          : Subsonic Venturi Flow
  p_b = p_b1          : Choked Subsonic Flow (M = 1 at throat)
  p_b2 < p_b < p_b1   : Over-Expanded with Normal Shock INSIDE divergent section
  p_b = p_b2          : Normal Shock at EXIT plane A_e
  p_design < p_b < p_b2: Over-Expanded with Oblique Shocks OUTSIDE exit
  p_b = p_design = p_a: PERFECTLY EXPANDED (p_e = p_a, Maximum thrust!)
  p_b < p_design      : Under-Expanded with Expansion Fans OUTSIDE exit

THRUST & EFFICIENCY:
  Gross Thrust: F_g = ṁ V_e + (p_e − p_a) A_e
  Isentropic Efficiency: η_n = V_e² / V_es²
  Velocity Coeff: C_v = V_e / V_es = √η_n
```

#### 📌 BLOCK 4 — Intakes & Combustors
```
INTAKES:
  Ram Recovery: π_d ≡ p_02 / p_00 ≤ 1.0
  Efficiency  : η_d = [π_d^((γ−1)/γ) − 1] / [((γ−1)/2) M_0²]
  Temperature : T_02 = T_00 = T_0 [1 + ((γ−1)/2) M_0²]

COMBUSTORS:
  Flow Zones  : Primary (15–20%, φ ≈ 1.0), Secondary (15–20%), Dilution (60–70%)
  Fuel-to-Air : f ≡ ṁ_f / ṁ_a ≈ [c_p (T_04 − T_03)] / [LHV · η_b]
  Equivalence : φ ≡ (f_actual) / (f_stoich) = (A/F_stoich) / (A/F_actual)
```

#### 📌 BLOCK 5 — The Brayton Cycle & Work Optimization
```
IDEAL BRAYTON CYCLE:
  Thermal Efficiency: η_th = 1 − 1 / [r_p^((γ−1)/γ)] = 1 − T₁/T₂ (Depends ONLY on r_p!)

MAXIMUM WORK OUTPUT:
  Condition             : T₂ = T₄ = √(T₁ T₃)
  Optimum Pressure Ratio: r_p,opt = (T₃/T₁)^(γ / [2(γ−1)]) = τ^(γ / [2(γ−1)])
  Maximum Specific Work : w_net,max = c_p T₁ (√τ − 1)² = c_p (√T₃ − √T₁)²

REAL CYCLE EFFICIENCIES:
  Compressor: η_c = (T_2s − T₁) / (T₂ − T₁)
  Turbine   : η_t = (T₃ − T₄) / (T₃ − T_4s)
```
