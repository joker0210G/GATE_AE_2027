```

### 📌 Pillar 3: Turbomachinery (Compressors & Turbines)
```
AXIAL COMPRESSOR VELOCITY TRIANGLES:
  U = V_θ + W_θ = C_a (tan α + tan β)
  Euler Work: w = U C_a (tan β₁ − tan β₂) = c_p ΔT_0,stage  |  Loading Factor: ψ = φ (tan β₁ − tan β₂)
DEGREE OF REACTION (R):
  R = (C_a / 2U) (tan β₁ + tan β₂) = 1 − (V_θ1 + V_θ2) / (2U)
  50% Symmetrical Stage (R = 0.5): α₁ = β₂, β₁ = α₂, V₁ = W₂, V₂ = W₁ (Optimum efficiency!)
  Work Done Factor: w_actual = Ω · U C_a (tan β₁ − tan β₂)  (Ω < 1.0)
CENTRIFUGAL COMPRESSORS:
  w = ψ_p σ U₂²  |  Slip Factor: σ ≡ V_θ2 / U₂ = 1 − π / Z (Stodola)
  Pressure Ratio: π_c = [1 + (η_c ψ_p σ U₂²) / (c_p T_01)]^(γ/(γ−1))  (π_c ≈ 4:1 to 6:1!)
AXIAL TURBINES:
  w = U C_a (tan α₂ + tan α₃) = c_pg ΔT_0,stage
  Impulse (R = 0): W₂ = W₃, β₂ = β₃, w_max = 2 U² (at U/V₂ = cosα₂ / 2)
  50% Reaction (R = 0.5): Symmetrical, w_max = U² (at U/V₂ = cosα₂)
  Cooling: Convection ──► Impingement ──► Film (Holes) ──► Transpiration (Porous wall)
