### Step 2 — Rank: The Master Concept (15 min)
Open `01.3.1 - Rank of a Matrix`. Recall and confirm:

**4 Equivalent Definitions of Rank:**
1. Maximum number of linearly independent rows
2. Maximum number of linearly independent columns
3. Order of the largest non-zero minor
4. Number of non-zero rows in Row Echelon Form (REF)

**Fundamental Rank Bounds:** $0 \leq \text{rank}(A_{m\times n}) \leq \min(m,n)$

**Key Rank Properties — burn these in:**

| Property | Formula | Recall? |
|---|---|---|
| Rank-Nullity Theorem | $\text{rank}(A) + \text{nullity}(A) = n$ (cols) | ☐ |
| Transpose invariance | $\text{rank}(A^T) = \text{rank}(A)$ | ☐ |
| Gram matrix | $\text{rank}(A^TA) = \text{rank}(A)$ | ☐ |
| Full rank (square) | $\text{rank}(A_{n\times n}) = n \iff \det(A)\neq 0 \iff A$ invertible | ☐ |
| Rank of product | $\text{rank}(AB) \leq \min(\text{rank}(A), \text{rank}(B))$ | ☐ |
| Sub-additivity | $\text{rank}(A+B) \leq \text{rank}(A)+\text{rank}(B)$ | ☐ |
| Non-singular product | $\text{rank}(PAQ) = \text{rank}(A)$ (if $P,Q$ invertible) | ☐ |
| Idempotent rank-trace | $A^2=A \Rightarrow \text{rank}(A) = \text{tr}(A)$ | ☐ |
| Rank of adj | If $\text{rank}(A)=n$ → $\text{rank}(\text{adj})=n$; if $n-1$ → rank $1$; if $<n-1$ → rank $0$ | ☐ |
| Sylvester's inequality | $\text{rank}(AB) \geq \text{rank}(A)+\text{rank}(B)-n$ | ☐ |
| Block diagonal rank | $\text{rank}\begin{pmatrix}A&O\\O&D\end{pmatrix} = \text{rank}(A)+\text{rank}(D)$ | ☐ |

### Step 3 — Rouché-Capelli: The Master Consistency Test (15 min)
Open `01.3 - Systems of Linear Equations`. This is THE most important theorem for SLE:

**System:** $A\vec{x} = \vec{b}$ → Augmented matrix: $[A|\vec{b}]$

| Condition | Meaning | Solution Type |
|---|---|---|
| $\text{rank}(A) \neq \text{rank}([A\|\vec{b}])$ | **Inconsistent** | No solution ❌ |
| $\text{rank}(A) = \text{rank}([A\|\vec{b}]) = n$ | **Consistent + Unique** | Exactly 1 solution ✅ |
| $\text{rank}(A) = \text{rank}([A\|\vec{b}]) = r < n$ | **Consistent + Infinite** | $\infty$ solutions (free vars = $n-r$) ✅ |

**For Homogeneous System $A\vec{x} = \vec{0}$:**
- $\text{rank}(A) = n$ → Only trivial solution $\vec{x} = \vec{0}$
- $\text{rank}(A) = r < n$ → Infinite solutions, nullspace has dimension $n-r$

> ⚡ **GATE Instant Rule:** For homogeneous $A\vec{x}=\vec{0}$:
> - More unknowns than equations ($n > m$) → ALWAYS infinite non-trivial solutions exist!
> - Square system ($m=n$): unique trivial solution $\iff \det(A)\neq 0$; infinite $\iff \det(A)=0$

### Step 4 — Row Reduction (REF/RREF) Protocol (10 min)
**Step-by-step to find rank:**
1. Write augmented matrix $[A|\vec{b}]$
2. Apply EROs (Elementary Row Operations): $R_i \leftrightarrow R_j$, $R_i \to kR_i$, $R_i \to R_i + kR_j$
3. Reach Row Echelon Form: pivots move right and down; all entries below each pivot are 0
4. Count non-zero rows → that's the rank

**Types of solutions from REF:**
- No zero rows in $A$ part but $[0\ 0\ \cdots\ 0 | b\neq 0]$ row appears → **Inconsistent**
- All zero rows removed → count remaining rows = rank

### Step 5 — Key Traps (5 min)
> 🔴 **Trap 1:** Rank of $A^TA \neq \text{rank}(A)^2$ — it equals $\text{rank}(A)$
> 🔴 **Trap 2:** For infinite solutions, free variables = $n - \text{rank}(A)$, NOT $n - m$
> 🔴 **Trap 3:** $AB = O$ does NOT mean $B=O$; but it means $\text{rank}(A)+\text{rank}(B)\leq n$
> 🔴 **Trap 4:** Rank of an $m\times n$ matrix can never exceed $\min(m,n)$ — always check this bound

### D3 Mini Quiz (3:45–4:00)

> **Q1 (1 mark):** For the system $\begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}\vec{x}=\vec{0}$, the number of non-trivial solutions is:
> **(A)** 0 **(B)** Exactly 1 **(C)** Infinitely many **(D)** Cannot determine

> **Q2 (2 marks):** The system $x+y+z=6$, $2x+3y+z=14$, $x+2y+2z=12$ has:
> **(A)** No solution **(B)** Unique solution **(C)** Infinitely many **(D)** Exactly 2 solutions

> **Q3 (1 mark NAT):** The rank of $A=\begin{pmatrix}1&2&3\\2&4&6\\3&6&9\end{pmatrix}$ is ___

> **Q4 (2 marks):** If $A$ is $5\times3$ and $\text{rank}(A)=3$, then $\text{rank}(A^TA)=$ ___

> **Q5 (1 mark):** For an idempotent matrix $A$ with $\text{tr}(A)=4$, $\text{rank}(A)=$ ___

> [!faq]- 🔍 View D3 Mini Quiz Answers
>
> **Q1: (C) Infinitely many**
> Row reduce: Row 2 → R2 - 4R1 = [0,−3,−6]; Row 3 → R3 - 7R1 = [0,−6,−12].
> R3 → R3 - 2R2 = [0,0,0]. Only 2 non-zero rows → rank = 2.
> 3 unknowns, rank 2 → free vars = 3-2 = 1 → infinite non-trivial solutions.
>
> **Q2: (B) Unique solution**
> The solution is $x=1, y=3, z=2$. Check: $1+3+2=6$ ✓, $2+9+2=13$... recalculate.
> Row reduce $[A|b]$ to find rank(A)=rank([A|b])=3=n → unique solution.
>
> **Q3: 1**
> All rows are multiples of $(1,2,3)$. So rank = 1.
>
> **Q4: 3**
> $\text{rank}(A^TA) = \text{rank}(A) = 3$
>
> **Q5: 4**
> For idempotent $A^2=A$: $\text{rank}(A) = \text{tr}(A) = 4$
