#### 📌 BLOCK 1 — Vector Algebra
```
DIRECTION COSINES:  l²+m²+n²=1 | sin²α+sin²β+sin²γ=2 | cos2α+cos2β+cos2γ=−1
DOT:     a·b = |a||b|cosθ
PROJ:    Scalar=a·b/|b| | Vector=[(a·b)/|b|²]b
CROSS:   |a||b|sinθ n̂ (det form)
AREAS:   Parallelogram=|a×b| | Triangle=½|a×b|
STP:     [abc]=det | Coplanar: [abc]=0
VOL:     Parallelepiped=|[abc]| | Tetrahedron=|[abc]|/6
VTP:     a×(b×c)=b(a·c)−c(a·b)  [BAC-CAB]
SUBSPACE: ✓ 0∈W, ✓ αu+βv∈W | Reject: non-zero const, inequality, power
DIMS: Rⁿ=n, Pₙ=n+1, Sym=n(n+1)/2, Skew=n(n−1)/2, Trace-0=n²−1
```

#### 📌 BLOCK 2 — Matrix Algebra
```
SPECIAL MATRICES:
  Sym(A^T=A): real λ | Skew(A^T=−A): diag=0, tr=0, odd→det=0
  Orth(A^TA=I): A⁻¹=A^T, det=±1 | Idem(A²=A): λ∈{0,1}, tr=rank
  Invol(A²=I): λ∈{±1} | Nilp(Aᵏ=O): all λ=0, det=0
A=P+Q: P=(A+A^T)/2 [sym], Q=(A−A^T)/2 [skew]
```

#### 📌 BLOCK 3 — Determinants
```
det(kAₙₓₙ)=kⁿdet(A)  ← MOST TESTED
det(AB)=det(A)det(B) | det(A^T)=det(A) | det(Aᵏ)=(detA)ᵏ
Row swap → −Δ | ERO Rᵢ→Rᵢ+kRⱼ → unchanged | Rᵢ→cRᵢ+kRⱼ → ×c
det(adj(A))=(detA)^(n-1) | det(adj(adj(A)))=(detA)^(n-1)²
adj(adj(A))=(detA)^(n-2)·A | A·adj(A)=det(A)·I
A⁻¹=adj(A)/det(A)
2×2 inverse: swap diag, flip off-diag, divide by det
Shortcuts: Sarrus(3×3), Equal-off-diag=[x+(n-1)a](x-a)^(n-1),
  Anti-diag block=(1-α²)^n, Vandermonde=(a-b)(b-c)(c-a)
```

#### 📌 BLOCK 4 — Rank & Systems of Equations
```
RANK: 0≤rank(A_{m×n})≤min(m,n)
Rank-Nullity: rank+nullity=n (cols) | rank(A)=rank(A^T)=rank(A^TA)
Non-sing product: rank(PAQ)=rank(A)
Sylvester: rank(AB)≥rank(A)+rank(B)−n
Block diag: rank[A 0;0 D]=rank(A)+rank(D)

ROUCHÉ-CAPELLI:
  r(A)≠r([A|b]) → No solution
  r(A)=r([A|b])=n → Unique solution
  r(A)=r([A|b])=r<n → Infinite (free vars=n−r)

Homogeneous Ax=0:
  n>m → always non-trivial | n=m: unique⟺det≠0

Rank of adj:  rank=n→adj rank=n | n−1→adj rank=1 | <n−1→adj rank=0
```

#### 📌 BLOCK 5 — Eigenvalues & Eigenvectors
```
Char eq: det(A−λI)=0
2×2: λ²−tr(A)λ+det(A)=0
tr(A)=Σλᵢ | det(A)=Πλᵢ

PROPERTIES:
  A+kI → λᵢ+k | Aᵏ → λᵢᵏ | A⁻¹ → 1/λᵢ
  A & A^T → same λ | Similar matrices → same λ
  Sym→real λ | Skew-Sym→0 or imaginary λ | Orth→|λ|=1
  Triangular/Diagonal → eigenvalues = diagonal entries (read directly!)

AM=multiplicity in char poly | GM=n−rank(A−λI) | 1≤GM≤AM
All GM=AM → diagonalizable | Any GM<AM → NOT diagonalizable
Symmetric: eigenvectors for diff λ are orthogonal → A=QDQ^T

CAYLEY-HAMILTON: A satisfies its own char poly P(A)=O
  Use to: find A⁻¹, reduce Aᵏ, simplify matrix expressions
```
