### Step 2 — Classification of 2nd Order Linear PDEs (20 min)
Open `03.3 - Classification of PDEs`.

General Second-Order Linear PDE in 2 Independent Variables $(x, y)$:
$$\boxed{A \frac{\partial^2 u}{\partial x^2} + B \frac{\partial^2 u}{\partial x \partial y} + C \frac{\partial^2 u}{\partial y^2} + D \frac{\partial u}{\partial x} + E \frac{\partial u}{\partial y} + F u = G}$$

The type of PDE is governed **strictly** by the second-order coefficients $(A, B, C)$ via the **Discriminant $\Delta = B^2 - 4AC$**:

| Discriminant ($\Delta = B^2 - 4AC$) | PDE Classification | Physical Archetype | Aerodynamics Regime |
|---|---|---|---|
| **$\Delta > 0$** | **Hyperbolic** | Wave Equation: $u_{tt} - c^2 u_{xx} = 0$ | Supersonic Flow ($M_\infty > 1$) |
| **$\Delta = 0$** | **Parabolic** | Heat / Diffusion: $u_t - \alpha u_{xx} = 0$ | Boundary Layer Equations / Transonic ($M=1$) |
| **$\Delta < 0$** | **Elliptic** | Laplace Equation: $u_{xx} + u_{yy} = 0$ | Incompressible / Subsonic Flow ($M_\infty < 1$) |

#### ⚡ Variable Coefficient Classification (GATE Favorite):
Example: $x \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0$ (Tricomi Equation)
- $A = x, B = 0, C = 1 \implies \Delta = B^2 - 4AC = 0 - 4(x)(1) = -4x$.
  - For $x > 0 \implies \Delta < 0 \implies$ **Elliptic** (Subsonic region)
  - For $x = 0 \implies \Delta = 0 \implies$ **Parabolic** (Sonic line $M=1$)
  - For $x < 0 \implies \Delta > 0 \implies$ **Hyperbolic** (Supersonic region)

### Step 3 — The Three Canonical PDEs & Standard Solutions (20 min)

#### 1. The 1D Wave Equation ($u_{tt} = c^2 u_{xx}$)
- **Type:** Hyperbolic ($\Delta = 4c^2 > 0$).
- **D'Alembert's General Solution:**
  $$\boxed{u(x, t) = f(x - ct) + g(x + ct)}$$
  *(Sum of right-traveling wave $f(x-ct)$ and left-traveling wave $g(x+ct)$ at speed $c$).*
- **Separation of Variables Solution:**
  $$u(x, t) = (A\cos px + B\sin px)(C\cos pct + D\sin pct)$$

#### 2. The 1D Heat / Diffusion Equation ($u_t = \alpha u_{xx}$)
- **Type:** Parabolic ($\Delta = 0$).
- **Separation of Variables Solution:**
  $$\boxed{u(x, t) = (A\cos px + B\sin px) e^{-\alpha p^2 t}}$$
  *(Notice: Decays exponentially in time $t$ with factor $e^{-\alpha p^2 t}$).*

#### 3. The 2D Laplace Equation ($\nabla^2 u = u_{xx} + u_{yy} = 0$)
- **Type:** Elliptic ($\Delta = -4 < 0$).
- **Properties of Harmonic Functions:**
  - **Mean Value Property:** $u(x_0, y_0)$ equals the average of $u$ on any circle centered at $(x_0, y_0)$.
  - **Maximum / Minimum Principle:** A harmonic function cannot have local maxima or minima in the interior of a domain; all extreme values occur on the **boundary**.

### Step 4 — Traps & 5-Min Self-Check (10 min)
> 🔴 **Trap 1: Derivative Identification in Classification**
> Be careful when variable names are $(x, t)$ instead of $(x, y)$. In $u_{tt} = c^2 u_{xx} \implies u_{tt} - c^2 u_{xx} = 0$, $A = 1, B = 0, C = -c^2 \implies \Delta = 0 - 4(1)(-c^2) = +4c^2 > 0$ (Hyperbolic!).
> 🔴 **Trap 2: First-Order Terms Irrelevance**
> Terms like $u_x, u_t, u$ have ZERO effect on PDE classification. Only $u_{xx}, u_{xy}, u_{yy}$ matter.

### Step 3 — D5 Mini Quiz (3:45–4:00) — 5 Questions (Timed 10 min)

> **Q2 (2 marks):** The partial differential equation $\dfrac{\partial^2 u}{\partial x^2} + 4\dfrac{\partial^2 u}{\partial x \partial y} + 4\dfrac{\partial^2 u}{\partial y^2} + 2\dfrac{\partial u}{\partial x} = 0$ is classified as:

> **Q3 (2 marks):** For the wave equation $\dfrac{\partial^2 u}{\partial t^2} = 9 \dfrac{\partial^2 u}{\partial x^2}$ with initial displacement $u(x, 0) = \cos x$ and zero initial velocity $u_t(x, 0) = 0$, the solution $u(x, t)$ is:
> **(A)** $\cos(x - 3t)$ **(B)** $\cos x \cos(3t)$ **(C)** $\cos x \sin(3t)$ **(D)** $\frac{1}{2}\cos(3x - t)$

> **Q4 (1 mark):** Which of the following functions is HARMONIC (satisfies Laplace equation $\nabla^2 u = 0$)?
> **(A)** $u = x^2 + y^2$ **(B)** $u = e^x \sin y$ **(C)** $u = x^2 - 2y^2$ **(D)** $u = \sin x \sin y$

> **Q5 (1 mark):** In the 1D heat conduction equation $\dfrac{\partial T}{\partial t} = \alpha \dfrac{\partial^2 T}{\partial x^2}$, the temperature distribution in steady state ($t \to \infty$) is:
> **(A)** Exponential **(B)** Parabolic **(C)** Linear **(D)** Sinusoidal

> [!faq]- 🔍 View D5 Mini Quiz Answers & Step-by-Step Solutions
>
> **Q1: (A) Quadrant I & III**
> $A = x, B = 0, C = y \implies \Delta = B^2 - 4AC = 0 - 4xy = -4xy$.
> For Elliptic: $\Delta < 0 \implies -4xy < 0 \implies xy > 0$.
> $xy > 0$ holds when both $x, y > 0$ (Quadrant I) or both $x, y < 0$ (Quadrant III).
>
> **Q2: (B) Parabolic**
> $A = 1, B = 4, C = 4$.
> $\Delta = B^2 - 4AC = 4^2 - 4(1)(4) = 16 - 16 = \mathbf{0} \implies$ **Parabolic**.
>
> **Q3: (B) cos x cos(3t)**
> Using D'Alembert's formula with wave speed $c = \sqrt{9} = 3$:
> $u(x, t) = \frac{1}{2}[f(x - ct) + f(x + ct)] = \frac{1}{2}[\cos(x - 3t) + \cos(x + 3t)]$.
> Using trig identity $\cos(A-B) + \cos(A+B) = 2\cos A \cos B$:
> $u(x, t) = \frac{1}{2}[2\cos x \cos(3t)] = \mathbf{\cos x \cos(3t)}$.
>
> **Q4: (B) u = e^x sin y**
> Check $u_{xx} + u_{yy}$:
> For (B): $u_x = e^x \sin y \implies u_{xx} = e^x \sin y$.
> $u_y = e^x \cos y \implies u_{yy} = -e^x \sin y$.
> $u_{xx} + u_{yy} = e^x \sin y - e^x \sin y = \mathbf{0} \implies$ **Harmonic**.
>
> **Q5: (C) Linear**
> In steady state, $\frac{\partial T}{\partial t} = 0 \implies \alpha \frac{d^2T}{dx^2} = 0 \implies \frac{d^2T}{dx^2} = 0 \implies T(x) = C_1 x + C_2$ (**Linear**).
