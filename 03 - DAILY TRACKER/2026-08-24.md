#### 📌 BLOCK 1 — Limits & Indeterminate Forms
```
STANDARD LIMITS (x → 0):
  sin(x)/x = 1 | tan(x)/x = 1 | (1 − cos x)/x² = 1/2
  sin⁻¹(x)/x = 1 | tan⁻¹(x)/x = 1
  (eˣ − 1)/x = 1 | (aˣ − 1)/x = ln a | ln(1 + x)/x = 1
  (1 + x)^(1/x) = e | lim(x→∞) (1 + a/x)^(bx) = e^(ab)
  (xⁿ − aⁿ)/(x − a) = n·aⁿ⁻¹

INDETERMINATE FORMS & RESOLUTION:
  0/0, ∞/∞   → L'Hôpital (diff num & den separately) OR Taylor Expansion (faster!)
  1^∞        → lim [f(x)]^g(x) = e^{lim g(x)[f(x) − 1]}
  ∞ − ∞      → Rationalize: √(x² + ax) − x → a/2
  0·∞        → Convert to 0/(1/∞) = 0/0
  Growth     → ln x ≪ xᵃ ≪ eˣ ≪ xˣ (as x → ∞)
  Squeeze    → g(x) ≤ f(x) ≤ h(x) with lim g = lim h = L ⟹ lim f = L
```

#### 📌 BLOCK 2 — Continuity & Discontinuity (RJIO)
```
CONTINUITY CRITERIA AT x = a:
  1. f(a) is defined
  2. lim(x→a) f(x) exists (LHL = RHL = L finite)
  3. lim(x→a) f(x) = f(a)

DISCONTINUITY TAXONOMY (RJIO):
  Removable   : LHL = RHL ≠ f(a) (or f(a) undefined) → repairable by redefining f(a) = L
  Jump        : LHL ≠ RHL (both finite) → |LHL − RHL| = jump size
  Infinite    : LHL or RHL = ±∞ (vertical asymptote)
  Oscillatory : lim DNE due to wild oscillation (e.g. sin(1/x) at x=0)

THEOREMS:
  Differentiable ⟹ Continuous (Converse FALSE: |x| at 0 is cts, not diff)
  IVT: f cts on [a,b], f(a)·f(b) < 0 ⟹ ∃ c ∈ (a,b) such that f(c) = 0
  EVT: f cts on closed [a,b] ⟹ absolute max and min are attained
```

#### 📌 BLOCK 3 — Differentiation, Rules & MVTs
```
KEY DERIVATIVES:
  tan⁻¹x → 1/(1 + x²) | sin⁻¹x → 1/√(1 − x²) | cos⁻¹x → −1/√(1 − x²)
  aˣ → aˣ ln a | xˣ → xˣ(ln x + 1)
  Log Diff: y = [f(x)]^g(x) ⟹ ln y = g ln f ⟹ y' = y [g' ln f + g f'/f]

MEAN VALUE THEOREMS:
  Rolle's : f cts on [a,b], diff on (a,b), f(a)=f(b) ⟹ ∃ c ∈ (a,b): f'(c) = 0
  LMVT    : f cts on [a,b], diff on (a,b) ⟹ ∃ c ∈ (a,b): f'(c) = [f(b) − f(a)] / (b − a)
  CMVT    : f'(c)/g'(c) = [f(b) − f(a)] / [g(b) − g(a)]
```

#### 📌 BLOCK 4 — Maxima, Minima & Curve Behavior
```
CRITICAL POINTS: x where f'(x) = 0 or f'(x) DNE

TESTS:
  1st Deriv: + to − ⟹ Local MAX | − to + ⟹ Local MIN | No sign change ⟹ Inflection
  2nd Deriv: f'(c)=0 & f''(c)<0 ⟹ Local MAX | f''(c)>0 ⟹ Local MIN | f''(c)=0 ⟹ Inconclusive
  Global Extrema on [a,b]: Compare f(x) at ALL critical points + endpoints a and b
  Concavity: f''(x) > 0 (Concave Up / Convex) | f''(x) < 0 (Concave Down)
  Inflection Point: f''(c) = 0 AND f''(x) changes sign at c
```

#### 📌 BLOCK 5 — Integration Techniques & Definite Properties
```
KEY INTEGRALS:
  ∫ 1/(x² + a²) dx = (1/a) tan⁻¹(x/a) | ∫ 1/√(a² − x²) dx = sin⁻¹(x/a)
  ∫ 1/(x² − a²) dx = (1/2a) ln|(x−a)/(x+a)| | ∫ √(a² − x²) dx = (x/2)√(a²−x²) + (a²/2)sin⁻¹(x/a)
  ∫ eˣ [f(x) + f'(x)] dx = eˣ f(x) + C

BY PARTS: ∫ u dv = uv − ∫ v du  (ILATE priority for u: Inverse, Log, Alg, Trig, Exp)

DEFINITE INTEGRAL GOLD RULES:
  King's Rule : ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a − x) dx ⟹ If f(x) + f(a−x) = k, I = ka/2
  General Shift: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b − x) dx
  Even/Odd    : ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx (even) | = 0 (odd)
  Wallis'     : ∫₀^(π/2) sinⁿx dx = [(n−1)!! / n!!] · (π/2 if n even, 1 if n odd)
  Leibniz     : d/dx ∫_{g(x)}^{h(x)} f(t) dt = f(h(x))·h'(x) − f(g(x))·g'(x)
```

#### 📌 BLOCK 6 — Taylor & Maclaurin Series
```
Taylor   : f(x) = Σ_{n=0}^∞ [f⁽ⁿ⁾(a) / n!] (x − a)ⁿ
Maclaurin: f(x) = Σ_{n=0}^∞ [f⁽ⁿ⁾(0) / n!] xⁿ

SERIES EXPANSIONS (x → 0):
  eˣ       = 1 + x + x²/2! + x³/3! + ... (∀ x)
  sin x    = x − x³/3! + x⁵/5! − ...     (∀ x)
  cos x    = 1 − x²/2! + x⁴/4! − ...     (∀ x)
  ln(1+x)  = x − x²/2 + x³/3 − x⁴/4 + ... (−1 < x ≤ 1)
  1/(1−x)  = 1 + x + x² + x³ + ...       (|x| < 1)
  (1+x)ⁿ   = 1 + nx + [n(n−1)/2!] x² + ...
```

### Step 2 — Week 3 (Multivariable & Vector Calculus) Preview (20 min)
Week 3 begins tomorrow (Aug 25, 2026). Here is the battlefield preview:

1. **Partial Differentiation & Euler's Theorem:**
   - Homogeneous functions of degree $n$: $x \frac{\partial u}{\partial x} + y \frac{\partial u}{\partial y} = n u$
2. **Total Derivative & Chain Rule for Multivariable:**
   - $\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}$
3. **Maxima & Minima of Two Variables ($r, s, t$ test):**
   - $rt - s^2 > 0$ and $r > 0 \implies$ Local Min; $rt - s^2 > 0$ and $r < 0 \implies$ Local Max; $rt - s^2 < 0 \implies$ Saddle Point
4. **Vector Differential Operators:**
   - Gradient ($\nabla \phi$ — normal vector), Divergence ($\nabla \cdot \vec{V}$ — flux density/solenoidal $\nabla \cdot \vec{V} = 0$), Curl ($\nabla \times \vec{V}$ — rotation/irrotational $\nabla \times \vec{V} = \vec{0}$)
   - Directional Derivative: $D_{\hat{u}} \phi = \nabla \phi \cdot \hat{u}$
5. **Integral Vector Theorems (Core GATE Weightage):**
   - **Green's Theorem:** $\oint (P dx + Q dy) = \iint \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) dx dy$
   - **Stokes' Theorem:** $\oint \vec{F} \cdot d\vec{r} = \iint (\nabla \times \vec{F}) \cdot \hat{n} dS$
   - **Gauss Divergence Theorem:** $\oiint \vec{F} \cdot \hat{n} dS = \iiint (\nabla \cdot \vec{F}) dV$
