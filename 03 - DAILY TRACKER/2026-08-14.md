### Step 2 — Core Definitions (10 min)

**Definition:** $\lambda$ is an eigenvalue of $A$ if $\exists\ \vec{x}\neq\vec{0}$ s.t. $A\vec{x} = \lambda\vec{x}$

**Characteristic Equation:**
$$\det(A - \lambda I) = 0 \quad \Rightarrow \quad \text{Characteristic polynomial } P(\lambda) = 0$$

**GATE Shortcut — Characteristic Polynomial Coefficients:**
For $n\times n$ matrix, $P(\lambda) = (-1)^n[\lambda^n - \text{tr}(A)\lambda^{n-1} + \cdots + (-1)^n\det(A)]$
- Coefficient of $\lambda^{n-1}$ → involves trace
- Constant term → $(-1)^n\det(A)$

### Step 3 — The 10 Fundamental Eigenvalue Relations (20 min)
These are the core GATE-tested properties. Recall every one:

| Property | Formula / Rule | Recall? |
|---|---|---|
| **Trace-Eigenvalue** | $\text{tr}(A) = \sum\lambda_i$ | ☐ |
| **Det-Eigenvalue** | $\det(A) = \prod\lambda_i$ | ☐ |
| **Scalar shift** | Eigenvalues of $A + kI$ are $\lambda_i + k$ | ☐ |
| **Power** | Eigenvalues of $A^k$ are $\lambda_i^k$ | ☐ |
| **Inverse** | Eigenvalues of $A^{-1}$ are $1/\lambda_i$ (if $A$ invertible) | ☐ |
| **Transpose** | $A$ and $A^T$ have same eigenvalues | ☐ |
| **Polynomial** | If $P(A)=O$, then $P(\lambda)=0$ for each eigenvalue | ☐ |
| **Symmetric** | All eigenvalues are REAL | ☐ |
| **Skew-Symmetric** | All eigenvalues are purely imaginary or ZERO | ☐ |
| **Orthogonal** | $|\lambda_i| = 1$ (magnitude = 1) | ☐ |
| **Idempotent** | $\lambda\in\{0,1\}$ | ☐ |
| **Nilpotent** | All $\lambda = 0$ | ☐ |
| **Involutory** | $\lambda\in\{-1,+1\}$ | ☐ |
| **Triangular/Diagonal** | Eigenvalues = diagonal entries (read directly!) | ☐ |
| **Similar matrices** | $B=P^{-1}AP$ → same eigenvalues | ☐ |

### Step 4 — Spectral Radius & Special Results (10 min)

**Cayley-Hamilton Theorem (EXAM FAVORITE):**
> Every square matrix satisfies its own characteristic equation.
> If $P(\lambda) = \lambda^2 - 5\lambda + 6 = 0$ is the char. poly of $A$,
> then $P(A) = A^2 - 5A + 6I = O$.

**Uses of Cayley-Hamilton:**
1. Find $A^{-1}$: rearrange $P(A)=O$ to express $I$ in terms of $A$ and $A^2$, etc.
2. Find high powers of $A$: express $A^k$ in terms of lower powers
3. Verify a matrix satisfies its characteristic polynomial

**Diagonalization:**
$A$ is diagonalizable if it has $n$ linearly independent eigenvectors.
Then: $A = PDP^{-1}$ where $D = \text{diag}(\lambda_1,\ldots,\lambda_n)$
- $A^k = PD^kP^{-1}$
- All eigenvalues distinct → always diagonalizable

### Step 5 — GATE Speed Shortcuts (10 min)

**⚡ Shortcut 1: 2×2 Eigenvalue via Trace & Det**
For $A = \begin{pmatrix}a&b\\c&d\end{pmatrix}$:
$$\lambda^2 - \text{tr}(A)\lambda + \det(A) = 0 \quad \Rightarrow \quad \lambda = \frac{\text{tr}(A)\pm\sqrt{\text{tr}(A)^2 - 4\det(A)}}{2}$$

**⚡ Shortcut 2: Check eigenvalue without solving fully**
To check if $\lambda_0$ is an eigenvalue of $A$: compute $\det(A-\lambda_0 I)$. If = 0 → yes!

**⚡ Shortcut 3: Eigenvalues of $A+kI$ without solving**
If eigenvalues of $A$ are $\{\lambda_1,\lambda_2,\ldots\}$, then eigenvalues of $A+kI = \{\lambda_1+k,\lambda_2+k,\ldots\}$

**⚡ Shortcut 4: Find unknowns using Trace and Det**
Given matrix with unknown parameter, and knowing one eigenvalue:
- Sum of eigenvalues = trace → find other eigenvalues
- Product of eigenvalues = det → cross-check

### Step 6 — 4 Traps (5 min)
> 🔴 **Trap 1:** Diagonal entries are eigenvalues ONLY for triangular/diagonal matrices, NOT for general matrices
> 🔴 **Trap 2:** $A$ and $A^T$ have same eigenvalues but generally different eigenvectors
> 🔴 **Trap 3:** All eigenvalues = 0 does NOT mean $A = O$ (nilpotent matrix!)
> 🔴 **Trap 4:** $\det(A-\lambda I) = 0$ → eigenvalue; $\det(A-\lambda I) \neq 0$ → NOT an eigenvalue

### D4 Mini Quiz (3:45–4:00)

> **Q1 (1 mark):** If $A = \begin{pmatrix}3&1\\0&4\end{pmatrix}$, the eigenvalues are:
> **(A)** 3, 1 **(B)** 3, 4 **(C)** 4, 1 **(D)** 0, 4

> **Q2 (2 marks):** If $A$ is $3\times3$ with eigenvalues $1, 2, 3$, then $\det(A^2+2A)=$ ?

> **Q3 (1 mark):** The characteristic polynomial of a $3\times3$ real symmetric matrix has all:
> **(A)** Complex roots **(B)** Purely imaginary roots **(C)** Real roots **(D)** Zero roots

> **Q4 (2 marks NAT):** If eigenvalues of $A$ are $2, -1, 3$, then $\text{tr}(A^2)=$ ___

> **Q5 (1 mark):** Which property CANNOT hold for a non-zero nilpotent matrix?
> **(A)** $\det(A)=0$ **(B)** $\text{tr}(A)=0$ **(C)** All eigenvalues = 0 **(D)** $A$ is invertible

> [!faq]- 🔍 View D4 Mini Quiz Answers
>
> **Q1: (B) 3, 4**
> Upper triangular matrix → eigenvalues = diagonal entries = 3 and 4.
>
> **Q2:** Eigenvalues of $A^2+2A$: for each $\lambda_i$, eigenvalue of $A^2+2A$ is $\lambda_i^2+2\lambda_i$.
> $\lambda=1$: $1+2=3$; $\lambda=2$: $4+4=8$; $\lambda=3$: $9+6=15$
> $\det(A^2+2A) = 3\times8\times15 = 360$
>
> **Q3: (C) Real roots**
> Real symmetric matrices always have all real eigenvalues.
>
> **Q4: 14**
> Eigenvalues of $A^2$ are $\lambda^2$: $4, 1, 9$.
> $\text{tr}(A^2) = \sum\lambda_i^2 = 4+1+9 = 14$
>
> **Q5: (D) A is invertible**
> Nilpotent matrix has $\det(A)=0$ → NOT invertible. So (D) cannot hold.
