#### 📌 BLOCK 6 — Accelerated Flight & Vertical Maneuvers
```
LOAD FACTOR & ACCELERATED STALL:
  n = L / W
  V_stall,acc = V_stall √n

PULL-UP MANEUVER (BOTTOM OF LOOP):
  n = 1 + V² / (g R)
  R_min = V² / [g (n_max − 1)]
  Pitch Rate: θ̇_max = [g (n_max − 1)] / V

PULL-DOWN MANEUVER (TOP OF INVERTED LOOP):
  n = V² / (g R) − 1
  R_min = V² / [g (n_max + 1)]
  Pitch Rate: θ̇_max = [g (n_max + 1)] / V
```

#### 📌 BLOCK 7 — Coordinated Turning Flight & High-Lift Devices
```
COORDINATED LEVEL TURN:
  Load Factor: n = 1 / cos φ ⟹ cos φ = 1 / n
  Bank Angle : tan φ = V² / (g R) = √(n² − 1)
  Turn Radius: R = V² / (g tan φ) = V² / [g √(n² − 1)]
  Turn Rate  : ω = ψ̇ = (g tan φ) / V = [g √(n² − 1)] / V (rad/s)

TURN OPTIMIZATION (CORNER SPEED V*):
  Corner Speed: V* = √[(2 n_max (W/S)) / (ρ C_L,max)] = V_stall √n_max
  Min Turn Radius: R_min = (V*)² / [g √(n_max² − 1)] ∝ (W/S) / (ρ C_L,max)
  Max Turn Rate  : ω_max = [g √(n_max² − 1)] / V* ∝ √[(ρ C_L,max) / (W/S)]

HIGH-LIFT DEVICES:
  Trailing-Edge Flaps: ↑↑ C_L,max | ↓ α_stall | Shifts α_{L=0} negative | Strong Nose-Down ΔC_m < 0
  Leading-Edge Slats : ↑↑ C_L,max | ↑↑ α_stall (delays separation) | α_{L=0} unchanged
```

#### 📌 BLOCK 8 — V-n Diagram & Atmospheric Gust Loads
```
V-n MANEUVER ENVELOPE:
  Stall Limits: n = ± (1/2 ρ V² S C_L,max) / W  (Parabolic ∝ V²)
  Corner Speed: V* = √[(2 n_max (W/S)) / (ρ C_L,max)] = V_stall √n_max
  Ultimate Load Factor: n_ultimate = 1.5 · n_limit

ATMOSPHERIC GUST LOADS:
  Δα_g = U_de / V
  ΔL = (1/2) ρ V S a U_de
  Gust Load Factor: Δn = [(1/2) ρ₀ V a K_g U_de] / (W/S)
  Total Gust Load : n_gust = 1 ± Δn

INVARIANTS:
  Δn ∝ V (Increases linearly with speed!)
  Δn ∝ 1 / (W/S) (Decreases with higher wing loading!)
  Gust lines on V-n are STRAIGHT lines from (0, 1g)!

PRATT GUST ALLEVIATION:
  K_g = (0.88 μ_g) / (5.3 + μ_g)
  Mass Ratio: μ_g = [2 (W/S)] / (ρ g c̄ a)
```

#### 📌 BLOCK 9 — Longitudinal Static Stability (Stick-Fixed)
```
STABILITY & TRIM CRITERIA:
  1. C_m0 > 0 (Positive zero-lift pitch)
  2. C_mα < 0 (Negative restoring slope)
  3. C_L,trim > 0 at C_m = 0 ⟹ α_trim = −C_m0 / C_mα > 0

TAIL VOLUME RATIO & DOWNWASH:
  V_H = (l_t S_t) / (c̄ S)
  Tail AoA: α_t = α (1 − dε/dα) + i_t − ε₀
  Tail Contribution: (∂C_m/∂α)_t = −V_H η_t a_t (1 − dε/dα) < 0 (Stabilizing!)

NEUTRAL POINT & STATIC MARGIN:
  Neutral Point: x_np / c̄ = x_ac,wb / c̄ + V_H η_t (a_t / a) (1 − dε/dα)
  Static Margin: SM = (x_np − x_cg) / c̄ = −C_mα / a

STABILITY RULES:
  x_cg < x_np ⟹ SM > 0 ⟹ C_mα < 0 (STABLE)
  x_cg = x_np ⟹ SM = 0 ⟹ C_mα = 0 (NEUTRAL)
  x_cg > x_np ⟹ SM < 0 ⟹ C_mα > 0 (UNSTABLE)
  Moving CG aft (rearward) DECREASES stability!
```

#### 📌 BLOCK 10 — Stick-Free Stability & Elevator Controls
```
ELEVATOR CONTROL POWER:
  C_{m\delta_e} = −V_H η_t a_t τ < 0 (Negative!)
  Elevator Trim: δ_{e,trim} = −(C_m0 + C_mα α_trim) / C_{m\delta_e}

HINGE MOMENTS & FLOATING ANGLE:
  C_h = C_h0 + C_{hα} α_t + C_{h\delta_e} δ_e + C_{h\delta_t} δ_t
  Floating Angle (C_h = 0): δ_{e,float} = −(C_{hα} / C_{h\delta_e}) α_t

STICK-FREE NEUTRAL POINT:
  x'_np / c̄ = x_np / c̄ − V_H η_t (a_t / a) (1 − dε/dα) [τ (C_{hα} / C_{h\delta_e})]
  RULE: x'_np < x_np (Stick-free neutral point is always FORWARD of stick-fixed!)
  Static Margin: SM' < SM (Stick-free stability is always LESS!)

STICK FORCE GRADIENT:
  Speed Stability: dF_s / dV < 0 (Push to speed up, Pull to slow down)
```

### Step 2 — Week 3 (Directional & Lateral Static Stability, Cross-Coupling, and Dynamic Modes) Preview (20 min)
Week 3 begins tomorrow (Oct 20, 2026):
1. **Directional Static Stability (D1):** Weathercock effect ($C_{n\beta} \equiv \frac{\partial C_n}{\partial \beta} > 0$), Vertical tail sizing ($V_v = \frac{l_v S_v}{b S}$), Fuselage destabilizing effect, Rudder control power ($C_{n\delta_r} < 0$), One-Engine-Inoperative (OEI) asymmetric thrust trim.
2. **Lateral Static Stability (D2):** Dihedral effect ($C_{l\beta} \equiv \frac{\partial C_l}{\partial \beta} < 0$), Wing geometric dihedral ($\Gamma$), Wing sweepback ($\Lambda$), Wing high/low vertical position on fuselage, Aileron control power ($C_{l\delta_a} < 0$), Adverse yaw mechanics, Aileron reversal.
3. **Decoupled 6-DOF Equations of Motion (D3):** Body axes system, Euler angles ($\psi, \theta, \phi$), Small disturbance linearization, Decoupling into Longitudinal (3-DOF: $u, w, q$) and Lateral-Directional (3-DOF: $v, p, r$) state spaces.
4. **Longitudinal Dynamic Modes (D4):**
   - **Short Period Mode:** High frequency, heavily damped ($\omega_n \approx 1\text{--}10\text{ rad/s}, \zeta \approx 0.3\text{--}0.8$), rapid pitch angle and $\alpha$ oscillations at constant speed $V$.
   - **Phugoid Mode:** Very low frequency, lightly damped ($\omega_n \approx 0.05\text{--}0.2\text{ rad/s}, \zeta \approx 0.05\text{--}0.1$), slow exchange between kinetic energy (airspeed $V$) and potential energy (altitude $h$) at nearly constant $\alpha$.
5. **Lateral-Directional Dynamic Modes (D5):**
   - **Roll Subsidence:** Pure non-oscillatory heavily damped rolling motion ($T_{1/2} < 0.5\text{ s}$).
   - **Spiral Mode:** Slow non-oscillatory mode (can be slightly divergent if $C_{l\beta} C_{nr} < C_{n\beta} C_{lr}$, easily corrected by pilot).
   - **Dutch Roll:** Coupled yawing and rolling oscillation with sideslip ($\omega_n \approx 1\text{--}3\text{ rad/s}, \zeta \approx 0.1\text{--}0.3$).
